# 为何四论(证明论，模型论，递归论，集合论)明明是数学和计算机科学的基础，计算机科学与技术专业却不教? - rainoftime 的回答

## 阅读前置卡

- 价值判断：高。用具体研究方向、人物和定理区分“涉及逻辑”与“接近逻辑四论”，并保留研究所需知识的限定，具有较强导读价值；但未系统讨论专业课程设置。
- 信息密度判断：高。篇幅短，却集中列举类型系统、语言设计、自动定理证明等联系及其边界，包含多个人物、定理和进一步阅读入口，实质信息密集。
- 是否继续阅读：3 全文。适合阅读全文：各领域联系的具体例子和“不一定需要”“恐怕交集有限”等限定共同构成观点，单看总论容易遗漏差异。

## 核心洞察

一、涉及逻辑不等于接近四论：理论计算机科学、编程语言、形式化方法、数据库及人工智能的部分方向虽涉及逻辑，但目前没有哪个计算机科学领域与逻辑四论太接近。相当一大部分相关领域的人，很可能连相关书籍都没翻过，更不用说论文；这里列举的只是程序语言、形式化方法中的一些个例。
[[#^pr-dca767f6c028|正文跳转]]

二、集合论与指称语义有联系：公理集合论与指称语义存在联系，Dana Scott 是其中的例子，他对集合论和模型论均有贡献。
[[#^pr-c01e8f72cc67|正文跳转]]

三、研究类型未必需要结构证明论：结构证明论和类型系统确实有深刻联系，例如自然演绎风格的证明系统、子结构逻辑与子结构类型的对应；Dale Miller 也是一直从事证明论研究的例子。但研究类型不一定要懂结构证明论，尤其是一些偏 type system 而非 type theory 的研究。至于证明论中的反推数学，与这里讨论的方向联系应该很少？
[[#^pr-c01e8f72cc67|正文跳转]]

四、递归论与程序语言的具体联系：Neil Jones 年轻时研究过递归论的 Spectrum Problem，并有相当贡献；他还建立了一些递归论与程序语言的联系，例如 Kleene 的 S-m-n 定理与部分求值、Kleene 的二阶递归与反射。也许有人觉得计算理论应该与递归论联系紧密，但那应该是几十年前的事了，现在两者恐怕交集有限。
[[#^pr-c01e8f72cc67|正文跳转]]

五、模型论的应用及深度限定：模型论与很多自动定理证明、约束求解研究联系较多，例如一阶逻辑的插值定理、实闭域的量词消去；Peter Andrew 在 JSL 92 提出 uniform interpolation 也是相关例子。不过，这些应用似乎不用上太多深或新的东西；有限模型论比较特殊，在计算机领域用得更多一些。
[[#^pr-c01e8f72cc67|正文跳转]]

六、LICS兼有计算机与纯逻辑论文：推荐 LICS（Logic in Computer Science）会议：除了计算机科学各方向，也有一些偏数学、哲学等背景的老师发表比较偏纯逻辑的论文。
