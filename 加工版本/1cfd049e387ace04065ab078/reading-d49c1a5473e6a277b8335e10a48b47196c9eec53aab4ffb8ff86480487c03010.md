种种迹象都表明我不太属于 “我在南大做普通人” 这档专栏：学生时代有过学分绩第一拿过国奖、带南大第一次进 ACM-ICPC World Finals；读 PhD 的时候发了南大第一篇第一单位的 ICSE (再次拿了国奖)，整天不务正业瞎腾还拿到 CCF 优秀博士论文……

^pr-210f48d9f0f1

然而，我现在面对的是对未知的虚无和恐惧：**在 AI 的车轮下，没有一匹马不是普通的**。这也是我多次做出 “违背祖宗决定” 的原因：我先是把内核从《操作系统》里砍掉了，这样留出了课时可以给同学们更深入地展示操作系统的接口、讲解比如 Git 这种系统程序的实现原理，再到现在决定冒着课程还没结内容就过时的风险开了《生成式软件工程》。

^pr-279ca9f8e199

作为坚定的降临派，我看到一种 test-time scaling 毁天灭地的恐怖景象。这个感觉在 2016 年开始萌芽，那时候我还在过美东时区，在 University Village 的小房间里熬夜看 AlphaGo 的直播。就在那时候，我感觉到 problem solving，也就是人类智力的最高峰，无非也就是个搜索过程：

^pr-3f9b00ee4130

我们可以掏出一本字典，把一定长度以内的句子组合全部找出来，拿每个看起来 “还算有趣” 的句子去做实验——这就构成了一个搜索树。无论是你想要一个更好的操作系统，一个自我改进的语言模型，还是想回到 Galois 的时代发明群论——那时候根的轮换对称性已经被反复应用，缺少的是一个最精妙的启发，剩下的是无需天才级智慧的数学推导：

> **对于一个方程，把所有 “不会破坏根之间已知代数关系” 的根的置换收集起来；如果连续做两个这样的置换，会得到什么结构？**

答案其实都在搜索空间中，无非是那个 “品味够好” 使搜索能在负担得起的代价下完成的神经网络什么时候到来。

^pr-85ebba23a620

然后就是大家熟悉的故事了：模型先是学会了说话，学会了用工具写代码，学会了数学 (在思维链里组织搜索)；从 IMO/IOI 满分，破解了千禧年难题，再到就这几天发生的数学/理论计算机科学地震 (看到 3SUM, UGC, FFT, ... 的最新结果以后，震惊瘫坐，仿佛看到原子弹爆炸)。人类学习的路径不太一样，是先理解世界才学会说话，再是数学、品味……有点殊途同归的味道了。

^pr-7601ece310d4

驱动这个世界的，一直都是各式各样的 scaling law，通过投入更多资源换来更大优势。于是寻找资源 + scale up 就成了世界上广泛存在的基础机制——从星系这种 “随机数种子” 到基因，从蛋白质到神经元，从语言到工具，再到学术圈、产业循环，它们的成功也都建立在能够良好 scale up 的机制上，无一不是某种形式的 “算力换能力”。我们每个普通的个体在演化洪流中的的价值，恰恰就在于 “成长” 给我们带来的偏见，这样的多样性成就了沟通的意义——每个人都是一个搜索的分支。

2022 年做的报告，当时和不少人讨论过这个想法，大家都觉得我太疯癫，现在可能不这么想了

于是忽然就在一夜之间，我们的大学似乎赶不上世界进步的速度了。本科生们十多年的寒窗苦读，毕业即被 $20 的 Claude Pro 订阅斩杀；研究生们焦虑地做着无意义的微创新，就为了一篇论文可以毕业，但 peer review 的体系已然开始崩溃；学阀为了攫取资源不择手段，早就把学校对人类的贡献抛诸脑后。我们做出的努力，似乎在更大的框架下无处安置：如果任何人的任何努力、任何能力都将不再具有稀缺性，也无法再换来期待的收入和地位，我们千年以来形成的培养/筛选的社会根基就发生了动摇。如果我们只要把人类知识拆开重组，一个贴吧就足够 Agent 推动世界的运转和进步，系统的成长不再依赖人的成长，这个世界会变成什么样？

^pr-246d312793eb

我不知道——我看不清我们还有多少时间，还剩多少意义。曾经我觉得能 “让别人受到启发，从而对世界产生积极的影响” 是件很有价值的事 (利他就是终极的利己)，但也预见，自己的价值将在 AI 面前泯然众人。前段时间我发了个帖子说 “要在人生巅峰退休了”。但退休之前，还想趁自己在 (自认为) 认知还没有崩溃的时候再挣扎一下，在 AI 暂时还太不擅长的领域做两件小事，如果这也做不过 AI，那可能就真的只能每天钓鱼了。

第一件事比较小，不确定性很大 (或者说我没能完全理解)，但很有趣：我们想做一个能生产艺术品的 Agent Harness——现在的 AI 也许能生成一个让你 99% 满意的作品，但为了纠正剩下的 1%，也许需要 1,000 次愤怒的痛骂，甚至模型的偏执可能让你永远到不了你想要的那个终点。但其实 (至少是一定框架之内的) 艺术设计是有迹可循的，而我们希望的，是把能用数学和代码精确表达的东西精确表达，再让模型发挥剩下的部分。模型可以变得更强，但如果你看过设计师如何操作 Photoshop，就会知道仅凭 “聊天” 是很难和人心中的图景 “心有灵犀” 的。这个 project 这来自一位我的在读学生，他写得一手好字，对美感有自己的理解——我们有个起步阶段的 startup (甚至没有融资)，有些客户可以试试水拿点反馈，现在就打磨打磨技术，在合适的时候再走向更大的世界。
