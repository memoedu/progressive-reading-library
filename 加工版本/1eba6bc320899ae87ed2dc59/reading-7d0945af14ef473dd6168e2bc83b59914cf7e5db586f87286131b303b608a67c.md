## 0\. 深度学习的本质

我先给一个不那么严肃、但很有解释力的定义，然后我们再慢慢拆解开：**深度学习像是一层伪装成矩阵乘法的动力系统**。GPU 是仿真器，`optimizer.step()` 像时间积分，`.backward()` 是求力的高效算法。

^pr-9387d4c6d9df

## 1\. 反向传播：高效的力场求解器

先做一个小实验，省去繁琐的数值对比。假设你有一个玩具神经网络，参数数量为 N。你想知道“如何调整参数才能让损失下降”，传统上我们有以下几种方式：

-   **随机搜索**：在高维空间里瞎蒙，完全找不到方向。
-   **有限差分**：对每个参数逐个扰动，每次迭代需要 O(N) 次前向传播来估计梯度。当 N 很大时（现实中动辄数十亿），这等价于每次迭代做数十亿次前向传播，完全不可行。
-   **反向传播**：通过链式法则，一次前向 + 一次反向即可算出所有 N 个参数的梯度，计算量通常只是前向的常数倍。

反向传播的伟大之处在于把“求方向”这件事从 N 次前向降到常数次前后向。如果一次前向成本近似随参数量 N 线性增长，有限差分的总成本才会表现成 O(N^2)；反向传播避免了这件事。方向本身——沿着梯度下降——牛顿和拉格朗日早就写下来了。

^pr-edc8a98cc15d

**但更有趣的观察在这里：** 如果把权重当成一个有质量粒子在 d 维空间中的位置，把损失函数 L(\theta) 当成势场 V(\theta)，那么 **SGD-with-momentum** 和“粒子在势场中受粘性阻尼运动”的离散化形式高度同构。虽然它不是严格意义上的同一个物理系统，但他们的公式一模一样。

^pr-c91a7f77db8a

所以，GPU 里跑的那几十亿浮点数，不只是抽象的“计算机符号”，也可以被看成一个高维动力系统的状态——粒子在损失势场里滚动，同时被噪声扰动、被摩擦拖拽、被弹簧约束。所谓“训练神经网络”，可以理解成在数字硬件上跑一场离散动力系统演化，让系统进入低损失区域。`.backward()` 是这场演化里最关键的“数字原生”部分——一个高效的力场求解器。

## 2\. 优化器 vs 运动方程

先把公式两两摆出来。

**SGD（Robbins–Monro 1951）：**

\\theta\_{t+1} = \\theta\_t - \\eta \\nabla L(\\theta\_t)

**Polyak 1964 年提出的 heavy ball method：**

v\_{t+1} = \\gamma v\_t - \\eta \\nabla L(\\theta\_t)

\\theta\_{t+1} = \\theta\_t + v\_{t+1}

**牛顿粘性阻尼运动（牛顿 1687 + 斯托克斯 1850）：**

m \\ddot{x} = -\\nabla V(x) - \\mu \\dot{x}

用显式 Euler 形式离散化，记速度变量仍为 v，有：

v\_{t+1} = \\left(1 - \\frac{\\mu \\Delta t}{m}\\right) v\_t - \\frac{\\Delta t}{m}\\nabla V(x\_t)

x\_{t+1} = x\_t + \\Delta t\\, v\_{t+1}

如果把 \Delta t v 吸收到优化器里的 momentum buffer，或者把上式中的速度变量重参数化，就得到 heavy ball 的常见写法。它们不是“一字不差的同一个方程”，但在变量重参数化后形式同构。字母对照表：

| 物理 | ML | 意义 |
| --- | --- | --- |
| x | \\theta | 位置 / 参数 |
| \\Delta t\\,v 或重参数化速度 | 动量 buffer | 离散位移 / 速度变量 |
| \-\\nabla V | \-\\nabla L | 力 |
| 1 - \\mu\\Delta t/m | \\gamma（常取 0.9） | 阻尼后的速度保留系数 |
| \\Delta t / m | \\eta（学习率） | 步长（质量吸收进 lr） |

换个说法：你写 `optim.SGD(model.parameters(), lr=0.01, momentum=0.9)` 的那一刻，**可以近似理解成在告诉 GPU：请给我模拟一个在 loss 势场里滚动的粘性小球，离散步长由 lr 控制，上一时刻位移保留 90%**。这是一个有数学对应关系的数值动力学类比，而不只是文学比喻。

**Adam 可以粗略理解成把步长缩放做成自适应的。** 按物理学家的直觉排一下：

```
force        = -grad                             # F = -∇V
velocity     = β1 * velocity + (1 - β1) * force  # 速度累积（动量）
roughness    = β2 * roughness + (1 - β2) * force**2  # 梯度的二阶矩，衡量"路况颠簸程度"
friction     = sqrt(roughness) + ε               # 越颠簸 → 摩擦越大
θ           += lr * velocity / friction          # 时间积分一步
```

Adam 的自适应学习率，本质上是**在越颠簸的地方走越小的步**——就像开车过烂路会本能地减速。这里 \sqrt{v_t} 并非严格的物理表面粗糙度，而是对力的大小做 running estimate，再用来缩放步长；但从直觉层面理解成“路况”完全够用。\epsilon 是防止除零的最小值。

^pr-5dca263f134f

**Weight decay 是弹簧。** L' = L + \lambda \|\theta\|^2 / 2 的效果就是给每个参数加了个 -\lambda \theta 的中心回复力，把权重往原点拉。物理上就是简谐振子——胡克 1678 年就写下了 F = -kx。AdamW 之所以比 Adam + L2 正则效果好，是因为在 Adam 的自适应缩放里，L2 正则的力被 \sqrt{v_t} 除掉之后就不再是“纯粹的中心力”了；AdamW 把 weight decay 单独拎出来，让它保持“弹簧”的物理身份。

^pr-385ae54e6cc8

**LR schedule 也可以借用热力学直觉来理解。**

-   **Warmup**：从静止平稳加速。冷启动的车不能直接踩到底。
-   **Cosine anneal**：按谐波规律降温。训练后期 loss surface 越来越平坦，继续大步长只会引入噪声。
-   **Cosine restarts（SGDR）**：带一点模拟退火味道。周期性升温，让系统有机会跳出局部势阱。

^pr-23b270815af6

回头看，PyTorch 里 `optim` 这个包，可以被看成一个**离散动力学工具箱**。它跟 SciPy 的 ODE 求解器当然不是同一类软件，但在“给定状态、计算力、推进一步”这件事上，它们共享同一种数学直觉。

## 3\. Attention：Modern Hopfield 视角下的一步更新

先忘掉矩阵乘法，想象一个场景。

你的大脑里存了三个记忆：“猫”、“狗”、“汽车”。现在有人问你一个模糊的问题：“长得像猫但体型很大的动物”。

这个问题的表示（Query）处在一个三维空间里——离“猫”最近，离“狗”稍远，离“汽车”很远。

在 Hopfield 网络的物理图景里，这三个记忆就是三个深不见底的山谷（盆地）。山谷越深，代表这个记忆越稳定、越“确定”。整个地形叫作“能量景观”——能量越低，系统越稳定。你的 Query 就像一颗放在山坡上的钢珠，位置落在“猫”和“狗”之间。

“能量下降” 就是：这颗钢珠受重力影响，顺着山坡往下滚动一小步。它不再停在原来的模糊位置了——它滚向了“猫”的山谷，离“狗”和“汽车”更远了。这一步走完后，钢珠的位置变得更像“猫”了。

这里最容易搞混的，是和优化器（SGD）做对比：

-   SGD 的下降（训练过程）：钢珠在整个地形上走成千上万步，通常只能保证找到低损失区域或可用的局部盆地，而不是全局最低点。走一步只前进一小截。
-   Modern Hopfield 的更新（Attention 前向的一种解释）：钢珠只走一步，但这一步由 softmax 给出解析形式的加权组合。它足以把模糊的 Query 拉近到最匹配的记忆附近，但又没有彻底跌入某个单一谷底（否则输出就变成纯“猫”，失去了上下文信息）。

为什么“一步”就够有用？ 因为这一步并不是随机的“滚一下”，而是通过 softmax 求出了“在这个 Query 下，所有记忆的加权平均位置”。它跳过了“慢慢往下滚”的过程，直接给出一个解析形式的更新点——然后下一层在这个新位置上再来一步。深度网络的每一层，都像是让这颗钢珠在新的能量地形上迭代一步。

所以更准确地说：**在 Modern Hopfield 的形式下，attention 可以解释为一次 Hopfield 更新。**

^pr-4afbb33c3f97

\\text{Attention}(Q, K, V) = \\text{softmax}\\left(\\frac{QK^\\top}{\\sqrt{d\_k}}\\right) V

Attention 和统计物理的关系远不止“softmax 长得像玻尔兹曼分布”这么浅——**现代 Hopfield 网络给出了一个把 attention 解释成一次能量更新的严格视角**（Ramsauer et al., ICLR 2021）。

Hopfield 网络是 1982 年 Hopfield 直接从统计物理搬到神经网络里的模型，本质是自旋玻璃动力学；Hinton 1985 年把它推广到 Boltzmann Machine。2021 年的“现代”Hopfield 网络的关键贡献在于，把存储模式 X 从二进制向量推广到了连续嵌入空间，并证明了 Transformer 的 attention 是它的一个特例。

现代 Hopfield 网络的能量函数是：

E(\\xi) = -\\frac{1}{\\beta}\\log\\sum\_{i=1}^N \\exp(\\beta\\, x\_i^\\top \\xi) + \\frac{1}{2}\\xi^\\top\\xi + C

对它做一步 CCCP（concave–convex procedure）迭代，得到的更新规则是：

\\xi\_{\\text{new}} = X\\,\\text{softmax}(\\beta\\, X^\\top \\xi)

**这一步和最简形式的 attention公式也是一模一样。** 对应关系：\xi \leftrightarrow q、X \leftrightarrow K = V、\beta \leftrightarrow 1/\sqrt{d_k}。标准 Transformer 里通常 K \ne V：权重由 query-key 相似度决定，输出却是 value 的加权和。因此它不是“query 在 key 空间里做普通梯度下降”，而是在 Modern Hopfield 框架下可以写成一次模式检索 / 更新。

也就是说：

-   在 Modern Hopfield 形式下，可以写出一个**真实存在的能量函数** E(\xi)。
-   前向一次 attention 可以解释为一次 Hopfield 更新 / 模式检索。
-   如果另外引入 Langevin 动力学，形如 p(\xi)\propto e^{-\beta E(\xi)} 的玻尔兹曼稳态分布会自然出现；但这不是标准 Transformer 前向本身在采样稳态分布。
-   相似度项 q^\top k 可以被理解成一种成对相互作用强度，和 Ising / Hopfield 里的成对相互作用能有相近的数学形状。

对应关系：

| Attention | Hopfield / 统计力学 |
| --- | --- |
| q^\\top k\_i（单个 logit） | 一对之间的相互作用能 |
| q^\\top X（logits 向量） | 该 \\xi 相对所有存储模式的能量向量 |
| \\sqrt{d\_k} | 1/\\beta（温度） |
| 分母 \\sum \\exp | 配分函数 Z |

Hopfield 1982 → Boltzmann Machine 1985 → Modern Hopfield 2021 这条 40 年的线，在这里闭环。

## 4\. Normalization：无量纲化 + 恒稳

物理学家有个习惯：任何方程一到手先无量纲化。Navier–Stokes 方程写成无量纲形式后，雷诺数 Re 会把惯性力和黏性力的相对大小显式暴露出来，于是低速水流和高速气流可以放在同一套相似性框架里比较。无量纲化能改善尺度分析和数值条件，但不保证数值稳定；高 Reynolds 数问题反而常常更难算。

LayerNorm 干的就是这件事：

^pr-27cccfcf0f75

\\text{LayerNorm}(x) = \\gamma \\cdot \\frac{x - \\mu}{\\sqrt{\\sigma^2 + \\epsilon}} + \\beta

翻译：

-   (x - \mu)/\sigma：无量纲化。把每层输出重新压到零均值单位方差，后面的层就不用去追前一层的量纲漂移。
-   \gamma, \beta：允许网络学出量纲。有些层就是需要更大的动态范围，一刀切会伤模型——\gamma, \beta 是可学习的“设定点”。
-   \epsilon：防止除零的最小值。

**生理学的类比也现成。** 人体的血糖、体温、pH 被稳态系统压在很窄的区间里，不管你早饭吃了什么。LayerNorm 就是层间的稳态器——上游无论输出什么样的激活分布，它都能把交给下游的分布压回一个稳定范围。

**RMSNorm 更激进：**

\\text{RMSNorm}(x) = \\gamma \\cdot \\frac{x}{\\sqrt{\\text{mean}(x^2) + \\epsilon}}

省掉了减均值那一步。物理上就是“只做重整化，不平移原点”。事实证明大多数场景下 zero-centering 对性能贡献很小，但计算量能省一截。LLaMA 系列全用 RMSNorm。

**BatchNorm 是个例外。** 它在 batch 维度上归一化，更像是“一组测量仪器互相校准”——温度计们通过参照彼此矫正个体偏差。它在小 batch 下崩掉、在 Transformer 里几乎见不到，深层原因是：LayerNorm 在特征维度上做归一化，天然尊重”位置之间可交换”的对称性（每个位置独立归一化）；而 BatchNorm 需要跨样本做统计，序列长度维度长、batch 维度短的场景下，”校准样本”不够。

^pr-3359fb22de97

## 5\. 残差：显式 Euler 步

**残差连接是显式 Euler 步：**

^pr-f605ce4f39b6

x\_{t+1} = x\_t + f(x\_t)

这和常微分方程 \dot{x} = f(x) 的一阶数值积分（Euler 法）有同样的形式。Neural ODE（Chen et al. 2018）把这个观察写严谨了：在连续深度极限下，残差网络可以对应到一个 ODE，层数增加可以理解成时间离散更细。

**这不只是一个比喻。** Neural ODE 论文正是用这个观察，把残差网络重写成了一个连续的常微分方程，并展示了可以用 ODE 求解器（而非固定离散层）来训练网络。这意味着一个 ResNet-152 的前向传播，可以被看成沿着某个离散动力系统演化 152 步。ResNet 能训得很深，更直接的工程原因是 identity path 改善了优化和梯度传播；Neural ODE 提供的是连续深度视角，而不是说 ResNet 自动满足了数值稳定条件。

## 6\. Softmax：最大熵视角下的玻尔兹曼分布

这一步 Jaynes 1957 年就已经写清楚了，只是几乎没人在深度学习课上提。

**Jaynes 最大熵原理：** 在只知道某些期望约束的情况下，应该选择“信息量最少”（即熵最大）的分布。理由是不这么选，就相当于**凭空加入了你并不掌握的信息**。

^pr-d50010c40801

对离散分布 p_1, \dots, p_N，如果只给两个约束：

-   \sum_i p_i = 1（归一化）
-   \sum_i p_i E_i = \bar{E}（平均能量已知）

在固定 support、使用 Shannon entropy、并且只给定这类平均能量约束时，拉格朗日乘子法一算，最大熵分布**唯一地**是：

p\_i = \\frac{e^{-\\beta E\_i}}{Z}, \\quad Z = \\sum\_j e^{-\\beta E\_j}

这就是玻尔兹曼分布。把 logit 看成负能量（或把符号吸收到 \beta 里），它就是 softmax。

**换句话说，softmax 不是“拍脑袋选的一个平滑 argmax”**。在 Shannon entropy、固定支持集和给定期望能量约束这组条件下，它是信息量最少、额外假设最少的分布。其他归一化方式（sparsemax、entmax 等）对应不同的熵函数或几何偏好，隐含地偏好稀疏或有硬截断的分布。它们不是“错”，而是在表达不同先验。

温度 \tau 就是拉格朗日乘子 \beta 的倒数。温度低 → 你对能量约束“更认真”→ 分布向低能量集中；温度高 → 约束“松弛”→ 分布向均匀退化。

^pr-d7f2c37362da

## 7\. 来自玻尔兹曼原理

19 世纪那次谜团的解开可能更清楚。玻尔兹曼之前，人们已经知道热力学第二定律成立、Carnot 循环有效、气体状态方程 PV = nRT 好用——**每一条都很好用，但没人知道为什么**。玻尔兹曼给出了微观解释：熵就是 \log \Omega，状态数越多、宏观越“混乱”；所有热力学定律都是这个原理在不同边界条件下的表现。

深度学习现在的处境大概类似：

-   我们知道**注意力有效**（Modern Hopfield 给出了一种能量更新解释）。
-   我们知道**残差有效**（网络可以被看成离散动力系统，Neural ODE 给出了连续极限）。
-   我们知道**梯度下降有效**（它和阻尼运动方程的离散形式高度同构）。
-   我们知道 **scaling law 有效**（loss vs. compute 的幂律关系在训练算力跨越六七个数量级的范围内都成立）。

**但没有一个“深度学习版的玻尔兹曼”给出微观解释**——**为什么把这些东西堆在一起，恰好会得到一个能理解语言的系统**。

^pr-bec1d55db66b

我们不确定，是否真正的答案藏在“高维空间 + 双线性能量 + 最大熵采样”的组合几何里。可能存在某个原理性陈述，

我猜测也许：

> 给定一个足够高维的表示空间 \mathbb{R}^d，如果动力学（优化器）是含噪的耗散过程，能量（相似度）主要由双线性结构表达，采样（softmax）带有最大熵色彩，那么在自然数据分布的某种约束下，系统也许会**自发地**演化出一组能够表达数据集内部语义/组合结构的表示。

^pr-def2cfb25161

这只是一个直觉方向，不是一个主张。但它跟玻尔兹曼当年做的事情形状很像：把宏观上“看起来神奇”的现象（热平衡、熵增），归约到微观的组合计数上。今天的深度学习需要的可能就是这么一次归约。

不过看着 SGD 从山坡上滚下来、attention 在 Modern Hopfield 视角下做一次模式检索，总有一种说不清的既视感——像是有个我们还没写下来的方程，已经默默在起作用了。

也可能它已经在某篇论文里了，只是没人认出来。
