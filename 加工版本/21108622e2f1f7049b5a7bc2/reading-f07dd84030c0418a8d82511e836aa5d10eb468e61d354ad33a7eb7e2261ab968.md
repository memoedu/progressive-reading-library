# 人最核心的能力是什么？

---

## 正文

**主观能动性、交付力、领导力。**展开分析之前，我想先讲一下Elon Musk 特斯拉 Model3 车库工厂 和 xAI Colossal Data Center 两个令人称奇的事迹。

1.  **特斯拉 Model3 车库工厂的交付奇迹**

> 2017 到 2018 年，Tesla 在 Model 3 量产上给市场画了一个很大的饼：要把 Model 3 拉到每周 5,000 辆的生产节奏。这个目标本来更早就该实现，但 Model 3 的量产爬坡一直卡住。Musk 原本押注高度自动化生产线，后来发现“机器造机器”的复杂度被严重低估，电池模组、供应链、总装流程、人工返工都成了瓶颈。到 2018 年第二季度末，Tesla 已经非常接近自己承诺的最后期限，如果再达不到每周 5,000 辆，市场对 Model 3 量产能力的信心会继续受损。于是 Musk 没有走传统车厂那种慢慢扩建正式厂房、慢慢调试产线的路线，而是在 Fremont 工厂的停车场里搭了一个巨大的帐篷式结构，快速装进一条新的 Model 3 总装线 GA4。这个东西听起来很土，但本质上是用极端压缩的工程周期，临时补出一段关键产能。最后一周，Tesla 报告生产了 5,031 辆 Model 3，刚好压线达成每周 5,000 辆的目标；其中这条帐篷里的 GA4 线贡献了约 20% 的 Model 3 产量。也就是说，这个故事的重点并不是“车库改厂房然后完成交付” -- Tesla 在量产危机里，用一个非常规、很 Musk 式的临时总装线，硬是把 Model 3 的生产节奏推过了那个关键门槛。

**2\. xAI Colossal 的122 天建造奇迹**

> 2024 年，Elon Musk 创办 xAI 要在 AI 竞赛里追上 OpenAI 和 Google，最大瓶颈不是模型算法，而是硬件、算力、电力共赢。正常建一个这种 100,000 张 Nvidia H100 图形处理器级别的超级训练集群，通常要要 24 个月起步。
> Musk 没有按传统流程慢慢选址、建楼、拉电，而在田纳西州 Memphis 找到一座废弃的 Electrolux 工厂，直接把现成工业厂房改造成 Colossus 超算中心。这个项目最挑战的地方并在几万个服务器节点的接线布阵 -- 田纳西老旧的电力供应系统完全跟不上耗电猛兽的供电需求。
> 于是他们一边和当地公用事业公司推进正式供电，一边把天然气涡轮发电机、Tesla Megapack 电池、临时电力系统和变电站并行堆上去，用现场发电把进度顶住。据当地报道，xAI 后来甚至在 97 天内设计并建成一个 150 megawatt 级别的变电站。
> 为了快，xAI 没有完全等传统空气许可和长期电网接入流程跑完（等跑完一年都过去了），而是把发电机包装成临时、便携式设备，利用当地“不到 364 天不按固定设施处理”的监管灰区先跑起来。环保组织指控他们最多用了 35 台未获空气许可的燃气涡轮机；xAI 则说这些临时发电设备符合法律。
> 后来美国环境保护署明确收紧口径，认为这类燃气涡轮即使是临时或便携，也不能绕开空气质量许可。Musk 把厂房、图形处理器、液冷、网络、电力、变电站、燃气涡轮和地方协同全部压成并行工程，用极端资源调度把一个本来按年计算的基础设施项目，硬是把工期压到了短短几个月。

**主观能动性决定你敢不敢重新定义问题去构思解决方案，交付力决定你能不能把重新定义后的问题做成实物落地坐实，领导力决定你能不能让整个复杂系统跟着你一起动。**

**主观能动性强调的是在非常奇怪的限制下，不拘一格地、无羁无束、生猛狂野 却 精细巧妙地 解决任意一个奇怪的、前人没有解决过的问题的能力。**别想着有固定答案，别想着走“常规路线”，别想着经验主义 -- 当你面对的是一个极其长尾、极其犄角旮旯、极其小阴沟、极其超越约定俗成和常识、极其前沿和尖端、极其接近最下层的创新和试错的时候，常规解通用解基本都很难适用。具体情况具体分析，特殊情况特殊处理才是日常。

**交付力强调的是总是拿出成果，按时保质保量地交付 客观的、实在的、有工具和实用价值的交付物（deliverables）。**交付力的反面就是天天空谈方法论、设计方案、框架、解释框架、管理哲学、理论、愿景、战略路线、组织架构，而给不出真正的产品和能落地的系统。个人所见，交付力是执行力的高级形态和超集，多出来的是对广义工程哲学（即使要交付的成果是一个抽象指标也适用，因为抽象指标被解构到最小全是实实在在的产品和物）以及广义控制论的精通。

**领导力强调的是能够把价值观、专业背景、秉性性格、利益导向、各不相同的人整合凝聚在一起，使得他们能向着一个共同的目标去推进。**会协调（orchestrate），会统筹，会调度，会平衡，会控场，会做局，而不是被局做还不自知。

此三者，相互紧密咬合，而彼此本质不同。见过太多一个维度长板而其他两个维度瘸腿的人了。三者同时都具备的一定是“百年难得一遇的奇才”（滑稽）。不妨真的去翻开百科，去看看历史上做成果超大规模的伟人（毛爷爷，马斯克，洛克菲勒，etc），无疑都把这三种能力拉到了机制。
