## 核心洞察

一、低耦合工具联动原则：将Obsidian和Zotero解耦，让Zotero全权负责PDF下载、管理和标注，Obsidian专注Markdown笔记编辑和论文综述，两者仅通过链接相互跳转，实现最小程度联动。这一原则源自UNIX哲学'做好自己擅长的事情'，可避免功能重叠和复杂度提升。

二、本地存储与云端备份：Obsidian和Zotero都将数据保存在本地，因此可以通过坚果云等云服务进行备份，解决本地文件丢失问题。这是该工具链相比在线工具的重要优势，用户可自主控制数据安全。

三、标签管理优于文件夹嵌套：作者对比了文件夹层层嵌套与标签管理，指出标签管理更扁平化，优势包括：一篇文献可属于多个领域而无需复制文件、便于在关系图谱和DataView中使用、支持嵌套标签和一键改名。这解决了多领域文献归类难题。

## 正文

你还在为下载的 PDF 满天飞、笔记与论文割裂、本地文件总是丢失而烦恼吗？不妨试试 Obsidian+Zotero 的组合来管理文献、阅读文献、标注文献。

Obsidian 是 Markdown 笔记管理工具，Zotero 作为强大的文献管理工具，它们都有着大量活跃开发者提供各式插件，高度灵活，开源免费，是各自领域的集大成者。**而且它们都将数据保存在本地，这意味着可以用坚果云进行云端备份**。

^pr-838b11ef10df

我目前采用的科研工作流：

1.  Zotero Connector 插件从浏览器端下载论文 PDF 到 Zotero；
2.  Zotero 阅读并批注 PDF（最新版本 Zotero 自带 PDF 阅读器，十分方便）；
3.  用 Mdnotes 插件自动生成 Markdown 笔记；
4.  在 Obsidian 编辑 Markdown 笔记；

我会尽可能解耦两个工具，Zotero 全权负责 PDF 下载、PDF 管理、PDF 标注，Obsidian 将做 Markdown 笔记编辑以及论文综述。做最小程度的联动，只需两者能够通过链接相互跳转。

Obsidian 堪称 Markdown 的 IDE，双向链接、标签管理是它的亮点，尤其适合把零散的论文笔记组织起来。

### 标签管理

在使用这套工具流之前，我一直是采用文件夹层层嵌套管理文件。直到我遇到了标签管理，标签管理更扁平化，打标签的好处多多：

-   一篇文献同属于两个领域，采用文件夹管理需要复制一份文献，维护文献的同步太麻烦
-   标签适用于 Obsidian 的关系图谱、以及后文将提到的 DataView 插件
-   Obsidian 也支持嵌套标签，一键修改标签名

### 第三方插件

Obsidian 需要第三方插件才能发挥它的全部威力。

-   DataView：无敌好用的数据处理与展示工具，用表格罗列论文重要信息
-   Tag Wrangler：拓展标签管理功能
-   Admonition：美化引用块
-   Advanced Tables：格式化表格，提供基础的表格操作
-   Excalidraw：完美适配 Obsidian 的画图工具
-   Image auto upload Plugin：自动上传图床

* * *

下面重点介绍 DataView 插件，我一般会把所有**论文笔记 Markdown**放在同一个文件夹 notes 下，把某个领域的**综述型笔记 Markdown**放在文件夹 reviews 下。

在每篇论文笔记 Markdown 的开头写入这篇论文的元数据（也可以用 Zotero 插件 Mdnotes 自动生成）。举个例子：

```
***
#### Metadata
- 作者::xxx
- 作者机构::xxx
- 日期::xx
- 出处::xxx
- 标签::#od/anchor_free
- 备注::xxx
- pdf::xxx
***
```

其中::是DataView支持的语法，表示一个键值对。

在综述型笔记markdown中写入：

````
```dataview
table 日期,出处,作者机构,备注,pdf
from #od/anchor_free
sort 日期 asc
```
````

![](https://pic2.zhimg.com/v2-8ed64153e3842463d5078e7bb711ac4d_1440w.jpg)

就会以表格的形式展示所有带 `#od/anchor_free` 标签的文件，以及它的元数据。对于总结归纳某个领域中的论文是非常实用的。

^pr-2841af258248

DataView 还支持很多操作，可以详见官方文档。

## Zotero

Zotero 文献管理工具其实就是维护了一个数据库，数据库中的一条条目包括：文献的元数据（时间、会议/期刊、作者等），附件文件地址（PDF、Markdown 笔记），标签等。

Zotero 提供了非常多的文献导入途径，Zotero Connector 浏览器插件下载，查询 DOI 号下载，导入本地 PDF（自动识别 PDF 中的各种元数据，填充条目信息）。

Zotero 同样支持文件夹管理或者标签管理，可以打上 emoji 标签来区分已读/待读。

![](https://pica.zhimg.com/v2-cd969ad84c466be865f5779b8565a38e_1440w.jpg)

最新版本的 Zotero 自带 PDF 阅读器，双击某条目即可打开 PDF 附件，支持高亮、批注等操作。

![](https://pica.zhimg.com/v2-d309e79244ee4ff398158f0e92a3c94c_1440w.jpg)

### Mdnotes插件

Mdnotes 插件是 Obsidian 和 Zotero 联动的关键，它负责为文献自动生成 Markdown 笔记。

安装 Mdnotes 后，右键条目，选择创建完整的导出笔记就会自动生成 Markdown 笔记，可以在条目下找到该 Markdown。

点击 .md 文件即可打开 Markdown，当然需要设置此台电脑的 Markdown 默认打开方式为 Obsidian。

![](https://pic4.zhimg.com/v2-d78d53e15747b51e5e7f2c7797717295_1440w.jpg)

Mdnotes 最重要的功能是根据模板来生成笔记，我们需要先指定 Mdnotes 的模板，打开工具(T)/Mdnotes 首选项，弹出对话框，设置模板目录文件夹。在模板目录文件夹下新建 Mdnotes Default Template.md。

> 注意文件名不能随意修改，必须是Mdnotes Default Template.md

![](https://pic2.zhimg.com/v2-598459dca67419086f2953d70a396f4f_1440w.jpg)

在Mdnotes Default Template.md内写入模板，举个例子：

```
***
#### Metadata
- 作者::{{author}}
- 作者机构::
- 日期::{{date}}
- 出处::{{publicationTitle}}
- 标签:: {{tags}}
- 备注::
- pdf::{{pdfAttachments}}
- zotero::{{localLibrary}}
***

## Abstract

{{abstractNote}}

## Inroduction

## Experimental

## Results and discussions

## Conclusions
```

其中{{}} 表示占位符，\*\*\*之间的就是文献的元数据，这些元数据可以由DataView插件用表格展示。Mdnotes会为每篇文献自动填入正确的元数据。

^pr-32b9fcaf3434

生成的markdown笔记打开后：

![](https://pic2.zhimg.com/v2-9c1c7784e570b8aa224ed3e9ab6fcfeb_1440w.jpg)

点击 pdf 链接/Local library 链接就可以跳回 Zotero 中的 PDF/条目。

还可以自定义占位符，打开编辑(E)/首选项(N)/高级/编辑器，弹出对话框后，搜索mdnotes.placeholder.，修改占位符的value值，也可以新增占位符。具体规则见Mdnotes官方文档。

![](https://pic4.zhimg.com/v2-e0fc62273855b03e85862e25b752ce29_1440w.jpg)

Mdnotes 甚至能导出 PDF 高亮和标注，但秉着做好一件事情的原则，我不喜欢把 PDF 标注放入 MD 笔记。
