# L 站(LinuxDO) 已经烂完了，后会无期

## 阅读前置卡

- 价值判断：中。文章记录个人在 LinuxDO 发帖被拒、被要求加模板和友链、账号被解禁但失去删帖权限等具体经历，反映社区管理问题，有一定参考价值，但内容较个人化，深度有限。
- 信息密度判断：中。全文以叙述个人经历为主，包含具体事件和细节，但信息密度中等，核心信息集中在发帖受阻、规则变化、权限受限等几点，重复和情绪化表达较多。
- 是否继续阅读：2 概览与关键结论。文章核心是作者对 LinuxDO 社区管理的不满和退站决定，可快速了解事件经过和作者观点，但细节和情绪化内容较多，适合概览关键结论。

## 核心洞察

一、LinuxDO 发帖审核要求加模板和友链：作者在 LinuxDO 分享教程文章时，文章被多次退回。第一次要求添加声明模板，询问网站是否使用其 OAuth；添加后又被要求需在项目主页 README.md 添加友链。作者对此感到困惑，认为分享 GitHub 项目可能要先给项目提 PR 并在 README 中为网站引流才能发文章。

二、作者对社区规则变化的感受：作者一年前加入 LinuxDO 时，社区没有这些奇怪规矩，大家交流信息和知识已成习惯。作为用户，没有义务天天盯着社区规则看是否变化，并指出如果要求用户必须时刻关注规则变化、陪玩规则怪谈，是一种傲慢。
[[#^pr-9992d91dc65a|正文跳转]]

三、退站后失去删帖和发言权限：作者在决定退站后，想删除自己的文章，却发现连删除自己帖子的权限也没有了；在评论区发言也需要被审核。这加剧了作者对社区的不满，认为社区已从熟人酒吧变成养蛊之地。
[[#^pr-da277d710844|正文跳转]]

四、作者对社区氛围的怀念与失望：作者最初经知乎网友介绍认识 LinuxDO，曾觉得社区氛围不错，每篇教程都能很快得到评论，享受这种交流和连接，认为找到了极客交流技术和获取情绪反馈的港湾。在 L 站也认识了很多有趣的朋友，彼此结社交流技术和项目。但如今因审核和权限问题感到失望，决定离开。

## 正文

起因是这样的，和往常一样，我把我的教程文章复制一份，打算发到 LinuxDO 上和佬友们分享。

原文链接如下：[不会自动爬取电商数据？厌倦了手动填写表单？OpenCLI + AI 智能体瞬间实现浏览器自动化！](https://link.zhihu.com/?target=https%3A//kirigaya.cn/blog/article%3Fseq%3D378)

然后文章被多次退回，一开始说要在开头加什么奇怪的申明模板，里面要询问自己的网站是否使用了他们的 oauth。加了之后继续被退回，说什么「需在项目主页 [README.md](https://link.zhihu.com/?target=http%3A//readme.md/) 添加友链」，如下图所示：

^pr-937cb0f9429f

![](https://pica.zhimg.com/v2-0f0c6cc504dd0894fb6c95aac9e03670_1440w.jpg)

我纳闷呀，难不成现在分享个 github 项目都要先给项目提 pr，在 readme 里面为你的网站引流我才能发文章？

![](https://picx.zhimg.com/v2-200e90f605c0dcb9ed027b5faeb58721_1440w.jpg)

怀着纳闷的心情，我写下了这篇文章《L 站现在已经不欢迎分享 GitHub 项目了吗？》，里面的内容基本就是把我上面的困惑说了一遍。

![](https://pic1.zhimg.com/v2-5aaae596ad00547f354540cced3e46f0_1440w.jpg)

然后没过多久，我收到了如下的邮件：

![](https://pic2.zhimg.com/v2-88fb4a664618a244f8789f67c6786ffb_1440w.jpg)

我看到的第一感受是哭笑不得，继而感到解放，毕竟我未来写文章可以不用考虑什么平台会因为我在文章底部放上个人 IP 卡片而被要求整改文章了。

说实话，最初认识 L 站就是知乎网友介绍的，一开始确实是觉得社区氛围不错，我发的每一篇教程都能很快被人评论，嗯，我很享受你们评论我文章的感觉，因为这是一种交流和连接。L 站给了我这种感觉，我当时觉得我找到了属于我们极客们交流技术，获取情绪反馈的一个港湾。

^pr-ae80ca88c4c9

L 站上也认识了很多有趣的朋友，我们彼此结社，交流技术和项目，这是一个社区应该有的样子。

不过如今，我真觉得有点苦笑不得了。我想，这封信也在告诉我，这里不是有可以赊账的老板娘开的熟人酒吧，而是另一个养蛊之地，是时候离开，继续寻我的道了。

* * *

这篇文章发了一段时间后，我突然又收到邮件，说我的账号被解禁，文章批准了。

![](https://pic4.zhimg.com/v2-58cbfc88f28742acdcf7fd2a73ee4453_1440w.jpg)

但是我已经决定退站，想要删文章，一进网站，发现我连删除自己帖子的权限也没有了。

^pr-da277d710844

![](https://pic3.zhimg.com/v2-bcb6d9dea671cd19e03e6ad5f1405d3e_1440w.jpg)

评论区我发言也需要被审核了，蚌埠住了。

![](https://picx.zhimg.com/v2-854411f44bd42efca0a674bb6c867595_1440w.gif)

* * *

评论区有人说，社区规则在那，不看规则是你的问题，给我看笑了，不过我就知道肯定有人会这么说，我来澄清一下：

第一，我是一年前加入的l站，那时候没有这些奇怪的规矩，我们交流信息和知识，已经形成习惯。

^pr-9992d91dc65a

第二，我不住l站，我有自己的工作和生意，我没有义务天天盯着你的社区规则去看是不是已经变化了。

如果你认为作为社区用户，你必须天天去看规则是不是变化了，必须陪你玩规则怪谈，我只能理解为这是一种傲慢了。
