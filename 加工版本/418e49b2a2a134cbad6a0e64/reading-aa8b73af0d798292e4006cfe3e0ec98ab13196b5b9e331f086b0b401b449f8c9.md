# Absence of evidence and confidence intervals

---

## 正文

以下是一些 statistical interpretation anti-patterns：

-   这项 study 没有 found 任何表明 X 有任何 effect 的 significant evidence。因此……

-   （第一种的 Sub-pattern：由于 [conservation of expected evidence](http://lesswrong.com/lw/ii/conservation_of_expected_evidence/)，这是表明 true effect 为 zero 的 evidence。）

-   Study A found 了支持 X 的 significant evidence，但 study B 没有。因此，它们 disagree，或者存在 [heterogeneity](http://en.wikipedia.org/wiki/Study_heterogeneity)。

这样的 claims 存在几个问题。

首先，absence of evidence 可能只是 _only very slight_ 的 evidence of absence。例如，如果我在自家前门上方挂一块大牌子，写着“BEN 住在这里”，那就会是表明我叫 Ben 的 strong evidence——但没有这块牌子，只是表明我不叫 Ben 的 very weak evidence，因为本来就几乎没人会挂这样的牌子。从 Mathematically 来看，这就体现为 Bayes factor _P(~E|H)/P(~E)_ 是 very close to 1，因此看到 _~E_ 只是一次 very small negative update。（Conservation of expected evidence 说，如果 _E_ 是支持 _H_ 的 evidence，那么 Bayes factor 就不能 exceed 1，但它并没有说它能有多 close to 1！）所以，即使“absence of evidence 并不是 evidence of absence”这句老话并非 technically true，它在许多情况下仍是一个有用的 approximation。

其次，仅仅 reporting 一个 statistical hypothesis test 是否 significant，几乎是 _barely informative at all_ 的。这是因为，如果这个 test 的 [statistical power](http://en.wikipedia.org/wiki/Statistical_power) 是 low，那么即使 hypothesis 是 true，它也可能极不可能得出 significant 的结果——这种情况类似于我上面那个姓名牌子的例子。

因此，你其实不应该只关心 X 的 effect 并非 significantly different from 0 这一事实。相反，你应该关心这个 effect 周围的 _confidence interval_。confidence interval 基本上回答了这样一个问题：“哪些潜在的 _true_ effect sizes 构成了一个 set，使得看到我们实际看到的那个 _observed_ effect size 不会是太 improbable 的？”（更 precisely 地说，如果我们把 true effect size 与 observed effect size 之间的 difference 称为 _error_；那么，95% confidence interval 就是这样一个由 true effect sizes 构成的 set：在这些 true effect sizes 下，95% 的时候会看到 observed size 或 smaller 的 error。）

（小心！这不同于对 true effect size lies in 那个 interval 这一点“95% certain”！）

effect size 周围的 confidence interval 告诉你的，远不只是 test 是否 significant。具体来说，它不只是告诉你 observed effect size 与一个为 zero 的 true effect size 是 consistent with 的，还告诉你 true effect size 所 consistent with 的 effect sizes 的 _entire range_。这些信息多得多，也有用得多。

那么，这与 evidence-of-absence 问题有什么关系呢？最重要的是，知道 confidence interval 会给你一些关于 _P(~E|H)_ 的信息。如果 data 与每个 plausible effect size 都是 consistent with 的——比如说，你正在 examining donating blood 对 heart disease 的 effect，而你的 estimated risk ratio 是 1.0，CI 为 (0.1-10.0)——那么，即使 true effect 是 positive，你也很不可能 observed 到 significant outcome，因此 absence of evidence 只是 very weak evidence of absence。

同样，如果你 run 了两项 studies，其中一项结果是 significant，而另一项不是，那么你可能会把这 interpret 为对于 donating blood helping with heart disease 存在“mixed evidence”，或者你可能会开始担心，这些 studies 是在不同的 populations 中进行的，或 used 了不同的 procedures（heterogeneity）。但 confidence intervals 能给你丰富得多的 data：

-   如果你得到的 CIs 为 (0.1-10) 和 (0.7-0.8)，那么就存在支持某个 effect 的相当 strong evidence；第一项 study 只是反对某个 effect 的 very weak evidence，因为它实在太 underpowered 了。

-   如果你得到的 CIs 为 (0.1-0.9) 和 (0.5-1.5)，那么就存在支持某个 effect 的 moderate evidence，以及支持 heterogeneity 的 moderate to weak evidence，因为两项 studies 都与 range (0.5-0.9) 内的 values 是 consistent with 的。

-   如果你得到的 CIs 为 (0.1-0.2) 和 (0.9-1.1)，那么就存在表明 heterogeneity 的 strong evidence，因为这些 CIs 完全不 overlap。

正如你所看到的，在从 statistical studies 中 drawing conclusions 时，reporting 和 interpreting confidence intervals，而不只是 significance/non-significance，可能极有帮助。

## 原文

Here are some statistical interpretation anti-patterns:

-   This study found no significant evidence that X had any effect. Therefore…

-   (Sub-pattern of the first: because of [conservation of expected evidence](http://lesswrong.com/lw/ii/conservation_of_expected_evidence/), this is evidence that the true effect is zero.)

-   Study A found significant evidence for X, but study B didn’t. Therefore, they disagree or there’s [heterogeneity](http://en.wikipedia.org/wiki/Study_heterogeneity).

There are a couple problems with claims like these.

First, absence of evidence can be _only very slight_ evidence of absence. For instance, if I posted a large sign over my front door saying “BEN LIVES HERE,” that would be strong evidence that my name was Ben—but its absence is only very weak evidence that my name isn’t Ben, because hardly anyone posts such a sign anyway. Mathematically, this cashes out to the fact that Bayes factor _P(~E|H)/P(~E)_ is very close to 1, so seeing _~E_ is only a very small negative update. (Conservation of expected evidence says that the Bayes factor can’t exceed 1 if _E_ is evidence for _H_, but it doesn’t say how close to 1 it can get!) So even if the old saying “absence of evidence is not evidence of absence” is not technically true, it’s a useful approximation in many cases.

Second, reporting merely whether a statistical hypothesis test is significant is _barely informative at all_. That’s because, if the test has low [statistical power](http://en.wikipedia.org/wiki/Statistical_power), it may have been extremely unlikely to come up significant even if the hypothesis were true—a situation analogous to my name-sign example above.

For this reason, you shouldn’t really care about the mere fact that X’s effect isn’t significantly different from 0. Instead, you should care about the _confidence interval_ around the effect. The confidence interval basically answers the question: “what’s a set of potential _true_ effect sizes where it wouldn’t be too improbable to see the _observed_ effect size that we actually saw?” (More precisely, if we call the _error_ the difference between the true effect size and the observed effect size; then the 95% confidence interval is the set of true effect sizes where one would see an error of the observed size or smaller 95% of the time.)

(Be careful! This is different from being “95% certain” that the true effect size lies in that interval!)

The confidence interval around the effect size tells you a lot more than just whether the test was significant. In particular, instead of just telling you that the observed effect size is consistent with a true effect size of zero, it tells you the _entire range_ of effect sizes that the true effect size is consistent with. That’s way more, and way more useful, information.

So how does this play into evidence-of-absence issues? Most importantly, knowing the confidence interval gives you some information about _P(~E|H)_. If the data are consistent with every plausible effect size—say that you’re examining the effect of donating blood on heart disease and your estimated risk ratio is 1.0 with a CI of (0.1-10.0)—then it’s very unlikely that you would have observed a significant outcome even if the true effect was positive, so the absence of evidence is only very weak evidence of absence.

Similarly, if you run two studies and one turns out significant while the other doesn’t, then you might interpret this as having “mixed evidence” for donating blood helping with heart disease, or you might start worrying that the studies were in different populations or used different procedures (heterogeneity). But confidence intervals give you much richer data:

-   If you get CIs of (0.1-10) and (0.7-0.8) then there’s pretty strong evidence for an effect; the first study is very weak evidence against an effect because it was so underpowered.

-   If you get CIs of (0.1-0.9) and (0.5-1.5), then there’s moderate evidence for an effect, and moderate to weak evidence for heterogeneity, since both studies are consistent with values in the range (0.5-0.9).

-   If you get CIs of (0.1-0.2) and (0.9-1.1), then there’s strong evidence of heterogeneity because the CIs don’t overlap at all.

As you can see, reporting and interpreting confidence intervals, instead of mere significance/non-significance, can be extremely helpful when drawing conclusions from statistical studies.
