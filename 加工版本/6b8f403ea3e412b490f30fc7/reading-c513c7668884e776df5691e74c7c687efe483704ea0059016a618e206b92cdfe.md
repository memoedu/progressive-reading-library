## 核心洞察

一、柯尼希定理核心思想：柯尼希定理将两体系统的总动能分解为质心运动动能和相对运动动能两部分。质心运动动能只与质心速度有关，在系统动量守恒时保持不变；相对运动动能与两质点相对速度及折合质量有关，是碰撞中可损耗的部分。这一分解为分析碰撞和能量转化提供了清晰框架。
[[#^pr-363bf0295a98|正文跳转]]

二、质心速度与动量守恒：质心速度定义为系统总动量除以总质量，因此在动量守恒的碰撞过程中质心速度恒定。这导致质心运动动能成为不变量，而相对运动动能的变化反映了碰撞中能量的转化，例如弹簧模型中最大弹性势能等于初始相对运动动能。
[[#^pr-49c579e7a876|正文跳转]]

三、弹性碰撞相对速度反向：利用柯尼希定理，弹性碰撞中动能守恒要求相对速度大小不变，方向反向。结合动量守恒，可推导出碰撞前后每个物体速度关于质心速度对称的结论，简化了一动撞一动的计算。
[[#^pr-0148accf1af3|正文跳转]]

四、水平方向动能守恒：在滑块-曲面模型中，虽然竖直方向动量不守恒，但水平方向动量守恒，因此水平方向质心速度对应的动能守恒。这一守恒量可用于分析小球上升高度等问题，将能量转化限制在相对运动动能与竖直方向动能、重力势能之间。
[[#^pr-5faa59b96eb3|正文跳转]]

五、最高点相对速度为零：在滑块-曲面模型中，小球到达最高点时竖直方向速度为零，且相对于曲面水平速度为零，因此系统无相对运动动能和竖直方向动能，初始相对运动动能全部转化为重力势能。这一结论可直接用于计算最大高度。

## 第一部分 柯尼希定理的证明

先介绍一下柯尼希定理吧。**一言以蔽之，柯尼希定理就是把动能分成了两部分：质心运动动能和相对运动动能。**

下面对柯尼希定理做一个证明，顺便把上面这句话里面，高中生所不熟悉的概念给介绍了。

首先，我们先引入一个全新的概念：**质心位置以及质心速度**。

什么叫质心位置呢？质心位置是位置对质量的加权平均。（本来想在这里好好给大家掰扯一下什么是位置，什么是位移，但是为了避免在一篇回答里引入太多新概念，只能作罢，感兴趣的同学可以自己去找2024年江西高考物理选择题第三题，能做对的话说明你对这两个概念的理解基本没有问题）以一个一维运动为例，质心的坐标可以定义为：

x\_c=\\frac{\\sum\\limits\_{i=1}^{n}m\_ix\_i}{\\sum\\limits\_{i=1}^{n}m\_i}

稍微解释一下这个式子。我们在小学二年级就学过了加权平均，而质心位置其实就是**以质量为权重，求得的位置的平均数。**而上式中的下标 c ，取的是Center of mass（质量的中心）的c。

接下来举个具体的例子看看如何计算质心的位置：现在我们有一根数轴，假设质量为 m\_1=3kg 的物体在 x\_1=3m 处，质量为 m\_2=1kg 的物体在 x\_2=-1m 处，那么质心的位置在哪里呢？答案是 x\_c=2m 。

具体计算过程如下：

\\begin{align} x\_c&=\\frac{\\sum\\limits\_{i=1}^{2}m\_ix\_i}{\\sum\\limits\_{i=1}^{2}m\_i}\\\\ &=\\frac{m\_1x\_1+m\_2x\_2}{m\_1+m\_2}\\\\ &=2m \\end{align}

我们简单的介绍了一下质心的定义及其计算方法，接下来，我们就开始进入正题，讨论一下质心速度是什么。沿用质心位置的定义，我们把质心速度定义为：以质量为权重，求得的速度的平均数。

那么它的计算公式就应该是：

v\_c=\\frac{\\sum\\limits\_{i=1}^{n}m\_iv\_i}{\\sum\\limits\_{i=1}^{n}m\_i}

注意到上式中出现了一个 \\sum\\limits\_{i=1}^{n}m\_iv\_i ，那这玩意儿是什么呢？其实这是我们小学二年级就知道的，一个**系统的总动量**！由此，我们稍微改写一下上式，让质心速度的概念更清晰一些。

\\begin{align} v\_c&=\\frac{\\sum\\limits\_{i=1}^{n}m\_iv\_i}{\\sum\\limits\_{i=1}^{n}m\_i}\\\\ &=\\frac{P\_总}{m\_总} \\end{align}

现在我们再解释一下这个公式的意思。从数学上讲，它很简单，无非就是系统的总动量除以总质量嘛。然后我们会发现什么呢？欸，在动量守恒的时候，这个量是不是肯定不变？事实上，这就是这个公式如此重要的原因之一，你想想，高中物理在学动量的时候，是不是有很多碰撞的题目？我们知道，这些碰撞过程都是动量守恒的，那巧了，动量守恒不就代表着我们的质心速度也是不变的吗？由此，我们可以想到，假如质心速度代表着系统的某一部分动能，那这部分动能是不是也不变？接下来我们就来寻找这个不变量。

^pr-49c579e7a876

考虑一个只有两个质点的系统，它们的质量和速度分别为： m\_1、m\_2、\\overrightarrow{v\_1}、\\overrightarrow{v\_2}

那么，我们就可以对它的动能做一些数学操作：

\\begin{align} E\_k&=\\frac{1}{2}m\_1{\\overrightarrow{v\_1}}^{2}+\\frac{1}{2}m\_2{\\overrightarrow{v\_2}}^{2}\\\\ &=\\frac{1}{2}m\_1\[\\frac{m\_1\\overrightarrow{v\_1}+m\_2\\overrightarrow{v\_2}}{m\_1+m\_2}+\\frac{m\_2\\overrightarrow{v\_1}-m\_2\\overrightarrow{v\_2}} {m\_1+m\_2}\]^{2} + \\frac{1}{2}m\_2\[\\frac{m\_1\\overrightarrow{v\_1}+m\_2\\overrightarrow{v\_2}}{m\_1+m\_2}+\\frac{m\_1\\overrightarrow{v\_2}-m\_1\\overrightarrow{v\_1}} {m\_1+m\_2}\]^{2}\\\\ &=\\frac{1}{2}m\_1\[\\overrightarrow{v}\_c+\\frac{m\_2} {m\_1+m\_2}(\\overrightarrow{v\_1}-\\overrightarrow{v\_2})\]^{2} + \\frac{1}{2}m\_2\[\\overrightarrow{v\_c}+\\frac{m\_1} {m\_1+m\_2}(\\overrightarrow{v\_2}-\\overrightarrow{v\_1})\]^{2}\\\\ \\end{align}

为了化简一下表达式，我们不妨把 \\overrightarrow{v\_1}-\\overrightarrow{v\_2} 单独提出来，记为 \\overrightarrow{v}\_相 ，那么上式可以写为：

\\begin{align} E\_k &=\\frac{1}{2}m\_1\[\\overrightarrow{v}\_c+\\frac{m\_2} {m\_1+m\_2}\\overrightarrow{v}\_相\]^{2} + \\frac{1}{2}m\_2\[\\overrightarrow{v}\_c-\\frac{m\_1} {m\_1+m\_2}\\overrightarrow{v}\_相\]^{2}\\\\ &=\\frac{1}{2}(m\_1+m\_2)\\overrightarrow{v}\_c^2+\\frac{1}{2}\\frac{m\_1m\_2}{m\_1+m\_2}\\overrightarrow{v}\_相^2 \\end{align}

打公式太痛苦了，所以中间有些运算就留做读者的练习，请读者自证吧（手动狗头）。

我们简单地解释一下这个公式的意思，它是说，一个有两个质点的系统（我们一般称之为两体系统）的动能可以分为两部分，一部分只与质心速度有关，我们称之为**质心运动动能**，这一项在**动量守恒的时候是不变的**！而另一部分只与两个质点之间的相对速度有关，我们称之为**相对运动动能**，而相对速度平方前面的系数 \\frac{m\_1m\_2}{m\_1+m\_2} ，我们称之为**折合质量**；而这一部分动能，正是我们在**碰撞中所能损耗的那一部分动能**！

## 第二部分 柯尼希定理的简单应用

书接上文，我们在前一部分推导出了两体问题中的柯尼希定理，实际上该定理也可以推广至多体问题，有兴趣的读者可以自己搜索相关资料并推导（然而这在高中物理中好像并没有什么卵用）。

接下来，我们给一些具体的例子。

### 例题1 弹簧——物块模型

![](https://pica.zhimg.com/50/v2-dd242003444c8cd7e1d25861c814fdab_720w.jpg?source=2c26e567)

该题来自学科网

先考虑这个一维的弹簧—物块模型吧。由于题目中明确说到“光滑水平面”，那这个系统就是动量守恒的，这可太有用了，这不就代表着质心运动动能不变吗？那么整个运动过程中，参与动能转化为弹性势能的那部分能量就只有相对运动动能了。

而物块B的质量显然为 0.5m （读者自证不难）。那初始时刻，该系统的相对运动动能就应该是

\\frac{1}{2}\\frac{m\\times 0.5m}{m+0.5m}v\_0^2

在整个过程中，弹簧储存的最大弹性势能刚好就会是两物块共速的时候（不清楚的同学可以回去复习一下高一的追及相遇问题），因此弹簧储存的最大弹性势能就是 \\frac{1}{6}mv\_0^2 ，D选项正确。

### 例题2 滑块——曲面模型

![](https://picx.zhimg.com/50/v2-b37bc5ceb182a09574993011295c2f02_720w.jpg?source=2c26e567)

该题来自学科网

接下来我们考虑这么一个二维的问题，我们先只讨论A、B、C三问。这三问只涉及B小球和C曲面，所以我们的讨论也**先只涉及B、C两个物体**。而且A、B碰撞完，在B与C发生“类碰撞”的过程中，也没A的事儿。

首先问读者一个问题，该体系的动量守恒吗？（请读者稍加思考）

答案是，竖直方向不守恒，而水平方向守恒，想不明白的同学可以私信或评论区问我。既然存在水平方向动量守恒，那么这部分运动是否也能对应某个守恒量呢？事实上是可以的，我们将质心运动动能\\frac{1}{2}(m\_1+m\_2)\\overrightarrow{v}\_c^2 中的质心速度 \\overrightarrow{v}\_c 分解为水平方向质心速度 \\overrightarrow{v}\_{c//} 与竖直方向质心速度 \\overrightarrow{v}\_{c\\bot} ，就可以得到，水平方向质心速度所对应的动能 \\frac{1}{2}(m\_1+m\_2)\\overrightarrow{v}\_{c//}^2 。我们此刻可以惊奇得发现，由于水平方向动量守恒，**这个量将是守恒的**！

^pr-5faa59b96eb3

从而得到了我们想要的守恒量（我称之为水平方向运动动能，这种说法似乎被挺多老师批判过，因为能量是个标量，不存在“xx方向能量”的说法，但是大家能理解这个概念在讲什么就行了）。对于初始时刻，由于不存在竖直方向的动能，我们的能量可以只“分解”为水平运动动能和相对运动动能两部分，在此后的过程中，水平运动动能不变，小球B在往上爬，从而增加了**竖直方向动能和重力势能**，这两部分能量就是**由相对运动动能转化而来**的。

接下来考虑A、B选项。这俩选项问的问题其实是差不多的，也就是B小球能运动到多高，那这个问题就等价于问，B小球的重力势能最大为多少？我们刚才提到了，相对运动动能转化为了竖直方向动能和重力势能。在数学中，我们知道，当某函数的一阶导数等于0，其函数值会取到极值，这个结论对应在这道题当中，其实就是，当小球到达最高点的时候，它一定是没有竖直方向速度的。

而没有竖直方向速度又可以推出，该物块相对于曲面是没有水平方向速度的。这里限于篇幅，我偷个懒，将论证略去，读者可以自己尝试证明（提示：可以分为小球升到最高点时仍在曲面上or小球升到最高单时不在曲面上两种情况进行讨论）。

以上，我们证明了小球B在最高点的时候没有竖直方向速度，也没有**相对于曲面的水平方向速度**，因此没有相对于曲面的速度，所以小球B和曲面所组成的系统在这时候**没有相对运动动能，也没有竖直方向动能**！即：初始时刻的**相对运动动能全部转化为重力势能**！由这个重要结论，我们可以很快地计算出A选项。而B选项所要求的速率，其实就是B、C共速时（因为二者在这一时刻没有水平方向的相对速度）的速率。至于C选项，这不就是个简单的“一动撞一静”模型吗？其实不然，接下来我将会教你一个帅炸了的计算一动撞一静，甚至一动撞一动的方法（这个方法来自蔡神 [@物理竞赛蔡子星](https://www.zhihu.com/people/5b04228f63c380f66c1ce32d851d797c) 的竞赛课）。

### 例题3 一动撞一动

我在这里直接把前面的柯尼希定理抄下来，前提条件也同上。

E\_k =\\frac{1}{2}(m\_1+m\_2)\\overrightarrow{v}\_c^2+\\frac{1}{2}\\frac{m\_1m\_2}{m\_1+m\_2}\\overrightarrow{v}\_相^2

考虑一个动量守恒的弹性碰撞过程，碰撞前后动能应该保持不变。而为了保持这一点， \\frac{1}{2}\\frac{m\_1m\_2}{m\_1+m\_2}\\overrightarrow{v}\_相^2 必须不变，故而 E\_k 表达式的右边唯一可变的量 {v}\_相 只有两种可能： {v}\_{相前}={v}\_{相后} 或 {v}\_{相前}=-{v}\_{相后} 。而第一种可能显然是废话，碰撞前后啥都不改变，那你碰撞了个寂寞。所以物理上会取的解只能是 {v}\_{相前}={-v}\_{相后} ，也就是：**弹性碰撞前后，相对速度大小不变，方向反向**。

^pr-0148accf1af3

接下来我们再考虑碰撞前后动量守恒，那就要求碰撞前后的速度满足如下方程：

\\begin{cases} \\begin{align} &动量守恒:m\_1v\_1+m\_2v\_2=m\_1v\_1^{\\prime}+m\_2v\_2^{\\prime} \\\\ &相对速度反向:v\_1^{\\prime}-v\_2^{\\prime}=-(v\_1-v\_2) \\end{align} \\end{cases}

再加上 v\_c=\\frac{m\_1v\_1+m\_2v\_2}{m\_1+m\_2} ，可以计算得到如下图所示的结果。这个结果归纳为一句话，就是一个物体**碰撞前后的速度要关于质心速度对称**！

## 第三部分 最终大BOSS 2023年全国乙卷第25题

## 2023全国乙卷真题解读研究

## 解题思路概要

### 参考系与碰撞条件

-   以圆盘为参考系，第一次碰撞时相对速度为 V\_相=\\sqrt{2gl}
-   碰撞后相对速度大小不变，方向反向。

### 碰撞时间间隔

每次碰撞到下一次碰撞的时间间隔为：

t = \\frac{2V\_{\\text{相}}}{g}= {2\\sqrt{\\frac{2l}{g}}}

### 系统冲量定理分析

-   系统所受冲量变化： I = \\Delta P = \\frac{MV\_相}{2}
-   设每次碰撞中两物体间的冲量大小为 I ，则有： \\Delta V\_{\\text{虚}} = \\frac{I}{M}, \\quad \\Delta V\_{\\text{球}} = \\frac{I}{m}
-   碰撞过程相对速度反向，所以相对速度变化为 2V\_相 ： \\Delta V\_{\\text{相}} = \\Delta V\_{\\text{虚}} + \\Delta V\_{\\text{球}} = \\frac{I}{M} + \\frac{I}{m} = 2V\_{\\text{相}}
-   解得： I = \\frac{M \\cdot V\_{\\text{相}}}{2} = \\frac{M\\sqrt{2gl}}{2}

### 各次碰撞位移分析

1.  **第一次碰撞后**： V\_1 = \\frac{\\sqrt{2gl}}{2} , \\quad X\_1 = V\_1 \\cdot t = 2l
2.  **第二次碰撞后**： V\_2 = \\sqrt{2gl}, \\quad X\_2 = V\_2 \\cdot t = 4l
3.  **第三次碰撞后**： V\_1 = \\frac{ 3\\sqrt{2gl}}{2} ,\\quad X\_3=6l
4.  **第四次碰撞后**： V\_4 = \\frac{ 4\\sqrt{2gl}}{2} ,\\quad X\_3=8l

### 总位移与碰撞次数

-   总位移为： X\_1 + X\_2 + X\_3 + X\_4 = 20l \\geq l \\cdot p \\cdot l
-   **结论**：最多可发生 **4 次碰撞**。
