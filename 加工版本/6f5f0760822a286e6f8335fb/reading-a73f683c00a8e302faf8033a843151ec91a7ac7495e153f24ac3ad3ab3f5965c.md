## 正文

这里是 Microsoft anti-trust case 中 exhibits 的链接，并对其中一些链接附有少量笔记。共有 945 份 public exhibits（编号最高的 exhibit 是 2519，但许多 exhibits 只获准 admitted under seal，还有许多并未获准 admitted），所以，随着我逐一阅读这些 exhibits，这项工作也在持续进行中。

我觉得，把人们对 Microsoft execs 当时想法的普遍印象与 execs 的实际想法作比较，反差十分鲜明。例如，在这些 documents 进入 public record 将近十年后，Paul Graham 写下了一段典型的评论，认为 Microsoft 浑然不知当时的形势。他说：

> Gmail 还表明，如果利用后来被称为“Ajax”的东西，你就能用 web-based software 做很多事。而这正是 Microsoft 消亡的第二个原因：每个人都看得出，desktop 的时代已经结束了。如今看来，applications 将在 web 上运行似乎已不可避免——不只是 email，而是一切，乃至 Photoshop。就连 Microsoft 现在也明白这一点了。
> 
> 讽刺的是，Microsoft 无意中帮助 create 了 Ajax。Ajax 中的 x 来自 XMLHttpRequest object，它让 browser 能在 displaying 一个 page 的同时，在 background 与 server 进行 communicate。（最初，与 server 进行 communicate 的唯一方式就是请求一个新的 page。）XMLHttpRequest 是 Microsoft 在 90 年代末 created 的，因为他们在 Outlook 中需要它。他们没有意识到的是，它对许多其他人也会有用——事实上，对任何想让 web apps 像 desktop 应用那样 work 的人都会有用。

但如果看看 execs 在 90 年代中期说过的话，其中包含了许多可追溯到 90 年代初的想法，就会发现 Microsoft execs 完全知道自己在做什么：他们 extended 了 web standards，而且有相当充分的理由这样做（指的是 business savvy，而不是 moral）。[他们的 game plan 因多种原因而未能成功](https://twitter.com/danluu/status/1562856542860619776)，但他们成功地 execute 了一半的 strategy，这正是 Microsoft 在 2022 年的今天成为一家 $2T company（全球第 2 大 most valuable tech company）的原因；与此同时，他们当时担忧并长篇讨论过的 traditional competitors（Novell、IBM、AT&T、Yahoo、Sun 等）如今不是已经消亡，就是已无足轻重，而 Microsoft 则是 created 了 TypeScript、LINQ、VSCode、WSL 等的那家公司。

Microsoft 的 strategy 没有奏效是有切实原因的，这些原因也有值得吸取的教训，但吸取这些教训需要真正理解发生了什么，而不是只把 Microsoft 贬斥为一家充斥着糟糕 leadership、[没有任何优秀 programmers 的公司](https://twitter.com/danluu/status/1356462960172883969)。

Links to exhibits from the Microsoft anti-trust case, with a few notes on some of the links. There are 945 public exhibits (the highest numbered exhibit is 2519, but many exhibits were only admitted under seal and many were also not admitted), so this is a work in progress as I read through exhibits.

I think it's striking to compare pop conceptions of what Microsoft execs were thinking vs. actual thoughts from execs, e.g., Paul Graham, writing almost a decade after these documents went into the public record, in typical comment about Microsoft cluelessness, said

> Gmail also showed how much you could do with web-based software, if you took advantage of what later came to be called "Ajax." And that was the second cause of Microsoft's death: everyone can see the desktop is over. It now seems inevitable that applications will live on the web—not just email, but everything, right up to Photoshop. Even Microsoft sees that now.
> 
> Ironically, Microsoft unintentionally helped create Ajax. The x in Ajax is from the XMLHttpRequest object, which lets the browser communicate with the server in the background while displaying a page. (Originally the only way to communicate with the server was to ask for a new page.) XMLHttpRequest was created by Microsoft in the late 90s because they needed it for Outlook. What they didn't realize was that it would be useful to a lot of other people too—in fact, to anyone who wanted to make web apps work like desktop ones.

But if we look at what execs said in the mid 90s, which encompasses a lot of thoughts running into the early 90s, Microsoft execs knew exactly what they were doing they extended web standards and had fairly good (as in business savvy, not moral) reasons for doing so. [Their game plan didn't work out for a variety of reasons](https://twitter.com/danluu/status/1562856542860619776), but the fact that they managed to half execute their strategy is the reason a $2T company today in 2022 (the 2nd most valuable tech company on the planet), while the traditional competitors they were worried about and discussed at length (Novell, IBM, AT&T, Yahoo, Sun, etc.) are now dead or irrelevant and Microsoft is the company that created TypeScript, LINQ, VSCode, WSL, etc.

There are real reasons that Microsoft's strategy didn't work and lessons to be learned from those reasons, but learning those lessons requires actually understanding what happened and not just trashing Microsoft as a company full of bad leadership [that doesn't have any good programmers](https://twitter.com/danluu/status/1356462960172883969).
