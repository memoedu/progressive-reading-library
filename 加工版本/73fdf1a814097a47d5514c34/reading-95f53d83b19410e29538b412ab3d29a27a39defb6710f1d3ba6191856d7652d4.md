# 为什么使用 squared error？

---

## 正文

最近有人在 statistics Stack Exchange 上问，[为什么 statistics 中会使用 squared error](http://stats.stackexchange.com/questions/127598/square-things-in-statistics-generalized-rationale/128619)。这也是我最近一直在琢磨的问题，所以我决定试着回答一下。下面这篇文章改编自[那个回答](http://stats.stackexchange.com/questions/127598/square-things-in-statistics-generalized-rationale/128619#128619)。

## 为什么使用 squared error？

确实，我们可以选择使用比如 absolute error，而不是 squared error。事实上，当你根据 model 作出 predictions 时，absolute error 往往更接近你所“关心”的东西。例如，如果你买入一只 stock，预期它的 future price 是 `$P_{predicted}$`，但它的 future price 却是 `$P_{actual}$`，那么你损失的金额 proportional to `$(P_{predicted} - P_{actual})$`，而不是它的 square！在许多其他情境中也是如此。

然而，squared error 具有好得多的 mathematical properties。例如：

-   如果 `$X$` 是一个 random variable，那么 `$X$` 的、使 squared error 达到 minimizes 的 estimator 就是 mean，即 `$E(X)$`。另一方面，使 absolute error 达到 minimizes 的 estimator 是 median，即 `$m(X)$`。mean 的 properties 比 median 好得多；例如，`$E(X + Y) = E(X) + E(Y)$`，但对于 `$m(X + Y)$`，并没有 general expression。

-   如果你有一个 vector `$\vec X = (X_1, X_2)$`，它由 `$\vec x = x_1, x_2$` 来 estimated，那么对于 squared error，无论你是分别还是一起考虑 components，都没有影响：`$\left|\left|\vec X - \vec x\right|\right|^2 = (X_1 - x_1)^2 + (X_2 - x_2)^2$`，因此 components 的 squared error 只需 adds。对于 absolute error，你不能这样做。这意味着 squared error 是 _independent of re-parameterizations_：例如，如果你 define `$\vec Y_1 = (X_1 + X_2, X_1 - X_2)$`，那么 `$Y$` 和 `$X$` 的 minimum-squared-deviance estimators 是相同的，但 minimum-absolute-deviance estimators 却不是。

-   对于 independent random variables，variances（expected squared errors）会 add：`$Var(X + Y) = Var(X) + Var(Y)$`。对于 expected absolute error，情况并非如此。

-   对于来自 multivariate Gaussian distribution 的 sample（其中 probability density 是关于到 mean 的 squared distance 的 exponential），无论你使用什么 coordinate system，它的所有 coordinates 都是 Gaussian。对于 multivariate Laplace distribution（类似于 Gaussian，但使用的是 absolute distance，而不是 squared distance），情况并非如此。

-   一个 probabilistic classifier 的 squared error 是一种 [proper scoring rule](https://en.wikipedia.org/wiki/Scoring_rule#Proper_score_functions)。如果有一个 oracle 告诉你每个 item 的每个 class 的 actual probability，而且你正根据自己的 Brier score 接受 scored，那么最好的做法就是对每个 class 都 predict 这个 oracle 告诉你的内容。对于 absolute error，情况并非如此。（例如，如果 oracle 告诉你 `$P(Y=1) = 0.9$`，那么 predicting `$P(Y=1) = 0.9$` 会 yields 一个为 `$0.9\cdot 0.1 + 0.1 \cdot 0.9 = 0.18$` 的 expected score；你应该改为 predict `$P(Y=1) = 1$`，从而得到一个为 `$0.9\cdot 0 + 0.1 \cdot 1 = 0.1$` 的 expected score。）

我会说，这些良好的 properties 只是带来了“方便”——如果使用 absolute error 不会在 solving problems 时造成 technical issues，我们也许会选择改用它。但涉及 squared error 的某些 mathematical coincidences 更加重要。它们不仅涉及 technical problem-solving issues；更重要的是，它们为 minimizing square error 为什么可能是个好主意提供了 intrinsic reasons：

-   当对一组 data 进行 fitting a Gaussian distribution 时，maximum-likelihood fit 是使 squared error 达到 minimizes 的那个，而不是使 absolute error 达到 minimizes 的那个。

-   进行 dimensionality reduction 时，finding 使 _squared_ reconstruction error 达到 minimizes 的 basis 会 yields [principal component analysis](https://en.wikipedia.org/wiki/Principal_component_analysis)，它便于 compute，是 coordinate-independent 的，而且对于 multivariate Gaussian distributions 有一种 natural interpretation（finding 该 distribution 形成的 ellipse 的 axes）。有一种称为“robust PCA”的 variant，有时会被用于 minimizing absolute reconstruction error，但它似乎研究得还不够充分，也更难理解和 compute。

## 再深入一些

人们很可能会问，squared error 带来的种种便利背后，是否存在某种深层的 mathematical truth。据我所知，确实有几个（它们在某种意义上是 related 的，但在我看来，并不是相同的）：

### Differentiability（可微性）

squared error 是 [everywhere differentiable](https://en.wikipedia.org/wiki/Differentiable_function) 的，而 absolute error 不是（它的 derivative 在 0 处是 undefined 的）。这使 squared error 更适于使用 [mathematical optimization](https://en.wikipedia.org/wiki/Mathematical_optimization) 的 techniques。要 optimize squared error，你只需将它的 derivative 设为 equal to 0，然后 solve；而要 optimize absolute error，往往需要更 complex 的 techniques。

### Inner products（内积）

squared error 是由 underlying space 上的一个 [inner product](https://en.wikipedia.org/wiki/Inner_product_space) 所 induced 的。inner product 基本上是一种“将 vector `$x$` 沿着 vector `$y$` 进行 projecting”的方式，或者说，是弄清楚“`$x$` 在多大程度上与 `$y$` 指向 same direction”。在 finite dimensions 中，这就是 standard（Euclidean）inner product `$\langle a, b\rangle = \sum_i a_ib_i$`。Inner products 使我们能够以 geometrically 的方式思考一个 space，因为它们提供了以下 notion：

-   一个 right angle（`$x$` 和 `$y$` 是 right angles，条件是 `$\langle x, y\rangle = 0$`）；
-   以及一个 length（`$x$` 的 length 是 `$\left|\left|x\right|\right| = \sqrt{\langle x, x\rangle}$`）。

我说“squared error 是由 Euclidean inner product 所 induced 的”，意思是 `$x$` 与 `$y$` 之间的 squared error 是 `$\left|\left|x-y\right|\right|^2$`，也就是它们之间的（squared）Euclidean distance。事实上，在某种意义上，Euclidean inner product 是 finite-dimensional vector space 中“唯一可能的”axis-independent inner product，这意味着 squared error 具有独特而良好的 geometric properties。

事实上，对于 random variables，你可以 define 一个类似的 inner product：`$\langle X, Y\rangle = E(XY)$`。这意味着，我们可以设想 random variables 的一种“geometry”，其中两个 variables 会形成一个“right angle”，条件是 `$E(XY) = 0$`。`$X$` 的“length”是 `$E(X^2)$`，这与它的 variance 是 related 的，而这并非巧合。事实上，在这个 framework 中，“independent variances add”只是 Pythagorean Theorem 的一个 consequence：

`$$Var(X + Y) = \left|\left|(X - \mu_X) + (Y - \mu_Y)\right|\right|^2 = \left|\left|X - \mu_X\right|\right|^2 + \left|\left|Y - \mu_Y\right|\right|^2 = Var(X) + Var(Y).$$`

## 超越 squared error

既然有这些良好的 mathematical properties，我们还会有 _不_ 想使用 squared error 的时候吗？嗯，正如我在开头提到的，有时 absolute error 更接近我们在实践中“关心”的东西。例如，如果你的 data 的 tails 比 Gaussian 更 fatter，那么 minimizing 这个 squared error 可能使你的 model 花费过多精力去 getting close to outliers，因为相较于其余 data 上的许多 moderate errors，它对 outlier 上那一个 large error component “过于在意”。

absolute error 对这样的 outliers 是 less sensitive 的。（例如，如果你在 sample 中 observe 到一个 outlier，它就会 proportionally to 这个 outlier 的 magnitude 来 changes 那个 squared-error-minimizing mean，却几乎完全不会 changes 那个 absolute-error-minimizing median！）而且，尽管 absolute error 不具有与 squared error 同样良好的 mathematical properties，这也仅仅意味着 absolute-error problems _更难 solve_，而不是说它们在某种意义上客观地更差。结果是，随着 computational methods 的进步，我们已经能够 solve absolute-error problems numerically，从而促成了 [robust statistical methods](https://en.wikipedia.org/wiki/Robust_statistics) 这一 subfield 的兴起。

事实上，一些 squared-error 与 absolute-error methods 之间存在相当好的 correspondence：

| Squared error | Absolute error |
| --- | --- |
| Mean | Median |
| Variance | Expected absolute deviation |
| Gaussian distribution | Laplace distribution |
| Linear regression | Quantile regression |
| PCA | Robust PCA |
| Ridge regression | LASSO |

随着我们越来越善于运用 modern numerical methods，毫无疑问，我们会发现其他有用的 absolute-error-based techniques，而 squared-error 与 absolute-error methods 之间的差距也会缩小。但由于 squared error 与 Gaussian distribution 之间的 connection，我认为这一差距永远不会完全消失。

## 原文

Someone recently asked on the statistics Stack Exchange [why the squared error is used in statistics](http://stats.stackexchange.com/questions/127598/square-things-in-statistics-generalized-rationale/128619). This is something I’d been wondering about myself recently, so I decided to take a crack at answering it. The post below is adapted from [that answer](http://stats.stackexchange.com/questions/127598/square-things-in-statistics-generalized-rationale/128619#128619).

## Why squared error?

It’s true that one could choose to use, say, the absolute error instead of the squared error. In fact, the absolute error is often closer to what you “care about” when making predictions from your model. For instance, if you buy a stock expecting its future price to be `$P_{predicted}$` and its future price is `$P_{actual}$` instead, you lose money proportional to `$(P_{predicted} - P_{actual})$`, not its square! The same is true in many other contexts.

However, the squared error has much nicer mathematical properties. For instance:

-   If `$X$` is a random variable, then the estimator of `$X$` that minimizes the squared error is the mean, `$E(X)$`. On the other hand, the estimator that minimizes the absolute error is the median, `$m(X)$`. The mean has much nicer properties than the median; for instance, `$E(X + Y) = E(X) + E(Y)$`, but there is no general expression for `$m(X + Y)$`.

-   If you have a vector `$\vec X = (X_1, X_2)$` estimated by `$\vec x = x_1, x_2$`, then for the squared error it doesn’t matter whether you consider the components separately or together: `$\left|\left|\vec X - \vec x\right|\right|^2 = (X_1 - x_1)^2 + (X_2 - x_2)^2$`, so the squared error of the components just adds. You can’t do that with absolute error. This means that the squared error is _independent of re-parameterizations_: for instance, if you define `$\vec Y_1 = (X_1 + X_2, X_1 - X_2)$`, then the minimum-squared-deviance estimators for `$Y$` and `$X$` are the same, but the minimum-absolute-deviance estimators are not.

-   For independent random variables, variances (expected squared errors) add: `$Var(X + Y) = Var(X) + Var(Y)$`. The same is not true for expected absolute error.

-   For a sample from a multivariate Gaussian distribution (where probability density is exponential in the squared distance from the mean), all of its coordinates are Gaussian, no matter what coordinate system you use. For a multivariate Laplace distribution (like a Gaussian but with absolute, not squared, distance), this isn’t true.

-   The squared error of a probabilistic classifier is a [proper scoring rule](https://en.wikipedia.org/wiki/Scoring_rule#Proper_score_functions). If you had an oracle telling you the actual probability of each class for each item, and you were being scored based on your Brier score, your best bet would be to predict what the oracle told you for each class. This is not true for absolute error. (For instance, if the oracle tells you that `$P(Y=1) = 0.9$`, then predicting that `$P(Y=1) = 0.9$` yields an expected score of `$0.9\cdot 0.1 + 0.1 \cdot 0.9 = 0.18$`; you should instead predict that `$P(Y=1) = 1$`, for an expected score of `$0.9\cdot 0 + 0.1 \cdot 1 = 0.1$`.)

I would say that these nice properties are merely “convenient”—we might choose to use the absolute error instead if it didn’t pose technical issues when solving problems. But some mathematical coincidences involving the squared error are more important. They don’t just pose technical problem-solving issues; rather, they give us intrinsic reasons why minimizing the square error might be a good idea:

-   When fitting a Gaussian distribution to a set of data, the maximum-likelihood fit is that which minimizes the squared error, not the absolute error.

-   When doing dimensionality reduction, finding the basis that minimizes the _squared_ reconstruction error yields [principal component analysis](https://en.wikipedia.org/wiki/Principal_component_analysis), which is nice to compute, coordinate-independent, and has a natural interpretation for multivariate Gaussian distributions (finding the axes of the ellipse that the distribution makes). There’s a variant called “robust PCA” that is sometimes applied to minimizing absolute reconstruction error, but it seems to be less well-studied and harder to understand and compute.

## Looking deeper

One might well ask whether there is some deep mathematical truth underlying the many different conveniences of the squared error. As far as I know, there are a few (which are related in some sense, but not, I would say, the same):

### Differentiability

The squared error is [everywhere differentiable](https://en.wikipedia.org/wiki/Differentiable_function), while the absolute error is not (its derivative is undefined at 0). This makes the squared error more amenable to the techniques of [mathematical optimization](https://en.wikipedia.org/wiki/Mathematical_optimization). To optimize the squared error, you can just set its derivative equal to 0 and solve; to optimize the absolute error often requires more complex techniques.

### Inner products

The squared error is induced by an [inner product](https://en.wikipedia.org/wiki/Inner_product_space) on the underlying space. An inner product is basically a way of “projecting vector `$x$` along vector `$y$`,” or figuring out “how much does `$x$` point in the same direction as `$y$`.” In finite dimensions this is the standard (Euclidean) inner product `$\langle a, b\rangle = \sum_i a_ib_i$`. Inner products are what allow us to think geometrically about a space, because they give a notion of:

-   a right angle (`$x$` and `$y$` are right angles if `$\langle x, y\rangle = 0$`);
-   and a length (the length of `$x$` is `$\left|\left|x\right|\right| = \sqrt{\langle x, x\rangle}$`).

By “the squared error is induced by the Euclidean inner product” I mean that the squared error between `$x$` and `$y$` is `$\left|\left|x-y\right|\right|^2$`, the (squared) Euclidean distance between them. In fact the Euclidean inner product is in some sense the “only possible” axis-independent inner product in a finite-dimensional vector space, which means that the squared error has uniquely nice geometric properties.

For random variables, in fact, you can define is a similar inner product: `$\langle X, Y\rangle = E(XY)$`. This means that we can think of a “geometry” of random variables, in which two variables make a “right angle” if `$E(XY) = 0$`. Not coincidentally, the “length” of `$X$` is `$E(X^2)$`, which is related to its variance. In fact, in this framework, “independent variances add” is just a consequence of the Pythagorean Theorem:

`$$Var(X + Y) = \left|\left|(X - \mu_X) + (Y - \mu_Y)\right|\right|^2 = \left|\left|X - \mu_X\right|\right|^2 + \left|\left|Y - \mu_Y\right|\right|^2 = Var(X) + Var(Y).$$`

## Beyond squared error

Given these nice mathematical properties, would we ever _not_ want to use squared error? Well, as I mentioned at the very beginning, sometimes absolute error is closer to what we “care about” in practice. For instance, if your data has tails that are fatter than Gaussian, then minimizing the squared error can cause your model to spend too much effort getting close to outliers, because it “cares too much” about the one large error component on the outlier relative to the many moderate errors on the rest of the data.

The absolute error is less sensitive to such outliers. (For instance, if you observe an outlier in your sample, it changes the squared-error-minimizing mean proportionally to the magnitude of the outlier, but hardly changes the absolute-error-minimizing median at all!) And although the absolute error doesn’t enjoy the same nice mathematical properties as the squared error, that just means absolute-error problems are _harder to solve_, not that they’re objectively worse in some sense. The upshot is that as computational methods have advanced, we’ve become able to solve absolute-error problems numerically, leading to the rise of the subfield of [robust statistical methods](https://en.wikipedia.org/wiki/Robust_statistics).

In fact, there’s a fairly nice correspondence between some squared-error and absolute-error methods:

| Squared error | Absolute error |
| --- | --- |
| Mean | Median |
| Variance | Expected absolute deviation |
| Gaussian distribution | Laplace distribution |
| Linear regression | Quantile regression |
| PCA | Robust PCA |
| Ridge regression | LASSO |

As we get better at modern numerical methods, no doubt we’ll find other useful absolute-error-based techniques, and the gap between squared-error and absolute-error methods will narrow. But because of the connection between the squared error and the Gaussian distribution, I don’t think it will ever go away entirely.
