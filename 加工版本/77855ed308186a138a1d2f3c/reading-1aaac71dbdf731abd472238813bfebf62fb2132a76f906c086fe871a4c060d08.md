四、为避免切换混淆，我更改了Mac快捷键配置：Mac与Windows在鼠标滚动方向、复制粘贴按键等操作逻辑上有很大不同，但本质并无不同，没有孰优孰劣。我更习惯Windows快捷键，为避免经常在两个系统间切换时混淆，决定更改Mac上的快捷键配置。

五、关闭自然滚动以统一方向：关闭Mac鼠标的自然滚动，使滚动方向与Windows一致。
[[#^pr-03ad74724606|正文跳转]]

六、交换Control与Command：在Mac的“设置→键盘→键盘快捷键→修饰键”中交换Control与Command，方便之后在两个系统之间复制粘贴。
[[#^pr-f499cfdab9e0|正文跳转]]

七、用左上触发角显示所有窗口：在“桌面与程序坞”中配置触发角后，将鼠标移到左上角，即可显示当前打开的所有窗口。
[[#^pr-574a4f8e087a|正文跳转]]

八、触发角可按习惯配置：在所示 Mac 触发角配置中，鼠标移到左下角可打开启动台，右上角可启动屏幕保护程序，右下角可显示桌面；右下角显示桌面的逻辑与 Windows 相同。触发角可按自身需求调整，“桌面与程序坞”中还有其他配置可自行设置。
[[#^pr-3aca1bfabda5|正文跳转]]

九、两种全屏操作效果不同：Mac 上可以双击全屏，将窗口拖到屏幕边缘可以填充屏幕，这与 Windows 一样；而窗口左上角的全屏功能会新建一个桌面，并让窗口完全填充。
[[#^pr-3aca1bfabda5|正文跳转]]

十、Inputleap 共用键鼠与剪贴板：Inputleap 可以让两台设备共用一套键鼠和剪贴板。在所示左侧 Mac、右侧 Windows 的布局中，鼠标可以直接跨越两个系统，像使用扩展屏一样。
[[#^pr-e4ab8707ac30|正文跳转]]

十一、局域网内配置服务端与客户端：两台设备在局域网内分别安装 Inputleap 插件，一台配置为服务器端，另一台配置为客户端。服务器端点击 configure server，选择位置并输入客户端名字；客户端输入服务器端 IP 地址即可。
[[#^pr-e7c4ca527424|正文跳转]]

十二、按屏幕改键统一交互：在 Inputleap 服务器端可以更改不同屏幕下的部分按键，使两套系统的交互完全相同。这里的按键配置以 Mac 端已经交换 Control 和 Command 为前提。
[[#^pr-83851476fc8b|正文跳转]]

十三、Inputleap可在GitHub下载：Inputleap可以在GitHub上自行搜索并下载。
[[#^pr-a34a8472fae4|正文跳转]]

十四、通过文件共享连接两套系统：这套配置在 Mac 端共享整个外置硬盘和用户文件，在 Windows 端共享存放代码和数据的文件夹。Mac 端先开启文件共享，再右键点击需要共享的文件夹进行共享；Windows 端同样通过文件夹右键菜单进行共享。
[[#^pr-3ff384951fbf|正文跳转]]

十五、Mac 将共享文件夹挂载到本地路径：在 Mac 访达的“网络”中找到自己的 PC，输入对应账号密码即可看到共享文件。双击进入后，共享文件夹会挂载到系统 /Volumes/ 目录，写代码和使用一些应用时可以直接当作本地文件访问。
[[#^pr-e3babb589115|正文跳转]]

十六、映射驱动器实现双向文件访问：Windows 端在文件资源管理器中映射网络驱动器并输入对应地址，即可直接访问 Mac 端文件；上述共享配置也让 Mac 端可以直接访问和修改 Windows 端的数据和程序。
[[#^pr-3214b422b2dd|正文跳转]]

十七、Playcover补足部分Mac生态：Playcover可以通过对应的安装包或源直接安装移动端应用，弥补部分Mac生态问题。
[[#^pr-3b2365efb7b3|正文跳转]]

十八、Adndrop试用存在Mac发现问题：Adndrop是安卓端应用，使用体验很像苹果的隔空投送。据说Win和Mac开启文件共享和隔空投送后，它可以直接使用系统接口传输文件；实际试用中Win端没有问题，但Mac端一直找不到，原因不明，不确定是否与系统更新有关。
[[#^pr-86cd17334fa2|正文跳转]]

十九、Localsend传文件也比较方便：Localsend与Adndrop一样是文件传输软件，使用也比较方便，可以自行体验。
