Introduction（引言）

这是一篇关于 **systems** 和 **willpower** 的文章。Willpower 是个相当 fuzzy 的 concept；在本文中，我将把它 define 为“当我让自己做某件并非 default action 的事情时所 expended 的东西”。我发现，用 willpower 来思考，是审视自己生活的一个_关键_ lens，因为我认为自己是一个 willpower 异常 low 的人（至少，相对于我社交圈里那些强得离谱的 high-achievers 而言）。而这真的、真的很糟糕，因为 willpower 是采取我想采取的 actions、以 achieve 我的 goals 的显而易见的 tool。本文尝试概述我用来绕过这个问题的各种 tools 和 hacks，让我_无论如何_都能采取自己在意的 actions。

这里关键的 underlying idea 是：**willpower 是一种 limited resource**。每当我需要做有些不愉快的事情，每当我需要 make a decision，我都会 expend 一点 willpower。而当我的 willpower 耗尽时，我就会觉得_特别_累，感觉做什么都要花费过多的 energy，也很容易陷入毫无乐趣的 spirals of procrastination。这尤其糟糕，因为这些 spirals of procrastination 并不_有趣_。有些“unproductive”的事情能让我 rejuvenate，比如散步、meditating，或者读一本好书。但当我的 willpower 为 zero 时，我往往会做些远不那么 rejuvenating 的事情，比如无休止地刷 Reddit。问题不是我在 productivity 和 relaxation 之间左右为难——我很容易落入_两者都得不到_的陷阱。因此，弄清楚如何 solve 这个问题，是我的关键 bottlenecks 之一。如果你对前面的描述也有共鸣，希望这些 tools 对你也有用！

面对这类事情，人很容易陷入 guilt/self-hate，把它视为 personal weakness。但这显然很蠢。Guilt 是一种 mental mechanism，会促使我选择采取 actions，方式是_为这些 actions spending willpower_。对于 lacking willpower 而言，Guilt 是一种_糟透了_的 solution。[Guilt 存在于我的 mind 中，而我的 goals 存在于世界中](https://www.neelnanda.io/blog/mini-blog-post-12-the-map-and-the-territory)——如果 guilt 无助于我 achieve 我的 goals，guilt 就是一种愚蠢的 emotion。我发现，把 willpower 看作 finite resource 的 framing 要有成效得_多_。因为没有足够的 time 来 achieve 自己所有的 goals 而 feel guilty，是很蠢的——我要么需要在使用 time 时更加 efficient，要么就需要减少 goals。完全相同的 logic 也 applies to willpower——它是一种更 abstract、更不 objective 的 resource，但终究仍是一种 finite resource。

而我在这里使用的主要 tool 是 **systems**。我把 system define 为任何我能提前 set up、让我未来采取 actions 时**能 spending less willpower**的东西。人很容易落入只会 [pushing the Try Harder button](https://www.neelnanda.io/blog/mini-blog-post-6-stop-pressing-the-try-harder-button) 的陷阱——本质上就是 assuming willpower 是 limitless，觉得自己下次只要再努力一点就行。Systems 能够 short-circuit 这种 failure mode，让我退后一步看全局，确保自己是 [deliberate](https://www.neelnanda.io/blog/be-deliberate) 的，并 focus on 想要的 actions，而非其背后的 mental state。

以 Systems 思考

人们经常把 systems 和 routines 混为一谈，但对我而言，这是一个宽泛得多的 idea。一些重要的 categories：

-   Routines（例行安排）

    -   Time based：早晨、晚上等

    -   Location/context based：到工作地点、进入课堂时做什么

-   Algorithms（算法）

    -   Checklists（检查清单）

    -   Policies——例如，针对工作时累得无法 focus 的情况，有一份明确的 plan，规定究竟该做什么

-   Automation（自动化）

    -   例如 Calendars、reminders、spreadsheets 等

-   Triage——对事情 prioritising、quitting，以及妥善 managing commitments

    -   这确实_看起来_像是 system 的一个 central example，但往往 quitting 某件不必要的事情，会是释放 time 和 willpower 的_最佳_方式

这里的 underlying point 是，systemisation 是一种 _mindset_，而不是 algorithm。它是一种审视自己生活的 perspective，留意其中 inefficient、require willpower，或者就是始终没有完成的部分

关于如何找到起点——某件需要 systematising 的事情——有一些建议：

-   想想_你自己_生活中的 abstract resources。对我而言，最大、最重要的 resource 是 willpower，但这相当 subjective。对你而言，它可能是 money、energy、time、health、focused time、mental energy、social energy 等。寻找最大的 bottleneck，寻找你消耗这种 resource 最多的地方，想想如何将其 systematise

-   寻找 **inefficiency**。在接下来的 24 hours 里，mindfully 地体验自己的生活。留意感觉不对劲的事情，留意那些让你觉得“_一定_有更好的办法”的事情，看看能不能建立一个 system 来改善它

    -   Underlying point——我们很容易忽略生活中的 trivial inconveniences，但它们会积少成多。每天浪费一分钟的 time，一年就是浪费 6 hours 的 time。如果有个小麻烦很容易解决，那就解决它！

-   Managing attention——寻找那些你总会忘记、或者很难记住的事情。把某件事一直记挂在心里，会 consumes attention 和 willpower。看看能不能找到一些办法，既把其中重要的事情做好，又不 consuming 那么多 attention

    -   Routines 和 to-do list systems 对此很有价值。例如，随着时间推移，我会积攒一堆细小而无聊的 tasks。需要回复但不紧急的邮件、想买的东西、需要回复的消息等。这些都会 consume 我的一点 attention。我的 solution 是在 [Trello](http://trello.com/) 中维护一份 to-do list，每周六下午将它 priority order，再尽可能多地完成——这些 tasks 不再 consuming 我的 attention，却仍然能完成！

对于 systems，有一些 underlying points 要始终记住：

-   **Minimise decision points**——主要 consumes willpower 的，并不是做某项 task 的过程，而是_一开始就 deciding to do the task_。我的 goal 是把事情搞定，而不是 _decide_ 要把事情搞定，所以这里有 optimise 的空间！

    -   要 Minimise switching costs

    -   对 similar tasks 进行 Batch up

    -   Automation 在这方面做得极好

-   **Shape the default** \- ideal situation 是，让采取正确的 action 感觉就像 default，因此_不需要任何_ willpower

    -   这就是 routines 和 habits 背后的 underlying point

    -   这也可能涉及更宽泛的事情，比如 [changing 你的 self-image](https://www.neelnanda.io/blog/become-a-person-who-actually-does-things)

-   **警惕** [**trivial inconveniences**](https://www.lesswrong.com/posts/reitXJgJXFzKpdKyd/beware-trivial-inconveniences)——我发现，用 **activation energy** 来思考 decisions 很有帮助，也就是做这件事所需的、_perceived_ effort 的量。我的 willpower 就是花在_这上面_的。

    -   因此，微小的 inconveniences 很重要，因为它们_感觉_很大，所以 overcome 它们需要 willpower。我的 goal 是 minimise 所需的 willpower，而不是实际所需的 effort

    -   例如，从我的房间走到水龙头需要 20 seconds。这意味着我经常 dehydrated，因为再去接水是一种 trivial inconvenience。给自己买了一个大水壶之后，这个问题就_彻底解决_了

    -   通过_制造_ trivial inconveniences，这也能发挥很大作用。circumvent blocking software 有点麻烦，但它是一种 trivial inconvenience，所以我往往不会这么做。

一个好的 system 应当是：

-   **Robust** 且 **reliable** \- 在我希望它起作用时就能起作用，只需要 minimal 的 active maintenance

    -   Minimising decision points 是关键！例如，不要定成“每周去一次健身房”，而要定成“每周日早晨 10am 去健身房”

    -   注意：有些 systems _不可能_是 perfectly reliable 的。一个非常粗略的 rule of thumb：一个 robust system > 一个 weak system > 完全没有 system

-   **Efficient**——真正 reduces 实现某个 action 所需的 effort

有句好口号值得记住：“**我的 goal 是过一种 willpower 为 zero 的生活**”。这相当 idealised，在实践中不可能实现，在实践中也未必显然 desirable。但我发现，把它当作自己的 goal，往往能在 building systems 时激励我朝正确的方向前进。如果一个 system _by design_ 就要求我投入大量 effort，我就应该重新考虑。例如，如果每次接到 assignment，我都得强迫自己熬通宵，那我就是在犯傻，挥霍 willpower（还有 sleep！）。

然后，**implement 你的 systems**！这是我（以及其他所有人）总会忘记的 step——光是有个解决生活中某个 problem 的巧妙 idea 还不够，你还需要付出一些 effort，确保它感觉就像 default。这感觉没那么有成就感，却是_关键_。

最后，**review 并 iterate 你的 systems**。Building 一个好的 system _很难_，而且需要 time 和 effort。无论你多么努力，它都不太可能第一次就完美地起作用。在使用这个 system 一两周后，花点时间 review 它，留意 weak points，然后要么修好它，要么舍弃它。

方便的是，这两件事都能被 systematised！我维护着一份列有“to-implement”和“to-review” system ideas 的清单，并分别在每周二和周三下午清空它们。

我有一个粗略的 algorithm，确保自己走完这一整套过程：

1.  找到一个 problem

2.  Explore 这个 problem——仔细思考 examples 和 hypotheticals，对一个 hypothetical solution 进行 mindful walkthrough

3.  制定一个 plan！力求做到 **effortless** 且 **reliable**。

4.  进行 Reality Check：逐一检查 plan，让它变得 robust。我的主要 technique：想象一个它已经 broken 的世界，并尝试解释发生了什么

    1.  把制定粗略的 plan 和制定 robust plan 分开是有益的，否则很容易纠结于细节，结果什么也没做成

5.  进行 Implement！这一步_实在太_容易忘记了。我建议设一个 5 minute timer，并立刻开始 implementation。

6.  …

7.  进行 Review！

在实践中，这个 algorithm 是一份 high-effort guideline。照着它做，有助于 build 正确的 skills 和 intuitions，但实践中我经常会跳过一些 steps（不过_绝不_跳过 implementation step！）。如果这种 mindset 对你而言还不自然，我强烈建议照着它做！

在实践中，这个 algorithm 帮我 build 的 mental habits 是：

-   留意自己什么时候有 resource bottleneck，并[_采取一些行动来应对它_](https://www.neelnanda.io/blog/mini-blog-post-7-problems-are-for-fixing)

-   留意生活中什么时候有事情是 inefficient 的，并尝试修正——在实践中，这已经变成了一种相当本能的“呃，好恶心”的反应

-   留意那些消耗我 attention 和 willpower 的事情，问自己：“这真的有必要吗？”

-   留意自己什么时候在 [pressing the Try Harder button](https://www.neelnanda.io/blog/mini-blog-post-6-stop-pressing-the-try-harder-button)，问自己：“有没有什么巧妙的 hack 能绕过这个问题？”（剧透：答案通常是有）——例如，因为忘记某件事而 feel guilty 的时候

-   留意自己什么时候对某个 problem 的 solution 有了巧妙的 idea，却并没有_采取任何行动_，然后转向[真正 implementing 事情](https://www.neelnanda.io/blog/become-a-person-who-actually-does-things)！

个人 examples

COVID + social distancing 带来的一个意外好处是，过去 3 个月里，我对自己生活和 routine 的 control 比平时多了_很多_。所以，我一直在尝试尽人所能地将生活中的更多部分 systematising。这已经稍微有些过头了，不过我觉得自己学会了很多有用的 habits，而且打算保留下来！Systematisation 是一种相当 applied 的 mindset，而查看 examples 极其有用，所以接下来我要概述自己目前已经建立起来的所有重要 systems，希望能提供一些有用的启发！

一般注意事项：

-   这还是相当 experimental 的东西，我也一直在 tweaking 它

-   minimising willpower 与 spontaneity 之间存在一点 trade-off。我发现 spontaneity 对我并没有 _那么_ 有用，而向 minimising willpower 这一侧 trading off 会让我开心 _得多_，但你的情况可能不同

    -   不过请注意：这个 trade-off 远没有大多数人想象的 _那么_ stark。通常，一个好的 system 由我的 [outer optimiser](https://www.neelnanda.io/blog/mini-blog-post-9-what-it-means-to-optimise) 来完成，而 seeking spontaneity 则由我的 [inner optimiser](https://www.neelnanda.io/blog/mini-blog-post-9-what-it-means-to-optimise) 来完成

        -   例如，我在特定时间工作，但我 _如何_ 完成工作的细节完全自由

        -   例如，我安排好休息时间，并在这些时间做任何我认为最 rejuvenating 的事情

        -   甚至还可以有一个 explicit system，确保我会 seek out spontaneity，而不是总被 short-term busywork 缠住！

-   我的 systems 各不相同，有些是“尽量做到 robust”，有些则是“如果我认为改变它是个好主意，就可以改变，但它应该让人感觉像 default”

我的一天：

-   早晨的 routine

    -   每天在同一时间设置闹钟——这似乎能明显 improve 我的 sleep

    -   起床第一件事就是 Take medication——我把它放在窗边，所以拉开窗帘时首先看到的就是它

    -   我有 10 minutes 来做其他想在起床后立刻做的事情

        -   Check 我的 calendar，看看我要做什么，并给每个要和我通话的人发消息确认

        -   用 [Complice](https://complice.co/) 来 planning 我的一天（这会 reduces 关于每个时刻做什么的 decision load，并 practices “estimate 我一天能够 feasibly 做什么”这一 skill）

        -   在我的 [habits spreadsheet](https://www.ultraworking.com/lights) 中 Track 前一天的情况——这是一种有用的方式，可以提醒自己那些正在忘记的 habits，并 track 哪些没有起作用

            -   这充当了一个很好的 scaffold system，让添加新的 habits 更容易

        -   为了帮助自己坚持下来，我使用 [Freedom](https://freedom.to/)，在这 10 minutes 内 block distracting websites

    -   然后，我的 laptop 会通过 [Cold Turkey](https://getcoldturkey.com/) 来 automatically locks——这就免去了起身去洗手间所需的 willpower

    -   然后，我花 15 minutes，一边刷牙等一边做 [Anki](https://ankiweb.net/)——[Lock Me Out](https://play.google.com/store/apps/details?hl=en_GB&id=com.teqtic.lockmeout) 会把我的 phone 设置为只能做 Anki

-   上午的工作

    -   我按 50 minute pomodoros 工作——这是一个很适合用来思考的“unit of work”，也是我基本能够保持 focus 的一段时间

        -   我在开始和结束时快速填写一份 [form](https://docs.google.com/forms/d/e/1FAIpQLSd15ild3HRCc8N3VebWZwkkpuLV5H6wJRpS-oQoImFzycrfRg/viewform)，predicting 我将做什么，并 calibrating 我做了什么——这能 improves 我对于自己在 50 minutes 内 realistically 能完成什么的 standards。我的 standards 在 default 情况下高得离谱，而这能 increases 我的 net satisfaction

            -   Google forms 是 set up 一个 system 的 _绝佳_ 方式——它像一个更 modular 的 checklist，会 stores 我的全部 answers，供以后 review，并让“以正确的方式做事”只需要 minimal decision making

    -   我使用 [Focusmate](http://focusmate.com/)，安排几次与陌生人的 50 minute co-working calls（双方各自独立工作，同时保持 muted）

        -   这让“在正确的时间工作”感觉像 default，并 minimises 所需的 willpower——如果我不出现，我知道对方就会难以 focus，所以出现会让人感觉像 default action

        -   这是一个 _非常_ 因人而异的 system，但我 estimate，在过去几个月里，它让我更加 productive，提升幅度 >20%——它 significantly reduces 我浪费的时间

    -   我把 phone 设置为在每次 pomodoro break 中 lock 10 minutes，并设置手表闹钟，提醒自己去外面，例如阅读、meditate 或躺一会儿——在 default 情况下，我不擅长进行 rejuvenating breaks

    -   我尽量把一天的前半段留给 highest priority project，后半段留给一个 side project（目前是 blogging，因为这实在太他妈耗时了……）——我发现同时推进几个 projects 要有趣得多，而这样不必直接 prioritise 就能做到

-   我尽量在午饭时通个电话——[Calendly](https://calendly.com/) 让我很容易在那一小时内 schedule 事情，而且我相当 extroverted，所以觉得这很 energising

-   之后，我把 phone 和 laptop 设置为 lock 半小时，让自己进行一次“no screen time”的休息，例如阅读、散步、做些家务

-   下午的工作——与上午类似

    -   我尽量从中留出 2 hours，给各种 meta habits

-   傍晚

    -   尽量把这段时间主要用来通话——这绝对是我最喜欢 + 最 energising 的 leisure time 度过方式，而且它所 uses 的 energy pool 与“focus 于工作”相当不同

        -   Calendly 依然能让这件事的 scheduling 变得 effortless！

-   夜间

    -   服用一些 [melatonin](https://www.gwern.net/Melatonin)（这不是 medical advice，如果你从我这里获取 medical advice，那你就是个傻瓜。但我认为它值得了解一下！）

    -   我让 phone + laptop 在就寝前一小时 lock，尽量在前半小时出去晚间散步，后半小时读一本 physical book

        -   强烈推荐用这段时间读点东西！（没有 backlight 的 Kindles 也很好）。我发现，开始逐一阅读自己的“待读”清单特别令人满足，这也让我更有动力坚持良好的 sleep hygiene

    -   我的 [lightbulb](https://www.amazon.co.uk/adjustable-dimmable-required-HomeKit-Assistant/dp/B0753SBGK2/ref=sr_1_1?crid=RQKYKMBXVQUR&dchild=1&keywords=lifx%20day%20dusk&qid=1593359106&sprefix=lifx%20day%2Caps%2C157&sr=8-1) 会在这半小时内自动变得 redder 和 dimmer，接着变得 _非常_ dim，持续 2 minutes，然后关闭。这让我进入良好的 sleep mindset，并让“在正确的时间上床睡觉”感觉像 default——重新打开它就是一种 trivial inconvenience！

其他 systems：

-   社交（Social）

    -   我用一个 spreadsheet 来 keeping track of 上次与朋友交谈的时间，并提醒自己何时再次问候或 schedule 一次通话

        -   这真是个 _特别_ 好的主意——当我在现实生活中见不到别人时，很容易忘记他们的存在，而这能在不 consuming mental energy 的情况下纠正这个问题

        -   有了一个 robust system，这也能确保我与那些不那么亲近的朋友保持联系，例如，我希望每隔几个月问候一次的朋友

    -   要 schedule 什么，我只需发送一条预先写好的消息 + 一个 Calendly link——这让保持联系变得 _极其_ low effort

        -   Calendly 很棒，因为它确保 scheduling 在我提供 0 input 的情况下也能 functions，而且别人可以 reschedule、cancel、选择最喜欢的时间等。我发现 scheduling 是 willpower 的一大 drain，因为其中涉及许多来回沟通、别人回复缓慢、大家忙碌等情况。

    -   有些人觉得这样过于冷漠——我的个人看法是，这意味着我能更多地见到朋友，又不会消耗自己，而这显然比其他任何因素都重要。

    -   我发现，这是解决 social initiative 这一 problem 的一个好 solution——empirically，大多数人不容易想起“我有一阵子没和 Neel 说话了，应该联系一下”，所以拥有 robust systems 来让自己做这件事，能确保我与所有朋友都保持密切联系

-   日历（Calendar）

    -   拥有一个 digital calendar 是个 _绝妙_ 的 decision——这意味着，只要我能坚持“把所有 events 放入我的 calendar”和“每天 check 我的 calendar 几次”这些 habit，我就能 organised，并记住所有 commitments。养成这些习惯花了一些 effort，但已经带来了 _极大_ 的回报

    -   这还能与 Calendly 很好地 integrates！

-   待办清单（To-do list）

    -   我非常喜欢 [Trello](http://trello.com/)——它是一个 to-do list，让我非常容易 add 事情（例如，无论我当前处于哪个 window，CTRL+ALT+SPACE -> type the note -> enter 都会 create 一个新的 item）

        -   我发现，拥有一个“要做的事”的 queue，而不是 reminders，很有价值——我有些星期忙，有些星期清闲。这能确保，如果一个 system 在忙碌的一周 breaks，我还能在清闲的一周重新捡起来

-   元层面（Meta）

    -   我每周做一次 weekly review——我会 review 这一周的情况，包括 productivity + social，并 plan 下一周

        -   我添加了一些不错的 habits：

            -   记下所有让我心怀感激的人，并发消息告诉他们原因

            -   Noticing 令人不快的 interactions，并 brainstorming 哪些地方不好，以及下次如何 improve

            -   写下我目前最大的 bottleneck

            -   写下这周一次很棒的 success

    -   随兴的下午（Afternoons of Whimsy）：我每周留一个自由的下午，忘掉所有 external obligations 和 goals，去做“任何我觉得最 intrinsically exciting 的事情”——我认为，following intrinsic curiosity 是一种有价值、但我很不擅长的 skill，而 explicit practice 对此有所帮助

    -   我每周留出 2 个下午进行 debugging——想透生活中的 problems、designing 和 implementing solutions，并 reviewing solutions

        -   我在一个 Trello board 中 track 这一切，这能确保我记得 implement + review 各件事，并 keep track of 以前的想法

    -   这是 Experimental 的安排：我每周留一个下午想透自己的 high-level goals（我怀疑自己不会长期坚持，但过去三周这样做还挺有意思）

-   生活杂务（Life admin）

    -   我每周留一个下午，处理所有积累下来的琐碎、无聊的 administrative tasks——这样能把事情做完，而且只需 minimal energy，因为这些事情的大部分 cost 都是 switching costs。我已经形成一种 reflex，会把它们 add 到 Trello，然后就可以忘掉它们

结语（Conclusion）

我发现，thinking in systems 是我为把事情搞定、弥补自己普遍缺乏 willpower 而培养出的最有价值的 life skills 之一。希望这些 systems 中至少有一个让你产生了共鸣！（而且你不会觉得我 _太_ 古怪）。如果有什么看起来有意思，或者这篇文章中的任何想法给了你启发，请记住——世界的 default state 是，你会忘记 implement 这些事情。如果你从未把这篇文章中的想法付诸行动，你会感到意外吗？你能不能 _现在就_ 做些什么来 change 这个 default，让自己真正行动起来？

## 原文

_(This post is about the mindset of thinking in systems and routines. This post is mostly from my perspective, but the technique is pretty subjective. I’ve written up a_ [lesson plan](https://dynalist.io/d/pgngbu6nDQbQzu1Gcof3Dj1i#z=pznohefw9903y9277WlU56fW) _aimed more at teaching the tools for how to find systems for_ your _problems)_

Introduction

This is a post about **systems** and **willpower**. Willpower is a pretty fuzzy concept, for the purposes of this post I will define it as “that which is expended when I get myself to do something that isn’t the default action”. I find thinking in terms of willpower a _key_ lens for examining my life, because I consider myself to be a person with unusually low willpower (at least, relative to my social circle of bullshit high-achievers). And this is really, really bad, because willpower is the obvious tool for taking the actions I want to take to achieve my goals. This post is my attempt to outline my various tools and hacks for getting around this, and taking the actions I care about _anyway_.

The key underlying idea here is that **willpower is a limited resource**. Every time I need to do something a bit unpleasant, every time I need to make a decision, I expend a bit of willpower. And when I run out of willpower, I just feel _super_ tired, everything feels like it would take far too much energy, and it’s easy to fall into un-fun spirals of procrastination. This is especially bad, because these spirals of procrastination aren’t _fun_. There are “unproductive” things I can do that rejuvenate me, like going for a walk, meditating or reading a good book. But when I have zero willpower, I tend to do far less rejuvenating things, like scrolling endlessly through Reddit. It’s not that I’m torn between productivity and relaxation - it’s easy to fall into the trap of getting _neither_. So figuring out how to solve this is one of my key bottlenecks. And if you relate to the descriptions so far, I hope these tools can be useful to you too!

It’s easy to slip into guilt/self-hate about this kind of thing, and seeing it as a personal weakness. But this is obviously dumb. Guilt is a mental mechanism that prompts me to choose to take actions _by spending willpower on them_. Guilt is an _awful_ solution to lacking willpower. [Guilt lives in my mind, while my goals live in the world](https://www.neelnanda.io/blog/mini-blog-post-12-the-map-and-the-territory) - if guilt does not help me achieve my goals, guilt is a dumb emotion. I find the framing of willpower as a finite resource _far_ more fruitful. It would be dumb to feel guilty about lacking time to achieve all of my goals - I need to either be more efficient about how I spend my time, or have fewer goals. And exactly the same logic applies to willpower - it’s a more abstract and less objective resource, but a finite resource nonetheless.

And my main tool here are **systems**. I define a system as anything I can set up in advance, that lets me take actions in future **while spending less willpower**. It’s easy to fall into the trap of just [pushing the Try Harder button](https://www.neelnanda.io/blog/mini-blog-post-6-stop-pressing-the-try-harder-button) - essentially assuming willpower is limitless and I can just try harder next time. Systems are a way to short-circuit this failure mode, zooming out and ensuring that I am [deliberate](https://www.neelnanda.io/blog/be-deliberate), and focus on the desired actions rather than the mental state behind them.

Thinking in Systems

People often conflate systems and routines, but for me this is a much broader idea. Some important categories:

-   Routines

    -   Time based: morning, evening, etc

    -   Location/context based: what to do upon getting into work, a lecture

-   Algorithms

    -   Checklists

    -   Policies - eg having a clear plan for exactly what to do when I am too tired to focus while working

-   Automation

    -   Eg Calendars, reminders, spreadsheets, etc

-   Triage - prioritising things, quitting things, managing commitments well

    -   This does _seem_ like a central example of a system, but often quitting something unnecessary can be the _best_ way to free up time and willpower

The underlying point here is that systemisation is a _mindset_, not an algorithm. It’s the perspective of looking at your life, noticing the parts that are inefficient, or require willpower, or just never get done

Some tips for finding a starting point - a thing that needs systematising:

-   Think about the abstract resources in _your_ life. For me, the biggest and most important resource is willpower, but this is pretty subjective. For you it might be money, energy, time, health, focused time, mental energy, social energy, etc. Look for the biggest bottleneck, look for the places you spend that resource the most, and think about how you could systematise it

-   Look for **inefficiency**. Spend the next 24 hours going through your life mindfully. Notice the things that feel off, the things that feel like “there _must_ be a better way”, and see if you can make a system that improves this

    -   Underlying point - it’s easy to miss the trivial inconveniences in our lives, but these add up substantially. A minute of wasted time a day is 6 hours of wasted time over a year. If there’s a small annoyance that’s easy to fix, fix it!

-   Managing attention - look for things you always forget, or struggle to remember. Keeping something in the back of your mind consumes attention and willpower. And see if you can find ways to still get the important ones done, without consuming as much attention

    -   Routines and to-do list systems are valuable for this. Eg, I accumulate a bunch of tiny, boring tasks over time. Non-urgent emails to respond to, things I want to buy, messages I need to respond to, etc. These all consume a bit of my attention. My solution is to keep a to-do list in [Trello](http://trello.com/), and every Saturday afternoon to priority order it and do as much as I can - these tasks stop consuming my attention, but still get done!

There are some underlying points to always bear in mind with systems:

-   **Minimise decision points** - the main thing that consumes willpower isn’t the process of doing a task, it’s _deciding to do the task in the first place_. My goal is to get shit done, not to _decide_ to get shit done, so there’s room to optimise!

    -   Minimise switching costs

    -   Batch up similar tasks

    -   Automation does this extremely well

-   **Shape the default** \- the ideal situation is for doing the right action to feel like the default, so it takes _no_ willpower

    -   This is the underlying point behind routines and habits

    -   This can involve broader things, like [changing your self-image](https://www.neelnanda.io/blog/become-a-person-who-actually-does-things)

-   **Beware** [**trivial inconveniences**](https://www.lesswrong.com/posts/reitXJgJXFzKpdKyd/beware-trivial-inconveniences) - I find it useful to think of decisions in terms of **activation energy**, the amount of _perceived_ effort required to do it. _This_ is what I spend willpower on.

    -   Thus tiny inconveniences are a big deal, because they _feel_ big, and thus is takes willpower to overcome them. My goal is to minimise willpower required, not actual effort required

    -   Eg, My room is 20 seconds walk from a tap. This means I’m frequently dehydrated, because getting more water is a trivial inconvenience. This was _completely solved_ by getting myself a large water jug

    -   This can also be powerful by _creating_ trivial inconveniences. It’s a minor pain to circumvent blocking software, but it’s a trivial inconvenience, so I often don’t do it.

And a good system should be:

-   **Robust** and **reliable** \- something that will work when I want it to, with a minimal amount of active maintenance

    -   Minimising decision points is key! Eg, don’t “go to the gym once a week”, “go to the gym at 10am every Sunday morning”

    -   Note: Some systems _can’t_ be perfectly reliable. Very rough rule of thumb: A robust system > a weak system > no system at all

-   **Efficient** - something that actually reduces the effort required to achieve an action

A good slogan to bear in mind: “**my goal is to live a life with zero willpower**”. This is pretty idealised, impossible in practice, and not obviously desirable in practice. But I find thinking of this as my goal tends to motivate me in the right direction when building systems. If a system requires me to put in a lot of effort _by design_, I should reconsider. Eg, if every assignment I get requires me to force an all-nighter, I am being an idiot and squandering willpower (and sleep!).

Then, **implement your systems**! This is the step that I (and everybody else) always forgets - it’s not enough to have a clever idea for solving a problem in your life, it will take some effort to ensure it feels like the default. This doesn’t feel as rewarding, but is _key_.

And finally, **review and iterate your systems**. Building a good system is _hard_, and takes time and effort. It’s unlikely to work perfectly the first time, no matter how hard you try. Once you’ve had the system for a week or two, take some time to review it, notice weak points, and either fix it or discard it.

Conveniently, these can both be systematised! I maintain a list of “to-implement” and “to-review” system ideas, and empty out that list every Tuesday and Wednesday afternoons (respectively).

I have a rough algorithm to ensure I go through this all:

1.  Find a problem

2.  Explore the problem - think through examples and hypotheticals, do a mindful walkthrough a hypothetical solution

3.  Make a plan! Strive to be **effortless** and **reliable**.

4.  Reality Check: go through the plan and make it robust. My main technique: Imagine a world where it has broken and try to explain what happened

    1.  It’s good to separate making a rough plan and making a robust plan, otherwise it’s easy to agonise over details and get nothing done

5.  Implement! It’s _so_ easy to forget this step. I recommend setting a 5 minute timer, and getting started on the implementation immediately.

6.  …

7.  Review!

In practice, the algorithm is a high-effort guideline. It’s useful to do it to build the right skills and intuitions, but in practice I’ll often skip some steps (but _never_ skip the implementation step!). If this mindset doesn’t come naturally to you, I highly recommend following it!

In practice, the mental habits this algorithm has helped me to build are:

-   Notice when I have a resource bottleneck, and [_do something about it_](https://www.neelnanda.io/blog/mini-blog-post-7-problems-are-for-fixing)

-   Notice when something is inefficient in my life, and try to fix it - in practice this has become a pretty visceral “ew” reaction

-   Notice the drains on my attention and willpower, and ask myself “is this really necessary?”

-   Notice when I’m [pressing the Try Harder button](https://www.neelnanda.io/blog/mini-blog-post-6-stop-pressing-the-try-harder-button), and ask myself “is there a clever hack around this?” (spoilers: the answer is usually yes) - eg when I feel guilty for forgetting something

-   Notice when I have a clever idea for a solution to a problem, but am not _doing anything_ about it, and pivot into [actually implementing things](https://www.neelnanda.io/blog/become-a-person-who-actually-does-things)!

Personal examples

One of the unexpected benefits of COVID + social distancing, is that I’ve had a _lot_ more control over my life and my routine than normal the last 3 months. So I’ve been experimenting with systematising as much of my life as is humanly possible. This has gone slightly too far, but I think I’ve learned a lot of useful habits that I intend to keep! Systematisation is a pretty applied mindset, and it’s extremely useful to see examples, so I’m now going to outline all of the important systems I’ve currently built up, and hope this provides some useful inspiration!

General warning notes:

-   This is pretty experimental, and something I’m constantly tweaking

-   There’s a bit of a trade-off between minimising willpower and spontaneity. I’ve found that spontaneity isn’t _that_ useful to me, and I’m a _lot_ happier trading off towards minimising willpower, but your mileage may vary

    -   Though note: this trade-off is _much_ less stark than most people think it is. Often a good system is done by my [outer optimiser](https://www.neelnanda.io/blog/mini-blog-post-9-what-it-means-to-optimise), while seeking spontaneity is done by my [inner optimiser](https://www.neelnanda.io/blog/mini-blog-post-9-what-it-means-to-optimise)

        -   Eg, I’m working at specific times, but the details of _how_ I get work done are totally free

        -   Eg, I set out times for having breaks, and do whatever I think is most rejuvenating in these times

        -   Or, even, have an explicit system to ensure I seek out spontaneity, rather than perpetually getting caught up in short-term busywork!

-   My systems vary with regards to “try to be as robust as possible” and “I can change this if I think it’s a good idea, but it should feel like the default”

My day:

-   Morning routine

    -   Have an alarm for the same time every day - this seems to notably improve my sleep

    -   Take medication first thing - I keep this next to the window, so it’s the first thing I see when I open the curtains

    -   I have 10 minutes for doing other things I want to do first thing

        -   Check my calendar for what I’m doing, and message every person I’m having a call with to confirm

        -   [Complice](https://complice.co/) for planning my day (this reduces decision load for what to do at each point, and practices the skill of “estimate what I can feasibly do in a day”)

        -   Track the previous day in my [habits spreadsheet](https://www.ultraworking.com/lights) - this is a useful way to remind myself of habits I’m forgetting about, and to track which ones aren’t working

            -   This serves as a good scaffold system, that makes it easier to add new habits

        -   To help this stick, I use [Freedom](https://freedom.to/) to block distracting websites for the 10 minutes

    -   Then my laptop automatically locks with [Cold Turkey](https://getcoldturkey.com/) - this removes the willpower required to get up and go to the bathroom

    -   Then I spend 15 minutes doing [Anki](https://ankiweb.net/) while brushing my teeth etc - [Lock Me Out](https://play.google.com/store/apps/details?hl=en_GB&id=com.teqtic.lockmeout) sets my phone to only be able to do Anki

-   Morning work

    -   I work in 50 minute pomodoros - this is a good “unit of work” to think in terms of, and a time period I can mostly focus for

        -   I fill out a quick [form](https://docs.google.com/forms/d/e/1FAIpQLSd15ild3HRCc8N3VebWZwkkpuLV5H6wJRpS-oQoImFzycrfRg/viewform) at the start and end predicting what I’ll do, and calibrating what I did - this improves my standards for what I can realistically do in 50 minutes. By default my standards are way too high, and this increases my net satisfaction

            -   Google forms are an _awesome_ way to set up a system - it’s like a more modular checklist, that stores all of my answers to review later, and makes “do things the right way” take minimal decision making

    -   I use [Focusmate](http://focusmate.com/) to arrange several 50 minute co-working calls with strangers (both people working on their work independently, while muted)

        -   This makes “work at the right time” feel like the default, and minimises willpower required - if I don’t show up, I know they’ll struggle to focus, so it feels like the default action

        -   This is a _strongly_ “your mileage may vary” system, but I estimate it’s made me >20% more productive over the last few months - it significantly reduces my amount of wasted time

    -   I set my phone to lock for 10 minutes in each pomodoro break, and a watch alarm to remind me to go outside and eg read, meditate or lie down - I am bad at taking rejuvenating breaks by default

    -   I try to keep the first half of my day for my highest priority project, and the second half for a side project (currently blogging, because this takes too damn long…) - I find it much more fun to have several projects on the go at once, and this achieves that without needing to directly prioritise

-   I try to have a call over lunch - [Calendly](https://calendly.com/) makes it easy to schedule things during that hour, and I’m pretty extroverted so I find this energising

-   I set my phone and laptop to lock for half an hour after that, to get me to take a “no screen time” break, eg reading, going for a walk, doing some chores

-   Afternoon work - similar to the morning

    -   I try to keep 2 hours of this for various meta habits

-   Evening

    -   Try to mostly fill this with calls - it’s by far my favourite + most energising way to spend leisure time, and uses a pretty different energy pool from “focus on work”

        -   Calendly continues to make scheduling this effortless!

-   Night

    -   Take some [melatonin](https://www.gwern.net/Melatonin) (this is not medical advice, and if you take medical advice from me, you’re an idiot. But I think it’s worth looking into!)

    -   I have my phone + laptop lock an hour before my bedtime, I try to go for an evening walk for the first half hour, and read a physical book for the second half hour

        -   Strong recommend for using this time to read something! (Kindles with no backlight are also good). I’ve found it super satisfying to start working through my “To be read” list, and this makes keeping to good sleep hygiene much more motivating

    -   My [lightbulb](https://www.amazon.co.uk/adjustable-dimmable-required-HomeKit-Assistant/dp/B0753SBGK2/ref=sr_1_1?crid=RQKYKMBXVQUR&dchild=1&keywords=lifx%20day%20dusk&qid=1593359106&sprefix=lifx%20day%2Caps%2C157&sr=8-1) automatically gets redder and dimmer for this half hour, goes _very_ dim for 2 minutes, then turns off. This gets me in a good sleep mindset, and makes “go to bed at the right time” feel like the default - turning it back on is a trivial inconvenience!

Other systems:

-   Social

    -   I have a spreadsheet keeping track of when I last spoke to friends, and reminding me when to next check in/schedule a call

        -   This was _such_ a good idea - it’s really easy to forget people exist when I’m not seeing them in real life, and this rectifies that without consuming mental energy

        -   With a robust system, this also ensures I keep in touch with less close friends, who I eg want to check in on once every few months

    -   To schedule something, I just send a pre-written message + a Calendly link - this makes keeping in touch _incredibly_ low effort

        -   Calendly is wonderful, because it ensures scheduling functions with 0 input from me, and people can reschedule, cancel, choose their favourite time etc. I find scheduling is a major drain of willpower, because it involves a lot of back-and-forth, people being slow at responding, being busy etc.

    -   Some people find this overly cold - my personal view is that this means I see my friends much more, without being a drain on me, and this obviously outweighs every other factor.

    -   I find this is a good solution to the problem of social initiative - empirically most people will not easily remember “I haven’t spoken to Neel in a while, I should reach out”, so having robust systems to do this myself ensures I stay in close touch with all of my friends

-   Calendar

    -   Having a digital calendar was an _amazing_ decision - this means I’m organised and remember all of my commitments, so long as I can stick to the habit of “put all events into my calendar” and “check my calendar several times a day”. These took a bit of effort to build, but have _majorly_ paid dividends

    -   This integrates nicely with Calendly!

-   To-do list

    -   I am a big fan of [Trello](http://trello.com/) - it’s a to-do list which lets me add things very easily (eg CTRL+ALT+SPACE -> type the note -> enter will create a new item, no matter what window I’m currently in)

        -   I find it valuable to have a queue of “things to do” rather than reminders - I have busy weeks and quiet weeks. This ensures that if a system breaks during a busy week, I can pick it back up again in a quiet week

-   Meta

    -   I do a weekly review once a week - I review how the week went, productivity + social, and plan the next week

        -   Nice habits I’ve added:

            -   Noting down everyone I feel grateful to, and messaging them why

            -   Noticing unpleasant interactions, and brainstorming what was bad and how I can improve this next time

            -   Writing down my current biggest bottleneck

            -   Writing down an awesome success this week

    -   Afternoons of Whimsy: I have a free afternoon each week to forget all external obligations and goals and do “whatever I find most intrinsically exciting” - I think following intrinsic curiosity is a valuable skill that I suck at, and explicit practice is helpful with this

    -   I have 2 afternoons a week for debugging - thinking through problems in my life, designing and implementing solutions, and reviewing solutions

        -   I track all of this in a Trello board, this ensures I remember to implement + review things, and keep track of old thoughts

    -   Experimental: I have an afternoon a week for thinking through my high-level goals (I doubt I’ll keep this long-term, but it’s been interesting for the past three weeks)

-   Life admin

    -   I keep an afternoon a week for doing all the tiny, boring administrative tasks that accumulate - this gets stuff done, and is minimal energy, because most of the cost of these is switching costs. I have a reflex to add them to Trello, and then can forget about them

Conclusion

I’ve found thinking in systems one of the most valuable life skills I’ve ever developed for getting shit done, and compensating for my general lack of willpower. Hopefully at least one of those systems resonated with you! (And you don’t think I’m _too_ weird). If anything seemed interesting, or any of the ideas in this post have inspired you, remember - the default state of the world is that you will forget to implement things. Are you surprised if you never act on the ideas in this post? And can you do anything _right now_ to change the default so that you do?
