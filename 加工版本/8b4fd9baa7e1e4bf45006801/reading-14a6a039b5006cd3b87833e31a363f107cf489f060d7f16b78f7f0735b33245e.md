### 基本语法

> 在深度使用任何生产力工具之前，最好的方式是使用它的默认配置，除非你知道自己在干什么。

通过阅读下面的语法和注释，在文章结束时你就应该可以直接上手，使用 obsidian 愉快的生成笔记了！

### 1\. 设置当前笔记对应的 deck

针对单独的笔记，我们可以使用单行或多行格式[$$4$$](https://zhuanlan.zhihu.com/p/20212941627#ref_4)。关键字（默认设置）为 `TARGET DECK`。下面是官方文档中的两个例子。

```text
# 多行文本
TARGET DECK
Mathematics

# 单行文本
TARGET DECK: Mathematics
```

### 2\. 撰写单个 note

在 Anki 中，每个 `deck` 对应着多个 `note`, 而每个 `note` 可以生成多张卡片（例如，通过 cloze 挖空的形式）。在 `obsidian` 中，我们要编辑的是 Anki 中的 `note`。为了与正文区分，从而让插件可以识别我们的 `notes`,我们需要使用特定的语法格式。下面主要以 `cloze` 模板为例，说明具体的操作。

> 这里列出 cloze 的原因是笔者只使用这一种模板来应对各类笔记。如果你想使用其他的格式，请参考官方文档。

### 2.1 一般格式(多行）

这里简单的提一下通用的语法，方便大家使用其他模板。

```text
{START_declaration}
Basic
{Front}: This is a test
{Back}: Test successful
{End_declaration}
```

上面示例中 `START_declaration` 代表开始一张 note 的关键字，默认为 `START`。`End_declaration` 同理，默认为 `END`。`Basic` 为模板名称，`Front` 和 `Back` 为模板对应的各个 `field`。 这里`{` `}` 需要省略。

下面是一个具体的例子以及对应的效果图。

```text
START
Basic
Front: How to format a field in `obsidian_to_anki` plugin?
Back: Apart from the first field, each field must has a prefix (:) to indicate the its *field name*.
END
```

basic 模板效果图

### 2.2 单行 Note

这个插件同样支持单行 Note 。具体的格式为：`{inline_start} [{Note Type}] {Note Data} {inline_end}`，其中 `inline_start` 和 `inline_end` 对应的默认关键字为 `STARTI` 和 `ENDI`。

下面是一个简单的使用 cloze 模板的示例：

```text
STARTI [Cloze] You can have {{c1::a bullet point list of inline notes}} <!--ID: 1720158517556--> ENDI
```

> 这里的 `ID` 是卡片对应 `nid`, 可以在 Anki 中使用 `nid:`1720158517556 来查找对应卡片。

这里插一句题外话，上面的 cloze 是一个很典型的错误示例。正确的做法是仅对 _bullet point_ 挖空。

### 2.3 Cloze Note

在 obsidian 中挖空的形式和 Anki 中是一样的，及使用 {{c1:: text}} 格式。值得注意的是，在对数学公式进行挖空时，要注意公式内部连续的 }} 与挖空的语法冲突。解决方式很简单，就是在数学公式内部连续的 }} 中间加一个空格，变成 `} }`。

> 笔者同样写了一个 `popclip` 插件，用来自动解决挖空和解决上面数学公式的问题。

Anki 与 popclip 结合经验贴见:

Cloze 模板对应的多行/单行语法如下。

**多行格式**

```text
START
Cloze
Hello {{c1::World}}
Extra:
Some extra information
END
```

**单行格式**

```text
STARTI [Cloze] Hello {{c1::World}} ENDI
```

### 4\. 删除笔记

当对应的 nid 或 Anki 卡片已经生成时，我们需要通过在 `<!--ID:xxx>` 上放添加 DELETE 来删除对应卡片。之后，需要点按工具栏左侧插件图标与 Anki 同步删除 。

删除单行笔记同理，但需要在笔记内容和 DELETE 添加一个空格以示区分。
