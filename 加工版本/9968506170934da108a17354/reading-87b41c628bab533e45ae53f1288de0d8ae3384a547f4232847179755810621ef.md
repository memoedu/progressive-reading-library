# 世界模型初探与碎碎念——写在博一结束

## 阅读前置卡

- 价值判断：中。文章是个人科研随笔，记录了从UMMs转向世界模型的过程，包含具体项目（InternVLA-M1、SRUM、UniSandbox、Universe、Echo-Memory）和实验结论，对关注该领域的研究者有参考价值，但整体是个人经验分享，非系统性综述或重大突破，价值中等。
- 信息密度判断：中。全文约2300字，包含多个项目名称、技术术语和实验结论，信息量尚可，但多为概述性描述，缺乏深入技术细节，密度中等。
- 是否继续阅读：2 概览与关键结论。文章提供了作者从UMMs转向世界模型的个人历程和Echo-Memory项目的核心结论，适合快速了解其研究思路和项目概况，但深度有限，无需精细阅读。

## 核心洞察

一、UMMs路线遇阻：持续训练成本高且效果有限：作者在完成InternVLA-M1、SRUM、UniSandbox和Universe等项目后，彻底感觉到UMMs（统一多模态模型）可能没有想象中通向未来。用预训练完成的VLM进行持续训练（continual training）的成本比预期高很多，且很难达到更好的效果，这促使作者迷茫并转向世界模型研究。
[[#^pr-4ef2a60dff92|正文跳转]]

二、世界模型研究契机：与Cambrian-S团队直觉契合：作者开始世界模型研究的契机是Saining老师、Jihan和Shusheng等人完成了Cambrian-S项目。作者对Supersensing感到amazing，在与Saining老师交流时发现很多直觉（intuition）不谋而合，尤其是关于Streaming World Model及其Memory机制的实现，这促使作者下定决心抛开UMMs积累，转向世界模型和视频生成研究。
[[#^pr-42a8e1edadd5|正文跳转]]

三、记忆方法四分类：基于100多篇论文的规约：作者在Mentor Zeyue给予较大探索自由度的情况下，梳理了最近一年多以来的100多篇Memory相关论文，结合agent总结，将记忆方法规约为四种模式：Context（原始上下文）、Compression（压缩）、Spatial（空间摘要）、State-Space（块状递归）。这为后续公平比较记忆机制奠定了基础。
[[#^pr-c29b19d7c3b7|正文跳转]]

四、现存记忆比较不公平：缺乏统一基准：作者在文献综述后强烈感觉到，现存的世界模型记忆比较并不公平：数据、模型甚至评估接口都没有完全统一，各框架各有各的比较模式，难以得出什么记忆机制更有潜力、更可扩展（scalable）的结论。这直接催生了Echo-Memory项目，旨在通过固定其他变量、只换记忆模块来公平比较。
[[#^pr-8872453f5261|正文跳转]]

五、Echo-Memory核心发现：Block State-Space泛化性强但一致性不足：Echo-Memory采用固定backbone、训练、采样器和评测，只更换记忆模块，公平比较四类设计。结果超出作者作为传统视觉人的先验：Block State-Space具有很强的泛化性，尽管其一致性（consistency）质量不够高。这暗示记忆能力可能与提升单纯视觉质量解耦（decouple），结构化信息可能更重要。
[[#^pr-6ab573295c93|正文跳转]]

六、零基础团队从一般基础模型训练出五分钟级一致结果：作者团队在几乎零基础的情况下，从头在一个比较一般的基础模型LTX2.3上训练，得到了五分钟级别音频和视频都比较一致（consistency）的结果。这超出作者想象，表明即使基础模型一般，通过细致工作和公平实证研究也能取得可观成果。
[[#^pr-f468cc959c4b|正文跳转]]

七、研究风格：以实证消融验证想法，重视工程化：团队正职大哥非常细致，为说服对方会额外做多组消融，通过公平的实证研究（empirical study）验证想法。理论分析不一定是公式推bound，也可以是practical的推断和结论，这符合其研究品味，也体现在工程化问题上。
[[#^pr-5f49f14bed2d|正文跳转]]

八、未来计划：更新支持动态数据的V2版本：作者自认仍是视频领域新人，很多infra设计如架构细节仍在学习。同时认为记忆设计和探索仍有更多道路，团队后续将更新支持动态数据（dynamic data）的V2版本，逐步推进世界模型领域到预期状态。

## 正文

大家好，我已经很久没在知乎写随性的随笔了，恰逢合适的契机，想聊聊我探索世界模型的心路，顺带复盘博士生涯起步阶段的经历。

记得去年这个时候，和 [@Purshow](https://www.zhihu.com/people/f9f03a9f446b156c6005b1cdef98586d) 当时初入 Unified Multimodal Models 这个领域，我们对于之前比如 MetaQuery 还有 MetaMorph 给出的有趣结论很关心，然后就基于一些数据开始自己训练，但是失败了，可能确实是当时的大家还是太稚嫩，没有什么基础模型训练的经验。我们一开始的野心很高，想要打败 OpenUni 做一个真正的有影响力的甚至可以说在 UMMs 领域 LLaVA 的那种开源项目，但是显然还是各种意义不够充分。

后面到了毕业假期，辗转来到了 ailab，期间和 [@阿汐猫猫](https://www.zhihu.com/people/6b551ee37100b681d39c71da84da0002) 完成了 InternVLA-M1 这个项目，开始对具身（VLM initial）的有了初步认知。然后在博士入学前，顺便利用薅羊毛到手的资源把 [SRUM](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/2510.12784) 做完，期间 xihui 老师给了很多支持和引导，稍微 Recycle 了一下收获了一些关注度，陆陆续续又发表了 Evaluation Pipeline [UniSandbox](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/2511.20561) 和数据集 Universe（CVPR2026），算是总体性梳理了前面的工作并且彻底感觉到 UMMs 这件事可能没有我想象的那么通向未来，很多时候用一个 pretrain 完成的 VLM 去 continual training，所花费的成本比我想象的要高不少，并且也很难达到更好的效果，所以之后算是迷茫了一段时间，开始四处看 paper。

^pr-4ef2a60dff92

而做世界模型的契机是当时 Saining 老师 Jihan 还有 Shusheng 他们完成了 Cambrian-S，当时对于 Supersensing 这件事其实感觉上还是觉得比较 amazing 的，从一个 position 角度看和 Saining 老师交流起来，发现我们有很多 intuition 不谋而合的地方，尤其是关于 Streaming World Model 以及其 Memory 机制的实现。

^pr-42a8e1edadd5

于是我下定决心，抛开之前关于 UMMs 的积累，在收尾 [NEPA](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/2512.16922) 之后正式开始的关于 World Model 和视频生成的项目研究。

一开始其实主要是用师兄的 Codebase 逐渐梳理一些基本的训练流程，后面加入了 Joy Echo Team 之后发现其实虽然人均资源和 data 的 infra 不少，但是依旧是草创的状态。当时感觉其实属于想得很多，但是落脚点很少。索性我的 Mentor Zeyue 给我的探索自由度很大，当时就下定决心还是要在 Memory 这个道路上至少先搭一个最基本的框架，于是我梳理了大概最近一年多以来的 100 多篇 Memory 相关的 paper，然后结合 agent 总结，大概规约成了四种模式的记忆方法。

^pr-c29b19d7c3b7

做完这步 literature review 之后，其实我就有一种强烈的感觉：现存的 memory 比较在 World Model 里面并不公平，数据/模型/甚至 eval 接口都没有完全统一起来，尤其是大家都各有各的框架，各有各的比较模式，很难下一个结论说什么样的 memory 机制才是更有潜力才是更加 scalable 的。

^pr-8872453f5261

于是Echo-Memory诞生了（顺便不要脸的求一下star）：

我们采用了固定 backbone、训练、采样器、评测，只换记忆模块，公平比较四类设计：Context（原始上下文）、Compression（压缩）、Spatial（空间摘要）、State-Space（块状递归）。最终其实很多结论都超出了我的 inductive bias 或者说作为一个传统视觉人的 prior，比如 Block State-Space 其实具有很强的泛化性，即便他对于 consistency 质量不够高，所以进一步说明了可能某种意义上 Memory 的能力可以和提升单纯的视觉质量 decouple，更多结构化的信息反而比较重要。

^pr-6ab573295c93

其实整个项目不是一个research paper，而是一个开源框架和对应的结果report，所以我们依旧期望社区的同学能够一起参与建设完善，我们也会持续保持更新和merge更多的记忆方法。

除此之外，超乎我想象的是，我们团队在几乎零基础的情况，从头在一个比较一般的基础模型 LTX2.3 训练出来五分钟级别音频和视频都比较 consistency 的结果：

在这个过程中，其实几位正职大哥都非常细致并且肝，很多时候为了说服对方都是额外做了很多组消融，通过公平 empirical study 来验证想法，这点非常对味我的 research taste，尤其是工程化的问题，和我之前一篇文章一样，理论的分析不一定是公式推 bound，也可以是 practical 的推断和结论。比较有趣的是，我们团队也和 LTX 团队建立了 connection，yaofeng 学弟非常社牛的在两次 hands up meeting 的时候在我们一群哑巴英语患者之间鹤立鸡群，交流得非常融洽。

当然，我依旧是视频领域的新人，很多 infra 设计比如深入到架构的细节我仍旧在学习。另一方面，我还是觉得 memory 的设计和探索依旧存在更多道路，我们后面还会更新一版支持 dynamic 数据的 V2，一步一步努力将世界模型这个领域尽可能推进到预期的状态。

对比上一次随笔，这段时光恍如隔世，变故、成长与反思贯穿全程。所幸我对热爱的领域有了全新理解，对课题方向的把控也愈发自信；更难得的是，结识了不少志同道合的新朋友，收获颇丰。
