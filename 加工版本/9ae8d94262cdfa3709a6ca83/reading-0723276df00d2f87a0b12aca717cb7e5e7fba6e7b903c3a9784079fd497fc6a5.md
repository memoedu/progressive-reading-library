## 核心洞察

一、分层模型组合与脏活外包：通过 OpenCode + Qwen3.8 27B、ClaudeCode + GLM5.3/5.3flash 等组合，并配置 toil-offloading skill，将简单任务交给 Qwen，中等难度给 GLM-flash，最难的给旗舰 GLM-5.3，主控模型 GPT5.6-sol 开启 50 个 subagent 并行处理，可显著提升多项目多进程联动的效率。
[[#^pr-b1ee0c2e47ba|正文跳转]]

二、设置求助机制避免死循环：为 OpenCode 和 ClaudeCode 编写 ask-for-help skill，规定尝试 5 次失败后结束当前轮次并请求大模型协助，避免 agent 陷入无效循环，保证任务推进的可靠性。
[[#^pr-e3c092089298|正文跳转]]

三、外包非标准化信息收集任务：将基本审计、模板化修改、有成熟解法的模块以及大批量非标准化信息收集（如查找 200 位教授的博士生名单和邮箱、查询 Google Map 店铺详情）外包给 agent，因为爬虫难以处理这类需要逐一点击的操作，外包可节省人力。
[[#^pr-c6b84249579a|正文跳转]]

四、本地 agent 与网页端强模型协作：标准工作流为：本地 agent 执行任务，每完成一个 checkpoint 打包交付物和工作日志，交给网页端 GPT5.6 Pro 或 Claude Opus 5 进行详细审查、给出修改意见和下一轮执行计划，甚至生成雏形代码，从而无需人工盯守，且结合脏活外包可削减三分之二 token 成本。
[[#^pr-9b33cc19ce8b|正文跳转]]

五、SSH 远程控制实现局域网运维：配置 ssh-remote-control skill 后，Codex 可管理 homelab 中 24 台机器，涵盖 Linux、macOS、Windows、k8s、Ansible、分布式数据库等，叠加 sunshine/moonlight 可实现远程 GUI 操作，进而支持分布式计算并享受软件生态红利，建议增加 Kali 节点（可用虚拟机替代）。
[[#^pr-9f7f782db8ca|正文跳转]]

六、打通验证码与登录凭据服务：将邮箱验证码、短信验证码、Duo 验证点击、密码 token 和密钥做成 local agent 可访问的服务，并购买能解 Cloudflare captcha 的服务，使 Codex 能自主处理各类登录验证，从而真正实现在网上的自主操作。
[[#^pr-f5b53c14173d|正文跳转]]

七、安卓设备农场扩展操作范围：通过 adb 连接多台安卓设备（如 4 台 oneplus 8T，成本不到一千美元），Codex 可自主操作小红书、抖音、LinkedIn 等平台，用于账号运营，节省人工。
[[#^pr-4c8a2fe50b0d|正文跳转]]

八、边缘计算与物理世界自动化：利用 Arduino、树莓派、ESP32 开发板外接传感器，可实现自动浇花、物理运维（如控制机械臂开关设备，出差时尤其有用）、智能门禁和监控，将 Codex 的能力扩展到物理世界。

## 正文

介绍一些压箱底的技巧，愿意执行的生产力保证高一个数量级。

1\. 接通 OpenCode + Qwen3.8 27B（有条件还可以本地配 Qwen3.8-Flash），还有 ClaudeCode + GLM5.3/5.3flash，同时配一个 toil-offloading（脏活外包）skill，让主控模型 GPT5.6-sol（一般开 high 或者 xhigh）去爽开 subagent（一般开 50 个最多了），多项目多进程联动非常靠谱。Qwen3.8 可以自己本地部署，GLM 买的他们的 [coding plan](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=coding+plan&zhida_source=entity) 36 刀一个月 max 档。

^pr-b1ee0c2e47ba

原则就是最简单的脏活给 Qwen，有难度一点的给 GLM-flash，最难的需要动脑子的给旗舰 GLM-5.3。

但是同时，要给 OpenCode 和 ClaudeCode 去写个 skill，叫 [ask-for-help](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=ask-for-help&zhida_source=entity)，就是如果尝试 5 次都不行就要结束轮次然后喊大模型帮忙。

^pr-e3c092089298

基本审计，写一些模板化修改，有比较成熟的解法的模块，大批量非标准化信息收集（比如找 200 个教授当前的 phd students 都有谁邮箱是多少，比如查 Google Map 里登录的店铺详细信息）都可以直接外包，毕竟爬虫不好做这些事儿，点来点去地很麻烦。

^pr-c6b84249579a

2\. 解放人力无限执行。配 [browser-use](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=browser-use&zhida_source=entity) 相关的 skill，懂得都懂。你甚至可以通过 codex 操控网页版的 GPT5.6 pro 去做复杂策划和方案设计。现在我的一个标准工作流就是，让本地的 agent 去干活，每做完一个大的 checkpoint，都打包好本轮次的可交付产物 + 本轮的详细工作日志，然后交给网页端的 GPT5.6 Pro（或者 [Claude Opus 5](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=Claude+Opus+5&zhida_source=entity) 也勉强凑合），让最强的模型去详细甚至，给修改意见和下一轮次执行计划，甚至让网页端 gpt 直接把下一轮次雏形代码写好。

^pr-9b33cc19ce8b

这样你自己就不用盯着了，有市面最强的模型把关呢。配合第一点说的脏活外包原则，基本上 token cost 能被砍掉三分之二。

3\. 配 ssh-remote-control skill，homelab 现在 24 个机子，运维整个局域网现在全靠 codex 顶着，甭管 Linux mac windows 还是什么 k8s [ansible](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=ansible&zhida_source=entity) 分布式数据库 都给你搞定。还可以叠加 sunshine/moonlight 完成远程 gui 操作。

^pr-9f7f782db8ca

然后就能实现分布式计算了，软件生态红利也都吃到了。有条件一定要再加个 Kali 节点（虽然可以跑虚拟机）。

一定要装 [Tailscale](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=Tailscale&zhida_source=entity) 啊喂。

4\. 邮箱验证码，短信验证码，Duo 验证点击，各种登录的密码 token 和密钥都做成本地 agent 可以访问的服务。买能解 cloudflare captcha 的服务。然后，懂得都懂，Codex 就真正意义地能在网上横着走了。

^pr-f5b53c14173d

5\. 把电脑怼上安卓机（嗯 我怼了 4 台，但去配一个 [oneplus 8T farm](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=oneplus+8T+farm&zhida_source=entity) 大概也就不到一千刀），装 adb，然后你的 Codex 就能自己刷小红书抖音 [linkedin](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=linkedin&zhida_source=entity) 等等恶意最大的网站了，也能去帮着运营账号了，省心。

^pr-4c8a2fe50b0d

6\. 如果你边缘计算玩的转的话，搞几个 arduino 树莓派 [ESP32](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=ESP32&zhida_source=entity) 开发板，外接一些传感器，就能实现自动浇花，物理运维（控制小机械臂点设备的开关，出差尤其好用），智能门禁/监控了。

^pr-647c1be7c68b

7\. 让 Codex 给自己上定时的 resume cron job，或者事件触发型 job，然后就能实现一直跑了（只要烧的起 token）。

^pr-093e401071a6

8\. 众所周知，codex 自己的 image generation tool 极其昂贵，但是聪明人看了本篇都知道要怎么捣鼓。让 codex 去操控网页版 nano banana，gpt image，grok image，还有各种 video generation 3d model generatioj 全都能做。就是需要比较铁的头不怕被封号～

^pr-12dde746153f

9\. 虽然我 3D 打印和 CAD 现阶段玩的比较菜但是 codex 适配 [Bambu Studio](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=Bambu+Studio&zhida_source=entity) 真的体验很好，去让 GPT 用 OpenCascade 或者 [SolidWorks](https://zhida.zhihu.com/search?content_id=796061361&content_type=Answer&match_order=1&q=SolidWorks&zhida_source=entity) 这类设计软件弄个低复杂度模型基本已经很靠谱了，反正我家显卡支架以及很多三脚架桌下挂钩挂盒都是 GPT 老师设计打印出来的。Codex 在未来是一定能编程物理世界的。

^pr-8e60a158b534

10\. 上述配置完成以后，脑子里真的有地图的人维护几百几千个常驻服务是靠谱的（毕竟我敢这么写因为已经跑通了），从 GIS 到图书馆，从财报到浇花，从个人智库到企业 ERP，全都能打通，脑子里没地图的可以让 codex 自己从图书馆里找书看让他自己努力打败主人造出超越主人认知的造物。

^pr-192c6e200865
