# 深度学习模型和软件架构的联系——宏观核心逻辑的重要性

---

## 正文

深度学习模型的三驾马车是模型结构，优化算法和损失函数。[$$1$$](https://zhuanlan.zhihu.com/p/18092754009#ref_1) 在学习 git 架构的过程中，[$$2$$](https://zhuanlan.zhihu.com/p/18092754009#ref_2)指出软件架构师在构建程序是往往将优先级较低的部分放在最后，最重要的是整个问题的逻辑链。其中前者只是一个代表，后者则决定着整个架构结构的完整性。原文是在 git 语境下的，我放在这里以供参考：

> 在我们描述这个架构的时候，或者在 Linus 开始实现这个架构的时候，引入了 SHA1，但对每个熟悉架构控制的工程师来说，应该很容易要分辨出，SHA1 不是这个问题的本质，Hash 才是这个问题的本质，你换一个 Hash 算法，上面的逻辑全部成立，这种情况下，我们就不能认为 SHA1 是架构定义的一部分，而是一个“代表”，代表一种 Hash。我们要分清楚一个架构代码或者架构描述，哪部分只是一个“代表”，哪部分是架构的核心，要关注的是整个逻辑链，如果你修改一个概念的实现，逻辑链是不会变的，那么，我们就不认为那是一个架构限制。

从上面的论述中，我们可以总结出在 git 中，核心逻辑链是“是需要在磁盘上保存一个目录树，以及这个目录树的版本“，核心诉求则是”保存一条修改过程的链表“。[$$2$$](https://zhuanlan.zhihu.com/p/18092754009#ref_2) 而诸多的优化问题，类似增量文件存储的优化，object 中的存储，则完全可以抽象为一个代表，或者留待后续解决。那把同样的事情放在深度学习中呢？

就笔者自己的学习经验而言，三驾马车中的模型结构定义支撑了整个深度学习模型的逻辑。而优化算法和损失函数则决定了具体的运行效果，但他们仅仅是优化，是深度学习模型中的一个”代表“（类比上面 git 架构的讨论）。

值得注意的是，就优化算法和损失函数而言，如果我们将他们抽出来单独研究，那我们需要分别定义不同的核心逻辑链，而这往往是前人已经给出/定义好的。现有的文章往往是对其中结构“代表”的一些提升，并不会或很少能够修改这个领域的核心逻辑。此外，除开这些 domain-specific 的逻辑，核心逻辑往往也可以是跨学科的，通用的。例如 _Summer Clover_ 撰写的关于 **如何理解 Adam" 优化算法** 的文章中，一个很有用的通用思想是 **但是当一个东西不能定量分析的时候，从科学的角度来讲，我们对其可以说几乎是一无所知的**。[$$3$$](https://zhuanlan.zhihu.com/p/18092754009#ref_3) 而其中有关 Adam 的具体细节则属于被抽象的层级，其具体实现并不会影响优化领域的整体脉络。而 _Untitled_ 在他的文献综述则给出了对 **Variational inference(VI)** 领域精彩绝伦的概括，而这就是从核心逻辑链的角度实现的。[$$4$$](https://zhuanlan.zhihu.com/p/18092754009#ref_4)

上面的讨论主要是围绕 git 和 深度学习领域，给出了核心逻辑的一些具体定义或特征。其实，看待核心逻辑的另一个很有趣的例子是观察优秀的学习经验贴是如何撰写的。我们这里以深度学习的学习资料为，探讨一下核心逻辑链的另一种表现形式。王源在“《运筹学》,《线性规划》，《非线性规划》，《凸优化》，《最优化方法》这几门课程有什么区别和联系？“问题中的回答中从宏观角度分析了优化领域内不同课程的具体内容，给出了优化领域的核心逻辑并吐槽了本科运筹学课程教学思维的落后。[$$5$$](https://zhuanlan.zhihu.com/p/18092754009#ref_5) yoka 则就深度学习入门讨论了不同课程的学习建议。[$$6$$](https://zhuanlan.zhihu.com/p/18092754009#ref_6)仔细阅读这些回答，我们可以发现他们都是从 big picture 的角度给出了分析，从而进一步提出具体建议。提问或学习者阅读时往往会根据这个 big picture 和自己的基础去进行下一步的规划。

从这些例子我们可以看出，核心逻辑链往往是最核心的信息，它决定了整个过程的成功与否。我们在学习或完成工作项目时，首先对具体科目/项目有一个具体理解是极为重要的。举例来说，国内外很多学生会采用 Anki 进行复习巩固，FSRS 记忆算法的作者就给出了一些经典的错误模式 [$$7$$](https://zhuanlan.zhihu.com/p/18092754009#ref_7)，这其中很多都是因为忽略了宏观的核心逻辑造成的。
