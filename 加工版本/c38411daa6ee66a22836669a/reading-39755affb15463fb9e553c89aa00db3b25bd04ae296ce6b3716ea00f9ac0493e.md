## 阅读前置卡

### 一句话核心
这是一篇对蒋炎岩讲座简介中三个核心命题（everything is a state machine、spec-oriented programming、small explanation hypothesis）的批判性短评，核心在于质疑“技术万能论”的宏观叙事。

### 核心洞见
- 对“everything is a state machine”的质疑：全称断言在科学史上随时可能被推翻，技术优化永无止境，打补丁不是终极方案。
- 对“spec-oriented programming”的判断：其本质类似“Claude.md”式的规格驱动开发，真正难点不在技术而在权利与法律——码农的价值在于对代码负责和担责，而非写代码本身。
- 对“small explanation hypothesis”的批评：认为其隐含“暴力枚举可解决一切”的假设，但“一切问题”这类全称命题无法穷举验证，属于不可证伪的宏观空谈。
- 核心立场：科研/技术人走火入魔时会认为技术能解决一切，但混沌系统视角下，理想理论的可验证性与现实世界的不可穷举之间存在根本断裂。

### 对我的价值判断
**中**。这篇文章本身信息量不大，且作者自述“懒得看”讲座，属于基于简介的即兴评论。但其中对“spec-oriented programming”的“责任与担责”视角、以及对“技术万能论”的批判，对你在搭建 AI Agent 工作流时判断技术边界有参考价值，值得提取为批判性视角卡片。

### 信息密度判断
**中**。密度主要来自作者对三个命题的独立判断和批判框架（全称命题不可验证、责任归属问题、混沌视角），而非新事实或新方法论。有一定观点增量，但存在重复性吐槽和低信息量段落。

### 能解决我的什么痛点
- 避免在 AI 工作流设计中陷入“技术万能”的过度乐观，帮助你在 Agent 编排时明确技术边界与责任归属。
- 为你在评估“spec-oriented programming”类工具（如 Claude.md、规格驱动开发）时提供“责任与担责”这一非技术维度的判断框架。
- 提醒你在渐进阅读中区分“可验证的具体命题”与“不可穷举的宏观全称”，提升信息筛选的批判性。

### 具体用处
- 可沉淀为 RemNote 卡片：“技术万能论批判——全称命题不可验证性”与“spec-oriented programming 的责任归属问题”。
- 可用于 AI 工作流设计时的边界判断清单，作为“何时不应依赖 Agent 自主决策”的参考依据。
- 可作为教育产品/课程设计中“技术局限性”主题的讨论素材，用于引导学生批判性思考。
- 可用于创业判断中评估“AI 替代人力”类产品的真实壁垒（法律与责任 vs 技术能力）。

### 是否急需阅读
**可延后**。文章本身是短评而非深度分析，核心观点可快速提取；除非你正在设计规格驱动开发工作流或需要批判性素材，否则不必优先阅读。

## 原文

# 如何评价蒋炎岩在ChinaSys'25 Winter的讲座《一个软工人的辩白》？

## 对简介部分的总体态度

少就是多。我懒得看，也懒得讨论过于宏观的东西，所以针对问题详情提到的简介部分稍微讨论一下。

## everything is a state machine

1.everything is a state machine。很遗憾作为一个普通得不能再普通的cs under，我并没怎么了解过cs语境的状态机细节。然而仍然可以从形式逻辑和符号逻辑的方向浅薄地分析一下，全称+断言结论，从科学史的经验而言，无论暂时看来多么完美多么有说服力的论证或证明，也可能哪天就被推翻了。这之后呢？打技术补丁吗？回到cs老生常谈的问题了，技术优化永无止境

## spec-oriented programming

2.spec-oriented programming。这个没有更具体的表述我不好对齐颗粒细节，不过感觉像Claude.md？消灭码农我觉得不在于，这方面劳动力需求大概率迅速减少倒是真的，另外也属于内部地位变化，以前code review在很多公司可能很少做或者根本不做，以后恐怕不行了。码农的价值从来不在于写的代码（除非你写的是天才级代码），而在于对自己写的代码负责和担责。难以跨越的点在于权利和法律问题，而非技术问题。

## small explanation hypothesis

3.small explanation hypothesis，有点没理解表述什么，不过按照消灭全人类的研究问题来看，，我猜大概率认为暴力枚举可以解决一切，虽然说cs的算法一般都这么讲，主要说这种宏观又无法验证的话根本不用负责啊喂。

## 对技术万能论的批评

cs冷笑话，搞科研或者技术的人走火入魔了会认为技术能解决一切问题。然而，，所谓一切问题这种无法量化描述的宏观抽象全称，你根本就无法穷举，这就是混沌视角的混沌系统和理想理论视角的混沌系统最显眼的区别，可惜部分人走火入魔就分不清了
