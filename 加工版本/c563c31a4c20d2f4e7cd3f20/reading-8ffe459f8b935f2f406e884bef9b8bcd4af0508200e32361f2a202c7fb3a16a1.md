## 正文

![](https://pic1.zhimg.com/50/v2-acd5ef21d754b98845504fc3a6a2c3c3_720w.jpg?source=2c26e567)

背景：我在阶跃星辰做语言大模型后训练，主页是 [https://github.com/hzwer](https://link.zhihu.com/?target=https%3A//github.com/hzwer)

曾经以为做语言模型是水多加面、面多加水，最后大家一起训 1000B 模型；今年感觉是后训练能把小模型训上天。

^pr-de334a97c93d

以及，我从记事本编程爱好者变成 Cursor 重度粉丝

### 还在古法编程吗

说来惭愧，学了十来年编程，今年才感觉自己会搞点工程。2024 年以前，我一直在搞算法小作坊模式：在轻量框架上小改做实验，搞古法编程，对大规模协作和重型工程不太适应。虽然 23 年开始就每天在用 AI，但大多时候只是让它写点数据处理脚本和读论文。

今年以来训模型变成集团军作战，特别是 Agent 相关工作让框架变得很长很重，被迫成为了 Cursor 的重度使用者，最近几天就能用完一个 20 刀账号。

^pr-80e398c70ac0

现在感到写代码时的心智负担大幅减轻，只要关注抽象的逻辑，也不用担心自己的编程功底太弱了

### 强化学习真的强

24 年初开始，我比较关注模型在编程竞赛上能力的提升，因为看到当时基于 llama 和 qwen 做的模型，和 GPT-4 最大的差距在编程能力上，但研究并不是很顺利，虽然能把 humaneval 这种简单榜单提升，但难题上收效不够大，RL 做的也并不太 work。回头看当时主要想通过增加语料源来提升模型的编程水平，而没有深入到思维链范式和数据中蕴含的思维智能的研究。

在复现 o1/R1 的过程中，非常痛苦的认知重塑：

-   **智能深度挖掘：** 今年上半年，把长思维链（LongCoT）强化学习调通后，模型进化速度真是远超想象，做同样多的题进步比人还快！深感我们以往对预训练模型智能的挖掘实在太浅了。
-   **留下“会下金蛋的鸡”，产品害我不浅（：** 以前大家追求“首字延迟”，现在发现当模型能给出超越普通人的思维路径时，用户对延迟的容忍度其实很高。之前通过牺牲推理长度来“优化”体验，是本末倒置。
-   **后训练不再微调：** 以前隔三差五传闻“1k 条数据出 SoTA”，现在看后训练已经成了极其复杂的系统工程。算力可能还在预训练，但人力资源正在大规模向后训练倾斜。
-   **bug 比想象的多：** 数据、算法、评测，哪哪都会搞错，修一个就能进步一截。

^pr-270448eefda2

### 规模焦虑的缓解：8B 也能做难题

24 年初，业界普遍存在“模型不够大”的焦虑。结果训完几百个 B 的基座做不动后续实验，线上用起来也很困难。而 2025 年的不同：

-   **小模型的奇迹：** 我亲眼看到经过精心后训练的 8B 模型解决 NOI 级别算法题。进步的关键不在于盲目加参数，而在于数据逻辑的纯度和工程的扎实程度。
-   **极致压榨效率：** 做视觉模型时我就发现，“穷人”比想象中多。一个算法变快 5-10 倍，它就能成为更高级算法的一环。注意力层的精细设计、超稀疏激活、训练时量化会是长期的标配。

^pr-080eb56386f4

### agent 网络与按需思考

初次体验 Gemini-pro 的 thinking 就非常喜欢，感觉总是恰到好处。有 GPT-oss 给大家打样，推理强度可变感觉将成为标配。根据任务复杂度、成本和延迟，给模型“挂不同档位”，将极大扩展推理模型的应用场景。相信国内各家厂商把 RL 算法稍加打磨，模型在这方面会有很大进步。最近两个月感觉 Cursor 的 auto 也在大幅进步。

^pr-38d1b3c0494f

大模型从语言生成器进化为原生智能体 (Agentic LLM)：顶级模型不再只预测下一个 Token，而是内置了指令层级（System > Developer > User）。通过特殊 Token 和通道区分信息，为多方参与的系统提供可靠护栏。

^pr-f910eb09c1c5

智能体网络取代单一应用：最初多 Agent 的 Pipeline 非常脆弱，一耦合 bug 到处都是。随着模型鲁棒性提升，协调分工变得简单。未来，Agent 之间不再是简单的 API 调用，而是能通过高级领导 Agent 进行信息交换和任务拆解。agent 网络将取代很多模型应用。

^pr-ab6e938e8ca0

### 在阶跃星辰工作

过去国内大模型行业在商业化压力和范式选择中反复横跳，阶跃也走过弯路，我自己在其中也有很多痛苦的时期。感觉内部/外部一年多前真的相信智能快速提升和 AGI 的人比例太低，今年见证 deepseek 的成功以后很多工作终于走上正轨，期待不远将来就能给大家上点好菜吧。
