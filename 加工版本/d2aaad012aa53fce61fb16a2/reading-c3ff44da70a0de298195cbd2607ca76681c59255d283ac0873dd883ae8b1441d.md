# Tools for keeping focused

---

## 正文

一旦意识到[我的 attention 比我的 time 还要 scarcer](https://www.benkuhn.net/attention/)，我就成了一个 anti-distraction 狂热者。在我的 [weekly reviews](https://www.benkuhn.net/weekly/) 期间，我会 methodically 回顾过去一周，弄清楚什么一直在 distracting 我，并尝试 eliminate 它，或用某种 less distracting 的东西 replace 它。

随着时间推移，这让我找到了许多 tools（以及使用这些 tools 的方式），帮助我保持更加 focused。以下是我已经开始做的一些事情：

[![](https://www.benkuhn.net/focustools/slack_hu9a9f5beab477f5d6455ea073c0ec506a_21261_146x146_resize_box_3.png)](https://www.benkuhn.net/focustools/slack.png "full size")

已经感到焦虑了吗？

-   我会 _aggressively_ disable notifications 和 badges，这样我就不会 mindlessly open distracting apps。如果你热衷于 eliminating distractions，你大概已经这样做了。但如果还没有，这绝对是你能为 improve 你的 focus 做的最重要的事情，所以我还是把它放在最前面。

    我有一套 zero-tolerance notification policy：如果某个 app interrupts 我，我就会问自己，这次 interruption 是否有价值；如果没有，这个 app 就不能再 notify 我了。这基本上排除了所有东西，只留下 inboxes（phone、texts、reminders）以及另一端有真人的 apps（ride sharing、delivery）。

    Slack 尤其值得点名批评，它很容易在你毫无察觉的情况下吞掉你四分之一的时间。如果你使用 Slack，却还没有 disabled 那个“unread messages” badge，就先别读这篇文章，现在就去做。（可以考虑设置一个两分钟的 timer，提醒自己 quit，以免你在 checking 你的 unreads 时受到 distracted，就像我在拍摄上面的 screenshot 时那样。）

-   说到 Slack，我尽量让它保持 closed，每天只分几次集中 check 它。并非所有 workplace Slack cultures 都允许这样做，但如果你所在的地方允许，我非常、_非常_推荐这样做。这带来了我的[最大一次 single quantifiable productivity improvement](https://www.benkuhn.net/50pct)。✻✻ 如果你的 workplace culture _不_允许你让 Slack 保持 closed，因为它要求 quick Slack responses，这可不是个好迹象。

-   我每天只 check 一次 email。

    Gmail filters 会把 important email send 到名为“Temp Inbox”的 label，把其余的 send 到名为“Unimportant”的 label。我每天晚上 check Temp Inbox，每周 check 一次 Unimportant。由于 incoming email 不会进入 inbox，我就可以 open Gmail 来 compose 或 search messages，而不会被 unread messages distracting。

    （我为此使用[一段 Google Apps Script](https://www.benkuhn.net/inbox/)，但我觉得 Gmail UI 最近已有 improved，所以现在你可以用 filters 做类似的事情，而且它会有不错的 ergonomics。）

-   我有第二个 monitor，上面始终 shows 一个 [Complice](https://complice.co/?r=6ct6ukjyqf) window，里面是我当前正在处理的 task。（Complice 是我最喜欢的 app，用来为今天想做的事情 making lists。）这能帮助我在不经意间钻进牛角尖后迅速回过神来。

    [![](https://www.benkuhn.net/focustools/complice_hud9dd0579ba03395b10f5550a0290b118_133053_1024x290_resize_box_3.png)](https://www.benkuhn.net/focustools/complice.png "full size")
-   我使用 [Focus](https://a.paddle.com/v2/click/447/116794?link=46) 来打破自己 mindlessly checking sites 的习惯。

    对于那些 habit-forming、但总体而言仍让我觉得有用的 websites，例如 Twitter 或 Hacker News，Focus 让我能够将自己的 usage restrict 到一天中的某些时段。它是我用过的唯一一个 website blocker，能够让我完全按照自己的想法，对 blocking 各种东西进行 [fully automate](https://www.benkuhn.net/zero/)。

    对我来说，使用一个 fully automatic 的 website blocker 尤其重要，因为我最需要它的时候，恰恰也是我最没有 willpower 去执行任何 manual steps 的时候！

-   我也会 block 手机上大多数 websites（使用 iOS 内置的 content blocking，并采用 whitelist mode）。遗憾的是，这不如 Focus 好用，因为我有时想 disable 它，随后却忘了 re-enable 它。

-   我[在自己的 Kindle 上进行大部分 Internet reading](https://www.benkuhn.net/krss/)，借助的是 [Kindle4RSS](http://kindle4rss.com/)。

    使用 RSS 意味着我可以掌控自己的 feed，不必为了获取新的阅读材料而 visit 像 Facebook 这样 [adversarially distracting](https://www.benkuhn.net/skinner/) 的 site。

    Kindle delivery 每天会在一个可预期的时间到达一次，这也很有帮助，所以我不会有反复 check 新 content 的冲动。

-   我会 [block websites 中 distracting 的部分](https://www.benkuhn.net/ublock/)，用的是 [uBlock Origin’s](https://github.com/gorhill/uBlock) 出色的“element blocker”，它让你可以 select 和 remove page 的任意部分。作为 web design 中 minimalism 的爱好者，我非常享受能在任何不守规矩的 webpage 上 adversarially enforce 它。

    例如，我用它来 block Stack Overflow 上 clickbaity 的“hot network questions” sidebar，否则它经常会 distracts 我；我也会 block 没用的 notifications 和 left sidebar：

[![](https://www.benkuhn.net/focustools/so_before_hu4c17283b85ae39c0aa61b0459ebf639c_1002753_600x382_resize_box_3.png)](https://www.benkuhn.net/focustools/so_before.png "full size")[![](https://www.benkuhn.net/focustools/so_after_hu4c17283b85ae39c0aa61b0459ebf639c_792298_600x382_resize_box_3.png)](https://www.benkuhn.net/focustools/so_after.png "full size")

-   我使用 [Witch](https://manytricks.com/witch/)，一个 augmented window switcher，以避免意外 switching 到错误的 window。Witch 能将 separate app windows 分别 display，只 display 当前 workspace 中的 windows，并且 supports [text search on window titles](https://www.benkuhn.net/autocomplete/)，这样你就可以直接 search 自己想要的 window，而不必逐个跳过。

    [![](https://www.benkuhn.net/focustools/witch_hu67410178f274942d783676016cd30ef5_192544_1224x282_resize_box_3.png)](https://www.benkuhn.net/focustools/witch.png "full size")

    我发现 Witch 的 configure 稍微有些不直观，所以如果你好奇，这里是我的 configs 的 screenshots：[“actions” tab](https://www.benkuhn.net/focustools/witch-actions.png)、[“advanced” tab](https://www.benkuhn.net/focustools/witch-advanced.png)。

[![](https://www.benkuhn.net/focustools/phone_hu55da1dd6cea9817316278c34442dff94_216758_164x354_resize_box_3.png)](https://www.benkuhn.net/focustools/phone.png "full size")

-   我已经 hidden 手机上的 apps。我的 homescreen 就像右图那样。

    这两个 folders 分别是“badges”（用于少数获准 notify 我的 apps）和“其余所有东西”。如果我想用某个 app，我会在 search bar 中 type 它的 name，这迫使我有意识地行动（而且通常也比翻找一页页 apps 更快）。bottom bar 中的 app 是 Kindle app。

-   我使用 web apps 的 native versions，而不是让它们在 browser tab 中保持 open。这让我能够使用 app，而不至于被吸进 browser 里。有两种方式可以这样做：

    -   有些 apps（例如 [Roam](https://roamresearch.com/)）已经是“installable”的，也就是说，它们会告诉你的 browser 如何将它们变成 native app。（遗憾的是，目前 Chrome 似乎是唯一能够在 desktop 上 install installable apps 的 browser。）

    -   对于其余的 apps（例如，奇怪的是，大多数 Google web apps），我会使用一个名为 [nativefier](https://github.com/jiahaog/nativefier) 的 command-line tool，将它们变成 desktop apps。

-   事实上，我现在正在尝试一条“完全不用 browser tabs”的规则。我注意到，自己有时会被很久以前 opened、原本应该 closed 却忘了关的 tabs distracting。所以我 installed 了一个 extension，把每个 window limit 为 single tab，并 changed Firefox，让它 [open links in a new window by default](http://kb.mozillazine.org/Browser.link.open_newwindow)。（这与 Witch 这样强大的 window switcher 有很大的 synergy。）

这些做法单独来看都很小，但[就像我在 weekly reviews 期间处理的许多事情一样](https://www.benkuhn.net/weekly/)，它们逐渐累积并 compounded，让我更容易按照自己想要的方式投入 attention。

## 原文

Once I realized that [my attention was even scarcer than my time](https://www.benkuhn.net/attention/), I became an anti-distraction fanatic. During my [weekly reviews](https://www.benkuhn.net/weekly/) I methodically went through my past week, figured out what had been distracting me, and tried to eliminate it or replace it with something less distracting.

Over time, this has led me to find lots of tools (and ways of using my tools) that help me stay more focused. Here are some of the things I’ve started doing:

[![](https://www.benkuhn.net/focustools/slack_hu9a9f5beab477f5d6455ea073c0ec506a_21261_146x146_resize_box_3.png)](https://www.benkuhn.net/focustools/slack.png "full size")

Anxious yet?

-   I _aggressively_ disable notifications and badges so that I don’t mindlessly open distracting apps. If you’re into eliminating distractions you’ve probably already done this. But if you haven’t, it’s by far the most important thing you can do to improve your focus, so I’m putting it first anyway.

    I have a zero-tolerance notification policy: if an app interrupts me, I ask myself whether the interruption was valuable, and if not, the app doesn’t get to notify me anymore. This has weeded out pretty much everything except for inboxes (phone, texts, reminders) and apps with a human on the other end (ride sharing, delivery).

    A special dishonorable mention goes to Slack, which can easily suck away a quarter of your time without you noticing. If you use Slack and you haven’t disabled the “unread messages” badge, stop reading this post and do it now. (Consider setting a two-minute timer to remind you to quit in case you get distracted by checking your unreads, like I did while taking the screenshot above.)

-   On the subject of Slack, I try to keep it closed as much as possible and check it in batches a few times a day. Not all workplace Slack cultures allow this, but if yours does, I highly, _highly_ recommend it. Doing this led to my [biggest single quantifiable productivity improvement](https://www.benkuhn.net/50pct).✻✻ If your workplace culture _doesn’t_ allow you to keep Slack closed, because it requires quick Slack responses, this is a bad sign.

-   I only check my email once per day.

    Gmail filters send important email to a label called “Temp Inbox” and the rest to a label called “Unimportant.” I check Temp Inbox each evening and Unimportant once a week. Since incoming email doesn’t go to the inbox, I can open Gmail to compose or search messages without getting distracted by unread messages.

    (I use [a piece of Google Apps Script](https://www.benkuhn.net/inbox/) for this, but I think the Gmail UI has improved recently so that you can now do something similar with filters and it’ll have decent ergonomics.)

-   I have a second monitor that always shows a [Complice](https://complice.co/?r=6ct6ukjyqf) window with the task I’m currently working on. (Complice is my favorite app for making lists of what I want to do today.) This helps me recover quickly from unintentionally going down rabbit holes.

    [![](https://www.benkuhn.net/focustools/complice_hud9dd0579ba03395b10f5550a0290b118_133053_1024x290_resize_box_3.png)](https://www.benkuhn.net/focustools/complice.png "full size")
-   I use [Focus](https://a.paddle.com/v2/click/447/116794?link=46) to break my habit of mindlessly checking sites.

    For websites that are habit-forming but still feel useful on net, like Twitter or Hacker News, Focus lets me restrict my usage to certain times of day. It’s the only website blocker I’ve used that lets me [fully automate](https://www.benkuhn.net/zero/) blocking things in the exact way I want.

    It’s especially important for me to use a website blocker that’s fully automatic, because the times when I need it most are exactly those times at which I have the least willpower to do any manual steps!

-   I also block most websites on my phone (using the iOS built-in content blocking in whitelist mode). Unfortunately, this works less well than Focus since I sometimes want to disable it and then forget to re-enable it.

-   I [do most of my Internet reading on my Kindle](https://www.benkuhn.net/krss/) via [Kindle4RSS](http://kindle4rss.com/).

    Using RSS means I’m in control of my own feed and don’t need to visit an [adversarially distracting](https://www.benkuhn.net/skinner/) site like Facebook to get new reading material.

    It’s also helpful that the Kindle delivery comes once per day at a predictable time, so I don’t have an urge to check over and over again for new content.

-   I [block distracting parts of websites](https://www.benkuhn.net/ublock/) with [uBlock Origin’s](https://github.com/gorhill/uBlock) amazing “element blocker,” which lets you select and remove any part of the page. As a fan of minimalism in web design, I really enjoy being able to adversarially enforce it on any rogue webpage.

    For instance, I use it to block the clickbaity “hot network questions” sidebar on Stack Overflow, which otherwise frequently distracts me, as well as the useless notifications and left sidebar:

[![](https://www.benkuhn.net/focustools/so_before_hu4c17283b85ae39c0aa61b0459ebf639c_1002753_600x382_resize_box_3.png)](https://www.benkuhn.net/focustools/so_before.png "full size")[![](https://www.benkuhn.net/focustools/so_after_hu4c17283b85ae39c0aa61b0459ebf639c_792298_600x382_resize_box_3.png)](https://www.benkuhn.net/focustools/so_after.png "full size")

-   I use [Witch](https://manytricks.com/witch/), an augmented window switcher, to avoid accidentally switching to the wrong window. Witch can display separate app windows separately, only display windows from the current workspace, and supports [text search on window titles](https://www.benkuhn.net/autocomplete/) so that you can search directly for the window you want without having to skip over.

    [![](https://www.benkuhn.net/focustools/witch_hu67410178f274942d783676016cd30ef5_192544_1224x282_resize_box_3.png)](https://www.benkuhn.net/focustools/witch.png "full size")

    I found Witch slightly unintuitive to configure, so if you’re curious, here are screenshots of my configs: [“actions” tab](https://www.benkuhn.net/focustools/witch-actions.png), [“advanced” tab](https://www.benkuhn.net/focustools/witch-advanced.png).

[![](https://www.benkuhn.net/focustools/phone_hu55da1dd6cea9817316278c34442dff94_216758_164x354_resize_box_3.png)](https://www.benkuhn.net/focustools/phone.png "full size")

-   I’ve hidden the apps on my phone. My homescreen looks like the figure on the right.

    The two folders are “badges” (for the few apps that are allowed to notify me) and “everything else.” If I want an app I type its name in the search bar, which forces me to be intentional (and is often faster than hunting through pages of apps anyway). The app in the bottom bar is the Kindle app.

-   I use native versions of web apps instead of keeping them open in a browser tab. This allows me to use the app without getting sucked into my browser. There are two ways of doing this:

    -   Some apps (e.g. [Roam](https://roamresearch.com/)) are already “installable,” meaning that they tell your browser how to turn them into a native app. (Sadly, Chrome seems to be the only browser that can install installable apps on desktop right now.)

    -   For the rest (e.g., oddly, most Google web apps), I use a command-line tool called [nativefier](https://github.com/jiahaog/nativefier) to turn them into desktop apps.

-   In fact, right now I’m trying out a “no browser tabs at all” rule. I noticed that I’d sometimes get distracted by tabs that I’d opened a long time ago and should have closed, but forgot about. So I installed an extension to limit each window to a single tab and changed Firefox to [open links in a new window by default](http://kb.mozillazine.org/Browser.link.open_newwindow). (This has lots of synergy with a powerful window switcher like Witch.)

Each of these is small on their own, but [like many of the things I work on during weekly reviews](https://www.benkuhn.net/weekly/), they’ve added up and compounded to make it much easier for me to spend my attention in ways I want.
