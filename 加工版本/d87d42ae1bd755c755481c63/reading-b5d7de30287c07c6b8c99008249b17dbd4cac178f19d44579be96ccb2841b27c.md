大多数人根本不知道该如何 learning。

因为大多数人根本不知道 learning process 是什么。

大多数 learning 失败的原因是缺少 _no negative feedback loop_。

可以这样理解。

如果你没有 _goal_ 要求自己保持身材（我说的是深层、内在生成的 goal，而不是为了融入群体而追求的肤浅 goal，比如新年决心），那么一晚上的酗酒狂欢就不会被视为 _problem_（negative feedback），因为它不会影响你那根本不存在的 goal——第二天早晨跑步或去健身房时表现出色。即使宿醉，你也能照常上班，因为你根本不在乎自己工作做得好不好。

Learning 是一个 cybernetic process。

Cybernetics 听起来像是与 cyborgs 有关的东西，但它源自希腊词 _kybernētēs_，意思是 steersman 或 helmsman，也就是掌舵的人。

“cybernetics”这个词之所以被选中，是因为 helmsman 是 feedback system 的绝佳形象。helmsman 不会只把船 _point_ 向某个方向一次；他会不断读取 current state（风、浪、航向），将它与 intended course 作比较，并进行调整。换句话说，这就是 _trial and error_ 的过程，而很少有人拥有能让自己注意到生活中错误的方向感。

Cybernetics 展示了 intelligent systems 的属性。

1.  **Reference signal (the goal)** – system 持有一个 target state。

2.  **Sensor (perception)** – system 读取自己的 current state。

3.  **Comparator (the gap)** – system 计算 target state 与 current state 之间的 difference。这个 difference 就是 error signal。

4.  **Actuator (behavior)** – system 采取行动以 reduce error。

就像 thermostat 在温度过低时会打开暖气，或者你的 pancreas 会在 blood sugar 上升时释放 insulin。

这样就很好地揭示了问题所在。

大多数人尝试 learning 新东西时，关注的是 _content_。他们囤积材料，试图通过 space repetition、flashcards、courses 和 learning the fundamentals 来吸收内容。_他们以为 learning 是一个 **input** process。_

实际上，learning 是一个 output process，因为 output 需要 input。

goal 会产生 error signal。

error signal 会形成 filter。

filter 会产生 relevance（大多数人把 noise 和永远用不上的东西塞满脑子）。

relevance 会带来 retention。

一个人如果一生都受到 conditioning，几乎无意识地以去上学、找工作为 goal，自然就会朝那个方向 learning 和行动。他们被分配的 destiny 终将成真。

一个人如果深受 conditioning，沿着默认道路前进，就连工作之外的 money-making opportunities 都不会注意到，因为自己的 brain 正在把它们过滤掉。他们出生时被分配的宏大 life goals 决定了他们的 behavior 和 learning。他们是他人 ideals 的傀儡，无法掌控自己的人生。

但如果你有意识地创造自己的 frame，**准确了解自己不想从人生中得到什么，并将其与不断发展的、关于自己想从人生中得到什么的 vision 作比较**，只有这样你才能察觉自己何时偏离轨道、注意到 error、修正前进方向，并以此为副产品 learning。

有道理，但你具体该怎么做？

### 2）别从 learning 开始**。**

你想要的人生，始于一系列有意义的 projects 的终点。

你应该把自己的 mind 当作一个 project。body、relationships 和 financial situation 也是如此。一个 project 就是一组有结构的 goals 和 milestones。一个 project 会为你的 learning 建立一个 frame（通过过滤不重要的 noise）。_任何不能直接推动 project 前进的东西，现在都不值得 learning，因为反正你也不会 retain 它。_

换句话说，当你想学点新东西时，别从 learning 开始，而是先朝着 goal 迈出第一步。

### 3）**寻求 specific knowledge。**

> 我最终认为，每个人都应该找出自己最擅长做什么——这要与他们的本质相符，赋予他们 authenticity，带给他们 specific knowledge，给予他们 competitive advantage，让他们无可替代。然后，他们就应该顺着这条路走下去。有时候，只有亲自去做，你才会知道那是什么。
>
> – Naval

Schools 教授 general knowledge，或完成一份工作所需的 knowledge。

它们不会教你如何走自己的路。它们把你限制在一个 study 领域，而这个领域的本质决定了它无法让你为通过 entrepreneurship 之路自主安排工作做好准备——或者说，无法让你为单纯做自己想做的事做好准备。

Self-education 是 learning 必要内容以实现 self-generated goals 的过程。再说一次，别囤积 general knowledge，只为了 _感觉_ 自己在 learning。

举个例子，假设我想学习 After Effects——这款 animation software。

去看一堆通用的 After Effects tutorials，把这个 software 的每个细枝末节都学一遍，那就太蠢了。

相反，你需要先对自己想要构建的 project 有一个 vision。

你用自己已有的 knowledge 开始这个 project；如果你没有相关 knowledge，就找一个 specific tutorial，尽可能选择与自己想创作的 project 相似的教程。

现在，因为你有了一个 filter（你想创作什么），tutorial 的大部分内容都会毫无用处，但你会找到一个小 technique，至少能让你启动这个 project。

你应用这个 technique，然后不断重复，直到积累了足够多的 techniques；等你开始创作下一个 project，再下一个时，就会变得越来越容易。

学习 guitar 或其他乐器也是一样。

你不会去学 music theory。

你会_选一首想弹的歌。_

然后你学这首歌的第一个 chord。再学第二个，再学第三个。最终，你会学会用一种特定方式调音，也会掌握一些能让自己弹得更好的小技巧。

学了几首歌之后，你会觉得自己也能创作一首_属于自己的_简单歌曲。

这就是 learning 的方式。

## 第二潜意识（删掉你的笔记系统）

我以前试过所有这些 systems，而且都很喜欢。我从 Roam Research 开始，它彻底改变了我的写作方式。我建立了一个收录有力 ideas 的 knowledge base，每次坐下来准备把文字写到屏幕上时，都会从中汲取 ideas。

几年前，我甚至打造了 Kortex。它原本并不是要做成 second-brain software，但在最终失败之前，它就变成了那样。其实它并没有真正失败，只是艰难地演变成了 Eden；Eden 已经成为市场上最好的 tool，既能为 creators 找到 social media 上的热门趋势，也能让 creatives 从任何地方捕捉 ideas。

所以，我不是要说 second brains 毫无用处。

我只是觉得它们被_用错了。_

你收藏书签、记笔记，结果之后再也不会看它们。你确实浪费了时间，以为自己在 learning；正如我们前面讨论过的，你本来可以真正地 learning。

过去，人们没有一个广受欢迎、又很会营销的“second brain”。他们有一本_commomplace book_。

Marcus Aurelius 的《Meditations》本质上是一本私人 commonplace book，里面有他写给自己的 notes 和消化过的 philosophy。它从来就不是为了出版而写的。

Leonardo da Vinci 在数千页笔记本上写满了 sketches、observations、questions 和借来的 ideas。

Mark Twain、H.P. Lovecraft、Thomas Jefferson、Ronald Reagan、Montaigne、Rick Rubin 等许多人，也都各自有某种形式的这种笔记。

但普通的 second brain 追随者和他们之间，有一个重大区别。

他们收集的 ideas 是创作的_fuel_。

如果没有某种形式的 commonplace book，他们的 inventions、writing 和 music 就不会成为今天的样子；我甚至可以说，如果没有它，你可能根本不会知道这些名人是谁。

当你创作某样东西时，你的 subconscious 会吐出有助于提升作品 quality 的 relevant ideas，但它的 processing power 仍然有限，有时它干脆决定不帮你，让你陷入 creative rut。

Seneca 用过一个 metaphor：从许多花朵中采集 pollen，再把它消化成你自己的 honey。

用现代的话来说，就是像艺术家一样偷取灵感。

这是 writers block 的解药。你写作、创作 content 或制作 videos 时没有 ideas，是因为没有可供取用的 ideas repository。这封信里我写的每一件事，都来自我以前保存过的 articles、videos、social posts、random ideas 和 highlights。

我想你已经明白了，但我们究竟该怎么搭建它？

我们如何创建一本 digital commonplace book，或第二潜意识，让它伴随我们一生不断积累，而不会变成一个杂乱的 note-taking app，让 ideas 在里面走向消亡？

### Step 1) 选择 The Right Software，或者 Create Your Own AI System

> 别因为 AI 有多“smart”而激动得喘不过气来。它比一袋湿锤子还蠢。
>
> 相反，要 Leverage 它在 large datasets 上为 simple tasks 执行 rapid input and output 的能力。
>
> – Devon Eriksen

大多数 note-taking 和“second brain” software 仍然需要 manual upkeep。

有些软件还附带了 AI chat，这当然很有用，但它们缺少其中最有用的 application：让你的 ideas 不会消失在虚空中——因为你的 creative work 取决于你能否让它们重新浮现。

这里有 2 个 options。

我们的 goal 是有个地方可以放下 ideas，并能轻松让适合我们 project 的那些 ideas 重新浮现。

*   **Option 1** - 使用 Claude Code + Obsidian 这样的组合，把你的 knowledge 存在一个地方，再用 AI retrieve ideas

*   **Option 2** - 使用 MyMind 或 Eden 这样的 software，它们会 auto-tags、categorizes，并将你的 knowledge embeds 到“meaning space”中，从而连接看似无关的 ideas，催生 novel insights

网上有很多关于 option 1 的 tutorials。它现在很流行，因为人们把自己珍爱的 Notion templates 集合换成了 Claude skills 集合（这种 fad 最终也会像其他 fad 一样消退），不过下面是你自己动手做的 80/20 方法：

1.  下载 Obsidian 和 Claude

2.  打开 Claude Code 或 Claude Cowork，并选择电脑上的 Obsidian vault folder 作为你的 working folder

3.  创建一个“save an idea” skill——请 claude 创建一个 skill，在 inbox folder 中创建一条带有清晰 title 的 note

4.  创建一个“process my inbox” skill——请 claude 创建一个 skill，遍历你的 inbox folder，add tags，把内容移到合适的 folder，并在 vault 中为它添加指向其他相关 notes 的 backlinks

5.  请 Claude 帮你定义 taxonomy，这样它就知道该用哪些 tags/categories

这样你就能把 ideas、notes 和 knowledge 收集到一个经受住时间考验的 note-taking tool 里。

然后，你随时可以请 Claude“Search my vault for everything related to \[idea I’m writing about\].”

这能帮你找到大多数 ideas，但 good writing 和 creative work 来自 novel connections，而不是 keyword search 或 AI 为了找到 related matches 而 brainstorm synonyms。

如果你不想手动完成这一切，就可以使用 MyMind 这样的 software，它能让你把任何 link 或 idea 保存到一个大型、可搜索的 library 中。

Eden 做的也是同一件事（你可以快速把任何内容 capture 到 library 中），但它更进一步。你保存一个 link，比如 Substack article 或 YouTube video 时，它会 transcribe 内容，并让你 highlight。除此之外，你还可以 integrate with Kindle，把以前所有的 highlights 导入进来——这些都是强大的 creative fuel。

MyMind 和 Eden 与 Obsidian 和 Claude 的区别在于，你添加到 library 的所有内容都会被 automatically tagged、categorized 和 embedded。因此，你可以执行 Claude 能帮你做的同样的 search，而不必浪费宝贵的 AI usage（如果你确实想用 Claude 来 build 和 access your knowledge base，Eden 也有 MCP）。此外，如果你是 writer 或 creator，Eden 还有一个 outlier search feed，你可以在其中找到自己 niche 中表现出色的 social posts，并直接保存到 library。

我不太确定 MyMind 能不能做到这一点，但 Eden 还有一个不同之处：它可以基于 _meaning_ 进行 search。

Obsidian 能向你展示“what’s related”，Eden 则能展示“what’s nearby”，因为每个 idea 都会 embedded 成大约 1500 个数字，充当该 idea 的 GPS coordinates。即使它们没有任何相同的 words，也能找到这些 ideas。正因如此，你可以只把一个 idea 放进去，然后不再操心，因为你知道自己会在恰好需要它的时候找到它。

### Step 2) 收集最能代表你理想 mind 的 Ideas

现在你有了一个可以放下 ideas、无需担心 organization 的地方（因为只有想以后找到东西时才需要组织，而我们刚刚已经解决了这个问题），你可别把所有东西一股脑儿都 dump 进去。

_当 AI 能创造任何东西时，curation 比以往任何时候都更重要。_

你需要一个经过 curated 的 space，存放能激发灵感的 ideas。它与我们称作 social media feed 的无尽噪声消防水带正好相反。

作为 writer、creator，或试图做 independent work 的人（也就是说，你需要通过吸引受众关注你发布的 ideas 来 build an audience），人们如今关注你不再是为了你的 content。

有 Google、AI，还有大量只需点击按钮就能找到的信息。

人们关注你，是为了你的 point of view。你的 opinion。你的 interpretation。你的 personality。你的 story。而所有这些都源自构成你 worldview 的 ideas，也就是你用来理解世界的 ideas。

举例来说，当我参与一场关于 reality 本质的 conversation 时，我的思绪会跳到关于 history、integral theory、spiral dynamics 等等的 ideas 上——因为我认为这些是观察那场 conversation 最有用的 lens。与我听过的其他那些往往说不通的 ideas 相比，它们最能解释得通。

那些就是你要 capture 的 ideas。

你要 curate 一大批最能代表你理想 mind 的 knowledge。

因为这不正是你那套 fancy note-taking system 原本该成为的样子吗？

你只是一直没能把那些 ideas 巩固为自身的一部分。通常可以通过思考、写作和公开分享来做到这一点，这样你就能从 market 获得 feedback，让最好的 ideas 胜出。

该怎么做呢？

多读 books。让 curiosity 引导你。拒绝 doomscrolling，拥抱那些致力于产出好 ideas 的 authors 和 thinkers 所编选的 lists。为“research”留出时间，因为作为 writer 或 creator，这就是你工作中 80% 的内容。

你工作的其余部分，就是把这些“research”综合成对其他人有益的东西。

### Step 3) 通过创作来打造你的 Ideal Mind

让我们把整个流程闭合起来。

我们已经有了用于捕捉和检索 knowledge 的 system。

但现在我们也需要用来应用它的 project，这样它才不会白白浪费。

而且，我们仍然没有捕捉 _specific knowledge_，因为我们没有学习的理由。我们没有为自己的 mind 提供一个 frame，让它能有效地发出 signal，指出哪些 ideas 重要到值得捕捉，正如我们前面讨论过的。

这就是我们追求的全部 goal，对吧？

我们想变得更聪明。我们想保留并记住自己学到的东西。我们想表达得 articulate。也许是出于肤浅的理由，但也是因为我们人生的结果取决于我们做出的 decisions，而我们的 smartness 水平以及 articulate 自身价值的能力，绝对会对结果产生积极影响。

我无法告诉你要创作什么。

但如果你对 writing 感兴趣，我可以分享一部分我的 process；它最近帮助了别人。

比如要写一篇 Substack article、YouTube script 或 X article，我会这样做：

**1) 选择一个 topic。**

显然。

最好的 topics 是那些处于 performance 和 excitement 交叉点上的 topics。

Performance = 已经证明表现良好的 topics。

你可以保存那些已经 viral 的 social posts 来找到这些 topics，或者使用一个 [research tool](https://eden.so)，它能让你找到 outlier content 并研究 creator 的 top posts。

（我现在写的这篇 article，就是基于“How to remember everything you read”这个 topic；它 viral 的次数多到我数不过来，但我对它应用了自己的 contrarian perspective。）

Excitement = 出于好奇、你想进一步探索的 topics 和 ideas。

你的工作是把你想写的 topic（它可能不会在 social media 上表现出色）与一个已经证明表现良好的 topic 配对，这样 _你就能写自己想写的内容，并提高它真正获得 traction 的可能性。_

大多数 beginners 就是在这里失败的。

**2) Braindump → Outline → Draft**

先别开始 writing。

Writer’s 不会只是打开一页，然后指望所有 ideas 线性地落到恰当位置。

先做 braindump。把所有可能适合你正在写的 topic 的 ideas 都写下来。也看看你的 notes、ideas 和 links，并把它们也加进去。

然后，用 outline 开始添加一些 structure。把 braindump 里的所有 ideas 拿出来，试着把它们放进一个通用的 storytelling framework：Problem → Insight → Solution。

把 ideas 安排在 outline 中各个 sections 之下。

然后，打开 outline、ideas 和 knowledge library，准备好随时取用，再把 ideas 串联成一份真正的 draft。

**3) 用 AI 消除 friction，而不是让它替你写。**

我以后会写一封信谈谈自己对 AI writing 的看法，但当我说“别用 AI 来 writing”时，我实际想说的是“别用 AI 来 articulate 你自己的 beliefs 和 opinions”。

既然 Substack 现在有了 AI writing estimator，人们就会开始指出哪些 accounts 在 writing 中使用了 AI。我已经遇到几个人指出，我的一些 articles 里有 AI writing。

别犯傻。

是的，在提供纯粹信息时，我会直接从 AI 复制粘贴——比如对 Greuter’s 9 stages of ego development 的解释，这和你通过 Google search 能得到的信息一样。我不会浪费口舌试着用自己的话重写，因为这没有必要。那样做对我和读者都是一种损害。

我认为，努力 articulate 自己的 thoughts 和 beliefs 是有价值的；反 AI 的人似乎做得不太好，因为他们的新 religion 让他们变得狭隘。

当我说“用 AI 消除 friction”时，我指的是在学习 skill 的过程中，像使用 course、mentor 或 editor 那样使用它。

如果你不知道如何 structure article，就请它列出一些你的 ideas 可以套用的 structures。

如果你不知道接下来写什么，就请它给出几个 article 可以发展的方向。

如果你不理解某件事，就去 research；过去任何 writer 也会这样做，只不过他们得用效率更低的方法在 internet 上搜寻正确的信息。

总之，我相信你有脑子。

最终，决定发布什么的人是你。

如果它没有体现你想要的 values、ideas 和 beliefs，那就继续 refine，直到体现出来。

我就说到这里，因为我还有很多想说的，会留到另一封信里。

– Dan
