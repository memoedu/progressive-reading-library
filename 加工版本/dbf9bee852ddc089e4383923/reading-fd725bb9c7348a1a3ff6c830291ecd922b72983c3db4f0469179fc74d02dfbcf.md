# 复数丢失全序性，四元数丢失交换律，八元数丢失结合律，十六元数丢失交错性，能推广得到定量一般规律吗?

## 黄金律

把实数看成黄金律法，看啥都是礼崩乐坏，这些“美好性质”恰恰是应该被打破的基因锁。

复数 ![\\mathbb{C}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BC%7D) 从 1 维到 2 维，非排序的 ![i^2=-1](https://www.zhihu.com/equation?tex=i%5E2%3D-1) 可以轻松处理平面旋转。

四元数 ![\\mathbb{H}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BH%7D) 从 2 维到 4 维，非交换的 ![i^2=j^2=k^2=-1](https://www.zhihu.com/equation?tex=i%5E2%3Dj%5E2%3Dk%5E2%3D-1) 可以完美描述三维空间中的旋转。

八元数 ![\\mathbb{O}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BO%7D) 从 4 维到 8 维，其交错特性反而与例外李群和弦论中的超对称性联系起来了。

所以十六元数 ![\\mathbb{S}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BS%7D) 难道真的是垃圾吗？

还是说，人类还没准备好迎接它？

## Cayley–Dickson 构造

从一个已知的代数系统出发，用标量加向量创造出一个维度翻倍的、全新的代数系统。

这就是 Cayley–Dickson 构造的核心思想，通过这个构造过程反复迭代，我们就可得到一连串维度不断升高的代数系统，这便是 Cayley–Dickson 序列。

Cayley–Dickson 构造的核心操作是用一个已有的代数 ![A](https://www.zhihu.com/equation?tex=A) 中的元素，来定义一个新代数 ![A'](https://www.zhihu.com/equation?tex=A%27) 的元素。

![A'](https://www.zhihu.com/equation?tex=A%27) 中的一个新数可以被看作是来自 ![A](https://www.zhihu.com/equation?tex=A) 的一个有序数对 ![(a, b)](https://www.zhihu.com/equation?tex=%28a%2C+b%29)。

新代数中的加法规则十分简单，就是将数对的相应分量直接相加：

![ (a, b) + (c, d) = (a+c, b+d) ](https://www.zhihu.com/equation?tex=+%28a%2C+b%29+%2B+%28c%2C+d%29+%3D+%28a%2Bc%2C+b%2Bd%29+)

真正的精髓在于乘法规则的定义，它引入了微妙的扭转：

![ (a, b)(c, d) = (ac - d^\*b, da + bc^\*) ](https://www.zhihu.com/equation?tex=+%28a%2C+b%29%28c%2C+d%29+%3D+%28ac+-+d%5E%2Ab%2C+da+%2B+bc%5E%2A%29+)

星号 \* 代表共轭运算：

![ (a, b)^\* = (a^\*, -b) ](https://www.zhihu.com/equation?tex=+%28a%2C+b%29%5E%2A+%3D+%28a%5E%2A%2C+-b%29+)

共轭是整个构造过程的灵魂，它本身也随着维度的提升而演化。

这个不断嵌套、并且每次都引入一个负号的共轭运算，每次迭代都必然打碎一些旧的律法。

## Cayley–Dickson 序列

### 实数 ![\\mathbb{R}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BR%7D)

我们的起点是实数 ![\\mathbb{R}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BR%7D)，实数是 Cayley–Dickson 序列的起点，也可以写成 ![\\mathbb{A}\_0](https://www.zhihu.com/equation?tex=%5Cmathbb%7BA%7D_0)。

它是一个看起来完美的代数，拥有所有黄金律：

满足加法交换律、加法结合律、乘法的交换律、乘法结合律，并且是一个有序的集合，任何两个不相等的实数都可以比较大小。

对于一个实数 ![a](https://www.zhihu.com/equation?tex=a)，它的共轭就是它自身：![a^\*=a](https://www.zhihu.com/equation?tex=a%5E%2A%3Da)。

### 复数 ![\\mathbb{C}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BC%7D)

我们将实数 ![\\mathbb{R}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BR%7D) 作为原料，进行第一次构造 ![\\mathbb{A}\_1=\\mathbb{C}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BA%7D_1%3D%5Cmathbb%7BC%7D) 。

新代数中的数是实数对 ![(a, b)](https://www.zhihu.com/equation?tex=%28a%2C+b%29)，这正是我们熟悉的复数 ![a+bi](https://www.zhihu.com/equation?tex=a%2Bbi)。

根据构造法则，我们取 ![a,b,c,d \\in \\mathbb{R}](https://www.zhihu.com/equation?tex=a%2Cb%2Cc%2Cd+%5Cin+%5Cmathbb%7BR%7D)：

-   乘法：![(a, b)(c, d) = (ac - db, da + bc)](https://www.zhihu.com/equation?tex=%28a%2C+b%29%28c%2C+d%29+%3D+%28ac+-+db%2C+da+%2B+bc%29)，因为 ![d^\*=d](https://www.zhihu.com/equation?tex=d%5E%2A%3Dd)。
-   共轭：![(a, b)^\* = (a, -b)](https://www.zhihu.com/equation?tex=%28a%2C+b%29%5E%2A+%3D+%28a%2C+-b%29)，复数的共轭成对出现。

在这里，有序性被破坏了。

在复平面上，我们无法在不产生矛盾的前提下定义 ![i](https://www.zhihu.com/equation?tex=i) 与 ![0](https://www.zhihu.com/equation?tex=0) 的大小关系。

代数失去了线性排列的秩序。

### 四元数 ![\\mathbb{H}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BH%7D)

接下来，我们以复数 ![\\mathbb{C}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BC%7D) 为基础，构造维度为4的新代数 ![\\mathbb{A}\_2=\\mathbb{H}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BA%7D_2%3D%5Cmathbb%7BH%7D)。

一个四元数可以看作是一对复数 ![(a, b)](https://www.zhihu.com/equation?tex=%28a%2C+b%29)，其中 ![a, b \\in \\mathbb{C}](https://www.zhihu.com/equation?tex=a%2C+b+%5Cin+%5Cmathbb%7BC%7D)。

-   乘法：![(a, b)(c, d) = (ac - d^\*b, da + bc^\*)](https://www.zhihu.com/equation?tex=%28a%2C+b%29%28c%2C+d%29+%3D+%28ac+-+d%5E%2Ab%2C+da+%2B+bc%5E%2A%29)。

在这里，乘法交换律被破坏了。

![ij \\neq ji](https://www.zhihu.com/equation?tex=ij+%5Cneq+ji)，乘法的前后顺序开始变得重要。

### 八元数 ![\\mathbb{O}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BO%7D)

以四元数 ![\\mathbb{H}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BH%7D) 为原料，我们得到8维的八元数系 ![\\mathbb{A}\_3=\\mathbb{O}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BA%7D_3%3D%5Cmathbb%7BO%7D)。

一个八元数可以用四元数写成 ![(a, b)](https://www.zhihu.com/equation?tex=%28a%2C+b%29)。

-   乘法：![(a, b)(c, d) = (ac - d^\*b, da + bc^\*)](https://www.zhihu.com/equation?tex=%28a%2C+b%29%28c%2C+d%29+%3D+%28ac+-+d%5E%2Ab%2C+da+%2B+bc%5E%2A%29)。

在这里，乘法结合律被破坏了， ![(xy)z](https://www.zhihu.com/equation?tex=%28xy%29z) 不再总是等于 ![x(yz)](https://www.zhihu.com/equation?tex=x%28yz%29)。

八元数仍然是一种交错代数，交错律是结合律的一种弱化形式。

### 十六元数 ![\\mathbb{S}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BS%7D)

从八元数 ![\\mathbb{O}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BO%7D) 出发，我们可以构造 16 维的 ![\\mathbb{A}\_4=\\mathbb{S}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BA%7D_4%3D%5Cmathbb%7BS%7D)。

在十六元数中，开始出现零因子。

也就是说可以找到两个非零的十六元数 ![x](https://www.zhihu.com/equation?tex=x) 和 ![y](https://www.zhihu.com/equation?tex=y)，使得它们的乘积 ![xy=0](https://www.zhihu.com/equation?tex=xy%3D0)。

这在实数、复数、四元数、八元数中都是不可能发生的。

交错性也被破坏了，同时失去了作为除法代数的资格。

### 三十二元数 ![\\mathbb{P}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BP%7D)

以十六元数 ![\\mathbb{S}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BS%7D) 为基础，得到32维的 ![\\mathbb{A}\_5=\\mathbb{P}](https://www.zhihu.com/equation?tex=%5Cmathbb%7BA%7D_5%3D%5Cmathbb%7BP%7D)。

它继承了之前代数所有的“缺陷”，比如非交换、非结合、非交错、非柔性、非幂结合，并且拥有更多的奇异零因子。

三十二元数往后，数系到底丢掉了什么性质变得难以用已知律法名称来描述，非结合性、零因子等奇异结构的复杂性和数量在急剧增加。

至此，我们对传统代数运算的许多基本直觉都已失效。

继续往下迭代，代数结构看起来越来越病态。

![](https://pic4.zhimg.com/v2-063e3b991174c594a19458c606f0ea1b_r.jpg)

传统数学家已经完全放弃了这些数系,认为它们是畸变的怪物，然而，事实果真如此吗？

![](https://pic2.zhimg.com/v2-859c6f0bf72fe313a4bc64a4180d4daf_b.jpg)

从简单到复杂，从规则到混沌，整个过程遵循着一种虽然隐晦，但确定无疑的深刻数学法则。

当所有黄金律法中明显的性质都已不在时，代数结构并非陷入完全的无序，而是展现出更细致、更复杂的非结合性模式。

或许，这才是代数真正的底层规则，可以称之为非结合代数。

## 非结合代数

非结合不是不结合。

对于一个乘法运算，如果 ![(xy)z \\neq x(yz)](https://www.zhihu.com/equation?tex=%28xy%29z+%5Cneq+x%28yz%29)，我们称其为非结合的。

为了衡量这种非结合程度，数学家定义了结合子（Associator）：

![ \[x, y, z\] = (xy)z - x(yz) ](https://www.zhihu.com/equation?tex=+%5Bx%2C+y%2C+z%5D+%3D+%28xy%29z+-+x%28yz%29+)

-   如果结合子恒为零，那么这个代数就是结合的。
-   如果结合子不恒为零，则代数是非结合的。

凯莱-迪克森序列从八元数开始，其结合子就不再恒为零了。

但是，仅仅说“结合子不为零”是远远不够的，三元非结合性比你想的更加复杂。

* * *

### 非结合序列

现在我们选择代数中的三个不同的纯虚基元素，例如在八元数中可以选择 ![e\_1, e\_2, e\_3](https://www.zhihu.com/equation?tex=e_1%2C+e_2%2C+e_3)，我们称这三个元素为一个三元组（Triad）。

对于这三个元素，存在 ![3! = 6](https://www.zhihu.com/equation?tex=3%21+%3D+6) 种排列方式，每种排列方式的结合子都可能为零或非零。

![\\left\\{\\begin{aligned} &\[e\_1, e\_2, e\_3\]\\stackrel{?}{=}0\\\\ &\[e\_1, e\_3, e\_2\]\\stackrel{?}{=}0\\\\ &\[e\_2, e\_1, e\_3\]\\stackrel{?}{=}0\\\\ &\[e\_2, e\_3, e\_1\]\\stackrel{?}{=}0\\\\ &\[e\_3, e\_1, e\_2\]\\stackrel{?}{=}0\\\\ &\[e\_3, e\_2, e\_1\]\\stackrel{?}{=}0\\\\ \\end{aligned}\\right.](https://www.zhihu.com/equation?tex=%5Cleft%5C%7B%5Cbegin%7Baligned%7D+%26%5Be_1%2C+e_2%2C+e_3%5D%5Cstackrel%7B%3F%7D%7B%3D%7D0%5C%5C+%26%5Be_1%2C+e_3%2C+e_2%5D%5Cstackrel%7B%3F%7D%7B%3D%7D0%5C%5C+%26%5Be_2%2C+e_1%2C+e_3%5D%5Cstackrel%7B%3F%7D%7B%3D%7D0%5C%5C+%26%5Be_2%2C+e_3%2C+e_1%5D%5Cstackrel%7B%3F%7D%7B%3D%7D0%5C%5C+%26%5Be_3%2C+e_1%2C+e_2%5D%5Cstackrel%7B%3F%7D%7B%3D%7D0%5C%5C+%26%5Be_3%2C+e_2%2C+e_1%5D%5Cstackrel%7B%3F%7D%7B%3D%7D0%5C%5C+%5Cend%7Baligned%7D%5Cright.)

此外，由于结合子有一些通用性质，例如 ![\[x, y, z\] = -\[z, y, x\]](https://www.zhihu.com/equation?tex=%5Bx%2C+y%2C+z%5D+%3D+-%5Bz%2C+y%2C+x%5D)，这六个值之间并非完全独立。

一个三元组的非结合性模式，是由这六个结合子的哪些为零，哪些非零，以及它们之间的符号关系所决定的。

更进一步，如果我们考虑三元组 ![(x, y, z)](https://www.zhihu.com/equation?tex=%28x%2C+y%2C+z%29) 的所有可能排列，总共有 ![24](https://www.zhihu.com/equation?tex=24) 种。

这 ![24](https://www.zhihu.com/equation?tex=24) 种排列的结合子，其取值模式构成了非结合性的指纹。

最后分类讨论发现，三元的非结合性模式一共有四种，分别记为 XABC。

### Type X (交错型序列)

对于属于 Type X 的任何三元组 ![\\{x, y, z\\}](https://www.zhihu.com/equation?tex=%5C%7Bx%2C+y%2C+z%5C%7D)，其所有 ![3! = 6](https://www.zhihu.com/equation?tex=3%21+%3D+6) 种排列的结合子都是非零的。

这种类型传统上也被成为交错代数（Alternating Algebra）。

在交错代数中，如果结合子不是零，那么它在任意交换两个相邻元素时会改变符号，例如 ![\[x, y, z\] = -\[y, x, z\]](https://www.zhihu.com/equation?tex=%5Bx%2C+y%2C+z%5D+%3D+-%5By%2C+x%2C+z%5D)。

同时，对于包含重复元素的结合子，如 ![\[x, x, y\]](https://www.zhihu.com/equation?tex=%5Bx%2C+x%2C+y%5D) 或 ![\[x, y, x\]](https://www.zhihu.com/equation?tex=%5Bx%2C+y%2C+x%5D)，它们的值是零。

简而言之，结合子要么是零，要么是非零且符号严格交替。

八元数就属于这类。

### Type A, B, C (非交错型序列)

所有 ![24](https://www.zhihu.com/equation?tex=24) 种排列中剩下的可以归为三个等价组，数学家暂时没想好叫啥名字，只能统称为非交错型序列。

1.  Type A：对于属于 Type A 的三元组 ![\\{x, y, z\\}](https://www.zhihu.com/equation?tex=%5C%7Bx%2C+y%2C+z%5C%7D)，在 ![24](https://www.zhihu.com/equation?tex=24) 种结合子排列中，特定的一组排列的结合子是零，而其他排列的结合子是非零的。
2.  Type B：与 Type A 不同，属于 Type B 的三元组会使得另一组特定排列的结合子为零，而其余为非零。
3.  Type C：属于 Type C 的三元组会使得第三组特定排列的结合子为零，而其余为非零。

### 非结合基因

仅有模式片段式不够的，这些模式如何组合、如何影响整体代数？

这得靠 3-三元组循环（3-triad cycles），由三个相互关联的三元组所组成的结构。

例如给定一个基本的三元组 ![(b, c, d)](https://www.zhihu.com/equation?tex=%28b%2C+c%2C+d%29)，我们可以通过乘法生成另外两个相关三元组，如 ![(b, bc, d)](https://www.zhihu.com/equation?tex=%28b%2C+bc%2C+d%29) 和 ![(c, bc, d)](https://www.zhihu.com/equation?tex=%28c%2C+bc%2C+d%29)。

他们一共有八类：AAA, BBA, ACC, XBB, BXC, CAB, CCX, XXX。

-   XXX：表示该循环中的三个三元组都属于 Type X 非结合性，如八元数。
-   AAA：表示该循环中的三个三元组都属于 Type A 非结合性。
-   BBA：表示该循环中的两个三元组属于 Type B，另一个属于 Type A。
-   依此类推，这些基因名称代表了代数内部非结合性行为的整体模式。

* * *

## 数系进化论

现在，让我们结合 Cayley–Dickson 序列，看看这些非结合性基因如何组合成多样化的物种。

我们从传统代数视角下数系扩充的终点开始。

在八元数中，所有的非结合三元组都属于 Type X。

因此，八元数中只存在 XXX。

这是一个结构相对简单、高度对称的非结合代数。

当维度从 8 上升到 16 时，Cayley–Dickson 构造引入了更强的共轭扭曲，使得八元数的交错性消失。

这在微观层面体现为 Type A, Type B, Type C 这三种新的非结合序列的显现。

相应地，新的基因也开始涌现，例如 AAA, ACC, CCX。

十六元数不再是单一的 XXX 模式，而是多种非结合模式的首次组合。

在三十二元数中，非结合性进一步进化，更多的 Type A, B, C 序列被激活，并且它们以更复杂的模式组合。

新的基因 BBA, BXC 也开始出现，非结合性的种类和复杂程度都在迅速攀升。

在一百二十八元数中，随着维度的进一步提升，像 CAB 这样的新基因也首次出现。

在这个阶段，非结合性行为的种类达到了前所未有的丰富度。

二百五十六元数是整个进化过程的关键转折点。

此时所有一直的八种非结合性基因（AAA, BBA, ACC, XBB, BXC, CAB, CCX, XXX）全部都已经出现并占据一席之地。

这意味着虽然 Cayley–Dickson 构造可以继续生成更高维度的512维、1024维代数，但它们在非结合性行为的种类上，不会再有任何新的突破。

所有的基本基因和它们可能形成的所有主要物种都已经完全出现。

从这个维度开始，后续的 Cayley–Dickson 代数，其非结合性的复杂性增长只会表现为数量上的增殖，而不再是种类上的扩充。

非结合模式饱和了，至少三元非结合性饱和了。

而数系的进化从未停止，八元数并非终点，而是起点。

但是问题是前方的扩展方向，或者说进化方向实在是有点太多了。

数学家除了符号游戏意外，对实际应用也是有一定追求的，纸上谈兵的定义一堆新运算毫无意义。

我们对十六元数以上的认知还只是冰山一角，对其背后的图景知之甚少。

一个统一的非结合代数应该如何建立，尚处于争议之中。
