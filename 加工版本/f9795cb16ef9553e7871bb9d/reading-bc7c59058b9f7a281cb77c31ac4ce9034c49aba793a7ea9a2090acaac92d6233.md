# 二十五种实用思维工具｜Twenty-Five Useful Thinking Tools

---

## 正文

大多数人认为，smart 就是拥有更多 facts。像 _Jeopardy!_ 这样的 Trivia-shows 正体现了这种 knowledge 观。最 smart 的人，就是在 mind 中 stored away 了最多 names、dates 和 places 的人。

不过，这可能是 learning 中最不重要、最没有用的部分。比起 facts，我更愿意关注那些能充当 tools 的 knowledge。你拥有的越多，就越能用更多 ways 来 approach 不同的 problems。

[Charlie Munger](https://en.wikipedia.org/wiki/Charlie_Munger)，也就是 Warren Buffet 在 Berkshire Hathaway 多年的 investing partner，把这些称为 mental models。更多 mental models 意味着你有更多 ways 来 solve 更多 problems。

这个话题以前已经讨论过很多次了，但我想换个角度来看。

## 作为思考工具箱的职业：Professions 与 Thinking Toolkits

收听这篇文章

大多数人根据 professions 所做的事情来 define 这些 professions。Engineers 会 build 东西。Economists 会 study money。Psychologists 会探究人们的 minds。

不过，尽管这是一个显而易见的 distinction，我更感兴趣的不是 professions 试图 solve 什么 types 的 problems，而是它们如何尝试 solve 这些 problems。在这里，我们可以发现大量不同的 thinking tools；它们往往足够 abstract，能够 apply 到远远超出该 profession 典型关注范围的地方。

来看看 economics。虽然大多数人把它视为对 money 的 study，但它更像是一种思考世界的方式。因此，才会有像 [Freakonomics](http://freakonomics.com/) 这样的书，把 economics 的 thinking tools apply 到各种与 money 毫无关系的 scenarios 中。

## 二十五种思考工具：Twenty-Five Thinking Tools

下面是二十五种 tools，每一种都是我从自己认为最能 exemplifies 它的 profession 中 abstracted 出来的。

> 读者须知：这里并不打算对每个 profession 使用的每一种 tool 作 full descriptions。那样就太荒唐了。我只是想挑出一种看起来足够 unique、足够 abstract 的 tool，分享给其他人。这并不是要把一个 profession 的 full complexity reduce 到 single tool，所以请不要这样理解。

### 1\. Artist：如果把 Creativity 放在首位呢？

[![Artist（艺术家）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-001.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-001.png)

其他大多数 professions 都对一个人的 ideas 施加了种种 constraints。它们需要是 monetizeable、mathematical 的，还要 under budget、within specifications。Artists 所处的领域中，这些 constraints 大多得到了 reduced，因此更重要的问题是：“为什么它是 unique 而且 interesting 的？”

然而，这是一种可以 apply 到许多其他事情上的有用 thinking tool。最好的 companies 往往 produce 出看起来像 art 的东西。它们受到 uniqueness 和 creativity 的 driven，而不是平淡无奇地逐项满足一份 specs 清单。

如果你把 novelty 放在最优先的位置，你的 work 会发生什么变化？如果你优先考虑的是 coolness、interestingness，或对某个 original idea 的 refinement，你的 goals 和 projects 又会有什么不同？

### 2\. Economist：人们如何 React 于 Incentives？

[![Economist（经济学家）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-002.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-002.png)

economics 中有许多自身特有的 thinking tools，但其中一种 foundational 的 tool 很简单：人们会 respond to incentives。

身为 economist 的 Tyler Cowen [把这一点讲得最透彻](https://www.youtube.com/watch?v=actEhnPE4VM)。他解释说，economic reasoning 的一个 key element 是：当你 changing 一个涉及人的 system 时，人们并不会停留在原处。相反，他们会相应地 respond 于新的 incentives。

你采取的几乎任何 action，都会 alters 与你打交道的其他人对 incentives 的 perceptions。你心中的 economist 应该问自己：“如果我 change 这个，人们将如何 react？”

### 3\. Engineer：我能对它进行 Model 和 Calculate 吗？

[![Engineer（工程师）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-003.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-003.png)

Engineering 建立在 hard sciences 的基础之上，它的一些 estimates 是所有 profession 中最 precise、最 accurate 的。你的 financial advisor 在 picking 哪些 stocks 会 rise 时，只能像掷飞镖一样碰运气；psychologist 也只能给出一些关于人们会做什么的 hints。相比之下，engineers 却经常 create 目前还不存在、而且需要在 100% 的时间里都能 work 的东西。

做到这一点的 essence 是：为你试图处理的对象 create 一个 model，measure 相关的 variables，并知道这些 measurements 预计会有多大 degree of error。在此基础上，你就能真正知道会发生什么，而不只是 guessing。

最近，我和团队把这种方法 applied 到了我们遇到的一个 problem 上：predicting 我们的 sales。我们决定根据人们 subscribed 了多久，以及他们获得 sign up 机会的频率，来 make 一个关于 sales numbers 的 model。在此基础上，我们将能够对 sales 作出好得多的 estimates，而我们以前的 guesses 常常会偏离得非常离谱。

### 4\. Entrepreneur：多做些尝试，看看什么 Works

[![Entrepreneur（创业者）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-004.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-004.png)

Entrepreneurs 往往缺少 money、resources、support 或时间。然而，他们需要设法拼出一种无论如何都能 make money 的 solution。他们可以通过 adopting 一套在普通 professionals 中往往很少见的 thinking tools 来做到这一点。

一种主要的 tool 是 [rapid prototyping](https://en.wikipedia.org/wiki/Rapid_prototyping)。许多人把它视为一种 product development strategy。你做出一个刚刚勉强能 works 的东西，看看是否有人想要它。但实际上，它是一种 abstract thinking tool，适用范围远远不止 product R&D。

这种 thinking tool 的 essence 是，你走出去，尝试许多事情，而不是一直等待一个 perfect answer。它还要求你认真倾听 feedback，从而获得接下来该做什么的 hints。Speed 和 volume 弥补了在一个充满 uncertainty 的 noisy environment 中 making decisions 的不足。

有时候，solve 一个 problem 的正确方式，就是多做些尝试，看看什么 works！

### 5\. Doctor：Diagnosis 是什么？

[![医生（Doctor）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-005.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-005.png)

Doctors 接诊的 patients 有一系列 symptoms，其中有些他们可能没有告诉你（或无法告诉你）。接下来，你需要像 detective 一样 deduce 最有可能的 disease，并 create 一个 plan 来 cure 它。在这期间，一步走错就可能 kill 你的 patient，所以你必须审慎选择。

medicine 中一个好的 thinking tool，是用 symptoms 来 deduce 一种 disease，并通过与 base rates 进行 comparing，来 make highly-accurate decisions。

虽然这适用于 medicine，但还有很多地方也很重视 diagnosis。你的汽车发出了奇怪的声音。你的 computer 不 work 了。你的 business 已经不再赚钱了。

首先要看看所有 possible causes 都可能是什么。这需要 study 和 knowledge。接着，你需要根据自己 observe 到的 symptoms，尽可能多地进行 rule out。最后，在剩下的 options 中，哪些是 rare afflictions，哪些又是相当 common 的？知道这一点，可以帮助你确定一个 most likely diagnosis。

### 6\. Journalist：只看 Facts

[![记者（Journalist）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-006.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-006.png)

Journalists 依靠大量不同的 thinking tools，来 write compelling stories，以 fairly 和 accurately 的方式 report news。

这些 thinking tools 之一是 [fact-checking](https://en.wikipedia.org/wiki/Fact-checking)。因为 journalists 经常需要 interview 可能具有 misleading 性（甚至 hostile）的 sources，所以通过 independent sources 来 corroborate 所说的内容十分重要。Fact-checking 可能很耗时，但它带来的 world-view，比仅仅盲从一句偶然听来的评论要 accurate 得多。

如果你深入查证自己赖以 make decisions 的关键 information 的 veracity，你的生活会是什么样？想象一下，如果你必须在 _New York Times_ 上 report 自己知道的内容，后来是否还需要 retracted？

### 7\. Scientist：提出一个 Hypothesis，并 Test 它

[![科学家（Scientist）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-007.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-007.png)

Scientists discover 关于世界的 truths。为此，他们需要 thinking tools。

science 的一个 basic thinking tool 是 [controlled experiment](https://en.wikipedia.org/wiki/Scientific_control#Controlled_experiments)。让所有 variables 保持 the same，只有你想 test 的那个除外，然后看看会发生什么。这需要 meticulous preparation 和 design，以防 outside contamination 破坏你的 results。

太多人从根本算不上“experiments”的经历中 draw inferences。其中有许多 conflicting variables，使得针对他们的 experiences 进行 drawing conclusions 困难得多。如果你像 scientist 一样对待自己的 diets，会怎样？对待自己的 working routines 呢？之后你还会相信它们吗？

你对工作和生活的 beliefs，有多少能 withstand 这样的 scrutiny？又有多少 Undergo 过这样的 testing？也许，在生活中多用一点 scientific thinking tools，能让你受益。

### 8\. Mathematician：直到你能 Prove 它，你才算知道

[![数学家（Mathematician）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/problems-001.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/problems-001.png)

mathematician 的 thinking tools，依赖于对什么才 constitutes 某件事的 proof 采用高得多的 standard。虽然 engineer 可以容忍 precision 在某些 bounds 之内，entrepreneur 也可能满足于一种 hunch，但 mathematician 的 statements 必须是 irrefutable 的，否则就不算数。

你可以在 programming 这样的 adjacent field 中，看到这个 thinking tool 如何 influence non-mathematical domains。在我的 [MIT Challenge](https://www.scotthyoung.com/blog/myprojects/mit-challenge-2/) 期间，我听 lecturers 谈起 MIT 的 programming 风格，以及源自 Bell Labs 的另一种风格。MIT 更偏 mathematical 和 academic，往往在 proving 自己的 programs worked 方面更加 rigorous；而 Bell Labs 常常只要有一个看起来能完成任务的 algorithm 就满意了，即使他们无法 guarantee 这一点。

Mathematical thinking tools 帮助你变得更加 rigorous，并 spot 那些后来可能证明是 relevant 的 mistakes。

### 9\. Programmer：有什么 Pattern 是我可以 Automate 的？

[![程序员（Programmer）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-008.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-008.png)

Programming 包含许多 thinking tools，但最 basic 的一个是 [algorithm](https://en.wikipedia.org/wiki/Algorithm)。Algorithms 是一组可以被 defined precisely 的 steps，因此 perform 其中每一步都不需要 intelligence，但 net result 却是一个 useful product。

这有一个 useful application：看看你所做的事情，找出哪些可以被 automated、simplified 或 refactored。Programmers 能够 spot repeated code，并尝试把 redundant 部分的 essence 进行 abstract out，形成能够 automatically 完成你所需任务的东西。

除了能自己 write code，你还可以在生活中的许多其他 domains 更像 programmer 一样思考。你在工作中经常 repeat 的事情，有哪些可以被 automated？你可以把什么 ambiguous process convert 成一组 foolproof 的 steps？

### 10\. Architect：Envisioning 未来

[![建筑师（Architect）](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-009.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-009.png)

Architects 需要 design buildings。这些是 large structures，可能需要数年才能 build，同时还必须 meet clients、contractors、city planners 和 building codes 的所有 criteria。哦，而且它们还应该是 beautiful 的。

为此，architects 需要一套 thinking tools（以及 software），从一个 idea 出发，envision 在花费数百万美元之后，它以 large scale 呈现时究竟会是什么样。其中一个 tool，就是 making a model。

先 Making 你想 create 的东西的 scaled down version，以便看看它的样子，再 envisioning 它的 larger version 会是什么样，这并不容易；但这往往能让你在来不及改变之前，就看清现实将会是什么样。

### 11\. Salesperson：比他们自己更 Understand 他们的 Minds

[![销售人员 Salesperson](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-010.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-010.png)

Selling 常常名声不佳。人们认为，这无非就是 trickery 和 deceit，试图通过 manipulating 让某人 buying 他们大概不该买的东西。

虽然这是 stereotype，但实际情况很少如此。相反，salespeople 努力 deeply understand customer 实际上 needs 什么，然后为他们 match 能够填补这一缺口的 products 和 services。这极其困难，因为你可能比 customer 自己更早 recognize，你拥有他们的 problem 的 solution。

要在这个 profession 中取得 success，一个关键的 thinking tool 是能够根据人们的（往往 contradictory behavior）来 infer 他们的 worries 和 needs 是什么。他们使用什么 language？他们的 actions 与他们 stated intentions 有何 differ？你能据此 infer 出什么？

这个 tool 的 apply 范围远不止多赚一笔 commission。你的配偶真正想要什么，而不是他们告诉你的那些？你的朋友呢？你的老板呢？

### 12\. Soldier：Routine 和 Discipline 能 Prevent Deadly Mistakes

[![士兵 Soldier](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-011.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-011.png)

military personnel 所体现的 discipline 是一种非常有用的 thinking tool，即使在 combat situations 之外也是如此。Discipline 和 routine 成为防范 careless mistakes 的 safeguard，而这些 mistakes 可能夺去生命。通过要求遵守那些 protocols，即使没有危险，也能大幅减少出错的余地。

每天早上整理床铺也许不能 prevent casualties，但如果你能完美地 follow 那项 procedure，你也就更有可能 follow 那些可以救你一命的 procedure。这种 discipline 也存在于另一个事关生命的领域：medicine。[The Checklist Manifesto](http://atulgawande.com/book/the-checklist-manifesto/) 将 military routine 的这一 idea apply 于 hand-washing 等日常小事，通过 avoiding infection 来挽救生命。

一旦知道做某件事的最佳方法，就要 precisely and exactly 地去做，不要马虎，否则可能有人受伤。

### 13\. Chess Master：在你的 Mind’s Eye 中 See 那些 Moves

[![国际象棋 Chess](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-012.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-012.png)

Chess 长期以来一直被认为是一种能够 improve 一个人的 thinking 的 game。虽然多年的 chess study 是否必然会让你更聪明值得怀疑，但仍有许多 thinking tools 可以从这个 game 中发掘出来。

其中之一是在 mind’s eye 中 simulate 这个 game 的能力。grandmasters 的一种常见技巧是进行 [blindfolded games](https://en.wikipedia.org/wiki/Blindfold_chess)。虽然这让观众惊叹，但它实际上 reinforces 一种有用的 practice——能够在脑海中 see 这个 game，从而 calculate 你的 opponent 将来会做出的 moves。

这在 chess 之外的其他 domains 中往往也很有帮助。试着 visualize 可能发生的事，然后将那个 prediction 与现实 compare。这可以磨炼你的 simulation abilities，让你在陷入困境时能够 predict 接下来会发生什么。

### 14\. Designer：你 Make 的东西会替你 Communicate

[![设计师 Designer](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-013.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-013.png)

我最喜欢的书之一是 [The Design of Everyday Things](https://www.amazon.com/Design-Everyday-Things-Revised-Expanded/dp/0465050654)。虽然这本书是写给 designers 的，但它实际上讲的是 designers 应当 cultivate 的 thinking tools。因此，即使你这辈子从未制作过任何东西，也可以拿起它来读一读。

这里一个有用的 tool 是：某件东西的 made 方式会 suggests 它的使用方式。一个 well-designed door handle 无须文字说明，就会 suggests 是 push 还是 pull。一个 well-designed light switch 应当已经能告诉你，拨动它时哪些房间会被 illuminated。

如果你 designed 自己的 speeches，让它们 automatically 促使 audience 将 thinking 转向你需要的方向，会怎样？如果你 designed 自己的 habits，让你能够 automatically applied 它们，又会怎样？这个 thinking tool 的 scope 确实相当广。

### 15\. Teacher：你能 See 不 Know 某件 Obvious 的事是什么感受吗？

[![教师 Teacher](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-014.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-014.png)

你如何在别人的 mind 中 create knowledge？你如何让他们获得以前没有的 abilities？

我们大多数人都把 teaching 实际上有多么神奇，以及我们自己从中 learn 的 ability，视为理所当然。要做到 effective，teachers 需要拥有一个 model，了解他们的 pupils 的 minds 如何 see 世界，同时还需要一个用于 changing 它的 game plan。

要在大多数 professions 中 succeed，你需要能够让别人像你一样 see 那些 problems。这涉及 identifying 他们 lack 什么 knowledge，并说出恰当的话，使他们达到你现在的理解程度。虽然对 teachers 而言，这是一项显而易见的 skill，但它也有益于那些试图 explain 自己的 code 的 programmers、试图 articulate 某项 medical procedure 的 reasons 的 doctors，或希望 employees 能够 follow 某个 vision 的 leader。

### 16\. Anthropologist：你能 Immerse 并 Join 另一种 Culture 吗？

[![人类学家 Anthropologist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-015.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-015.png)

Anthropology 就是 [study of cultures](https://en.wikipedia.org/wiki/Anthropology)。economics 往往侧重 mathematical models，psychology 往往进行大量 careful experiments；与它们不同，anthropologists 通过实际 immersing 于 cultures 之中来 learn 它们。

你如何让自己 immerse 于那些你并不属于的 groups？不同 nationalities 或 languages 的 groups？Politics 或 professions 的 groups？Hobbies、sports、religions 或 philosophies 的 groups？你如何 learn 这些 groups 中的人怎样 function，并在与他们共同生活时让他们接纳你？

### 17\. Psychologist：Test 你对其他人的 Understanding

[![心理学家](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-016.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-016.png)

Psychology 有不同的 thinking tools，既 embedded 在它关于 human nature 的 assumptions 中，也 embedded 在它 discovering human nature 的 methods 中。

就 psychology 本身这个 subject 而言，有无数 tools。Cognitive biases、attention 的 models、morality、preferences、instincts、memory，等等。关于如何使用这些 tools 更好地 think about 其他人，可以写出几十本书，而且确实已经有这样的书了。

有趣的是，psychology 也是一种 profession，拥有自己的一套用于 discovering psychology 的 tools。与所有 scientists 一样，这涉及 creating experiments，在其中，你可以 control 除了你想 study 的 variable 之外的所有 variable。不过，与其他 scientists 不同，你的 object of study 是 human beings，这意味着你往往不能让他们知道你正试图 adjust 什么。

### 18\. Critic：你能 Build on 他人的 Work 吗？

[![评论家](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-017.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-017.png)

许多 critics 不只是告诉你该读哪些 books、看哪些 movies。他们 build 的 analysis、interpretation 和 discussion 远远超出了 original work。

其中涉及的 thinking tools 相当重要，即使对于不以 analyze literature 为生的人也是如此。首先，是对 creative works 投入十分密切的 attention 的 ability。比起仅仅作为一个 shallow consumer，要更加 deeply 地 Experiencing 某个作品。其次，是能够把那些 knowledge connect 到由其他 issues 和 ideas 构成的 web 中的 tool。这会 builds on 一个 original creation，增添比原先更多的 insight 和 ideas。

### 19\. Philosopher：一个 Intuition 有哪些 Unexpected Consequences？

[![哲学家](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-018.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-018.png)

Philosophers，至少是其中的 [analytical kind](https://en.wikipedia.org/wiki/Analytic_philosophy)，往往拥有与 mathematicians 相似的 style 和 toolkit，只不过他们经常 dealing with 的事物是以 imprecise 的 words 为基础的。因此，对于 dealing with 无法 reduced to numbers 的事物，有许多有用的 thinking tools。

一个 powerful tool 是能够看出将某个 idea stretching 到其 limits 时的 unexpected consequences。这有两个好处。第一，它可以通过 [reductio ad absurdum](https://en.wikipedia.org/wiki/Reductio_ad_absurdum) 来 reveal 原先 idea 中的 flaws。第二，这可以帮助你 recognize 你对事物的 vague intuitions 背后的 fundamental principles。通过让你的 ideas 接受更强的 hypothetical critiques，你可以看出它们赖以 work 的 real mechanisms。

### 20\. Accountant：关注 Ratios

[![会计师](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-019.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-019.png)

Money 是 business 的血液。Accounting 所做的工作，就是观察它如何流动，检查并确保它没有淤塞。

accounting 中有许多有用的 thinking tools，可以用来 diagnosis 那些表面上看不出来的 problems。其中之一是 [ratio analysis](https://en.wikipedia.org/wiki/Financial_ratio) 这一 idea。Ratios 是一种 fraction，其 numerator 和 denominator 是 business 内部的两个不同 measurements。例如，Leverage ratio 是 company 所欠的 debt 与 owners 投入的 equity 之比。如果过高，default 的 risk 就会更大。Price-earnings ratio 根据 stock 的 profits，告诉你它有多 expensive。

这种 analysis（以及 accounting 中的许多其他 analysis）对 non-accounting domains 也有用。在 health 领域，[BMI](https://en.wikipedia.org/wiki/Body_mass_index) 就是一种颇为讲究的 ratio analysis，在这里，它是你的 weight 与你的 height squared 的比较。不过，你也可以设想 tracking 许多其他 numbers 及其 ratios：每 hours worked 的 output、每 lines of code 的 bugs、每花在 online dating 上的 hours 所获得的 dates。

对 data 进行 Organizing、对 details 进行 keeping track，以及看出表面之下的 patterns，都是你可以在 spreadsheet 之外 exploit 的 accounting tools。

### 21\. Politician：人们会 Believe 什么？

[![政治家](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-020.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-020.png)

Politics 提供了自己的一套 tools。politics 与 business 的一个主要 difference 是，虽然两者都旨在实现世界上的某种 objective——前者却高度依赖 voters 的 impression。一个 business 只要能 work 就行，而一个 politician 即使工作出色，也仍可能因为糟糕的 PR 而被赶下台。

因此，politicians 拥有的 thinking tools，不仅关乎 calculating 某个 action 的 effect，还关乎那个 action 将如何被 perceived。无论是 voting populace，还是自己的 allies 和 enemies，都是如此。

这里的 thinking tools 意味着，有时正确的 decision 并不可行，仅仅因为其他人不会这样看待它，而你又没有 power 去 convince 他们。这可能令人沮丧，但它适用于 reality 的许多方面，尽管我们宁愿不是这样。

### 22\. Novelist：你的 Story 是否 Make Sense？

[![小说家](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-021.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-021.png)

许多人把 stories 看作 history 的 linguistic embodiment。我们把实际发生的事情编织成 words，让其他人能够亲自看见。

Novelists 比任何人都更明白，实际发生的事情往往并不是一个好的 story。Stories 中的 characters 拥有 fixed traits，使他们的 actions 成为 predictable 的。在现实生活中，人们是 [more influenced by context](https://en.wikipedia.org/wiki/Fundamental_attribution_error) 的。Stories 有 beginnings、middles 和 ends。Reality 则是没有 arc 的 continuous stream of events。

遗憾的是，人们对 stories 的 understand 远胜于对 realities 的 understand。因此，你往往需要以他们能够 interpret 的方式，package up 你想告诉他们的 histories。有哪些人参与其中？那些事情是什么时候发生的？提供 information，让听者更容易跟上。

虽然这适用于 writing novels 或 making movies，但 telling stories 是每个人生活的一部分。从“你为什么想做这份工作”，到“你觉得自己五年后会在哪里？”这些都是 stories，而我们需要 understand 它们的 structures。

### 23\. Actor：Pretend 的最佳方式就是真实（The Best Way to Pretend is to Be Real）

[![演员](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-022.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-022.png)

acting 中一种常用的 thinking tool 叫作 [method acting](https://en.wikipedia.org/wiki/Method_acting)。这种 technique 要求你尝试真正 feel 你所 portraying 的 character 的 emotions，而不只是 faking 它。

这看起来可能是一个 contradiction：你怎么能 feel 某种自己明知是 fake 的东西？然而，这恰恰掩盖了 imagination 在 conjure up situations、create empathy 方面有多么强大。过去的 struggles 可以替代你所扮演的 role 的 struggles。当你确实在 experiencing 它们时，Fear、happiness、confidence 和 passion 的呈现都会更好。

这也提示了一种强大的 thinking tool，尽管它更多是 affective，而不是 cognitive：通过 changing 你的 emotional state，获得你想要的 results。你 Feeling insecure，却知道自己需要 confidence？为什么不能像 playing a part 那样，在自己内心唤起它？但不要 fake 它——要 _feel 它_。

### 24\. Plumber：把它 Take it Apart，看看哪里 Broken

[![水管工](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-023.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-023.png)

Tradespeople 拥有 unique problem solving tools 和 strategies，却没有因此得到足够的认可。许多 academic 和 intellectual 人士从来不会考虑从事 plumbing、carpentry 或 electrical work。然而，这些 professions 的收入往往超过拥有 college degree 的人，而且理由充分：这些是市场需要的 hard skills。

plumbing 的 essence 和许多其他 trades 一样，在于亲自动手，把东西 take something apart，看看哪里 broken。为此，你需要一个关于内部构造的 model——否则，你可能弄得到处漏水，或者遭遇危险的 shock。但你也需要把东西 take things apart，才能 understand 它们。

我们有多少人因为害怕亲自动手，而回避 understanding 事物？我们不想冒着把东西 breaking 的风险，于是从未真正 understand 它是如何 works 的？

### 25\. Hacker：底下究竟发生了什么？

[![黑客](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-024.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-024.png)

Hacking 是最经常被误解的 skills 之一。电视节目把它描绘成一种 computer 魔法，伴随着飞舞的立方体，以及不断降到 zero 的 firewall health bars。

然而，实际上，hacking 主要在于 understanding：一个 simpler layer 的下面，往往还有一个更 complicated 的 layer of instructions，它正是 built on top 于后者之上的。Computer 处于 hierarchies 中，因此每个 level of abstraction 都会 simplifies 并 reduces 它下面的 layer，使其更容易 understand。然而，有时这会让你做到一些在 higher level 看来 impossible 的事，而它们实际上是 lower level 的 works 方式所带来的 unintended feature。

其中一个 example 是 memory overflow exploit。许多 programs 在 higher level 上 work，memory 在其中以 restricted silos 的方式被 accessed。如果请求 memory 之外的东西，你就会得到一个 error。然而，实际上，所有 memory 都位于一条长线上，用于不同事物的 memory 彼此相邻。如果你能在“outside of the bounds”进行 write memory，就能让 computer 做到一些你原本会天真地以为 impossible 的事。

看看某个 Mario game 中的这个 glitch：一系列 inputs 会向 game 中一个 unintended section 进行 write code，让你通过 inputting 一串奇怪的 actions 来获胜：

这种 thinking tool 对 computers 有效，对生活的其他领域也同样有效。记住：你看到的一切，通常都是更深层 reality 的 simplification。这可能意味着，underlying system 会以你原本想不到的方式出现 broken 的状况。

## 关于 Thinking Tools 的最后一些想法

这些只是对不同 professions 中一种关键 tool 的 summaries。然而，实际上，每个 domain of skill 都有几十种、甚至几百种 thinking tools。不只是 professions，hobbies、subjects 和 general life skills 也会 develop thinking tools。

问题在于，人们往往很难 recognizing 这种 skill，并把它从产生它的地方 abstracting 出来。这是一个 far transfer 的问题，并不容易 resolve。

然而，如果你能说清楚 pattern 是什么，就能开始看出如何将它 apply 到其他地方。大多数这样的 tools，在远离起点的 domains 中并不能发挥最佳作用。一个 novelist 如果试图用 storytelling 来 diagnose medical problems，就会遇到大麻烦。但我们往往过于执着于使用自己最喜欢的 tools，以至于根本不去考虑哪些其他 tools 可能 apply。Creative solutions 需要 divergent thinking，让我们在需要其他 tools 时，能想到某一种 tool。

### Creative Work 需要 Diverse Thinking Tools

一项 [classic experiment](https://en.wikipedia.org/wiki/Candle_problem) 表明了这类 tools 的必要性。Subjects 被要求用一盒图钉把一支蜡烛固定在墙上。solution 是把盒子用作 base——试图直接把图钉用在蜡烛上，只会弄得一团糟。这很难，因为我们把盒子看作用来装 tools 的 container，而不是本身就是一种 tool。

同样，这些 tools 中的许多种，都可能为你未曾考虑过的 problems 带来 creative solutions。例如：

-   如果你是一位 entrepreneur，那么，假如你像 artist、teacher 或 novelist 那样对待自己的 business，它会是什么样子？
-   如果你是一位 programmer，假如你采用 salesperson 或 accountant 的 tools，你的 code 会如何 improve？
-   如果你是一位 journalist，假如你像 scientist、economist 或 plumber 那样行事，你的 pieces 会发生什么变化？

并非每一种 combination 都会有用，但其中许多种也许恰好能给你带来通向 breakthrough 的 solution。

## 原文

Most people think being smart is about having more facts. Trivia-shows like _Jeopardy!_ epitomize this view of knowledge. The smartest people are the people with the most names, dates and places stored away inside their mind.

This is probably the least important and useful part of learning though. Instead of facts, I’d prefer to focus on knowledge that acts as tools. The more you have, the more ways you can approach different problems.

[Charlie Munger](https://en.wikipedia.org/wiki/Charlie_Munger), Warren Buffet’s long-time investing partner at Berkshire Hathaway, calls these mental models. More mental models means you have more ways to solve more problems.

This is a topic that has been discussed a lot before, but I’d like to take a different angle at it.

## Professions as Thinking Toolkits

Listen to this article  

Most people define professions by what those professions do. Engineers build things. Economists study money. Psychologists look into people’s minds.

However, while this is an obvious distinction, I’m more interested not in what types of problems professions try to solve, but how they try to solve them. Here, we can uncover a wealth of different thinking tools that are often abstract enough to apply well outside the typical interest of the profession.

Consider economics. Although most people view this as a study of money, it is more like a way of thinking about the world. Hence we have books like [Freakonomics](http://freakonomics.com/) which apply the thinking tools of economics to all sorts of scenarios that have nothing to do with money.

## Twenty-Five Thinking Tools

Below are twenty-five tools, I’ve abstracted from the profession I feel exemplifies them best.

> Reader’s note: These are not intended to be full descriptions of every tool used by that profession. That would be silly. Instead, I wanted to pluck one tool which seemed unique and abstract enough to share with others. These aren’t meant to reduce the full complexity of a profession down to a single tool, so don’t take it as such.

### 1\. Artist: What if Creativity Were the Priority?

[![Artist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-001.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-001.png)

Most other professions are full of constraints upon one’s ideas. They need to be monetizeable, mathematical, under budget and within specifications. Artists operate in a realm where most of these constraints are reduced, so the bigger question is, “Why is this unique and interesting?”

This, however, is a useful thinking tool to apply to many other concerns. Often the best companies produce things that look like art. They are driven by uniqueness and creativity, rather than blandly filling out a list of specs.

How would your work change if you made novelty the biggest priority? How could your goals and projects be different if coolness, interestingness or refinement of an original idea were your priority?

### 2\. Economist: How Do People React to Incentives?

[![Economist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-002.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-002.png)

There are many thinking tools native to economics, but a foundational one is simple. People respond to incentives.

Tyler Cowen, economist, [delivers this best](https://www.youtube.com/watch?v=actEhnPE4VM), explaining that a key element of economic reasoning is that by changing a system involving people, the people do not stay in place. Instead, they respond to the new incentives accordingly.

Almost any action you’ll take alters the perceptions of incentives by other people you deal with. The economist in you should ask yourself, “if I change this, how will people react?”

### 3\. Engineer: Can I Model This and Calculate?

[![Engineer](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-003.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-003.png)

Engineering, being built off of the hard sciences, has some of the most precise and accurate estimates in any profession. While your financial advisor can only throw darts at picking which stocks will rise, and a psychologist can only give hints at what people will do, engineers routinely create things which don’t currently exist and need to work 100% of the time.

The essence of doing this is to create a model of what you’re trying to work with, measure the relevant variables, and know to what degree of error you can expect in those measurements. From there, you can actually know what will happen, instead of just guessing.

My team and I applied this recently to a problem we had involving predicting our sales. We decided to make a model of sales numbers based on how long people had subscribed and how often they had been offered a chance to sign up. From there, we will be able to make much better estimates of our sales, whereas our guesses before would often be wildly off the mark.

### 4\. Entrepreneur: Do a Lot of Things; See What Works

[![Entrepreneur](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-004.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-004.png)

Entrepreneurs often have too little money, resources, support or time. Yet they need to scramble together a solution that will somehow make money. They can do this by adopting a set of thinking tools that is often rare for normal professionals.

One major tool is [rapid prototyping](https://en.wikipedia.org/wiki/Rapid_prototyping). Many people see this as a product development strategy. You make something that just barely works to see if anyone wants it. But in reality, it’s an abstract thinking tool that applies to a lot more than product R&D.

The essence of this thinking tool is that you go out and try a bunch of things, without waiting around for a perfect answer. It also requires listening carefully for feedback, so you can get hints as to what to do next. Speed and volume make up for making decisions in a noisy environment full of uncertainty.

Sometimes the right way to solve a problem is simply to do a lot of things and see what works!

### 5\. Doctor: What’s the Diagnosis?

[![Doctor](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-005.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-005.png)

Doctors meet patients who have an array of symptoms, some of which they probably aren’t telling you (or can’t). From there, you need to act like a detective to deduce the most likely disease and create a plan to cure it. During this, a wrong move might kill your patient, so you have to choose wisely.

A good thinking tool from medicine is the idea of using symptoms to deduce a disease, and comparing with base rates to make highly-accurate decisions.

While this applies to medicine, there’s a lot of places where diagnosis is important. Your car is making a funny noise. Your computer doesn’t work. Your business has stopped making money.

The first thing to do is see what all the possible causes could be. This requires study and knowledge. Next, you need to rule out as many as possible based on the symptoms you observe. Finally, of the options that are left, which are rare afflictions and which are fairly common? Knowing this can help you settle on a most likely diagnosis.

### 6\. Journalist: Just the Facts

[![Journalist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-006.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-006.png)

Journalists rely on a ton of different thinking tools which allow them to write compelling stories that report the news fairly and accurately.

One of these thinking tools is [fact-checking](https://en.wikipedia.org/wiki/Fact-checking). Because journalists often need to interview sources who may be misleading (or even hostile), it’s important to corroborate what was said from independent sources. Fact-checking may be time consuming, but it results in a much more accurate world-view than simply blindly following a stray comment.

How would your life looked if you dug around to check the veracity of key pieces of information you’re depending on to make decisions? Imagine if you had to report what you know in the _New York Times_. Would it need to be retracted later?

### 7\. Scientist: Make a Hypothesis and Test It

[![Scientist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-007.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-007.png)

Scientists discover truths about the world. To do this, they need thinking tools.

A basic thinking tool of science is the [controlled experiment](https://en.wikipedia.org/wiki/Scientific_control#Controlled_experiments). Keep all the variables the same, except the one you want to test, and see what happens. This requires meticulous preparation and design to prevent outside contamination from breaking your results.

Too many people draw inferences from “experiments” that are anything but. They have many conflicting variables that make drawing conclusions about their experiences much more difficult. What if you approached your diets like a scientist? Your working routines? Would you still believe them after?

How many of your beliefs about work and life withstand such scrutiny? Undergo such testing? Maybe you could benefit from a little more scientific thinking tools in your life.

### 8\. Mathematician: You Don’t Know Until You Can Prove It

[![Mathematician](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/problems-001.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/problems-001.png)

The thinking tools of a mathematician depend on having a much higher standard of what constitutes a proof of something. While an engineer may tolerate precision within some bounds, and an entrepreneur may be satisfied with a hunch, a mathematician’s statements must be irrefutable or they don’t count.

One way you can see this thinking tool influence non-mathematical domains is in an adjacent field such as programming. During my [MIT Challenge](https://www.scotthyoung.com/blog/myprojects/mit-challenge-2/), I heard lecturers talk about the MIT style of programming versus the one originating out of Bell Labs. MIT, which was more mathematical and academic, tended to be more rigorous in proving its programs worked, while Bell Labs was often happy with an algorithm which seemed to do the job, even if they couldn’t guarantee it.

Mathematical thinking tools help you be more rigorous, and spot mistakes which may turn out to be relevant.

### 9\. Programmer: What’s the Pattern I Can Automate?

[![Programmer](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-008.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-008.png)

Programming encompasses a lot of thinking tools, but the most basic one is the [algorithm](https://en.wikipedia.org/wiki/Algorithm). Algorithms are a set of steps that can be defined precisely, so that they require no intelligence to perform each one, yet the net result is a useful product.

A useful application of this is to look at the things you do and see which could be automated, simplified or refactored. Programmers can spot repeated code and try to abstract out the essence of what is redundant into something that can do what you need automatically.

Beyond just being able to write code yourself, you can think more like a programmer in many other domains of life. What things do you repeat often in your work which could be automated? What ambiguous process could you convert into a foolproof set of steps?

### 10\. Architect: Envisioning the Future

[![Architect](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-009.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-009.png)

Architects need to design buildings. These are large structures which may take years to build, and nonetheless meet all the criteria of clients, contractors, city planners and building codes. Oh, and they should also be beautiful.

To do this, architects need a suite of thinking tools (and software) to take an idea, and envision what it will be like, exactly, on a large scale, after millions of dollars have been spent. One of those tools is simply making a model.

Making a scaled down version of the thing you want to create, so you can see how it looks, and then envisioning how it will be on a larger version is difficult, but it often lets you see how reality will be before it’s too late to change it.

### 11\. Salesperson: Understand Their Minds Better than They Do

[![Salesperson](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-010.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-010.png)

Selling often gets a bad rap. People think it’s all about trickery and deceit as you try manipulating someone into buying something they probably shouldn’t.

Although this is the stereotype, the actual reality is rarely like this. Instead, salespeople work to deeply understand what the customer actually needs, and then match them with products and services that fill that void. This is incredibly hard to do, as you may recognize that you have the solution to a customer’s problem, before they do.

A key thinking tool for success in this profession is to be able to infer what people’s worries and needs are by their (often contradictory behavior). What language do they use? How do their actions differ from their stated intentions? What can you infer about this?

This is a tool you can apply far beyond making an extra commission. What does your spouse really want, rather than what they’re telling you? What about your friends? Your boss?

### 12\. Soldier: Routine and Discipline Prevent Deadly Mistakes

[![Soldier](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-011.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-011.png)

The discipline embodied by military personnel is a very useful thinking tool, even outside of combat situations. Discipline and routine become a safeguard against careless mistakes which could cost lives. By demanding conformity to those protocols, even when there is no danger, there is much less room for slip-ups.

Making your bed every morning may not prevent casualties, but if you can follow that procedure perfectly, you’ll also be more likely to follow the ones that may save your life. This kind of discipline is also present in another live-endangering field: medicine. [The Checklist Manifesto](http://atulgawande.com/book/the-checklist-manifesto/) takes this idea of military routine and applies it to mundane things like hand-washing, which save lives by avoiding infection.

Once you know the best way to do something, do it precisely and exactly, without sloppiness or somebody might get hurt.

### 13\. Chess Master: See The Moves In Your Mind’s Eye

[![Chess](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-012.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-012.png)

Chess has long been considered a game to improve one’s thinking. While it’s doubtful that years of chess study will necessarily make you smarter, there are plenty of thinking tools which can be mined from the game.

One is the ability to simulate the game in your mind’s eye. A common trick of grandmasters is playing [blindfolded games](https://en.wikipedia.org/wiki/Blindfold_chess). While this amazes spectators, it actually reinforces a useful practice—being able to see the game in your head, so you can calculate future moves your opponent makes.

This is often helpful in other domains outside of chess. Trying to visualize what might happen, and then compare that prediction to reality. This can hone your simulation abilities, so when you’re in a tight spot you’ll be able to predict what happens next.

### 14\. Designer: The Things You Make Communicate For You

[![Designer](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-013.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-013.png)

One of my favorite books is [The Design of Everyday Things](https://www.amazon.com/Design-Everyday-Things-Revised-Expanded/dp/0465050654). While this book is meant for designers, it is really a book of thinking tools designers should cultivate. As such, it’s something you can pick up and read even if you’ve never made anything in your life.

A useful tool here is how something is made suggests how to use it. A well-designed door handle suggests push or pull, without needing to say it. A well-designed light switch should already tell you which rooms will be illuminated when you flip it.

What if you designed your speeches so that they automatically caused the audience to shift their thinking where you need them to go? What if you designed your habits so that you automatically applied them? The scope of this thinking tool is really quite broad.

### 15\. Teacher: Can You See What it is Like Not to Know Something Obvious?

[![Teacher](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-014.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-014.png)

How do you create knowledge inside someone else’s mind? How can you give them abilities they didn’t have before?

Most of us take for granted how amazing teaching actually is, and our own ability to learn from it. To be effective, teachers need to have a model of how their pupils minds see the world, as well as a game plan for changing it.

To succeed in most professions, you need to be able to make other people see the problems as you do. This involves identifying what knowledge they lack and saying the right things to get them where you are now. While this is an obvious skill for teachers, it also benefits programmers trying to explain their code, doctors trying to articulate the reasons for a medical procedure or a leader who wants employees to follow a vision.

### 16\. Anthropologist: Can You Immerse and Join Another Culture?

[![Anthropologist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-015.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-015.png)

Anthropology is the [study of cultures](https://en.wikipedia.org/wiki/Anthropology). Unlike economics, which tends to focus on mathematical models, or psychology, which tends to do a lot of careful experiments, anthropologists learn about cultures by actually immersing in them.

How could you immerse yourself in groups to which you don’t belong? Groups of different nationalities or languages? Politics or professions? Hobbies, sports, religions or philosophies? How could you learn how those groups of people function, have them accept you as you live alongside them?

### 17\. Psychologist: Test Your Understanding of Other People

[![Psychologist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-016.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-016.png)

Psychology has different thinking tools embedded both in its assumptions about human nature, as well as in its methods for discovering it.

On the subject of psychology itself, there are countless tools. Cognitive biases, models of attention, morality, preferences, instincts, memory and more. Dozens of books could be written on how to think better about other people by using these tools and there have been.

Interestingly, psychology is also a profession with its own set of tools for discovering psychology. Like all scientists, this involves creating experiments where you can control all but the variable you want to study. Unlike other scientists, however, your object of study are human beings, which means you often can’t let them know what you’re trying to adjust.

### 18\. Critic: Can You Build on The Work of Others?

[![Critic](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-017.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-017.png)

Many critics go beyond telling you which books to read and which movies to watch. They build analysis, interpretation and discussion that go well beyond the original work.

The thinking tools involved are quite important, even for people who don’t analyze literature for a living. For starters, there is the ability to pay quite close attention to creative works. Experiencing something much more deeply than just a shallow consumer. Second, there’s the tool of being able to connect that knowledge to a web of other issues and ideas. This builds on an original creation to add more insight and ideas than were there originally.

### 19\. Philosopher: What are the Unexpected Consequences of an Intuition?

[![Philospher](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-018.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-018.png)

Philosophers, at least the [analytical kind](https://en.wikipedia.org/wiki/Analytic_philosophy), tend to have a similar style and toolkit as mathematicians, except often in dealing with things that are based in words that are imprecise. As a result, there’s a lot of useful thinking tools for dealing with things that can’t be reduced to numbers.

One powerful tool is being able to see the unexpected consequences of stretching an idea to its limits. This has two benefits. First, it can reveal flaws in the original idea, by [reductio ad absurdum](https://en.wikipedia.org/wiki/Reductio_ad_absurdum). Second, this can help you recognize the fundamental principles behind your vague intuitions of things. By exposing your ideas to stronger, hypothetical critiques, you can see the real mechanisms by which they work.

### 20\. Accountant: Watch the Ratios

[![Accountant](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-019.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-019.png)

Money is the blood of a business. Accounting is the work that watches how it flows around, checking to make sure it isn’t getting clogged up.

There’s a number of useful thinking tools from accounting that allow the diagnosis of problems which are hidden on the surface. One of these is the idea of [ratio analysis](https://en.wikipedia.org/wiki/Financial_ratio). Ratios are a fraction with a numerator and denominator of two different measurements inside a business. Leverage ratio, for instance, is the debt the company owes to the equity put in by the owners. Get too high, and there’s a greater risk of default. Price-earnings ratio tells you how expensive stock is based on its profits.

This kind of analysis (and many others from accounting) is useful to non-accounting domains. In health, [BMI](https://en.wikipedia.org/wiki/Body_mass_index) is a kind of fancy ratio analysis, in this case it’s your weight compared to your height squared. But you could also imagine tracking many other numbers and their ratios: output per hours worked, bugs per lines of code, dates per hours spent on online dating.

Organizing the data, keeping track of the details and seeing the patterns beneath the surface are all accounting tools you can exploit outside of a spreadsheet.

### 21\. Politician: What Will People Believe?

[![Politician](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-020.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-020.png)

Politics offers its own set of tools. A major difference between politics and business is that while both are aimed at achieving some kind of objective in the world—the former depends highly on the impression of voters. A business can simply work, whereas a politician may do a great job, and still get kicked out because of bad PR.

Therefore the thinking tools possessed by politicians are about calculating not only the effect of some action, but also on how that action will be perceived. Both by the voting populace, and one’s allies and enemies.

The thinking tools here mean that sometimes the right decision isn’t possible, simply because other people won’t see it as such, and you don’t have the power to convince them. This may be frustrating, but it applies to many parts of reality we’d rather it didn’t.

### 22\. Novelist: Does Your Story Make Sense?

[![Novelist](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-021.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-021.png)

Many people see stories as the linguistic embodiment of history. We take what actually happened and weave it into some words so others can see it for themselves.

Novelists understand better than anyone that what actually happens is often not a good story. Stories have characters with fixed traits that make their actions predictable. In real life, people are [more influenced by context](https://en.wikipedia.org/wiki/Fundamental_attribution_error). Stories have beginnings, middles and ends. Reality is a continuous stream of events without an arc.

Unfortunately, people understand stories much better than realities. So often you need to package up the histories you want to tell people in a way that they can interpret. Who is involved? When did those things happen? Give information to make it easier for the listener to follow.

While this applies to writing novels or making movies, telling stories is a part of everyone’s life. From “Why do you want to work at this job,” to, “Where do you see yourself in five years?” These are all stories, and we need to understand their structures.

### 23\. Actor: The Best Way to Pretend is to Be Real

[![Actor](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-022.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-022.png)

A popular thinking tool for acting is called [method acting](https://en.wikipedia.org/wiki/Method_acting). This technique involves trying to actually feel the emotions of the character you’re portraying, rather than just faking it.

This may seem to be a contradiction: how can you feel something you know is fake? However, this belies how powerful the imagination is to conjure up situations to create empathy. Past struggles can stand in place for the struggles of the role you play. Fear, happiness, confidence and passion all look better when you’re really experiencing it.

Which also suggests a powerful thinking tool, although this one is more affective than cognitive: changing your emotional state to get the results you want. Feeling insecure, but know you need confidence? Why can’t you summon that up in yourself as if you’re playing a part? But don’t fake it–_feel it_.

### 24\. Plumber: Take it Apart and See What’s Broken

[![Plumber](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-023.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-023.png)

Tradespeople don’t get enough credit for having unique problem solving tools and strategies. Many academic and intellectual types would never consider a career in plumbing, carpentry or electrical work. Yet those professions often out-earn those with a college degree, and for good reason: they are hard skills which are in-demand.

The essence of plumbing, just like many other trades, is to get your hands dirty and take something apart to see what’s broken. To do this, you need a model of what’s in there—otherwise you might get water spilling everywhere or a dangerous shock. But you also need to take things apart to understand them.

How many of us avoid understanding things because we’re afraid to get our hands dirty? We don’t want to risk breaking something, so we never really understand how it works?

### 25\. Hacker: What’s Really Going on Underneath?

[![Hacker](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-024.png)](https://www.scotthyoung.com/blog/wp-content/uploads/2018/11/tools-024.png)

Hacking is one of the most commonly misunderstood skills. Television shows portray it as a kind of computer magic, with flying cubes and firewall health bars which go down to zero.

In practice, however, hacking is mostly about understanding that there is often a more complicated layer of instructions which a simpler layer is built on top. Computer sit in hierarchies, so each level of abstraction simplifies and reduces the layer below to make it easier to understand. However, sometimes this can allow you to do things which look impossible to a higher level, but are an unintended feature of how the lower level works.

One example of this is a memory overflow exploit. Many programs work on a higher level whereby memory is accessed in restricted silos. Ask for something outside of memory and you’ll get an error. However, in practice, the memory all sits on a big line, with memory for different things next to each other. If you can write memory “outside of the bounds” you can get the computer to do things you’d naively expect were impossible.

## Final Thoughts on Thinking Tools

These are just summaries of a key tool from different professions. In reality, however, there are dozens, if not hundreds of thinking tools for each domain of skill. Not just professions, but hobbies, subjects and general life skills also develop thinking tools.

The problem is that people often have a difficult time recognizing the skill and abstracting it away from where it was generated. This is a problem of far transfer, and it’s not easy to resolve.

However, if you can state what the pattern is, you can start to see how you could apply it elsewhere. Most of these tools won’t work best in domains far outside their starting zones. A novelist trying to use storytelling to diagnose medical problems will be in big trouble. But often we get so stuck using our favorite tools that we don’t even consider which ones could apply. Creative solutions require divergent thinking, causing us to think of one tool when we need others.

### Creative Work Requires Diverse Thinking Tools

A [classic experiment](https://en.wikipedia.org/wiki/Candle_problem) shows the need for tools like these. Subjects were asked to use a box of tacks to affix a candle to the wall. The solution was to use the box as a base—trying to apply tacks directly to the candle only made a mess. This is hard because we think of the box as a container for the tools, not a tool in and of itself.

Similarly, many of these tools may allow for creative solutions to problems you might not have considered. For instance:

-   If you’re an entrepreneur, what would your business look like if you approached it like an artist, or a teacher, or a novelist?
-   If you’re a programmer, how would your code improve if you took the tools of a salesperson or accountant?
-   If you’re a journalist, what would change about your pieces if you acted like a scientist, economist or plumber?

Not every combination will be useful, but many might just give you the solution that will lead to a breakthrough.
