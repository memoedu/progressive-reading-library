## 第一个程序：点灯 hello world

第一个程序，就是要控制 C13 这个端口的灯。

打开 Keil5，先在 Target 1 下添加两个 group `User` 和 `Start`

User 中添加 `main.c`，`stm32f10x_conf.h`，`stm32f10x_it.c` 和 `stm32f10x_it.h`。

Start 中添加 `core_cm3.c`， `core_cm3.h`，`stm32f10x.h`，`system_stm32f10x.c`，`system_stm32f10x.h` 和 `startup_stm32f10x_md.s`。

解释一下 Start 中的各个文件的含义：

- `stm32f10x.h`：stm32f10 系列的外设寄存器描述文件。用于描述 stm32 有哪些寄存器和它们的对应位置。
- `system_stm32f10x.c` / `system_stm32f10x.h`：用于配置和 system 相关的设置，比如时钟。stm32 的主频为 72 MHz，就是在这里配置的。

- `core_cm3.c` / `core_cm3.h`：stm32 内核寄存器内核的描述文件。cm3 就是 Cortex-M3 的简称。

在编译选项上，将 C/C++ 下的 Include Paths 添加 Start。`main.c` 就是我们的入口文件。



### 方法一：通过操控寄存器的方式

通过给寄存器赋值的方式操作 stm32 是最为基础的方法，我们需要参考 `STM32F10xxx参考手册（中文）.pdf`，为了点亮 C13 处的灯，我们需要进行如下几个步骤：

1. 使能 C 口的 GPIO，也就是开启 IOPC
2. 配置 C 处 GPIO 的输出模式，此处配置为 50MHz 的推挽输出
3. 给 C 处 GPIO 的13号位置写入数据，低电平为开灯，高电平为熄灯



打开 Keil5，

1. 在 Target 1 下新建文件夹 Start 和 User，

在编译配置里面，在 C/C++ 选项中，将 Include Path 加上 Start 文件夹

代码如下：

```c
#include "stm32f10x.h"                  // Device header

int main(void) {
	// 参考手册 7.3.7 APB2 外设时钟使能寄存器(RCC_APB2ENR)
	// 由于要控制 C13 处的灯，所以要使能 IOPC ，也就 IOPCEN 段置为 1
	// 写成 16 进制为 0x00000010
	RCC->APB2ENR = 0x00000010;
	// 参考手册 8.2.2 端口配置高寄存器(GPIOx_CRH) (x=A..E) 
	// CNF 配置为推挽输出；MODE 配置为输出模式 最大速度50MHz
	// 写成 16 进制为 0x00300000
	GPIOC->CRH = 0x00300000;
	// 参考手册 8.2.4 端口输出数据寄存器(GPIOx_ODR) (x=A..E) 
	// 给13号端口写入数据，对于教程使用的板子，ODR13 写入 0 为开灯，写入 1 为关灯
	// 写入 0，ODR = 0x00000000
	// 写入 1，ODR = 0x00002000
	GPIOC->ODR = 0x00000000;
	
	while (1) {
		
	}
}

```

在下载之前，查看一下你的 Debuger 是否和你使用的下载器一致。比如我使用的是 STLink 进行调试，那么在 Debug 的部分，就把 Debugger 设置成ST-Link：

### 方法二：使用库函数的方式

首先添加 Library 文件夹，并加入 stm32 的库函数文件，如下图所示：

<div align=center>
<img src="https://pic1.zhimg.com/80/v2-36646012851a187fdcec695657e2ca26_1440w.png" style="width: 50%;"/>a
</div>


然后在 Keil5 软件中开启对应的编译选项和宏等：

<div align=center>
<img src="https://picx.zhimg.com/80/v2-5013bccab4f7fdfd3c6ee85d259ffac0_1440w.png" style="width: 40%;"/>a
</div>


然后就可以在编辑器中编写代码了：

```c
#include "stm32f10x.h"                  // Device header

int main(void) {
	// 配置 GPIO C 外设时钟
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);
	
	// 
	GPIO_InitTypeDef GPIO_InitStructure;
	
	// 通用推挽输出
	GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
	// 13 号端口
	GPIO_InitStructure.GPIO_Pin = GPIO_Pin_13;
	// 输出频率为 50 MHz
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	// 使用该配置初始化 GPIOC
	GPIO_Init(GPIOC, &GPIO_InitStructure);
	
	// 将 C13 上设置为 高电平，熄灯
	GPIO_SetBits(GPIOC, GPIO_Pin_13);
	
	// 将 C13 上设置为 低电平用 GPIO_ResetBits
	
	while (1) {
		
	}
}

```

编译后，会得到类似的效果。



### 关于启动文件

在例程中，我们采用了 `startup_stm32f10x_md.s` 这个文件作为启动文件。但是当时并没有讲解为什么需要使用这个文件。 stm32 的启动文件选择和对应的芯片型号相关，根据不同的型号，启动文件分为 `LD_VL`，`MD_VL`，`HD_VL`，`LD`，`MD`，`XL`，`CL`。它们的对应关系如下表所示。

|     缩写     |        释义        | Flash容量 |       型号        |
| :----------: | :----------------: | :-------: | :---------------: |
|    LD_VL     | 小容量产品超值系列 |  16-32K   |     STM32F100     |
|    MD_VL     | 中容量产品超值系列 |  64-128K  |     STM32F100     |
|    HD_VL     | 大容量产品超值系列 | 256-512K  |     STM32F100     |
|      LD      |     小容量产品     |  16-32K   | STM32F101/102/103 |
|      MD      |     中容量产品     |  64-128K  | STM32F101/102/103 |
|    皇文器    |     大容量产品     | 256-512K  | STM32F101/102/103 |
| 加大容量产品 |    加大容量产品    | 大于512K  | STM32F101/102/103 |
|  互联型产品  |     互联型产品     |     -     |   STM32F105/107   |

我们采用的 stm32f103c8t6 根据 [STM32 外设与系统结构](https://kirigaya.cn/blog/article?seq=162) 中可以看出，c8 代表 64 KB 闪存，根据上表，这属于“中容量产品”，应当选择 MD。
