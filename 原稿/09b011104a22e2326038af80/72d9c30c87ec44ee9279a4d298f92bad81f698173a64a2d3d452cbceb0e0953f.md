半年前因为指导一个美国的学生，我重写并翻译了以前写的《多体计算科研环境配置指南》，并发在知乎上。半年后的今天，它变成了一个 26 章的在线教程网站，覆盖三个操作系统，还加入了 AI 辅助科研的全新章节。这篇文章介绍这次重写的动机、变化和思考。

### 回顾：旧版做了什么

2025 年 9 月，我写了《多体计算科研环境配置指南》（Guidelines for Computational Environment Setup in Many-Body Research），一份面向多体计算方向新生的环境配置攻略。它是一份 PDF 文档，主要覆盖 Windows 和 Linux 两个平台，内容包括：

-   网盘选择（OneDrive / Dropbox / 坚果云）
-   文献管理（Zotero）
-   WSL 安装与配置
-   Git / SSH 基础
-   C/C++/Fortran 编译器
-   MPI 与 OpenMP 并行计算
-   Conda 与 Python 环境
-   Julia 安装
-   BLAS/LAPACK/OpenBLAS
-   Intel MKL（oneAPI）
-   PETSc 与 SLEPc

这份指南在当时解决了一个实际问题：课题组的新生进来后，光配环境就要折腾好几天，而且每个人踩的坑都差不多。一份统一的指南可以省去大量重复劳动。

但随着使用，它的局限性也逐渐显现。

### 为什么要重写

### 1\. 覆盖面不够

旧版只覆盖了 Windows（通过 WSL）和 Linux。但物理学界有大量 macOS 用户，他们的配置流程和工具选择有显著不同（Homebrew vs apt，zsh vs bash，等等）。新版同时覆盖 **macOS、Ubuntu 和 Windows** 三个平台，并在每个关键步骤标注平台差异。

### 2\. 只有”怎么装”，缺少”怎么用”和”为什么”

旧版本质上是一份安装手册：告诉你运行哪些命令来安装软件、怎么验证安装成功。但一个刚接触计算物理的本科生或研究生，面临的不只是”Fortran 编译器怎么装”这一个问题——他可能连终端是什么都不清楚，不知道文件系统如何组织，不理解 PATH 环境变量的含义。

新版从**计算机基础知识**讲起，包括硬件概念（CPU/GPU/内存/磁盘）、操作系统原理、文件与进程的概念、”什么是编程”等最基本的问题。不再假设读者已经具备这些背景。

### 3\. 工具链的”中间地带”被忽略了

旧版跳过了很多日常科研中实际会用到的工具：

-   **终端与命令行操作**：ls、cd、grep、管道和重定向——这些是每天都要用的基本功，旧版完全没有涉及
-   **文本编辑器**：vim、nano、VS Code 的配置和使用
-   **Bash 脚本**：自动化日常任务
-   **Markdown 与 LaTeX**：笔记和论文写作
-   **Obsidian**：知识管理和双向链接笔记
-   **项目目录组织**：如何规范地组织 src/data/scripts/tests
-   **同步与备份**：3-2-1 备份原则、网盘与版本控制的关系

新版把这些全部补上了。

### 4\. 格式的局限

一份 PDF 文档天然不适合频繁更新的技术内容。软件版本在变，最佳实践在变，而 PDF 一旦发出去就很难让所有人看到最新版。

新版使用 **Docusaurus** 构建为在线网站，部署在 GitHub Pages 上。更新一次 push 即可生效，读者永远看到最新内容。同时支持**中英双语**，方便不同语言背景的读者。

### AI 带来的变化：不只是一个新章节

新版最大的变化之一，是加入了两个和 AI 直接相关的章节：**第 19 章「Agent 辅助研究」** 和 **第 22 章「Vibe Coding」**。但 AI 的影响远不止于此——它改变了整份教程的定位和写作思路。

### Agent vs Chatbox：一个关键区分

第 19 章花了相当篇幅区分 **Agent**（如 Claude Code、OpenCode）和 **Chatbox**（如 ChatGPT 网页版、Claude 网页版）的本质区别。这是我认为很多人还没有意识到的一个关键转变：

-   Chatbox 运行在浏览器里，你需要把代码复制粘贴给它看
-   Agent 运行在你的终端里，它**可以直接读取你的文件、执行命令、编辑代码**

这意味着 Agent 不再是一个”你问我答”的工具，而是一个能直接与你的研究环境交互的助手。你可以让它分析你的 Fortran 代码、帮你检查推导、批量处理数据、调试 LaTeX 编译错误，甚至帮你做 finite-size scaling 的绘图——全程不需要离开终端。

### Agent 不只是编程工具

第 19 章特别强调了一个观点：**Agent 辅助研究远不止写代码。** 对理论和计算物理的研究生来说，它可以用在：

-   **公式推导与验证**：让 Agent 逐步验证你的 Matsubara 频率求和，或者从 Hubbard 模型推导平均场自洽方程
-   **理解陌生代码**：接手师兄留下的几千行 DMFT 求解器，让 Agent 帮你分析代码结构和自洽循环的逻辑
-   **文献概念速查**：快速理解 Keldysh 形式体系和 Matsubara 形式体系的区别
-   **LaTeX 写作辅助**：论文润色、编译错误调试、figure 环境生成
-   **自动化重复任务**：批量数据处理、格式转换、参数扫描脚本生成

### 写在最后

可能在AI时代，计算物理的入门门槛不应该这么高，而一份好的指南可以让新生把时间花在真正重要的事情上：理解物理和解决问题如果你是理论/计算物理的学生或研究者，希望这份教程能帮到你。
