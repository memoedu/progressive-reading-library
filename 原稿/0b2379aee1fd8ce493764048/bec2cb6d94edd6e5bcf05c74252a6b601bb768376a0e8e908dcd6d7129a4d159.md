## 正文

### 安装

油猴脚本（Tampermonkey，有的地方也叫篡改猴）是 [Jan Biniok](https://github.com/derjanb) 开发的一个用于修改网站行为和页面的脚本执行器。**它属于浏览器插件**。因此，去各个浏览器的应用商店搜索 Tampermonkey 就能找到，然后添加拓展即可。当然，如果你不太熟悉浏览器的应用商店也没关系，进入油猴脚本的官网：https://www.tampermonkey.net/index.php?browser=chrome

然后选择你当前正在使用的浏览器：

<div align=center>
<img src="https://picx.zhimg.com/80/v2-d8b71762a5e48a0a5726216fb3d1edae_1440w.png" width="80%"/>
</div>

点击“去商店”，进入商店后，点击添加拓展（不同浏览器有点不一样）完成安装。

### 概念介绍

在着手编写油猴脚本前，有几个基本概念需要理清。

关于 Web 页面的执行逻辑我在本文就不赘述了，诸位只需要知道一点，当我们为网站 A 编写了一个油猴脚本后，当油猴脚本被开启时，它的执行逻辑为：

1. 目标网站被 GET 请求得到，解析，渲染完毕。（也就是标签页网站那个转转的加载标志消失时）
2. 执行油猴脚本。

也就是说，油猴脚本是在目标网站渲染结束后才会被执行的。

### 编写第一个油猴脚本 hello world

我们首先打开浏览器，在右上角的拓展管理中找到“篡改猴”，点击它，选择“管理面板”：

当然，阁下因为是第一次使用，上面应该是空空如也，此时，我们点击“已安装脚本”左侧的 “+”来创建我们的第一个脚本。点击+后，我们会进入油猴脚本的编辑器，初始内容如下：

```javascript
// ==UserScript==
// @name         New Userscript
// @namespace    http://tampermonkey.net/
// @version      2024-02-08
// @description  try to take over the world!
// @author       You
// @match        https://zhuanlan.zhihu.com/p/540098759/edit
// @icon         https://www.google.com/s2/favicons?sz=64&domain=zhihu.com
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    // Your code here...
})();
```

最上面的注释是当前脚本的配置信息，我来简单解答一下：

- name：脚本的名字
- description：脚本的介绍
- author：作者
- match：正则表达式，用于匹配该脚本在哪些链接上生效
- icon：给这个脚本设置头像

其中，最核心的参数就是 `match` 了，它的设置将会指定你的脚本在哪些网站上会生效。如果阁下在后期部署脚本时发现油猴插件找不到在当前网站上可用脚本时，你就应该看看是不是 match 没写对。其他的参数不影响脚本执行，只是用于进行分类的标记。

我们可以将我们的用户脚本写在 `// Your code here...` 这里。此处我们先简单写个 hello world 吧！目标网站设置成百度。match 就设置成 `https://www.baidu.com/*` ， 这个语法与 glob 文件系统是一致的。

> 如果你对 JavaScript 不是很熟悉，需要自动补全的话，不妨在 vscode 里面进行编写，然后再复制粘贴到油猴的编辑器中。 DOM 操作有一堆名字又臭又长的方法，确实需要一个自动补全。

Hello World 脚本如下：

```javascript
// ==UserScript==
// @name         Hello World
// @namespace    http://tampermonkey.net/
// @version      0.0.1
// @description  Just for practice
// @author       You
// @match        https://www.baidu.com/*
// @icon         https://pic1.zhimg.com/v2-b4251de7d2499e942c7ebf447a90d2eb_xll.jpg
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    alert("hello world");
})();
```

## UI 美化脚本

如果想要通过油猴脚本美化某一个你看着不顺眼的网站UI，那么通过 JavaScript 操作 DOM 就是一个很好的方法。比如去除广告，广告元素的 class 或者 id 属性都是固定的，我们可以通过如下的代码来去除它们：

```javascript
(function() {
    'use strict';

    // 去除广告
    const selectors = '.container,#boy,header';
    const adElements = document.querySelectorAll(selectors);
    for (const el of adElements) {
        el.parentNode.removeChild(el);
    }
})();
```

上面的代码会将所有 class 为 container 或者 id 为 boy 或者标签为 header 的 HTML 元素从 DOM 中去除。

你可以通过观察网站 HTML 源代码和善用 Ctrl F 的方式快速定位到广告元素或者你不想看到的内容元素的 class 或者id 或者 标签。

此处，我简单给出文章开头的那个 CSDN UI 美化脚本，非常简单。

需要注意，该脚本请勿商用！请勿随意传播，否则我会随时删除这篇文章。请诸位配合。

```javascript
// ==UserScript==
// @name         pretty CSDN
// @namespace    https://kirigaya.cn/home
// @homepage     https://kirigaya.cn/home
// @homepageURL  https://kirigaya.cn/home
// @version      0.0.1
// @description  更好看的 CSDN UI
// @author       锦恢
// @match        https://blog.csdn.net/*
// @icon         https://pic1.zhimg.com/v2-b4251de7d2499e942c7ebf447a90d2eb_xll.jpg?source=32738
// @grant        none
// ==/UserScript==

(function() {
    'use strict';

    // 去除广告
    const selectors = '.programmer1Box,.blog_container_aside,.csdn-side-toolbar,#recommendAdBox,#blogColumnPayAdvert,#toolbarBox,#rightAside,.recommend-box,#recommendNps';
    const adElements = document.querySelectorAll(selectors);
    for (const el of adElements) {
        el.parentNode.removeChild(el);
    }

    // 增加背景图片
    const body = document.body;
    body.style.backgroundAttachment = 'fixed';
    body.style.backgroundRepeat = 'no-repeat';
    body.style.backgroundSize = 'cover';
    body.style.backgroundPosition = 'center 0';
    body.style.backgroundImage = 'url(https://picx.zhimg.com/80/v2-56c5e8379d370a17716696a3c558a611_1440w.jpeg)';
})();
```
