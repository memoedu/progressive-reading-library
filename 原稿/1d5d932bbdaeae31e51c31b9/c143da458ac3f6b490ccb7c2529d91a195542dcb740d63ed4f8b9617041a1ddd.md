# 原理

mAP是评价多目标检测任务中模型性能好坏的一个重要指标，它主要是用来衡量分类好坏的一个量。关于mAP怎么计算的，网上有很多讲解，但是真正把问题讲清楚的并不多，碰巧，之前我看到了一个很好的例子[1]，我觉得刚好可以拿过来作为例子讲解一下。

首先我们需要明白，mAP是每个类别的AP的平均值，因此只需要计算每个类别的AP，然后取个平均值就可以了。AP是如何计算的呢？学过机器学习的同学应该都知道，是通过计算P-R曲线下方的面积计算得到的。那么我们只需要搞到每个类别对应的一组如同(recall, precision)的点集，然后计算该点集连成的P-R曲线下方的面积即可。

### 第一步 计算bbox是TP还是FP

第一大步，我们需要得到当前预测的所有的bbox是TP还是FP，这个地方的TP的意思是bbox框中了前景目标，或者说GT中存在一个bbox匹配上了预测中的那个bbox。很明显，在Image1中，0.3的那个框是TP，0.7的那个框是FP。

做法也很简单，那就是计算预测的bbox和GT中每个bbox的IOU，若所有IOU中最大的大于某个指定阈值（这个很重要，下面的例子中，这个阈值为0.5），那么就是TP，否则就是FP。

计算过程为，从大到小遍历confidence，将所有大于等于当前confidence的bbox预测为正类，其余为负类。很显然，通过我们上面的排序，当前遍历到的confidence的行号就是预测为正类的数量。

## 计算mAP

计算得到每个类别的AP之后，直接计算平均值或者加权平均即可。我想要讨论的主要是计算AP时的第一步用到的那个IoU的阈值，如果这个阈值为0.5，那么计算得到mAP被称为mAP0.5。

在许多论文中，你应该还会经常看到一个叫做mAP0.5:0.95的东西，它就是将IoU阈值取为0.5-0.95步长为0.05，分别计算mAP，然后再取平均得到的值。

## 其他函数

为了计算最终的结果，我们需要额外两个函数。

### IoU

输入两个bbox，每个bbox存储左上角和右下角坐标。计算两个bbox的交并比。

```python
def IoU(box1, box2) -> float:
    """box must be (x_min, y_min, x_max, y_max) style"""
    x1 = max(box1[0], box2[0])   
    x2 = min(box1[2], box2[2])   
    y1 = max(box1[1], box2[1])  
    y2 = min(box1[3], box2[3])  
 
    overlap = max(0., x2 - x1) * max(0., y2 - y1)
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - overlap
 
    return overlap / union
```

### AP

输入一连串坐标，坐标为(recall, precision)。函数返回这些坐标下的面积，这个非常简单：

```python
def AP(points : np.ndarray) -> float:
    """cal area under PR curve"""
    area = 0
    for i in range(len(points) - 1):
        width = points[i + 1][0] - points[i][0]
        height = (points[i + 1][1] + points[i][1]) / 2
        area += width * height
    return area
```

## 计算单个类别的AP

为了计算总的AP，我们需要先计算单个类的AP：

```python
def cal_ap_one_class(pred : pd.DataFrame, gt : pd.DataFrame, iou_thred : float = 0.5) -> np.ndarray:
    """cal ap of a class return numpy like List[(recall, precision)]"""
    # cal TP or FP of each line in pred
    ap_view = {
        "image_id" : [],
        "confidence" : [],
        "TP" : [],          # 1 is tp and 0 is fp
        "box_loss" : [],    # if TP == 0 then this item is -1
    }

    # loop each image
    for image_id, data in pred.groupby("image_id"):
        data : pd.DataFrame

        # align each line to a box or None
        image_id_gt = gt[gt["image_id"] == image_id]
        # recurse each line in this image
        for i in range(len(data)):
            pred_view = data.iloc[i]
            tp = 0
            box_loss = -1
            max_iou = -1
            pred_box = xywh2xyxy(pred_view.x, pred_view.y, pred_view.w, pred_view.h)
            for j in range(len(image_id_gt)):
                gt_view = image_id_gt.iloc[j]
                gt_box = xywh2xyxy(gt_view.x, gt_view.y, gt_view.w, gt_view.h)
                iou = IoU(pred_box, gt_box)
                if iou >= iou_thred:
                    if max_iou == -1 or iou >= max_iou:
                        max_iou = iou
                        tp = 1
                        box_loss = np.linalg.norm(np.array(pred_box) - np.array(gt_box))
            ap_view["image_id"].append(pred_view.image_id)
            ap_view["confidence"].append(pred_view.confidence)
            ap_view["TP"].append(tp)
            ap_view["box_loss"].append(box_loss)

    ap_df = pd.DataFrame(ap_view)
    ap_df = ap_df.sort_values(by="confidence", ascending=False)
    points = np.zeros((len(ap_df), 2))
    positive_num = len(gt)
    cur_tp = 0

    all_box_loss = []

    for i in range(len(ap_df)):
        view = ap_df.iloc[i]
        cur_tp += view.TP
        if view.box_loss > 0:
            all_box_loss.append(view.box_loss)
        precision = cur_tp / (i + 1)
        recall = cur_tp / positive_num
        points[i] = (recall, precision)
    
    ap_value = AP(points)
    box_loss = np.mean(all_box_loss)
    return ap_value, box_loss, points
```

最终返回该类的AP，所有匹配到的bbox和GT的bbox的距离，还有所有的(recall, precision)用于绘制PR曲线。

## 调用

在外部调用时，一定需要首先将当前的这个类剥离出来，建议使用DataFrame的分组方法`groupby`：

```python
for label, data in gt.groupby("label"):
	label_pred = pred[pred.label == label]
	label_gt = data
	ap_value, box_loss, points = cal_ap_one_class(label_pred, label_gt)
```

如此，你便可以得到标签为`label`时的AP，box_loss和绘制曲线需要的数据了。算完之后对所有的`ap_value`取一个平均就可以得到mAP了。
