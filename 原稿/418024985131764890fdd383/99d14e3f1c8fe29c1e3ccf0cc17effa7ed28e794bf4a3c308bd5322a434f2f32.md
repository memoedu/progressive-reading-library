## 前言

最近需要访问一个 Windows 的高权限区域，但是该死的 Windows 居然会对用户的明文脚本进行字符串级别的安全扫描！为了应对这个问题，需要采用一些加密算法对代码中的敏感部分进行加密，让 Windows 看不出来。所以用简单的对称加密就行了。

---

## 凯撒加密

这个非常简单，就是对字符进行简单的移位，比较简单。在 python 中，可以使用 `ord` 将字符转化为整数（Unicode 编码），将整数转化为对应的字符。

## XOR 对称加密

这个方法我很喜欢，因为加密解密函数都一样，基本原理就是 XOR 操作的复位性：

```
a === a ^ b ^ b
```

因此，可以将 `a ^ b` 作为加密， `a ^ b ^ b` 作为解密，一个函数，又能加密又能解密。代码如下：

```python
def encrypt_decrypt(data: str, key: str) -> str:
    return ''.join([chr(ord(data[i]) ^ ord(key[i % len(key)])) for i in range(len(data))])
```

基本使用：

```python
origin = 'hello world!'
key = '锦恢'
encrypted = encrypt_decrypt(origin, key)
decrypted = encrypt_decrypt(encrypted, key)
print(encrypted)
print(decrypted)
```
out:


```
镎怇镊怎镉恂镑怍镔怎镂恃
hello world!
```
