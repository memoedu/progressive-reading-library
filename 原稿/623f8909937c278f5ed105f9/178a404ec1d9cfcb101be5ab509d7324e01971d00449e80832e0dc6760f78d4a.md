## 前言

RM 是 “One-Repetition Maximum” 的缩写，意思是“一次最大重复次数”。简单来说，它指的是你以标准的动作，在不用借力的情况下，竭尽全力只能完成一次动作的最大重量。对于计划制定，RM 是很重要的一个参数，教练群体需要通过 RM 才能给出更加专业的训练计划。

通俗来讲，1-RM 就是“这个重量重到你只能做1次”，5-RM 就是“这个重量重到你只能做5次”。

但是在很多时候，对于一些动作，我们可能不知道自己的 RM 是多少，因为大部分朋友健身时不会特意去测试自己的 RM，这个时候，我们就需要通过一些算法来估算大家的 RM 了，这样才能让教练更加定制化地给出建议。

## 1-RM 估算方法 (V0.1)

### 符号说明

* **W**：自身体重（Body Weight）

* **r**：完成次数

* Lr ：在一组次数为 r 时，当前这一组的器械能上的最大重量

* **α**：是否为「自重负重动作」，如果是，则为1，否则为0

* **TW_r**：在一组次数为 r 时，当前的总重量（Total Weight），即

  $$
  TW_r = \alpha \cdot W + L_r
  $$

有了上述的定义后，有如下的三类不同的评估算法用来评估 TRM_1，这些都是通过历次的经验公式总结而成的公式。

### Epley（1985）

Boyd Epley 是美国最著名的力量教练之一，美国 NSCA（National Strength and Conditioning Association）的创始人之一。他通过大量运动员训练数据，总结出重量与次数之间近似线性关系，提出了：

$$
TRM_{1\text{Epley}}=TW_r (1 + 0.0333r)
$$
### Brzycki（1993）

Matt Brzycki 在普林斯顿大学体育部门任职时提出，用于体能评估。公式来自对大学生运动员数据的回归分析。

$$
TRM_{1\text{Brzycki}}=TW_r \frac{36}{37 - r}
$$
### Lombardi（1989）

Vincent P. Lombardi 提出于力量训练的生物力学分析，假设力量与重复数之间呈幂函数关系。

$$
TRM_{1\text{Lombardi}}=TW_r r^{0.1}
$$

## 最终综合估算（取三者平均值）

根据一般经验，我们采用最朴素的算术平均数来计算出预测的 TRM_1

$$
TRM_1=\frac{TRM_{\text{Epley}}+TRM_{\text{Brzycki}}+TRM_{\text{Lombardi}}}{3}=\lambda(r)TW_r
$$
我们记上述的关于 r 的一个系数如下：

$$
\lambda(r) = \frac{1 + 0.0333r + \frac{36}{37 - r} + r ^ {0.1}}{3}
$$
而 1RM 和 TRM_1 天然存在如下的关系：

$$
\begin{align}
1RM &= TRM_1 - \alpha W \\
&=(L_r + \alpha W)\lambda(r)-\alpha W
\end{align}
$$
利用上面的公式，我们在已经知道用户 1RM 的情况下推算出当前 r 配比动作计划下，应该设置负重 L 为多少。

$$
L_r=\frac{1RM + \alpha W}{\lambda(r)}-\alpha W
$$
当然，也可以考虑通过线性回归来预测，但是需要足够多的采集数据才行。后面再说了。有几篇类似的论文做过相关的研究，不过看起来，目前需要硬件设备才能准确采集到需要的输入数据：

* A Novel Approach to 1RM Prediction Using the Load‑Velocity Profile: A Comparison of Models (2021)：用 LVR 数据 + linear/quadratic 模型预测 free-weight squat 的 1RM — 给出较高的精度 (r > 0.97, SEE < 5 kg) 。这说明如果你有速度 + 负重数据，用 ML 或许也有潜力。 MDPI

* Using a Load–Velocity Relationship to Predict 1RM in Free‑Weight Exercise: A Comparison of the Different Methods (2018)： 系统比较了多种 LVR-based 方法 (minimal velocity threshold, load-at-zero-velocity, force–velocity)，指出了它们在 free-weight 练习中的可靠性与局限。

* The Predictive Validity of Individualised Load–Velocity Relationships for Predicting 1RM: A Systematic Review and Individual Participant Data Meta‑analysis (2023)： 最近的 meta-分析，总结 LVR 方法预测 1RM 在多种练习 / 人群中的有效性／统计特性 — 为决定是否用更复杂 ML 方法提供了背景和基线。

## 代码实现

通过代码实现这几种经典算法也非常简单，

```typescript
/**
 * Epley 模型的 λ(r)
 * λ_epley(r) = 1 + 0.0333r
 */
export function lambdaEpley(r: number): number {
    if (r <= 0) throw new Error("r 必须大于 0");
    return 1 + 0.0333 * r;
}

/**
 * Brzycki 模型的 λ(r)
 * λ_brzycki(r) = 36 / (37 - r)
 */
export function lambdaBrzycki(r: number): number {
    if (r <= 0 || r >= 37) {
        throw new Error("r 必须在 (0, 37) 区间内");
    }
    return 36 / (37 - r);
}

/**
 * Lombardi 模型的 λ(r)
 * λ_lombardi(r) = r ^ 0.1
 */
export function lambdaLombardi(r: number): number {
    if (r <= 0) throw new Error("r 必须大于 0");
    return Math.pow(r, 0.1);
}

/**
 * 三模型平均 λ(r)
 *
 * λ_avg(r) =
 * (λ_epley + λ_brzycki + λ_lombardi) / 3
 */
export function lambdaAverage(r: number): number {
    const e = lambdaEpley(r);
    const b = lambdaBrzycki(r);
    const l = lambdaLombardi(r);

    return (e + b + l) / 3;
}


/**
 * 支持的 λ 模型类型
 */
export type LambdaModel = 
    | "average"   // 三公式平均
    | "epley"
    | "brzycki"
    | "lombardi";

/**
 * 计算推荐负重 L_r
 *
 * 公式：
 * L_r = (1RM + αW) / λ(r) - αW
 */
export function calcRecommendedLoad(
    oneRM: number,
    weight: number,
    reps: number,
    alpha: number = 1,
    model: LambdaModel = "average"
): number {
    if (oneRM <= 0) throw new Error("1RM 必须大于 0");
    if (weight <= 0) throw new Error("体重必须大于 0");

    let lambda: number;

    switch (model) {
        case "epley":
            lambda = lambdaEpley(reps);
            break;
        case "brzycki":
            lambda = lambdaBrzycki(reps);
            break;
        case "lombardi":
            lambda = lambdaLombardi(reps);
            break;
        case "average":
        default:
            lambda = lambdaAverage(reps);
    }

    const load = (oneRM + alpha * weight) / lambda - alpha * weight;

    return Math.max(0, Number(load.toFixed(2)));
}
```
