大部分人会选择使用日志系统，tensorboard，或者甚至自己手动记录实验数据。事实上，这么多年下来，大部分时候我也是这么干的，可以看我三年前写的一篇博客 [PyTorch下的可视化工具](https://zhuanlan.zhihu.com/p/220403674)。但是总感觉不太方便，作为研究生阶段的第一份正式的工作，我打算这次好好更新一次我的数据收集与可视化工具。我希望这个工具能满足如下的一些要求：

- 最基本的数据渲染与可视化功能（就和 tensorboard 那样）
- 可以根据实验的名字和每组实验的配置进行科学合理的分组与管理 （基于这套管理系统可以瞬间写出上面那个表格里面的数据）
- 最好可以云同步，方便和其他人进行交流 （最基本的组队、数据分享功能还是要有的，而且可以在任何联网设备上监督实验进展）
- 可以看到纵向对比的结果、服务器的实时性能汇报（谁没有一点做 HPC 的私活呢）
- 可以展示出每一个指标的历史最佳记录（用来填表格的）

我想到了曾经玩 YOLO v5 时原项目里面的 `wandb` 这个库，于是简单使用了一下，发现几乎完全精准地满足了我上面的所有需求。于是本着安利的态度，简单介绍一下如何使用这个工具。

---

## Design Boundary

wandb 比较适合这样的场景：

- 专为 AI 实验设计的数据管理与校验平台
- 你们的电脑可以 ping 到 wandb.ai
- 不是什么公司涉密项目，不允许数据外漏

如果不满足上面的要求，你可以退出这篇文章了。

## 安装

安装 `wandb` 非常简单：

```python
pip install wandb
```

> wandb 是很多著名的开源 AI 算法的自带库，所以如果你是一个老炼丹师，那么服务器上应该早就装好了。

## 极简使用

### 首次使用

如果在当前服务器上首次使用 wandb，会在开头 barrier 住让你进行账号注册。直接点击出现的链接，然后进入 wandb 注册就行（我是使用的 GitHub 账号登录的）。

在注册完成后，你会得到一个 wandb 的 token，将这个 token 记录保存到你的云笔记里面。然后在终端的输入框中输入这个 token 即可。

### 初始化 & 认识 wandb.ai

假定我们现在需要在一个深度学习的训练任务中，检测训练集，验证集，测试集上的各项性能指标，从而完成论文撰写的数据搜集工作，首先要做的就是 wandb 的导入和初始化：

```python
import wandb

wandb.login()
run = wandb.init(
    job_type='train',
    project='out of distribution',
    name='ENN',
    notes='ENN, 反向 KL 散度, λ = min(1, epoch / 10)',
    tags=['ernn', 'reverse kl', 'train'],
    config=config
)
```

在真实启动时，建议将上面的一些用来区分实验不同点的属性，比如 `name`， `notes` 以参数的形式传入。此时只是为了方便演示。

上述的代码被执行后，会弹出一个链接，点进这个链接，便是当前这个实验的内容的云平台链接，也就是 wandb.ai 平台。点击左侧的 Runs，会进入我个人认为展现价值最高的平台：

这个界面会按照时间顺序，展示属于这个 project 的所有实验的记录，我们刚才设置的 `name`, `notes`, `tags` 全都可以在上图的第一行数据记录中找到。并且非常清晰地展示所有实验中的横向、纵向展示结果。ACC 谁最大，ROC 谁最大一目了然。通过这个管理平台，可以瞬间完成 Experiment 部分的指标撰写工作。而且因为是云端保存，你甚至可以轻易调出几年前的训练结果进行检视。再也不用把一大堆的 tensorboard log 文件移来移去了。

### 定义指标

在进行 wandb 的记录前，我个人推荐先定义你要记录的指标，这样 wandb 才知道你想要的是这个指标的历史最大，还是历史最小：

```python
# define metric we are interested in
run.define_metric('valid_loss', summary='min')

run.define_metric('AUROC', summary='max')
```

比如我们对验证集上的**最小值**损失比较感兴趣，那么就设置 `summary` 为 `min`；我们对 AUROC 的**最大值**比较感兴趣，那么就设置它的 `summary` 为 `max`。事实上，这个参数除了 `min` 和 `max` 还有别的用法，此处就不赘述了。



### 进行记录

在定义完指标后，记录它们非常非常简单，很 tensorboard 用法一样，直接 `run.log` 就完事了：

```python
for epoch in range(epoch_num):
    ...
	run.log({'AUROC': result_pent['AUROC']})
    ...
```

这样就会把每轮的指标记录下来并上传到云端让我们进行检视。用法主打一个简单有效。 wandb 还支持 图像，音频等多媒体的上传。除此之外，wandb.ai 平台能够通过鼠标点击完成的操作（比如导出数据，清理缓存），都可以通过 wandb 的 python API 实现。时间有限，我也不赘述了，感兴趣的朋友可以去他们的官网查看。
