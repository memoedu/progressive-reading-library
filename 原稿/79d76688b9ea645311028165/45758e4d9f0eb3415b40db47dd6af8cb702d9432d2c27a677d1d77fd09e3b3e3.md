式（2.13）写的是

\\partial\_x V\_x + \\partial\_p V\_p = 0也就是说

\\frac{\\partial V\_x}{\\partial x} + \\frac{\\partial V\_p}{\\partial p} = 0 那么把式(2.14)代进去肯定是能成立的。但是，如果我们不知道式(2.14)这个结果，怎么推导呢？

### 【方法一：用格林公式】

方程 \\partial\_x V\_x + \\partial\_p V\_p = 0 恰好满足格林公式（Green's Theorem）的路径无关条件，可知向量场 (-V\_p, V\_x) 是一个保守场。那么，数学上可以直接通过定积分显式地把标量函数 H(x,p) 给“算”出来：

H(x, p) = \\int\_{(x\_0, p\_0)}^{(x, p)} \\left( -V\_p \\, dx + V\_x \\, dp \\right)

其中 (x\_0, p\_0) 是任意选定的起点坐标，是能量的参考零点.

复习格林公式：对于向量场 \\mathbf{F} = (P(x,y), Q(x,y))，或者写成微分形式 P(x,y)\\,dx + Q(x,y)\\,dy，“线积分”和“面积分”之间有等式

\\oint\_L P\\,dx + Q\\,dy = \\iint\_D \\left( \\frac{\\partial Q}{\\partial x} - \\frac{\\partial P}{\\partial y} \\right) dx\\,dy

由它可推导的路径无关条件：在单连通区域（没有“洞”的空间）内，以下几个命题是等价的：

1\. 交叉偏导相等： \\frac{\\partial Q}{\\partial x} = \\frac{\\partial P}{\\partial y}

2\. 环路积分为零： 沿任意闭合曲线 L 的积分 \\oint\_L P\\,dx + Q\\,dy = 0

3\. 路径无关： 任意两点 A 到 B 的线积分 \\int\_A^B P\\,dx + Q\\,dy 的值，只取决于起点和终点

4\. 存在势函数（或者说，存在恰当微分）： 存在标量函数 u(x,y)，使得 du = P\\,dx + Q\\,dy（即 \\frac{\\partial u}{\\partial x} = P，\\frac{\\partial u}{\\partial y} = Q）.

上面用到了1和4. 教材解释到这里就可以了.

### 【方法二：外微分和庞加莱引理】

构造一个微分 1-形式（1-form）：

\\omega = -V\_p \\, dx + V\_x \\, dp

接下来，我们计算这个 1-形式的外微分 d\\omega：

d\\omega = -dV\_p \\wedge dx + dV\_x \\wedge dp

将 dV\_p 和 dV\_x 展开：

d\\omega = -\\left( \\frac{\\partial V\_p}{\\partial x}dx + \\frac{\\partial V\_p}{\\partial p}dp \\right) \\wedge dx + \\left( \\frac{\\partial V\_x}{\\partial x}dx + \\frac{\\partial V\_x}{\\partial p}dp \\right) \\wedge dp

利用外代数的性质dx \\wedge dx = 0, dp \\wedge dp = 0, 且 dp \\wedge dx = -dx \\wedge dp，化简得到：

d\\omega = -\\frac{\\partial V\_p}{\\partial p} (dp \\wedge dx) + \\frac{\\partial V\_x}{\\partial x} (dx \\wedge dp)

d\\omega = \\left( \\frac{\\partial V\_p}{\\partial p} + \\frac{\\partial V\_x}{\\partial x} \\right) dx \\wedge dp

根据我们的已知条件式（2.13），括号内的部分正好等于 0. 因此： d\\omega = 0当一个微分形式的外微分为零时，我们称其为闭形式（closed form）。庞加莱引理告诉我们，在一个单连通区域内，所有的闭形式都是恰当形式（exact form），即存在一个纯量函数 H(x, p)，使得：

\\omega = dH

而我们知道，函数 H 的全微分为：

dH = \\frac{\\partial H}{\\partial x} \\, dx + \\frac{\\partial H}{\\partial p} \\, dp

将这个定义与我们构造的 \\omega = -V\_p \\, dx + V\_x \\, dp 一一对应进行比较，就可以直接得出：

\\frac{\\partial H}{\\partial x} = -V\_p \\implies V\_p = - \\frac{\\partial H}{\\partial x}

\\frac{\\partial H}{\\partial p} = V\_x \\implies V\_x = \\frac{\\partial H}{\\partial p}

这就是为什么在力学中，任何相空间里散度为零（即，形如式（2.13））的向量场都可以被称为哈密顿向量场，而那个纯量函数 H 就是系统的哈密顿量（通常代表总能量）.

### 【方法三：基础微积分硬算，不过能扯出规范自由度的影子】

**第一步**，已知式（2.13）：\\frac{\\partial V\_x}{\\partial x} + \\frac{\\partial V\_p}{\\partial p} = 0将其移项，得到：\\frac{\\partial V\_p}{\\partial p} = -\\frac{\\partial V\_x}{\\partial x}

现在，对两边关于 p 进行不定积分：

\\int \\frac{\\partial V\_p}{\\partial p} \\, dp = -\\int \\frac{\\partial V\_x}{\\partial x} \\, dp

左边直接还原为 V\_p。在右边，把导数符号提到积分号外面（光滑性允许这样做）：

V\_p = -\\frac{\\partial}{\\partial x} \\left( \\int V\_x \\, dp \\right) + f(x)

这里 f(x) 是对 p 积分时产生的“积分常数”（因为它对 p 的导数为 0）.

**第二步**，我们看上式的右边，它由两部分组成：一个关于 x 的导数项：\-\\frac{\\partial}{\\partial x} (\\dots)，一个关于 x 的函数项：f(x)我们希望把这两项合起来写成一个函数的导数形式。注意到 f(x) 本身也可以是某个函数的导数：设 F(x) = \\int f(x) \\, dx，则 F'(x) = f(x)）于是：

V\_p = -\\frac{\\partial}{\\partial x} \\left( \\int V\_x \\, dp \\right) - \\frac{\\partial}{\\partial x} (-F(x))

提取公因子 \-\\frac{\\partial}{\\partial x}，成功地把这两项合起来写成一个函数的导数形式：

V\_p = -\\frac{\\partial}{\\partial x} \\left( \\int V\_x \\, dp - F(x) \\right)

**第三步**，给上式括号里的式子起个名字叫 H(x, p)：

H(x, p) = \\int V\_x \\, dp - F(x)

代回 V\_p 表达式，它满足：

V\_p = -\\frac{\\partial H}{\\partial x}

那么 V\_x 满足什么呢？我们对刚定义的 H(x, p) 关于 p 求偏导：

\\frac{\\partial H}{\\partial p} = \\frac{\\partial}{\\partial p} \\left( \\int V\_x \\, dp - F(x) \\right) = \\frac{\\partial}{\\partial p}\\left( \\int V\_x \\, dp \\right) - \\frac{\\partial}{\\partial p}F(x) = V\_x + 0 = V\_x

式（2.14）得证.

**讨论**：在刚才的推导中，我们定义了：

H(x, p) = \\int V\_x \\, dp - F(x)

这意味着 H并不是唯一的！在第一步积分中，我们为了表示对 p 积分时产生的“积分常数”，引入了 f(x)，进而定义了不定积分 F(x) = \\int f(x) \\, dx ，而对于任何常数 C，(F(x) + C) 都是 f(x) 的一个原函数. 这意味着

H\_\\text{new}(x, p) = H(x, p) + C

也会得到完全相同的 V\_x 和 V\_p。能量零点可以自由选择，呼应了【方法一】里的那个自由选择的积分起点.

我们在用数学公式描述大自然时，存在某种“冗余”：即使我们改变了数学描述的某种标尺读数（进行了“规范变换”），物理理论依然成立，即各物理量依然能满足这个数学公式. 这种“不管标尺如何变化，理论依然成立”的性质，就是这个理论的规范不变性（gauge invariance）.

这里可以被我们自由调整的标尺读数（在上例里是一个任意的常数），构成了一个规范群（上例里是全体实数构成的加法群），其维度即规范自由度（在上例里是一维）.

当然，不同的理论可以有不同的规范自由度. 经典力学里的规范自由度显得不那么重要，因为如上例所言，它只有一个自由度，而且这个自由选择在空间里是个与位置无关的常数，而且用标量加法就能在其规范群里从一个元素变换到另一个. 更高级的物理理论可以有更高维、更复杂的规范群.
