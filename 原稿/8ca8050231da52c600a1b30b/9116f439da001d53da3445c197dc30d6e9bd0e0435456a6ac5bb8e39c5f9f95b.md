你的这个问题很好，可惜目前为止底下的回答还没有人正经回答。

首先，你的感觉很对，有理数可以使用整数分式的方法定义，因此有理数继承整数环 \\mathbb{Z} 的加法和乘法是很自然的，进而我们可以获得有理数域 \\mathbb{Q} ，因为所有非零元都有逆。但是我们在逻辑上不能把这两个东西看作实数域 \\mathbb{R} 的子集来考虑，因为在集合论的框架下，我们在假定无穷公理的前提下只能获得自然数 \\mathbb{N} 和其上的加法和乘法，而一切东西都要基于自然数而构造。我们通过添加符号获得了整数，这是一个环；通过添加分式来获得有理数，这是一个域。在代数上，我们几乎已经可以认为有理数足够好了（实则不然，但它至少是一个域），但是我们事实上需要实数。我们并不先验地有实数，而是要构造出实数。

我们以下的这两段论述是观察性的，因为它们在逻辑上是存在跳跃的。这样做是为了帮助我们理解构造实数的动机。我们可以先假设我们有实数 \\mathbb{R} 和复数 \\mathbb{C} ，其中我们使用实数构造复数的方式是令 \\mathbb{C}:=\\frac{\\mathbb{R}\[x\]}{x^2+1} ，这是一个二次扩域，在代数上有很明显的动机，比如说我们希望获得一个代数闭的域，从而使得任何 n 次方程都有 n 个根。但是我们从有理数到实数的扩张并不是类似的代数扩张而是超越扩张（比如考虑收敛于 e 的有理数列），所以我们从直观上上理解，更应该从分析的角度考虑。当然，这只是一种理解方式，因为实数在代数上也有一些好的性质，但是引用中科大某泛函分析老师的名言：“代数是研究等式的，而分析是研究不等式的”，我认为一般实数的完备性是其众多性质中最重要的。

其次，如果我们已经有了实数，那么可以在有理数上定义一般的度量，因此可以说有理数不是一个完备的度量空间，因此可以使用一般的方法对其进行完备化。但是我们在没有构造出实数前，是不能这么说的。在数学分析教材中（其中陶哲轩的书专门强调了这一点），我们使用的方法是所谓的有理度量，即有理数是一个有序域，其上可以定义标准的度量拓扑，进而使用有理度量Cauchy列等价类的方式对有理数进行分析完备化。考虑一个有理数列 \\{q\_n\\} ，其被称为一个Cauchy列，若任意有理数 a>0 ，存在 N\\in\\mathbb{N}\_+ 使得任意 n,m>N 有：

|q\_n-q\_m|<a

我们发现有一些这样的数列是不收敛的，比如：

a\_n=1+\\sum\_{i=1}^n\\frac{1}{i!}

如果我们已经构造出了实数，那么在实数的标准拓扑下 \\lim\_{n\\to\\infty}a\_n=e 。此时我们的有理数可以被视为实数的一个子集继承子空间拓扑，由于实数是Hausdorff的，有理数也是，因此数列极限点若存在则唯一，从而我们可以导出如上的数列在有理数中不收敛。但是，我们又注意到如上的数列是一个Cauchy列，因此“存在一些不收敛的有理Cauchy列”。

为什么我们希望Cauchy列是收敛的？引用中科大某拓扑学老师的论述（当然，这其实是个很常见的论述），从直观上看，Cauchy列意味着这个数列在足够大的时候，任意两项靠得足够近，这和收敛的定义很像。同时，Cauchy列又是一个内禀的性质，因为我们判断一个数列是否收敛于某个点时，这个点可以不是数列中的元素（比如 \\frac{1}{n} ），甚至不是数列所在拓扑空间中的元素（比如 n ）；但是判断Cauchy性时，我们仅用到了数列中的元素。这种内禀性是我们所希望的。

我们可以考虑一些更直观的例子理解这种不完备性，比如考虑开圆盘：

D\_2:=\\{(x,y)\\in\\mathbb{R}^2|x^2+y^2<1\\}

考虑数列 a\_n=(1-\\frac{1}{n^2},0) ，它是Cauchy列，但是收敛于开圆盘外的一个点 (1,0) 。我们可以发现，这是由于我们的空间 D\_2 在实平面 \\mathbb{R}^2 中不是闭的，否则就没有这种情况。因此，我们的完备化某种意义上就是“取一个集合的闭包”。事实上，完备性就等价于“绝对闭”，即当这个空间被等距嵌入任意一个空间时，它的像都是闭的。

综上，我们有理由对有理数进行完备化。我们的完备化方法也正如上面所述，将有理数等距嵌入一个空间完备的空间，使得新空间是有理数像的闭包。这正是分析中完备化的标准手段，唯一的区别是我们要把定义中的实数换成有理数。考虑有理Cauchy列等价类：

\\mathfrak{R}:=\\{\\{q\_n\\}:\\mathbb{N}\\to\\mathbb{Q}|\\{q\_n\\}\\,is\\;a\\;Cauchy\\;sequence.\\},\\{q\_n\\}\\sim\\{p\_n\\}\\leftrightarrow\\lim\_{n\\to\\infty}(q\_n-p\_n)=0

则实数定义为：

\\mathbb{R}:=\\mathfrak{R}/\\sim

则我们立即有一个嵌入关系：

\\iota:\\mathbb{Q}\\to\\mathbb{R},q\\mapsto\\iota(q):=\[\\{q\_n\\}\],q\_n\\equiv q

因此我们把有理数嵌入到了实数中，同时它是等距且稠密的。

因此，这个问题其实问的是：为什么这个商集是一个域？为什么它可以有和有理数一样的运算法则？具体来说，我们要在其上定义加法和乘法，并且证明其在加法和乘法下形成一个域，且加法和乘法与代表元的加法和乘法一致（代表元是有理数列，这是一个环）。

因此，我们定义加法为： \[a\_n\] + \[b\_n\] = \[a\_n + b\_n\] ，乘法为 \[a\_n\] \\cdot \[b\_n\] = \[a\_n \\cdot b\_n\] ，并检验良定性：

加法：设 \[a\_n\] = \[a\_n'\],\[b\_n\] = \[b\_n'\] ，则 \\forall \\varepsilon > 0 有整数 N\_1, N\_2 使得

n > N\_1 \\implies |a\_n - a\_n'| < \\frac{\\varepsilon}{2},n > N\_2 \\implies |b\_n - b\_n'| < \\frac{\\varepsilon}{2}.

取 N = \\max\\{N\_1, N\_2\\} ，当 n>N 有

|(a\_n + b\_n) - (a\_n' + b\_n')| \\leq |a\_n - a\_n'| + |b\_n - b\_n'| < \\frac{\\varepsilon}{2} + \\frac{\\varepsilon}{2} = \\varepsilon

则加法是良定的。

乘法：类似地，由于Cauchy列是有界的，我们取正的 A,B 使得 \\forall n 有 |a\_n| \\leq P,|b\_n'| \\leq Q ，对于任意 \\varepsilon>0 ，有整数 N\_1, N\_2 使得

n > N\_1 \\implies |a\_n - a\_n'| < \\frac{\\varepsilon}{2A}, n > N\_2 \\implies |b\_n - b\_n'| < \\frac{\\varepsilon}{2B}.

取 N = \\max\\{N\_1, N\_2\\} ，当 n>N 有

|a\_n b\_n - a\_n' b\_n'| \\leq |a\_n| \\cdot |b\_n - b\_n'| + |b\_n'| \\cdot |a\_n - a\_n'| < A \\cdot \\frac{\\varepsilon}{2A} + B \\cdot \\frac{\\varepsilon}{2B} = \\varepsilon

则乘法是良定的。

加法交换律和结合律、乘法交换律和结合律以及加法乘法分配律直接继承自有理数列的性质，而这来自有理数的性质，因此这个证明实际上是显然的。加法单位元是 \[0\]=\\iota(0) ，乘法单位元是 \[1\]=\\iota(1) 。我们主要考虑除环的性质。对于 \[a\_n\]\\neq\[0\] ，存在 \\delta > 0 和N\_1 \\in \\mathbb{N}使得当 n > N\_1 时 |a\_n| \\geq \\delta。我们定义序列

c\_n = \\begin{cases} 1 & n \\leq N\_1 \\\\ \\frac{1}{a\_n} & n > N\_1 \\end{cases}

这是一个Cauchy列，因为 \\forall \\varepsilon > 0 ，由于 a\_n 是Cauchy列，存在 N\_2 \\geq N\_1 使得当m,n > N\_2时：

|c\_m - c\_n| = \\left| \\frac{1}{a\_m} - \\frac{1}{a\_n} \\right| = \\frac{|a\_m - a\_n|}{|a\_m a\_n|} \\leq \\frac{|a\_m - a\_n|}{\\delta^2} < \\varepsilon  
则我们有 \[c\_n\]\[a\_n\]=\[1\] 。

综上，我们证明了实数是一个域，且其运算与有理数的运算兼容。
