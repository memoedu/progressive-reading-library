Searle在1980年提出『中文屋』的时候，他攻击的目标非常明确。

他老人家提出的思想实验是这样：一个人不懂中文，但拿着一本规则手册，在屋里处理递进来的中文纸条，外面的人以为屋里有智能，其实屋里的人只是机械地操作符号。

![](https://pic1.zhimg.com/50/v2-2ed6ef82bc31fae850c2a2e975d9ebb2_720w.jpg?source=2c26e567)

中文屋的思想实验

Searle由此论证：计算机无论处理符号多复杂，都没有真正的『理解』，只是假装有智能。

他这个观点对于那个时候的 AI 有效，但，那时候的AI长什么样？

GOFAI，也就是Good Old-Fashioned Artificial Intelligence，完全的符号主义，人手工写规则，机器执行规则。

差不多就是 `if (input == 'hello') then output('hello')` 这种符号逻辑，真的就是翻规则书，抄一行字，纸条递出去。

Searle说，这不叫理解，这是符号操作，你在屋里翻手册，跟计算机跑if-else没有区别。

我们可以用经典的 AI 体对 Searle 说这句——

![](https://picx.zhimg.com/50/v2-1ccfa6b5f3dc563cbb8e41c4712a2e7d_720w.jpg?source=2c26e567)

GOFAI确实就是个中文屋，一个运行Eliza的IBM 5150，和一个在藏在屋子里翻手册的人，本质上没有任何区别。

Searle这这一招七伤拳打在了(当时的）AI的七寸上，GOFAI 受了重伤，从此再也没能爬起来。

但是，今夕不同往日，大语言模型 LLM不是GOFAI。

Searle攻击的AI，在1980年代就被他弄死了，但是如果现在还拿『中文屋』这个七伤拳来打今天的 AI，那就选错了目标。

因为，LLM 不是规则书。

* * *

中文屋要成立，需要两个前提，第一，屋里有一本规则书，第二，所有可能的输入都能在这本书里找到对应输出。

GOFAI满足这两个条件，但是LLM不满足。

一个1750亿参数的模型，训练完后所有知识被压缩在几十亿个浮点数里，你打开它的模型文件去看，全都是数字，没有任何 if else 。

LLM 怎么学会中文的？

是通过几万亿个token的文本的训练，自己总结出来的。

打个比方，你教小孩认狗，不是你给他写一本规则手册，狗有四条腿，有毛，汪汪叫。

相反，你是给小孩看一些狗的照片，小孩大脑里的神经元自然会训练自己，然后即便见到一张从未出现在照片上的狗，小孩也知道这是狗。

LLM 也一样，训练 LLM 的过程不是提供规则书，而是提供大量实例，让 LLM 自己总结出规律来。

Searle 受时代局限性，没有预料到 AI 到今天发展成 LLM 这个样子，他当年那颗子弹，打不中今天 LLM 这个靶子啊。

* * *

Searle就面对一个问题——如果LLM是中文屋，那人脑也是中文屋**。**

因为 LLM 的神经元网络，本来就是模拟人脑的工作机理构造的，不能说一样，但是有很多相似之处。

人脑860亿神经元从语言环境中统计出语法语义，LLM 靠上T的参数从文本数据中统计出语法语义。

神经科学家搞不清『理解』发生在哪个神经元，AI研究员搞不清『理解』发生在哪个参数。

![](https://pic1.zhimg.com/50/v2-d7ff1d0e46fdb7b8a87ff78c4a0b8d9e_720w.jpg?source=2c26e567)

John Seale

其实 Searle 老爷子2025年才去世，他感受过2023年之后 LLM 的爆发式增长，但是，他直到去世，依然坚持认为 LLM 不具备真正的理解力或意识。

他认为，LLM 是他提出的『中文屋』的终极体现，基于**统计句法**操纵**符号**，却不具备实际的语义理解能力。

对此，我只能表示遗憾。
