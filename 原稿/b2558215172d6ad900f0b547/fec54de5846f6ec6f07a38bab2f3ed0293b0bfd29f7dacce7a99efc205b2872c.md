## 问题的产生

每当我们开心地搭完一个模型，兴致勃勃地运行时，虽然程序没问题，模型选择没问题，优化算法也还行，但是一看损失函数关于迭代次数的函数，会发现Loss function的值会直播升天。

比如这样一个用二次函数试图拟合五个离散点的单层神经网络中：

```octave
输入：四个点（1,2）（2,4）（3.5，6）（6，7）（8，7.5）

输出：一个尽量拟合四个点的二次曲线。
```

代码：（因为使用函数封装，所以看起来会有点长）

```python
import numpy as np
import matplotlib.pyplot as plt

plt.figure(dpi=150,edgecolor="yellow")

class Network(object): #定义单层神经网络
    def __init__(self,weights_num):
        np.random.seed(0)
        self.w = np.random.randn(weights_num,1)
        self.b = 0

    def forward(self,x): #前向计算
        z = np.dot(x,self.w) + self.b
        return z

    def loss(self,z,y): #计算损失函数
        return np.mean((z - y)**2)

    def gradient(self,x,y): #计算前向梯度矩阵
        z = self.forward(x)
        gradient_w = np.mean((z - y) * x,axis=0)
        gradient_w.resize(2,1)
        gradient_b = np.mean(z - y)
        return gradient_w,gradient_b

    def update(self, gradient_w, gradient_b, eta=0.01):  # 使用GD更新梯度矩阵，学习率默认0.01
        self.w -= eta * gradient_w  # 往梯度相反的方向走
        self.b -= eta * gradient_b

    def train(self, x, y, iteration=100, eta=0.01):  # 训练模型，默认迭代100次
        losses = []  # 采集每次迭代的数据，用来绘制图像
        for i in range(iteration):
            z = self.forward(x)
            L = self.loss(z, y)
            gradient_w, gradient_b = self.gradient(x, y)
            self.update(gradient_w, gradient_b, eta)
            losses.append(L)
            if (i + 1) % 100 == 0:  # 每十个数据打印一下情况
                print("iter {} times,loss value is {}".format(i, L))
        return self.w,self.b,losses

def Draw_sample_point(x,y):#画样本点
    plt.grid(True)
    plt.xlabel("Size of house", fontsize=15)
    plt.ylabel("Price", fontsize=15)
    plt.text(4, 4, r'$\theta_0+\theta_1 x+\theta_2 x^2$', fontsize=15)
    plt.plot(x, y, 'rx')
    plt.ylim(0, 10)
    plt.xlim(0, 10)

def Draw_fitted_curve(w,b):#画我们拟合的二次曲线
    plt.grid(True)
    x = np.arange(0.2, 9.8, 0.01)
    y = b + w[0][0] * x + w[1][0] * x ** 2
    plt.plot(x, y)

def Draw_loss_function(iteration_time,losses):#画损失函数的图像
    plt.grid(True)
    plot_x = np.arange(iteration_time)
    plot_y = np.array(losses)
    plt.xlabel("times of iterations", fontsize=15)
    plt.ylabel("values of loss function", fontsize=15)
    plt.plot(plot_x, plot_y, 'g')

def get_data(x): # 获取二次函数的数据[x,x^2]
    x1 = x.tolist()
    x2 = (x ** 2).tolist()
    x_new = []
    for i in range(len(x)):
        roll = []
        roll.append(x1[i])
        roll.append(x2[i])
        x_new.append(roll)
    return np.array(x_new)

x = np.array([1,2,3.5,6,8])
y = np.array([2,4,6,7,7.5])
plt.subplot(121) #调整绘图区域
Draw_sample_point(x,y)
x = get_data(x)
y.resize(5,1)
net = Network(2)
print(x,y)
iteration_time = 1000 #迭代次数
w,b,losses = net.train(x,y,iteration = iteration_time,eta = 0.01)
print(w,b)

Draw_fitted_curve(w,b)
plt.subplot(122) #调整绘图区域
Draw_loss_function(iteration_time,losses)

plt.show()
```

## 有什么好的方法吗？

一般学习率的选择要看经验，可以动态调整，也可以手动调。不过像这一类的**超参数**，调整起来本身就很费时，就像vocaloid编辑器的12个参数一样，没有固定的计算公式。

### 方法一：手动调整学习率（传统艺能）

在[4] 的 3.3 节中，Leslie N. Smith 认为，用户可以以非常低的学习率开始训练模型，在每一次迭代过程中逐渐提高学习率（线性提高或是指数提高都可以），用户可以用这种方法估计出最佳学习率。

吴恩达的机器学习中，Ng的方法是每个数量级挑三个代表来测试:

- 数量级0.000001，取α=0.000001,0.000003,0.000005尝试。
- 数量级0.00001，取α=0.00001,0.00003,0.00005尝试。
- ......
- 数量级0.1，取α=0.1,0.3,0.5

将每个超参数决定的模型用验证集计算损失函数，再拿损失函数最小的那一个丢进测试集测试性能。

### 方法二：动态调整学习率

为什么这个超参数就得是一成不变的呢？正如[1]一文中所说：

> …无需使用固定的学习速率，并随着时间的推移而令它下降。如果训练不会改善损失，我们可根据一些周期函数 f 来改变每次迭代的学习速率。每个 Epoch 的迭代次数都是固定的。这种方法让学习速率在合理的边界值之间周期变化。这是有益的，因为如果我们卡在鞍点上，提高学习速率可以更快地穿越鞍点。

 

在 [2] 中，Leslie 提出了一种**「三角」方法**，这种方法使用了最简单的一次函数来动态调整学习率的大小：

左图中，LR 的最小值和最大值保持不变。右图中，每个周期之后 LR 最小值和最大值之间的差减半。

实现也很简单，我们设周期为T_max，最高点的衰减幅度为gamma，代码如下：

```python
import numpy as np
import matplotlib.pyplot as plt
import math

# Leslie的Triangle2学习率衰减方法
def Triangular2(T_max, gamma):
    def new_lr(step):
        region = step // T_max + 1    # 所处分段
        increase_rate = 1 / T_max * math.pow(gamma, region - 2)    # 增长率的绝对值
        return increase_rate * (step - (region - 1) * T_max) if step <= (region - 0.5) * T_max else - increase_rate * (step - region * T_max)
    return new_lr

# 获取映射
Lambda_lr = Triangular2(T_max=100, gamma=0.5)
x = np.linspace(1, 600, 1000)
y = np.array([Lambda_lr(num) for num in x])
plt.plot(x, y)
plt.show()
```

另一种常用的方法是由 Loshchilov＆Hutter [6] 提出的**预热重启（Warm Restarts）**随机梯度下降。这种方法使用余弦函数作为周期函数，并在每个周期最大值时重新开始学习速率。「预热」是因为学习率重新开始时并不是从头开始的，而是由模型在最后一步收敛的参数决定的 [7]。

### 方法三：高级优化算法

你可以直接另起炉灶，使用不需要配置学习率的高级优化算法。

- 共轭梯度法（Conjugate gradient）
- 变尺度法（BFGS）
- 限变尺度法（L-BFGS）

这三种优化方法有如下优点：

- 不需要人工挑选学习率。（No need to manually pick alpha）
- 通常比梯度下降法更快。（Often faster than gradient descent）
