`curl`是大家都非常熟悉的适用于大部分网络请求的命令行工具。简单做个备忘录，以便后续查看。

## 基础用法

### 发送请求

默认情况下，`curl`进行GET请求，并将得到的HTML（没有通过浏览器预解析的结果，毕竟你也不是通过浏览器发起的请求呀=_=）返回。

```bash
curl baidu.com
```

### 响应头信息

通过`-I`参数来展示请求的响应头信息：

```bash
curl -I baidu.com
```



## 请求类型

默认是GET请求，通过`-X`参数来设置请求类型，包括POST方法。在发送POST请求时，使用`-d`选项来指定请求主体数据。例如：

```bash
curl -X POST -d "name=value&foo=bar" http://example.com/path/to/resource
```

上述命令将向`http://example.com/path/to/resource` 发送POST请求，数据为 `name=value&foo=bar`。请注意，数据需要使用URL编码格式，并以字符串形式作为`-d`选项的参数传递。

`-d`也可以接受JSON字符串，但是外层必须用单引号：

```bash
curl -X POST -d '{"key":"value"}' http://example.com/path/to/resource
```

如果JSON比较大，还可以将其存储在一个文件中，并使用`-d @file` 选项来指定该文件的路径。例如：

```bash
curl -X POST -H "Content-Type: application/json" -d @data.json http://example.com/path/to/resource
```

这里假设 `data.json` 包含以下内容：

```json
{
  "name": "value",
  "foo": "bar"
}
```

上述命令将读取 `data.json` 文件中的 JSON 格式数据，并向 `http://example.com/path/to/resource` 发送POST请求。`Content-Type` 请求头指定了请求数据的 MIME 类型为 `application/json`。

除了`-d`选项，还可以使用`--data-urlencode`选项对数据进行URL编码，或使用`-F`选项上传文件。具体用法，请参考curl的文档。

## 请求参数

### 设置cookie

通过`-b`参数设置cookie，多个cookie通过`;`分割：

```bash
curl -b "sessionid=123456;csrftoken=abcdef" http://example.com
```

上面的例子设置了两个cookie：`sessionid`和`csrftoken`。

### 设置请求头

请求头通过`-H`参数设置，比如下面的例子修改了请求头中的Host：

```bash
curl -H "Host: 192.168.1.1" http://example.com
```

需要注意，多个请求头需要通过多个`-H`相连（估计是因为有些请求头的参数允许分号）：

```bash
curl -H 'Host:157.166.226.25' -H 'Accept-Language:es' -H 'Cookie:ID=1234' http://cnn.com 
```

对于一些常用请求头，也有比较简约的写法，比如：

- `-A`：User-Agent字段
- `-b`：Cookie字段
- `-e`：Refered字段

比如下面的请求：

```bash
curl -b "Authorization=Basic%20YWRtaW46NjU0MzIx;path=/" -H "Host:192.168.1.1" -e "http://192.168.1.1/" -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/114.0.0.0 Safari/537.36" http://example.com
```
