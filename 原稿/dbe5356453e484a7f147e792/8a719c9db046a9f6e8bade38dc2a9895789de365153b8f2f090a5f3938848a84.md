朋友们，可以叫我 Patrick，2026年刚刚在清华大学软件学院研究生毕业，今年年初进入 kimi 实习，而这个月正式开始以员工的身份工作了。现在也算是一个小资历了（

一般来说3到5年，人生就会有一个阶段性的变化，我在每一段转折之前，都会写一些东西回顾进入新环境的过程。2023年我进入清华大学之前，我记录下了考研进入清华的经历。眨眼间下一个阶段又开始了。

在清华，我研究的是“高性能区块链”，同时包含隐私计算等其他应用密码学的研究和工程。在研一幸运地找到了方向发表了一篇会议论文之后，满足了毕业要求，于是在完成实验室工作之余，开始了各种自由探索，包括但不限于在世界各地参与黑客松（ETHSeoul、ETH Global等等），以及在各类 Web3 项目担任区块链工程师，负责开发交易引擎、跨链桥、DeFi合约等等。

2025年中下旬，我作为 founding engineer 完成了一个去中心化交易所最早版本的开发，我个人负责的依然是跨链桥等部分。但和其他的项目不同的是，这个项目我们尝试尽可能全部使用 AI 来开发。这件事困难的地方在于，去中心化交易所（DEX）不同于你在推特上看到的各种 KOL 发的 showcase，它是一个安全要求非常高的软件，不是只需要看起来炫酷就可以的。因此我们需要通过文档、代码等，让 agent 戴着镣铐起舞。（实际上这些东西后来被称作 Harness）

当时的模型还只是opus-4.5，这些脚手架做得非常狼狈。但这个经历让我认识到的是，在2025年底，模型的使用价格和为用户产生的效益的比值已经接近了临界点，虽然目前的定价依然不健康，但是这个比值将会不可逆转地越来越小，且缩小的手段和路径也越来越明晰了。 AI 虽然也只是无数次技术炒作周期的主题之一，但就目前来看它绝对不是24/25年web3里各种 dapp，也不是一个永远不会填满的泡沫和无法实现的承诺。

### Harness 工程？

我在今年年初的时候正式开始在 Kimi 实习。面试我的是当时还在 Kimi 的 RC。RC 说他想招一个不是专门研究 Agent 的实习生，而我当时甚至还没听说过 skills，于是没有考 AI 的八股（Tool、MCP之类的），他开始描述一个场景，让我去想应该构造一个怎样的协议满足需求，最终我们构造出来的就是一个skill。这就是我的面经，可能没有任何参考价值可言。但也合理，因为需要我入组来做的就是一个个不知道是什么东西的东西。

于是 Harness 工程师的工作就是：不断观测模型和自己写的harness、接受批评和失败、快速总结和抽象、快速重构。这就要求Harness工程师要具备素质：1. 强大的问题抽象和系统架构能力；2. 接受批评和失败的能力。就像自动化理论一样，在 行动 和 观测之间不断循环。

前者，作为新人的我非常欠缺，这需要写过或维护过足够多的代码，并且有足够多 Debug 甚至处理线上事故的经验。曾经架构师负责设计整个系统的框架，除了实现性能之类的业务指标以外，也通过各种设计模式，使得之后的开发过程容易管理，即使开发人员能力参差不齐也能保证项目按时推进和交付。而今天vibe coding的时候，缺乏 架构能力 就是会导致代码库迅速腐烂、难以维护，比如网络上各种 KOL demo。这导致如今的软件开发对于新手来说，越来越不友好了。

然而后者——接受失败的能力，却是新人的特长。我在kimi的这小半年里，参与和负责了许多项目，我发现新人最大的优势在于，所有人都可以对你的作品毫无顾忌地提出负面意见。我曾经负责尝试做一个多智能体的探索，每隔一段时间我会开发一个版本出来，然后被同事们喷这里不好那里不本质，然后我删掉重新写，下一周再拿出一个新的来继续收集意见。批评是需要付费的。而作为新人的几年，能够免费收获批评，其实是很珍贵的事。如果你从来都没有经历过巨大的失败，这不是值得骄傲的事情，这也许证明你从来没有触及到过你的边界。

最近 K3 刚发，Kimi 内部的 “五戒” 被发出来，仔细看其中至少3个都是关于观测。观测是我在公司内印象最深的关键词之一。以目前我的理解：一个 Harness 组的工作流程和 Harness 工程师的责任就是为模型和产品提供观测支持并参与迭代，落实到具体可能就是构造观测框架、造题、拉通链路、研发新的 Agent Harness 这些 “脏活累活” 的不断重复。

### 缘起性空，不昧因果

说到 “脏活累活” 的循环，我想到一个说法。真实世界中的进步从来都是非线性的，需要经过很长的缓慢增长甚至是平台期，突然在某一天，因为某个契机大幅增长到达崭新的层次。

“历史和社会不是缓慢爬行的。它们是在跳跃…然而，我们…倾向于相信那种可预测的、微小的渐进式发展。”《黑天鹅》这本书里就说过类似的话。这种线性和非线性的增长，实际上对应了不同的对于世界的理解方式。

就像是在学校里做科研进入了一个新的领域，我们总是会先设置大量的假设让模型最简以便于研究。

首先，小的时候我们的生活就是“我想要，我得到”。我们实际上假设了整个世界都是可以被充分认识的，我们可以从一开始就给自己设定一个线性的人生计划，只需要埋头努力即可。

但正如我们所知道的，当我们走出学校逐渐和社会接触，会发现生活的路径并不是线性的，相对正确的方式应该是“实践-认识”的循环：在实践中认识到不足并提出新的目标。这虽然承认无法充分认识现实就开始行动，但依然坚信事物之间因果是可以被完全理解和利用的。

在学校里我们去了解学长学姐的经验，后来学习成功学，对历史上的成功与失败进行归因。即使我们抓住了真正正确的“因果关系”，当站在“非线性增长”前半段巨大的平台期面前，我们该怎样让自己相信自己是在正确的方向呢？

维特根斯坦的《逻辑哲学论》中说：因果本来就是人类的幻觉。而对于因果信仰的否定，更是佛教哲学里的重点。佛教中说缘是承认事物之间存在因果联系，而这种联系并不是明确的细线，而是一团云雾。它可以被部分认识，但无法彻底掌握，这也就是缘起性空。因此应当不昧因果：只管广结善缘，而不应执着于因果。也就是“尽人事，听天命”了。

那么抛弃根据因果来判断方向之后，唯一能够指引方向的就是观测了。我们唯一需要关心的就是要不断观测自己是不是在结“善”缘。

到这里实际上串起来上文的所有内容。我们庸常的人生，不断突破边界，不断自我观测，这就是意义本身。
