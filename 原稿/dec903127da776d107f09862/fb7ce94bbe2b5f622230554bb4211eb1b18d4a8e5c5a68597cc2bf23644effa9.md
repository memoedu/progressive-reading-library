Python默认使用`utf-8`编码，但是在诸多的网络编程中，我们经常会拿到编码不为`utf-8`的字符流。因此，在此情况下，有必要了解Python3对于字符串的编解码。
> 网上有许多的教程都是对于Python2的，那些都不适用于Python3

## `\u`开头的
分为两种情况
### 已经转义的
如果已经转义的，不需要去管，Python内部会自动转码
```python
text = "9\u201323 February"
# 如果看它不爽，可以通过两种方法强行转
# str(text)
# repr(text)
print(text)
```
out:
```
9–23 February
```
### 没有转义（原生字符串）
如果没有被转义，读入的就是\u字符串（这个应该是遇到最多的情况）：
```python
text = r"9\u201323 February"
print(text)
text = text.encode("utf-8").decode('unicode_escape')
```
out:
```
9\u201323 February
9–23 February
```

## `\x`开头的

### 带转义的
```python
text = '\xe4\xbd\xa0\xe5\xa5\xbd'
print(text)
text = text.encode('raw_unicode_escape').decode('utf-8')
print(text)
```
out:
```
ä½ å¥½
你好
```


### 不带转义的
先转成utf-8，然后做法和上面相同：
```python
text = r'\xe4\xbd\xa0\xe5\xa5\xbd'
print(text)
text = text.encode("utf-8").decode('unicode_escape').encode('raw_unicode_escape').decode('utf-8')
print(text)
```
out:
```
\xe4\xbd\xa0\xe5\xa5\xbd
你好
```
