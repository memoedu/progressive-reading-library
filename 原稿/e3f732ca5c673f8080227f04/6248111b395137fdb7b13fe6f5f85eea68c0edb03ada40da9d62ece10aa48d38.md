## 传感器电路解读

此处以光敏传感器为例子进行讲解。

### 电阻分压模块

<div align=center>
<img src="https://picx.zhimg.com/80/v2-3f9b1ba4cfa46c33ddf673958234a631_1440w.png"/>
</div>



首先是由 R1 和 N1 组成的分压电路，N1 代表光敏电阻，光线越强，阻值越低。AO 和 N1 直接相连，用于输出模拟量。为了给光敏传感器做一个简单的去噪和防抖，连接了一个 0.1 u 的 C2 做滤波电容。

:::info

在电路中，发现一个直接接地的电容接入电路中，该电容往往扮演滤波电容，用于进行廉价的去噪，防抖或者补偿。

:::

根据分压原理，光照越强，N1阻值越低，AO 值越低，IN+ 越低。我们在嵌入式开发时更喜欢数字信号，也就是 0 或者 1，所以 IN+ 用来引到后面的电路做二值化。

### 二值化模块

为了把 模拟输出 AO 转换成 数字输出 DO，需要连接一个比较器，此处使用了 LM393 运放，内部有两个独立工作的比较器，传感器模块只会使用上面那个比较器。

<div align=center>
<img src="https://picx.zhimg.com/80/v2-4e2ee8723356c094cece05f20ad16a79_1440w.png"/>
</div>

当分压模块的模拟输出量 IN+ 进入该模块后，通过比较器和 IN- 进行比较，如果 IN+ < IN-，那么就输出低电平，否则输出高电平。当光线比较暗时，根据之前的分析， IN+ 就比较小，此时就会输出高电平。因此，当我们在写嵌入式的传感器模块驱动程序时，高电平意味着光敏传感器当前接受的光线比较暗：

```c
int main(void) {
    Buzzer_Init();
    
    while (1) {
        // 此时光线比较暗，鸣响蜂鸣器
        if (LightSensor_GET() == 1) {
            Buzzer_ON();
        } else {
            Buzzer_OFF();
        }
    }
}
```



上图中的 IN- 其实是可以调整的，如下图：

<div align=center>
<img src="https://picx.zhimg.com/80/v2-8097bcd923d7ecb1b89f9bd36246eff8_1440w.png"/>
</div>



IN- 通过一个电位器进行调整，自动获取 VCC 到 GND 之间的分压，当我们转动电位器时，IN- 就会发生变化，从而可以调整比较器的输出结果。这样做我们就可以通过转动电位器来调整光敏传感器的数字输出对于光线的敏感程度了。

下图中蓝色的块块就是上面的 R2 电位器了。拿螺丝刀转动它就能调整 IN- 的电压从而调整光敏传感器的敏感程度。

</div>

而上面蓝色方块下面的那个八个引脚的黑色小芯片就是 LM393 公放了。



### 输出端口

在讲解完传感器的内部原理后，就来看看最终的输出了端口了。

<div align=center>
<img src="https://pic1.zhimg.com/80/v2-69723d4ba695966e81228430ea50e720_1440w.png"/>
</div>

AO 没啥好说的，本来就是直接接的 N1 的分压； LED1 那条电路是用来指明当年的传感器是否完成了通电。DO 在通过上面的 LM393 输出后直连一个上拉电阻 R5 到 VCC，这样如果 DO 如果没通电或者输出低电平，就会被上拉。而当 DO 电平比较低的时候，此处光线较强，LED2 就会通正向电流从而亮，因此 LED2 用来指示当年的光敏电阻是否检测到了比较亮的光。

正因为 DO 端会通过 LM393 输出一个比较低的电平，所以配置 DO 到 GPIO 的输出模式时，需要将 GPIO 配置成上拉输入模式；不过，因为传感器内部本来就接了一个上拉电阻 R5 到 VCC，所以 DO 端接入 GPIO 后，GPIO 本身的电路比较像下图的右上角那个图，因此，此时 GPIO 配置成浮空输入模式也是没问题的。

## 总结

- 传感器模块的 AD 是通过 LM393 实现的。
- 电位器可以用来调整传感器的 数字输入 对于不同物理量的敏感程度。
- 当使用 GPIO 连接 传感器 获取输入时，GPIO 的输入模式可以配置为 上拉输入模式 `GPIO_Mode_IPU` 或者 浮空输入模式 `GPIO_Mode_IN_FLOATING`。
