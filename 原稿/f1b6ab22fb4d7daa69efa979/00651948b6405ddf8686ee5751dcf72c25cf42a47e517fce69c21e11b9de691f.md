### 用书上的知识分析TCP拥塞控制reno算法

### reno及AIMD算法

AIMD是一种算法，它的思想非常简单，只规定了两件事：

1.  加性增加（AI）：每 RTT 增加一个固定量（通常是 +1）
2.  乘性减少（MD ：丢包时按比例减少（通常是 β=0.5）

reno就是一种TCP拥塞控制中典型的AIMD算法（加增乘减），每一次加一个mss（可以简单理解为一个数据包的大小），但是丢包时，判定线路发生了拥塞，会自动把窗口砍成原来的1/2。

AIMD算法可以自发完成公平性。

for t in range(steps):

如果超过容量了，意味着发生了丢包
    if w1 + w2 >= C:

## 非线性动力学

为了理解背后的原理，我们需要一点数学知识，一点动力学的知识。

### 不动点

什么叫不动点？

想象一下，在自然环境中，如果一个物种没有天敌，那么它就会快速增长，然后种群数量增加，竞争激烈，环境承受不住，种群数量就会开始锐减，然后空间又相对于个体来说变多，种群又增长，最终又减少。

最终，你会发现，种群数量会达到一个平衡，这个平衡点你就可以理解为不动点。

而且最有意思的是：这就是大自然的AIMD拥塞控制算法。

增加时，是一个个增加的，但是减少时，爆发疾病或者是因为气候变化导致食物减少，种群数量往往是按照比例锐减的。

### 连续系统与离散系统

在动力系统里，连续系统可以看成是离散系统在时间步长趋于 0 时的极限。为了说明这一点，我们先从离散系统开始。

### 离散系统：从变化大小推导稳定性条件

考虑一维离散系统：

$x_{n+1} = f(x_n)$

假设 x\*是不动点，即：

$f(x^*) = x^*$

为了研究它是否稳定，我们取一个小扰动：

$x_n = x^* + \eta_n$

代入映射并线性化：

$\eta_{n+1} = f'(x^*)\,\eta_n$

这意味着每一步扰动都会被乘上一个因子 f’(x^\*)。 因此扰动的大小是：

$|\eta_{n+1}| = |f'(x^*)|\,|\eta_n|$

为了让扰动越来越小，必须满足：

$|f'(x^*)| < 1$

这就是离散系统的稳定性条件，每一步变化误差都不能放大。

### 从离散系统推导连续系统

我们有：

$x(t+\Delta t) = f(x(t))$

于是：

$\frac{x(t+\Delta t) - x(t)}{\Delta t} = \frac{f(x(t)) - x(t)}{\Delta t}$

试试让步长趋于0，如果极限存在，我们得到一个连续系统：

$\dot{x} = F(x)$

其中：

$F(x) = \lim_{\Delta t\to 0} \frac{f(x)-x}{\Delta t}$

不动点条件变为：

$F(x^*) = 0$

在连续系统中，扰动满足：

$\dot{\eta} = F'(x^*)\,\eta$

解为：

$\eta(t) = e^{F'(x^*) t}\,\eta(0)$

注意这里的放大因子是指数函数：

-   指数函数永远是正的
-   不会反号
-   不会出现周期 2、倍周期等离散系统才有的行为

因此稳定性只取决于指数的指数部分是否为负：

$F'(x^*) < 0 \quad \Rightarrow \quad \eta(t)\to 0$

这就是为什么连续系统的稳定性判据是：

1.  导数为负 ->稳定
2.  导数为正 -> 不稳定

而不是像离散系统那样看绝对值。

### 连续系统是离散系统的极限

离散系统的稳定性条件：

$|f'(x^*)| < 1$

当时间步长很小时，离散系统的导数可以写成：

$f'(x^*) = 1 + \Delta t\,F'(x^*)$

代入离散稳定性条件：

$|1 + \Delta t\,F'(x^*)| < 1$

当步长趋于0时，这个不等式等价于：

$F'(x^*) < 0$

OK了，大功告成，我们已经具备了基本的数学及动力学知识了。

### 推导

让我们把公平性定义为A的带宽比总带宽：

$x_n = \frac{w_1^{(n)}}{w_1^{(n)} + w_2^{(n)}} \in (0,1)$

一次丢包更新的期望映射为：

$f(x) = x \cdot \frac{\beta x}{\beta x + 1 - x}       + (1-x) \cdot \frac{x}{x + \beta (1 - x)}$

这是一个标准的一维映射：

$x_{n+1} = f(x_n)$

我们要求解：

$f(x) - x = 0$

将 f(x)-x 展开、通分、整理，可化为：

$f(x) - x = (2x - 1)\,H(x)$

其中：

$H(x)= \frac{\beta(1-\beta)\,x(1-x)}      {(\beta x + 1 - x)\,(x + \beta(1-x))}$

判断符号：

-   β ∈ (0,1) ⇒ β(1-β) > 0
-   x ∈ (0,1) ⇒ x(1-x) > 0
-   分母始终 > 0

因此：

$H(x) > 0 \quad \text{对所有 } x\in(0,1)$

于是：

$f(x)-x = 0 \iff (2x-1)H(x)=0 \iff 2x-1=0 \iff x^* = \frac12$

若 |f'(x^\*)| < 1，则不动点是线性稳定的。

对 f(x) 求导，在 x^\*=1⁄2 处代入，得到：

$f'(1/2) = \frac{\beta^2 + 4\beta - 1}{(1+\beta)^2}$

### 判断 f’(1⁄2) < 1

$\frac{\beta^2 + 4\beta - 1}{(1+\beta)^2} < 1$

等价于：

$\beta^2 + 4\beta - 1 < (1+\beta)^2$

展开右边：

$\beta^2 + 4\beta - 1 < 1 + 2\beta + \beta^2$

消掉 β^2：

$4\beta - 1 < 1 + 2\beta$

$2\beta < 2$

$\beta < 1$

### 判断 f’(1⁄2) > -1

$\frac{\beta^2 + 4\beta - 1}{(1+\beta)^2} > -1$

等价于：

$\beta^2 + 4\beta - 1 > -(1+\beta)^2$

展开右边：

$\beta^2 + 4\beta - 1 > -1 - 2\beta - \beta^2$

移项：

$2\beta^2 + 6\beta > 0$

$2\beta(\beta+3) > 0$

对 β ∈ (0,1) 始终成立。

### 最后

$|f'(1/2)| < 1$

因此：

-   x^\* = 1⁄2 是不动点
-   且是线性稳定不动点

所以，在AIMD算法下，不同的流可以自发达到公平性和稳定性。
