最常踩的几条：

-   **破折号**限用：只在后面紧跟一句很短的解释时用；别拿它塞长插入语；整段别扎堆。
-   **引号能省则省**：常用词（消失、变了、增长、风险、影响……）别加引号——日常词打引号是 AI 腔，也累赘；只有"非字面义 / 反讽 / 术语首次出现下定义"才用。正常人打字本来就嫌引号麻烦，默认不加。
-   **对称/排比句 → 打破**：「不仅…而且」「既…又」「一方面…另一方面」。**「不是…而是」尤其少用**，能直说就直说（"其实是 Y""真正起作用的是 Y"）。
-   **「不是 X，是 Y」立靶子 → 绝对禁止**（2026-07-18 用户强调）：X 是没人主张过的假设时，等于自己造一个对手来衬托 Y——"风险第一的不是火箭会不会炸，是马斯克本人"（没人说过是火箭）。直接说"排第一的是马斯克本人"。判据：删掉"不是 X"整句意思不变 → 必删。只有 X 真是流行观点时才可以先立再破。
-   **别硬塞转折词**：前后不是真转折，就不要加"但 / 然而 / 不过 / 其实"。判据：删掉转折词意思不变 → 删。
-   **无意义程度/装饰词 → 删**：非常、极其、大大、显著地（非统计义）、关键、核心、至关重要、革命性、全方位。判据：删掉断言不变 → 删。
-   **空转过渡 → 删**：值得注意的是、需要强调的是、众所周知、不难发现；宣告式"说到底/归根结底/先说结论/划重点"。
-   **开头别预告，直接进内容**："先把 X 说清楚""先说清楚一件反直觉的事""把 X 先明确""我们先理清 Y""必须讲清楚 X""话说到前头""话说在前头""说在前头""先说在前头""话说回来""把话说前头"这类铺垫/打招呼式过渡一律删，直接进内容，内在逻辑本就清楚，不用提前打招呼。这套开场白已被各大 AI 互相蒸馏成统一腔调，是最扎眼的 AI 味来源之一，要刻意躲开。
-   **「清楚 / 反直觉」别乱贴**："说清楚 / 讲清楚 / 彻底搞懂"少用——科学问题很少能彻底说清，别替读者打这个包票；"反直觉"只在结论真的反直觉、且自己有把握时才贴，否则删。
-   **自问之后别垫"宣告"**：自问"为什么会这样？"后别接"背后是几股力量 / 原因有三 / 有几点"，直接写一、二、三。同类："还有一个关键地方容易被看漏"——别预设它"关键"或"被看漏"，直接说，或只用"另外""还有一点"。
-   **「把 X 搞清楚，就会发现 Y」→ 简化**：写成"了解清楚后，就会发现…"，别绕这个长句式。
-   **标题 / 小标题尤其干净**："先""必须""清楚""反直觉"这类词在标题和小标题里一律别用——标题最招摇，AI 味在这里最容易露馅，直接写结论或主题。
-   **「一句话」类 → 一律禁用**：「一句话」「就一句话」「核心建议只有一句」「一句话讲清」「一句话总结」一概不用。总结就直接说内容，听的人自然知道那是总结。
-   **「先说/先给/先看」宣告 → 删**："先说漂亮的一面""先给结论""先看打新"——内容本来就有先后，说出来的顺序就是顺序，不用宣告。直接进内容。
-   **「对词动手术」→ 直接讲事**（2026-07-25 用户定，附总根）：禁"先把 X 这个词拆开""拆解/解构/厘清/界定 X 这个概念""重新定义 X"式旁白——要讲的其实是**事的程度和差异**（开到什么程度、谁做了什么），不是词本身；真人不对词做手术。病根是**宾语错位**：句子的宾语本该是世界里的事，AI 把它换成语言本身，再表演一个分析动作。判据两条：① 宾语=「X 这个词/概念/说法」+ 手术动词（拆/解构/厘清/界定）→ 删旁白，宾语换回事；② **词可当主语陈述世界的现象**（"开源这个词被偷换了概念"✅，说的是别人干的事），**不可当自己手术动作的宾语**（"我们先把开源拆开"❌）。边界："举个例子/打个比方/算笔账"是真人真说的口语宣告，保留；判据=这个宣告的动作真人嘴里说不说。示范：❌"要看懂博弈，得先把开源这个词拆开" → ✅"开源这个词，其实是被偷换了概念的。要看懂博弈，得看它到底开了什么、没开什么"。

-   **总根（判所有表演性套路）**：AI 味的一大族 = 在表演美德而不是执行它——平衡句表演文采、拆词表演分析、"先说结论"表演条理、"问到点子上"表演倾听、金句收尾表演深刻。真人写作，分析是隐形的，只有结果出场。统一判据：**删掉这句，信息少了吗？没少 → 它是表演，删。**

-   **会议式编号总结 → 禁用**："三句话。第一句…第二句…第三句…""三点。第一点…"这种像开会念纪要的结构别用，总结连着说就行，口播尤其明显。
-   **对话/采访脚本的接话 → 直接答**："这个问题问到点子上了""问得好""这个问题很关键"这类接话表扬删掉，直接回答。本 skill 同样适用于口播/视频脚本，口语化不等于可以用这些套路。
-   **口播/TTS 脚本要有语气词**（2026-07-19 用户强调，仅口播，书面稿别加）：适度撒"哎/啊/呢/嘛/其实/你看/对吧/嗯"，让克隆声更自然流畅——尤其在回答开头、转话题处。别每句都加，一段两三处足够；书面文章不适用这条。
-   **叹词用「哎/唉」，不写「欸」**（2026-07-29 用户定，口播/字幕）：字幕和口播里的感叹开场词一律写「哎」（或语境合适时「唉」），不用「欸」——用户多次纠正过这个字。
-   **「老规矩」禁用**（2026-07-29 用户定）：口头禅式的"老规矩，咱们…"没有信息量，属于套话垫场，直接删，进入正题。同理少用其他自我仪式化开场（"还是那句话""照例"）。
-   **人为情绪标签 → 平实陈述**：扎心的真相、残酷的、令人揪心、触目惊心、可怕的是 → 删，事实平实说（温和语气可保留）。
-   **AI 腔词 → 换平实**：赋能、抓手、闭环、链路、维度（非专业义）、底层逻辑、深耕、彰显、保驾护航。
-   **文学化/比喻/拟人 → 还原**：画卷、基石、灯塔、揭开神秘面纱、踏上…旅程；给无生命物"想要/聪明地/决定"。每段最多留一个最贴切的比喻；去比喻别改因果强度。"家底""亮家底"这类拟人化说法照此处理——它是家公司，直说"财务情况"。
-   **被用滥的酷词 → 换普通词**（2026-07-18 用户强调：能用普通词就用普通词）："盯"（全世界都在盯）→ 关注；"狂飙""杀疯了""拉爆""起飞""血洗""屠榜""扎心""硬核" → 平实说涨跌和幅度。判据：这个词要是三年前的新闻稿不会用，现在满屏都是 → 换掉。
-   **「最 X」冗余修饰 → 删「最」**（2026-07-19 用户强调）："最"后面跟本身不分级的词就是重复——最真相、最硬核、最干脆、最客观、最直接、最一针见血、最开门见山、最不废话、最不煽情、最不装。真相就是真相，干脆就是干脆，不用加最。**真最高级保留**："最大的风险""最担心的是需求"这种去掉「最」句子就不成立的，照用。判据：去掉「最」意思不变或更别扭 → 那个「最」是装饰，删；去掉后语义残缺 → 保留。
-   **「到底」限频**（2026-07-19 用户强调）："到底怎么样/到底是什么/到底发生了什么"是 AI 高频句式，不禁用但**一篇/一集最多 1-2 处**，留给真正需要追问语气的地方；其余改成"是什么样""发生了什么""能有多好"。同类限频："究竟"。"底层逻辑""根本上"也尽量少用。
-   **生僻/文绉绉 → 最简同义词**：旨在→为了、藉由→通过、诸如→比如、予以→给、较之→比。（**专业术语保留，不强行简化**）
-   **明令禁用**：说白了、脊背发凉、掰开揉碎了说、直接给你答案、讲透了、毛骨悚然、值得一提的是。
-   **段首/句式别雷同**：连续相同的段首或句式适度变化、长短句交错（拿不准就别动）。

### 2\. 动词优先，去名词化（最常被忽略，优先级高）

名词化 = 把动作冻成抽象名词，是 AI 腔和翻译腔的大来源，也最难自查——形容词好删，动作藏进名词里却看不见。

-   **杀"弱动词+名词"空壳**：进行 / 开展 / 实现 / 做出 / 予以 / 给予 / 造成 + 名词 → 还原成那个名词的动词。"进行了分析"→"分析了"；"做出决定"→"决定"；"对 X 造成影响"→"影响了 X"；"实现增长"→"涨了"。
-   **状态 / 判断 → 动作 / 感官**（叙事、科普尤其）："他很紧张"→"他攥着杯子，指节发白"；"销量很好"→"货架两天就空了"。
-   **形容词 / 副词堆叠 → 一个准动词**："快速地走过去"→"冲过去"；"发出很大的声音"→"轰的一声"。
-   **判据**：一句里找那个主要动作，如果它躲在"的 / 进行 / 做"后面当名词，就解冻成动词。
-   **红线（别过度）**：① 专业术语本就是名词（磷酸化、凋亡、表达、糖尿病）——不是名词化，别碰；② 论文里承接上句的名词化（"这一抑制导致…"）在做"已知→新知"的衔接，留；③ 别把每句都改成短促动作，节奏会单一、反而像 AI——一段里留几处名词也行，够用就停。

### 3\. 语气：商量而非指令

-   要/必须/不要/务必/记住 → 不妨/可以/最好/建议/会更稳妥/记得（该强调紧迫的仍直说"尽快"，不弱化）。
-   居高临下（"很多人犯的错是…"）→ 平等共情（"有一种想法其实挺常见：…"）。
-   保留必要的模糊限定（可能/通常/多数/一般），不删成绝对化。
-   平实、不煽情、不制造焦虑，也不降成口水聊天腔。

### 4\. 铁律（怎么改才安全）

-   **只改命中风格问题的句子；干净的句子原样不动。**
-   **事实 / 数字 / 专有名词 / 引用 一律不动**（本 skill 只动语言，不做事实核查——那是内容层的事）。
-   **绝对词**（所有/从不/唯一/首个/必须）不擅自删弱，除非确知用错。
-   **拿不准就别动。**
