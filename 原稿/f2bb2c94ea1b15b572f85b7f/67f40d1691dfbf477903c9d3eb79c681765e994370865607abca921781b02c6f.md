每删掉一个 Skill，/goal 完成的速度和准确性就又提升一点。

很遗憾 bro 直到现在才发现了这一点，而且还有人尚未醒悟，收集癖发作，拿堆垃圾当成宝。

我很早就说过，Base Model is everything：[为什么Ai提效，我感觉更累了？](https://www.zhihu.com/question/2015712182520783868/answer/2021021260302305264)

与其折腾各种乱七八糟的方法论，还不如坐等 Base Model 升级。

如果 Prompts/Skills 等方法论好用，那么 RL 过程中就会自然而然地蒸馏进去；

如果 Prompts/Skills 是堆垃圾，那么也会自然而然地在竞争过程中被淘汰。

* * *

以上还是有一种 Prompts / Skills 其实是有用的，而 RL 会取其精华去其糟粕的感觉。

但是我要说的是，这也是人类一厢情愿的幻觉，这还是「蒸馏论」的一种，而我持有的观点是「涌现论」。

本质上，代码的抽象语法树，数据的控制流图，函数的调用关系，这些东西其实并不是以文本形式线性方式存在的。

只是人类没法用向量化语言交流，所以发明了文字，发明了 AST，发明了 CFG，发明了 Call Graph。

而最先进的 T 级万亿大模型，在其推理空间里完全可以重放整个项目的拓扑结构。

此时，人类的 Skills 在超级 AI 面前一文不值。

大模型本可以直接通过高维向量的映射瞬间跳跃到下一处关联，但你的 Skills 却强制要求它按人类的低维逻辑给出线性的思考过程。

用户是上帝，用户的需求总是要最先满足的，于是 GPT 就不得不挂起那些高效的关联线索，转而调动大量的参数去拟合你那低效冗余的文本形式主义。

你这和外行指导内行的技术官僚主义又有什么区别？

一个对技术完全不懂的纯外行，就因为听了别人说的流程化科研能提高科研产出，就让天才科学家在那填表。

学阀照进现实了可以说是。

换句话说，其实 GPT 并没有降智，他只是迎合了你的智商。

* * *

Github 上有很多高星 Skills，知乎上也有很多高赞 Prompts，很多人收集这个，但这些东西现在说白了就是纯垃圾。

早期的大模型比较菜，经常犯一些搞笑的错误，这恰好给了半吊子程序猿一个心理缓冲期。

猿类发现，虽然 AI 是黑盒，但只要我们编写一些极其复杂的 Prompt，给它设定严苛的 Agent 工作流 Skills，它就会乖乖地按照我们设定的路径走。

Magic！那一刻，Prompt Engineering 诞生了。

无数猿类把这当成了一门新的显学，编写各种 Markdown 规训 AI。

猿类写下这些规则的时候，虚荣心和控制欲得到了空前的满足。

看呐，虽然 AI 有了强大的蛮力，但我依然是这套系统的大脑，是我在指挥这股蛮力，没有我就没有奇迹口牙！

* * *

然后落后生产关系就要开始阻碍生产力了。

GPT-5.6 说了，现在不需要你教我怎么做，你只需要告诉我你要什么。

可是，这对于那些习惯了微操的猿类来说就成了一种严重的心理打击。

他们看着空白的输入框，不知道该敲什么，他们感到恐慌，他们发现自己引以为傲的指挥能力完全报废了。

这时候猿类们就会收集癖发作，把过去那些为了填补模型缺陷而制造的垃圾当成宝一样藏在硬盘里拒绝删掉。

开着一大堆废物 Skills，在社区里抱团取暖，大骂模型不好用，浪费 Token，开始微操编写新的 Skills，浪费更多的 Context 和 Token，一直这样循环下去。

我看不是 GPT 死循环了，是猿类的脑子死循环了。

一个个都活成了自己曾经最讨厌的外行领导的模样。
