## 实现原理

作为一个数据科学研究者，这种小事自己做就行，非常简单，我们先随便找个几篇论文作为数据源，如何构造 pdf paper 的 feature 呢？使用 `pdfplumber` 下的 `extract_text_lines` 方法，使用当前行的高度和两侧的坐标作为当前这一行的 feature ，不要忘了做列归一化。


```python

    line_height = line['bottom'] - line['top']
    x0 = line['x0']
    x1 = line['x1']
    data.append([line_height, x0, x1])

data = np.array(data)
data = (data - data.min(axis=0)) / data.ptp(axis=0)
```

## 代码：基于聚类的 pdf 标题提取算法

方法很多，没有标签就用用 聚类，我这里用的是 MeanShift，原因懒得写了。

你也可以自己打点标签，然后用监督的方法来训练模型，但是paper的标题一般都在line的最前面，我直接用先验 + 非监督搞定了：

```python
def extract_title(path: str, scan_page: int = 0, invalid_replacement: str = ' '):
    pdf = pdfplumber.open(path)
    page = pdf.pages[scan_page]
    data = []
    text = []
    for line in page.extract_text_lines(return_chars=False):
        text.append(line['text'])
        line_height = line['bottom'] - line['top']
        x0 = line['x0']
        x1 = line['x1']
        data.append([line_height, x0, x1])

    data = np.array(data)
    data = (data - data.min(axis=0)) / data.ptp(axis=0)
    
    model = MeanShift()
    labels = model.fit_predict(data)
    clusters = []
    for index in labels:
        if len(clusters) == 0:
            clusters.append([index])
        else:
            last_line_index = clusters[-1][-1]
            if last_line_index == index:
                clusters[-1].append(index)
            else:
                clusters.append([index])
    
    title = ''
    for i in range(len(clusters[0])):
        title += text[i]

    # handle invalid char
    invalid_chars = [':', '：', '/', '\\']
    for char in invalid_chars:
        title = title.replace(char, invalid_replacement)

    # filter space
    title = re.sub(r'\s+', ' ', title)

    return title
```
