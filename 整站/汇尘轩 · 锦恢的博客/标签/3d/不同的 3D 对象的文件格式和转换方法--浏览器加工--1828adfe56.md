## 前言

最近打算把 seed3d 上的一个格式转换的功能实现一下，考虑到现在的整体架构，我打算通过 faas 来部署这个功能模块。在那之前，先简单看一下目前常见的3D 格式吧。

| 格式   | 动画支持 | 材质支持    | 主要用途        | 适用场景                |
|--------|----------|-------------|-----------------|-------------------------|
| FBX    | ✅       | ✅          | 动画/游戏       | Maya/Unity/Unreal      |
| OBJ    | ❌       | 基础        | 静态模型        | 3D打印/工业设计         |
| GLB    | ✅       | ✅ (PBR)    | Web/AR/VR       | 网页/移动端实时渲染     |
| STL    | ❌       | ❌          | 3D打印          | 制造业/原型制作         |
| USDZ   | ✅       | ✅          | AR（苹果生态）  | iOS AR应用             |
| BLEND  | ✅       | ✅          | Blender项目     | 开源3D创作/全流程制作  |

<br>

如果需要对上面的格式进行相互转换的话，显然，我们是需要指定一个中间格式的，这样转换函数的编写复杂度才会降低到线性。从上面的支持中可以看到，FBX 是最通用的一种格式，所以我们选择 FBX 作为中间格式。

## 材质支持

如果想要编写转换函数，还有一点是需要明确的，那就是，这几个格式的材质都是如何实现的。做过 3D 相关工作的朋友应该都知道，有的文件格式是放在文件内部的，而有的则是放在外部。

直接放结论了

### 完全自包含格式 （适合分发）

- GLB (glTF二进制格式)
- USDZ (苹果AR专用)
- BLEND (当设置为打包资源时)

### 需外部支持格式

- OBJ (.obj + .mtl + 纹理图片)
- FBX (通常需要外部纹理，除非明确打包)

## 通过 blender api 进行转换

blender 自带一个 python 的解释器和一些特殊的库，比如 bpy。通过 bpy 我们可以直接操作 受打 blender 广泛支持的 3D 对象，然后将其导出成我们需要的格式。

一个可行的代码如下

文件名：fbx_to_blend.py

```python
import sys
import os
import bpy
from typing import Literal

def get_format_from_extension(output_path: str) -> str:
    """根据文件后缀自动判断格式"""
    ext = os.path.splitext(output_path)[1].lower()
    format_map = {
        '.obj': 'OBJ',
        '.glb': 'GLB',
        '.stl': 'STL',
        '.usdz': 'USDZ',
        '.blend': 'BLEND'
    }
    return format_map.get(ext, 'BLEND')  # 默认返回BLEND格式

def convert_fbx(
    fbx_path: str, 
    output_path: str,
    texture_file: str = None,
    preserve_materials: bool = True
) -> bool:
    # 清空场景
    bpy.ops.wm.read_factory_settings(use_empty=True)

    format_type = get_format_from_extension(output_path)
    
    try:
        # 导入FBX
        bpy.ops.import_scene.fbx(filepath=fbx_path)
        
        # 应用纹理材质
        if texture_file and os.path.exists(texture_file):
            # 创建新材质
            mat = bpy.data.materials.new(name="TextureMaterial")
            mat.use_nodes = True
            bsdf = mat.node_tree.nodes["Principled BSDF"]
            
            # 添加纹理节点
            tex_node = mat.node_tree.nodes.new('ShaderNodeTexImage')
            tex_node.image = bpy.data.images.load(texture_file)
            mat.node_tree.links.new(bsdf.inputs['Base Color'], tex_node.outputs['Color'])
            
            # 应用到所有网格对象
            for obj in bpy.context.scene.objects:
                if obj.type == 'MESH':
                    if obj.data.materials:
                        obj.data.materials[0] = mat
                    else:
                        obj.data.materials.append(mat)

        # GLB导出设置
        if format_type == 'GLB':
            bpy.ops.export_scene.gltf(
                filepath=output_path,
                export_format='GLB',
                export_yup=True,
                export_materials='EXPORT',
                export_texture_dir=os.path.dirname(output_path),
                export_texcoords=True,
                export_normals=True
            )
        elif format_type == 'OBJ':
            # 确保材质数据存在
            if not any(obj.data.materials for obj in bpy.context.scene.objects if obj.type == 'MESH'):
                # 如果没有材质，创建一个默认材质
                mat = bpy.data.materials.new(name="DefaultMaterial")
                for obj in bpy.context.scene.objects:
                    if obj.type == 'MESH':
                        obj.data.materials.append(mat)
            
            bpy.ops.wm.obj_export(
                filepath=output_path,
                export_materials=True,
                path_mode='COPY',
                export_colors=True,
                export_triangulated_mesh=True
            )
            
            # 处理纹理引用
            if texture_file:
                mtl_file = os.path.splitext(output_path)[0] + '.mtl'
                if os.path.exists(mtl_file):
                    with open(mtl_file, 'r+') as f:
                        content = f.read()
                        # 确保纹理引用正确
                        content = content.replace('texture.png', os.path.basename(texture_file))
                        f.seek(0)
                        f.write(content)
                        f.truncate()

        elif format_type == 'GLB':
            bpy.ops.export_scene.gltf(
                filepath=output_path,
                export_format='GLB',
                export_yup=True,
                export_materials='EXPORT' if preserve_materials else 'NONE'
            )

        elif format_type == 'STL':
            bpy.ops.wm.stl_export(
                filepath=output_path
            )

        elif format_type == 'USDZ':
            bpy.ops.wm.usd_export(
                filepath=output_path,
                export_animation=False,
                export_materials=True,  # 确保导出材质
                export_textures=True,   # 导出纹理
                overwrite_textures=True # 覆盖现有纹理
            )

        if format_type == 'BLEND':
            temp_glb = "temp.glb"
            bpy.ops.export_scene.gltf(
                filepath=temp_glb,
                export_format='GLB',
                export_materials='EXPORT'
            )
            bpy.ops.wm.read_factory_settings()
            bpy.ops.import_scene.gltf(filepath=temp_glb)
            bpy.ops.wm.save_as_mainfile(filepath=output_path)
            os.remove(temp_glb)

        return True
        
    except Exception as e:
        print(f"转换失败({format_type}): {str(e)}")
        return False

if __name__ == "__main__":
    if len(sys.argv) < 5 or sys.argv[-4] != '--':
        print("用法: blender --background --python {} -- input.fbx output.format texture.png".format(__file__))
        sys.exit(1)
    
    input_file = sys.argv[-3]
    output_file = sys.argv[-2]
    texture_file = sys.argv[-1] if len(sys.argv) > 5 else None

    success = convert_fbx(input_file, output_file, texture_file)
    sys.exit(0 if success else 1)
```

使用 blender 自带的 python 解释器，我们可以直接运行这个脚本。

先注册 blender 的路径：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python fbx_to_blend.py -- cup.fbx output.glb texture.png
```

> 如果是 linux 环境下，记得输入的文件都必须是绝对路径。


cup.fbx output.glb texture.png 分别是输入 fbx，输出文件，材质文件。

如果不需要材质文件，可以输入空：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python fbx_to_blend.py -- 3d-assets/cup.fbx ./output/output.glb xxx
```
