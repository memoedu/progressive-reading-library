最近在重新装机，正好遇到了一个曾经困扰了我很久的问题，那就是，Visual Studio的工具链到底安装在了哪里？趁着这次机会，我要好好记录下来。


> 为什么要记录这些路径？因为不少的适用于Windows的C++构建项目都需要VS的工具链的支持，而且都需要你把工具链链接加入环境变量。


首先需要注意，只有下载了VS且安装了“使用C++的桌面开发”才有下面提到的一些工具。

## CMake地址

```
C:\Program Files\Microsoft Visual Studio\2022\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin
```

## MSVC编译器地址

```
C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.37.32822\bin\Hostx64\x64
```

如果你不愿意下载VS，可以单独下载微软开发的C++工具链：[https://visualstudio.microsoft.com/zh-hans/visual-cpp-build-tools/](https://visualstudio.microsoft.com/zh-hans/visual-cpp-build-tools/)
