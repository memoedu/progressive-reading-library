## mp4转换为gif
### 基本命令
```bash
ffmpeg -i .\robotmove.mp4 -r 15 output.gif
```
将`robotmove.mp4`转换为`output.gif`，每秒的帧数为15。

### 截取指定片段转换为gif

```bash
ffmpeg -t 3 -ss 00:00:02 -i small.mp4 small-clip.gif
```
上述命令为从视频中第二秒开始，截取时长为3秒的片段转化为 gif

### 调整分辨率

```bash
ffmpeg -i small.mp4 -b 2048k small.gif
```
ffmpeg默认转化出中等质量的gif，若要转化出高质量的 gif，可以修改比特率。

### 去除 4k 录屏中的 Windows 任务栏

```bash
ffmpeg -i .\usage.mp4 -vf "crop=iw:ih-68:0:0" -c:a copy .\usage.0.mp4
```

## MP4基本操作

### 视频剪切
```bash
ffmpeg -ss 00:00:00 -t 00:00:30 -i test.mp4 -vcodec copy -acodec copy output.mp4
```
从0秒到30秒剪切，输入文件为test.mp4，输出文件为output.mp4

### 视频静音

```bash
ffmpeg -i input.mp4 -af "volume=0" output.mp4
```

## mp4 提取音频

```bash
ffmpeg -i input.mp4 -vn -acodec libmp3lame -q:a 0 output.mp3
```

其中 `-q:a` 参数代表了导出品质，一共 `0-9`， 0 代表最佳。
