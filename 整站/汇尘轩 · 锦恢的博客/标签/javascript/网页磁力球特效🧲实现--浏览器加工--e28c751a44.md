## 基本原理

基本原理非常简单，初始平面创建完成点后，监听鼠标移动事件：

```javascript
const movingCircles = {
	// 初始化
    init() {
        // 获取窗口基本属性
        this.resize();
	
        // 创建若干个半径为 30 的点
        this.create({ radius: 30 });
	
        // 监听鼠标移动事件
        document.addEventListener('mousemove', event => {
            event.preventDefault();            
            this.update(event.x, event.y);
        });
    }
}
```

在 `update` 函数中，每一次移动都重新计算出所有距离光标中心点距离不足 `mouseRadius` 的所有点，然后给这些点一个暂时远离光标中心的动画。这个可以基于 gsap.js 来优雅实现。代码我就放在附录里面了。

## 空间哈希优化

既然 js 层面的性能瓶颈之一是获取所有到给定 x, y 的所有欧式距离不足 K 的点这么一个操作（当然，事实证明渲染才是最大的性能瓶颈，但是既然是基于 svg 做的，渲染先按下不表，咱们鞭长莫及呐~）

在 jiejoe 大佬给出的例子中，他使用了全部遍历的方法，代码片段如下：

```javascript
    // 更新小球位置， (x, y) 为光标坐标
    update(x, y) {
        // 更新坐标到容器内
        const mouseX = x - layoutOpions.left;
        const mouseY = y - layoutOpions.top;
		
        // 遍历所有点
        for (const ball of this.balls) {
            const dx = ball.originX - mouseX;
            const dy = ball.originY - mouseY;

            const distance = Math.sqrt(dx * dx + dy * dy);

            if (distance <= mouseRadius) {
     			// 给范围内的小球施加动画           
            }
        }
    }
```

时间复杂度为 $\mathcal O(N^2)$, N 为点的数量。

我们可以用空间哈希算法来优化这个过程。空间哈希的基本思想是，根据 `mouseRadius` 的值作为网格大小对空间进行网格划分，这样每次查询距离 (x, y) 所有距离不足 mouseRadius 的 点就可以先 $\mathcal O(1)$ 地算出 (x, y) 属于哪一个网格，然后只需要计算相邻网格八分图内的所有点，而不是整个空间内所有点。网格划得越多，该方法的空间复杂度越低。我写的一个空间哈希的算法就放在附录里面了。

使用的时候，先在创建小球的代码结尾把小球加入空间哈希表：

```javascript
    // 创建小球
    create(option) {
		// ...
        for (let ri = 0; ri <= layoutOpions.rows; ++ ri) {
            for (let ci = 0; ci <= layoutOpions.cols; ++ ci) {
				// ...
                
                this.balls.push(ball);
                // 加入索引
                this.spaHash.push(ball);
            }
        }
    },
```

使用的时候如下：

```javascript
    // 更新小球位置， (x, y) 为光标坐标
    update(x, y) {
        // 更新坐标到容器内
        const mouseX = x - layoutOpions.left;
        const mouseY = y - layoutOpions.top;
		
        const disturbedBalls = this.spaHash.center(mouseX, mouseY);

        for (const target of disturbedBalls) {
            const { ball, distance } = target;
            // 给小球施加动画
        }
    }
```

代码更加简单，而且理论空间复杂度更低。

### 空间哈希算法

```javascript
class SpatialHash {
    constructor(K) {
        this.K = K; // 网格大小
        this.hashMap = new Map(); // 哈希表，存储网格中的点
    }

    // 插入一个二维点
    push(ball) {
        const x = ball.originX;
        const y = ball.originY;

        // 计算点所在的网格坐标
        const gridX = Math.floor(x / this.K);
        const gridY = Math.floor(y / this.K);
        const gridKey = `${gridX},${gridY}`;

        // 将点添加到对应的网格中
        if (!this.hashMap.has(gridKey)) {
            this.hashMap.set(gridKey, []);
        }
        this.hashMap.get(gridKey).push(ball);
    }

    // 查询距离目标点距离小于等于 K 的所有点
    center(cx, cy) {
        const targets = [];

        // 计算目标点所在的网格坐标
        const targetGridX = Math.floor(cx / this.K);
        const targetGridY = Math.floor(cy / this.K);

        // 检查目标网格及其相邻网格（3x3 区域）
        for (let dx = -1; dx <= 1; ++ dx) {
            for (let dy = -1; dy <= 1; ++ dy) {
                const neighborGridX = targetGridX + dx;
                const neighborGridY = targetGridY + dy;
                const neighborGridKey = `${neighborGridX},${neighborGridY}`;

                const currentPointBalls = this.hashMap.get(neighborGridKey) || [];
                for (const ball of currentPointBalls) {
                    const x = ball.originX;
                    const y = ball.originY;

                    const distance = Math.sqrt((x - cx) ** 2 + (y - cy) ** 2);
                    if (distance <= this.K) {
                        targets.push({ ball, distance });
                    }
                }
            }
        }

        return targets;
    }
}
```
