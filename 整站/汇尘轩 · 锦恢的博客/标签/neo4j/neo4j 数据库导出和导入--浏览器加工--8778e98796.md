## 前言

数据库的备份是非常重要的一件事，如果遇到数据库迁移，被网络攻击或者其他事情（比如我之前升级 glibc 导致服务器炸了）不得不重装服务器的情况下，我们都需要能够从数据库中导出数据。

作为标准的数据库，neo4j 提供了几种方法进行数据导出。

---

## 方法: neo4j-admin dump

首先查看你需要导出的数据库。

先登录数据库：

```bash
cypher-shell -a localhost -u <账号> -p <密码>
```

neo4j 中输入

```
show databases;
```

输出：

```
+-------------------------------------------------------------------------------------------------------------------------------+
| name     | aliases | access       | address        | role         | requestedStatus | currentStatus | error | default | home  |
+-------------------------------------------------------------------------------------------------------------------------------+
| "neo4j"  | []      | "read-write" | "0.0.0.0:7687" | "standalone" | "online"        | "online"      | ""    | TRUE    | TRUE  |
| "system" | []      | "read-write" | "0.0.0.0:7687" | "standalone" | "online"        | "online"      | ""    | FALSE   | FALSE |
+-------------------------------------------------------------------------------------------------------------------------------+

2 rows
ready to start consuming query after 4 ms, results consumed after another 1 ms
```

此处选择默认的 neo4j 即可。如果是企业版本，应该会有更多的表格，选择需要导出的表即可。

`:exit`退出会话后停止 neo4j ：

```bash
neo4j stop
```

neo4j-admin 给用户提供了一套工具用于进行数据库到磁盘的单文件 IO:

- `neo4j-admin dump --database <数据库名字> --to <路径>`：用于将 <数据库名字> 中的数据导入到 <路径处> 中。
- `neo4j-admin load --database <数据库名字> --from <路径>`：用于将 <路径处>中的数据导入到 <数据库名字> 中。

此处，我们将 `neo4j` 这个表导出到 `~/data/neo4j-backup/neo4j.db` 这个位置，那么就这么写：

```bash
neo4j-admin dump --database neo4j --to ~/data/neo4j-backup/neo4j.db
```

输出：

```
Done: 36 files, 257.1MiB processed.
```

查看备份文件夹：

```bash
l ~/data/neo4j-backup
```

输出：

```
total 12M
drwxrwxr-x 2 ubuntu ubuntu 4.0K Apr  1 23:10 .
drwxrwxr-x 3 ubuntu ubuntu 4.0K Apr  1 23:01 ..
-rw-rw-r-- 1 ubuntu ubuntu  12M Apr  1 23:10 neo4j.db
```

可以看到，导出的数据库 `neo4j.db` 只有 12MB。

如果希望在别的服务器上，将 `neo4j.db` 导入到 neo4j 的名为 db 的表中，则输入：

```bash
neo4j-admin load --database neo4j --from /path/to/neo4j.db
```

导出完成后，别忘了重启你的数据库和后端服务。

```bash
neo4j start
go run main.go
```

## 方法二: 在前端界面导出 json

如果你的服务器出现了严重的段错误，比如链接库被干烂了，此时你 ssh 也连不上，但是幸亏你之前看我的教程配置了 neo4j 的 https 前端服务，此时不要慌，你的数据仍然可以导出。

首先进入你的 neo4j 前端界面，希望你记得你开放的端口，登入你的前端界面后，输入如下语句查看所有节点类型的数据：

```cypher
match (n) return n;
```

> 为了避免卡顿，建议采用 Code 这种模式的视图

在返回的查询结果的右上角，有一个下载一样的标志，点击它，找到 “Export JSON”，会下载名为 `records.json` 的文件。我们将它另存为 `nodes.json`。

对于 Relationship 的节点也是一样：

```cypher
match p=()->() return p;
```

然后点击 Export JSON 后另存为 `relationships.json`。

这两个 json 文件就是当前数据库的这个表（neo4j）的备份文件了。

>  以我的数据库为例，这两个json大概有250MB大小，对比之前 neo4j 自己导出的，可以看到 neo4j 的存储还是相当紧凑的，毕竟是用二进制存储的，这里的 json 是纯 utf-8 ，大这么多也很正常。

如果我们希望在别的服务器上导入这个文件，还需要花点功夫，因为 neo4j 导出的 json 可能会出现双引号内有回车的现象，我们需要先简单清洗一下数据。我们下面需要使用 python，先安装用于连接 neo4j 的库：

```bash
pip install py2neo
```

工具函数如下，直接复制粘贴即可：

```python
import json
from py2neo import Graph, Node, Relationship, NodeMatcher
from tqdm import tqdm
  
def deal_json(file_name):
    with open(file_name, 'r', encoding='utf-8') as f:
        content = f.read()
        # necessarily, the beginning of file is an illegal character for utf-8
        if content.startswith(u'\ufeff'):
            content = content.encode('utf8')[3:].decode('utf8')
        # add other deal steps
        content = str(content).replace('	', '')
        load_dict = json.loads(content)
    return load_dict
 
 
def trans_nodes(graph, file_name):
    load_dict = deal_json(file_name)
    for row in load_dict:
        # select by json structure
        old_id = row['n']['identity']
        node_type = row['n']['labels'][0]
        properties = row['n']['properties']
        node = Node(node_type, old_id=old_id)
        for key, val in properties.items():
            node[key] = val
        print('creating-', node)
        graph.create(node)
 
 
def trans_relations(graph, file_name):
    load_dict = deal_json(file_name)
    mather = NodeMatcher(graph)
    index = 1
    for row in load_dict:
        start_id = row['p']['segments'][0]['start']['identity']
        start_label = row['p']['segments'][0]['start']['labels'][0]
        end_id = row['p']['segments'][0]['end']['identity']
        end_label = row['p']['segments'][0]['end']['labels'][0]
        relation_type = row['p']['segments'][0]['relationship']['type']
        start_node = mather.match(start_label, old_id=start_id).first()
        end_node = mather.match(end_label, old_id=end_id).first()
        relation = Relationship(start_node, relation_type, end_node)
        print('inserting ' + str(index) + '-', relation)
        index += 1
        graph.create(relation)

def clean_json(json_file):
    with open(json_file, 'r', encoding='utf-8') as fp:
        content = fp.read()
        current_string = None
        last_ch = None
        string_start = False
        clean_content = ''
        tags = ['\n', '\r']
        
        for ch in tqdm(content, ncols=100, colour='green'):
            if ch == '"':
                clean_content += ch
                if last_ch == '\\':
                    current_string += '"'
                elif string_start:
                    string_start = False
                        
                elif string_start is False:
                    string_start = True
                    current_string = ''
            else:
                if string_start and ch in tags:
                    clean_content += '\\n'
                else:
                    clean_content += ch
                    
                if string_start:
                    current_string += ch
    
            last_ch = ch
    
    with open(json_file, 'w', encoding='utf-8') as fp:
        fp.write(clean_content)
```

下面首先需要使用 python 登录数据库：

```python
# 第一个 url 和你的 neo4j 配置有关，具体请看我之前的文章的“开启 https 和 bolt 服务” 这一章： https://kirigaya.cn/blog/article?seq=199
# 如果你的 bolt 协议配置了 SSL，还可以写成 "bolt://<域名>:7687"
graph = Graph("bolt://<IP>:7687", auth=('账号', '密码'))
```

然后我们简单清理一下数据，把双引号内的回车替换成 \n：（这一步非常费时，你可以考虑用 C 重写一个，我这个数据比较小，就懒得折腾了）

```python
clean_json('./nodes.json')
clean_json('./relationships.json')
```

然后开始进行数据导入：

```python
trans_nodes(graph, './nodes.json')
trans_relations(graph, './relationships.json')
graph.run('MATCH (n) REMOVE n.old_id')
```

程序结束后，导入结束。
