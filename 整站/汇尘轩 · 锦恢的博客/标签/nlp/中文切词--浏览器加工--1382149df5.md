## 最大匹配算法

### 简介

最大匹配法的思想非常朴素：建立一个词汇表，里面囊括了所有可能出现的词语。对于需要分词的句子，从开头往后进行扫描，每匹配得到一个词语在词汇表中，就将匹配好的放入结果列表中。

```python
dictionary = ["欢迎","光临","学弟","学妹","学长","学姐","来","去","食堂","宿舍","就餐"] #列出所有可能出现的词汇

txt = "欢迎学弟学妹来食堂就餐"
# 逐一分词
# 欢迎,学弟学妹来食堂就餐 because "欢迎" in dictionary
# 欢迎,学弟,学妹来食堂就餐 because "学弟" in dictionary
# 欢迎,学弟,学妹,来食堂就餐 because "学妹" in dictionary
# 欢迎,学弟,学妹,来,食堂就餐 because "来" in dictionary
# 欢迎,学弟,学妹,来,食堂,就餐 because "食堂" in dictionary
# 欢迎,学弟,学妹,来,食堂,就餐 because "就餐" in dictionary
# 分词结束
```

但是最大匹配算法有巨大的缺陷，比如逐词切分“南京市长江大桥”，按照如上的切法就会切成

```python
# 南京,市长,江大桥
```

### 代码

```python
wordlib = ["南京","南京市","长江","市长","长江大桥","江大桥","大桥"]

def forward_match(txt): #前相匹配
    result = [] # 存放结果列表
    temp = "" #暂时存放待定匹配的字符串
    for word in txt:
        temp = temp + word
        if temp in wordlib:
            result.append(temp)
            temp = ""
    if temp != "":
        result.append(temp)
    return result

def backward_match(txt): #反向匹配
    result = []
    temp = ""
    for word in txt[::-1]:
        temp = word + temp
        if temp in wordlib:
            result.append(temp)
            temp = ""
    if temp != "":
        result.append(temp)
    result.reverse()
    return result

txt = "南京市长江大桥"
result = [forward_match(txt),backward_match(txt)]
for i in range(len(result)):
    print(result[i])
```

运行结果

```
['南京', '市长', '江大桥']
['南京市', '长江', '大桥']
```

所以如果我们有一个长度为M的词汇表，去切分长度为N的句子，那么最大前向匹配的时间复杂度是`O(NM)`。



## N-gram 算法

### 还是上面那个问题

前向最大匹配存在明显的缺陷。所以我们要从语料处理的角度分析。在通过最大前向匹配算法后，我们可以通过同样的实施反向匹配，得到多组实际上是计算字与字之间连接成词的概率，先通过上面的例子让大家对N-gram有一个感性的认识：

```python
txt = "南京市长江大桥"
# ......
ex1 = ["南京市","长江","大桥"]
ex2 = ["南京","市长","江大桥"]
```

下面就对每一个候选计算概率：
$$
P(ex1)=P(南京|[bos])*P(市|南京)*P(长江|南京市)*P(大桥|南京市长江)\\
P(ex2)=P(南京|[bos])*P(市长|南京)*P(江大桥|南京市长)\qquad\qquad\qquad
$$
最终结果

```python
ans = ex1 if p(ex1) > p(ex2) else ex2
```

### 介绍

> **N-gram模型（又称n元语法、N元模型**）是基于(n - 1)阶**马尔可夫链的一种概率语言模型**。
>
> 可用于定义字符串中的距离，也可用于中文的分词；常用的模型是**Bi-gram**和**Tri-gram**模型。

N-gram假设我们当前的分词只由之前的n-1个词决定，称为n元组：

例如对于句子"Life is short, I choose python"来说，$N=2$时的二元组如下：

- life is
- is short
- short I
- I choose
- choose python

> 则称此时有5个N-gram

$N=3$时的三元组如下：

- life is short
- is short I
- short I choose
- I choose python

> 称此时有4个N-gram

所以如果我们已知N-gram中的$N$，句子有$M$个单词，那么N元模型得到的N-gram数量为$M-N+1$。

### 算法推导

如果我们将一个长度为M的句子进行分词，分成了$result=[w_1,w_2,\cdots,w_m]$那么我们就需要计算这个分词排列的最大值所对应的一组排列。根据概率论中的链式法则，$w_1$到$w_m$组合的联合概率为：
$$
P(w_1,w_2, \cdots,w_m)=P(w_1)*P(w_2|w_1)*P(w_3|w_1,w_2)* \cdots *P(w_m|w_1,w_2, \cdots ,w_{m-1})
$$
熟悉概率图模型的同学应该能看出来，这其实就是一个**马尔可夫链（Markov chain）**。直接计算这个式子的时间复杂度是指数的。我们可以利用N-gram模型，假设当前的分词wi只与之前的N个词有关，那么根据N的取值不同，我们得到了不同的N元模型：

- $N = 1$时，一元模型（Uni-gram）
$$
P(w_1,w_2\dots,w_m)=\prod_{i=1}^{m}P(w_i)\\
$$
- $N = 2$时，二元模型（Bi-gram）

$$
P(w_1,w_2\dots,w_m)=P(w_1)\prod_{i=2}^{m}P(w_i|w_{i-1})\\
$$

- $N = 3$时，三元模型（Tri-gram）

$$
P(w_1,w_2\dots,w_m)=P(w_1)P(w_2|w_1)\prod_{i=3}^{m}P(w_i|w_{i-1},w_{i-2})\\
$$

### 算法描述

 1、将带分词的字符串从左到右切分为$w_1,w_2,\cdots,w_i$

  2、计算当前词与所有前驱词的概率

  3、计算该词的累计概率值，并筛选最大的累计概率则为最好的前驱点；

  4、重复步骤3，直到该字符串结束；

  5、从wi开始，按照从右到左的顺序，依次将没歌词的最佳前驱词输出，即字符串的分词结束。

word_dict = {}# 用于统计词语的频次
transdict = {} # 用于统计该词后面词出现的个数
def train(train_data_path):
    transdict['<BEG>'] = {}#<beg>表示开始的标识
    word_dict['<BEG>'] = 0
    for sent in open(train_data_path,encoding='utf-8'):
        word_dict['<BEG>'] +=1
        sent = sent.strip().split(' ')
        sent_list = []
        for word in sent:
            if word !='':
                sent_list.append(word)
        for i,word in enumerate(sent_list):
            if word not in word_dict:
                word_dict[word] = 1
            else:
                word_dict[word] +=1
            # 统计transdict bi-gram<word1,word2>
            word1,word2 = '',''
            # 如果是句首，则为<beg,word>
            if i == 0:
                word1,word2 = '<BEG>',word
            # 如果是句尾，则为<word,END>
            elif i == len(sent_list)-1:
                word1,word2 = word,'<END>'
            else:
                word1,word2 = word,sent_list[i+1]
            # 统计当前次后接词出现的次数
            if word not in transdict.keys():
                transdict[word1]={}
            if word2 not in transdict[word1]:
                transdict[word1][word2] =1
            else:
                transdict[word1][word2] +=1
    return word_dict,transdict

  

# 最大化概率2-gram分词
import math
word_dict = {}# 统计词频的概率
trans_dict = {}# 当前词后接词的概率
trans_dict_count = {}#记录转移词频
max_wordLength = 0# 词的最大长度
all_freq = 0 # 所有词的词频总和
train_data_path = "D:\workspace\project\\NLPcase\\ngram\\data\\train.txt"
from ngram import ngramTrain
word_dict_count,Trans_dict = ngramTrain.train(train_data_path)
all_freq = sum(word_dict_count)
max_wordLength = max([len(word) for word in word_dict_count.keys()])
for key in word_dict_count:
    word_dict[key] = math.log(word_dict_count[key]/all_freq)
# 计算转移概率
for pre_word,post_info in Trans_dict.items():
    for post_word,count in post_info:
        word_pair = pre_word+' '+post_word
        trans_dict_count[word_pair] = float(count)
        if pre_word in word_dict_count.keys():
            trans_dict[word_pair] = math.log(count/word_dict_count[pre_word])
        else:
            trans_dict[word_pair] = word_dict[post_word]

# 估算未出现词的概率，平滑算法
def get_unk_word_prob(word):
    return math.log(1.0/all_freq**len(word))
# 获取候选词的概率
def get_word_prob(word):
    if word in word_dict:
        prob = word_dict[word]
    else:
        prob = get_unk_word_prob(word)
    return prob
# 获取转移概率
def get_word_trans_prob(pre_word,post_word):
    trans_word = pre_word+" "+post_word
    if trans_word in trans_dict:
        trans_prob = math.log(trans_dict_count[trans_word]/word_dict_count[pre_word])
    else:
        trans_prob = get_word_prob(post_word)
    return trans_prob
# 寻找node的最佳前驱节点，方法为寻找所有可能的前驱片段
def get_best_pre_nodes(sent,node,node_state_list):
    # 如果node比最大词小，则取的片段长度的长度为限
    max_seg_length = min([node,max_wordLength])
    pre_node_list = []# 前驱节点列表

    # 获得所有的前驱片段，并记录累加概率
    for segment_length in range(1,max_seg_length+1):
        segment_start_node = node - segment_length
        segment = sent[segment_start_node:node]# 获取前驱片段
        pre_node = segment_start_node# 记录对应的前驱节点
        if pre_node == 0:
            # 如果前驱片段开始节点是序列的开始节点，则概率为<S>转移到当前的概率
            segment_prob = get_word_trans_prob("<BEG>",segment)
        else:# 如果不是序列的开始节点，则按照二元概率计算
            # 获得前驱片段的一个词
            pre_pre_node = node_state_list[pre_node]["pre_node"]
            pre_pre_word = sent[pre_pre_node:pre_node]
            segment_prob = get_word_trans_prob(pre_pre_word,segment)
        pre_node_prob_sum = node_state_list[pre_node]["prob_sum"]
        # 当前node一个候选的累加概率值
        candidate_prob_sum = pre_node_prob_sum+segment_prob
        pre_node_list.append((pre_node,candidate_prob_sum))
    # 找到最大的候选概率值
    (best_pre_node, best_prob_sum) = max(pre_node_list,key=lambda d:d[1])
    return best_pre_node,best_prob_sum
def cut(sent):
    sent = sent.strip()
    # 初始化
    node_state_list = []#主要是记录节点的最佳前驱，以及概率值总和
    ini_state = {}
    ini_state['pre_node'] = -1
    ini_state['prob_sum'] = 0 #当前概率总和
    node_state_list.append(ini_state)
    # 逐个节点的寻找最佳的前驱点
    for node in range(1,len(sent)+1):
        # 寻找最佳前驱，并记录当前最大的概率累加值
        (best_pre_node,best_prob_sum) = get_best_pre_nodes(sent,node,node_state_list)
        # 添加到队列
        cur_node ={}
        cur_node['pre_node'] = best_pre_node
        cur_node['prob_sum'] = best_prob_sum
        node_state_list.append(cur_node)
    # 获得最优路径，从后到前
    best_path = []
    node = len(sent)
    best_path.append(node)
    while True:
        pre_node = node_state_list[node]['pre_node']
        if pre_node ==-1:
            break
        node = pre_node
        best_path.append(node)
    # 构建词的切分
    word_list = []
    for i in range(len(best_path)-1):
        left = best_path[i]
        right = best_path[i+1]

        word = sent[left:right]
        word_list.append(word)
    return word_list
