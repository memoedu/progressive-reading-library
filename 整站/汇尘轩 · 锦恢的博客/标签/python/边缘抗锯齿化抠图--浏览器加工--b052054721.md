## 解决方法

学过计算机图形学的朋友应该都知道，制作抗锯齿化算法的基本思路就是沿着边缘的法向量做透明度递减，但是在像素级操作中，我们要如何做到这一点呢？其实，非常简单，如果你读过我过去在 APMCM 比赛中的 [赛后笔记](https://zhuanlan.zhihu.com/p/362077331)，就能想到，使用滤波和形态学操作就能等效替代一部分图形学里面的操作。

具体到我们这个抠图问题的边缘抗锯齿化，就非常简单，因为我们拿到了前景区域的 mask，只需要对 mask 先做形态学膨胀，然后通过高斯滤波平滑边缘，然后使用得到的 mask 作为原图像的 alpha 通道，加入色彩通道的第四个通道，然后导出 png 即可，代码如下：

```python
import cv2
import numpy as np
from collections import Counter

mask = cv2.imread('./mask.png')
mask = cv2.cvtColor(mask, cv2.COLOR_RGB2GRAY)
mask_size = max(mask.shape)
dilate_size = max(1, int(mask_size * 0.1))
if dilate_size % 2 == 0:
    dilate_size += 1
mask = cv2.morphologyEx(mask, cv2.MORPH_DILATE, np.ones_like((dilate_size, dilate_size)), iterations=5)
mask = cv2.GaussianBlur(mask, (dilate_size, dilate_size), 10)

origin = cv2.imread('./origin.png')
if len(origin.shape) < 3:
    raise ValueError('enter colorful images!')

h, w, c = origin.shape
if c == 3:
    alpha_layer = np.zeros((h, w), np.uint8)
    origin = np.concatenate([origin, alpha_layer[..., None]], axis=-1)

origin[..., -1] = mask

mask = mask.astype(np.float64)
mask = mask / mask.max()

cv2.imshow('default', origin)
cv2.waitKey(0)

cv2.imwrite('result.png', origin)
```
