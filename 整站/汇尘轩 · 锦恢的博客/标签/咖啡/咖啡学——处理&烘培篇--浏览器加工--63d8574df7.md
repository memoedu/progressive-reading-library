## 前言

咖啡豆从采收到成品会经历若干个阶段：采收、处理、烘培。这几个阶段结束后的结果就是消费者手中的成品咖啡豆了。虽然我们并不需要学会如何进行这三个阶段的作业，但是每个阶段的不同控制参数往往会作为描述标明在成品咖啡豆上面，如果你对咖啡处理的流程不熟悉，可能就无法彻底了解这些参数的意义和不同参数下的咖啡豆口味有何不同。

比如你点开淘宝，准备选购一款咖啡豆，结果看到了如下的参数：

其中水洗日晒是处理阶段的参数，而中深烘培则是烘培中的。通过对这两个过程的学习，你将能够通过这些参数大致了解咖啡豆本身的大致口感和味道。

所以后面的两个section，会简单讲讲这三个步骤中涉及的参数。

## 采收工艺

咖啡豆的采收就不多谈了，虽然也很有讲究，因为越是机械化的采收方式对于咖啡树本身的破坏越大，得到的咖啡豆的成熟纯度越低。

- 大致分为机械采收和人工采收。
- 最好的方式当然就是人工采收了，不过更贵。以中国云南地区为例，21世纪上半叶人工采收价格约为机械采收的两倍多。

但是咖啡豆的采收方式一般不会作为参数表明在烘培好的豆子上面，因此，如果只是想要自己制作咖啡，没有必要完全了解咖啡的采收工艺。

## 处理工艺

采收、筛选后的其实并不只是咖啡豆，还有咖啡果实的外皮和果肉。咖啡果实本身很容易腐坏。因此，在运输之前需要对咖啡进行处理，使得咖啡的含水率降低到12%左右，这样咖啡才不容易腐坏。

传统处理法一共有四种：日晒，水洗，蜜处理，湿刨法。虽然也派生出了很多新的处理法，但是如果只是按照处理外后的咖啡结构（果实哪些部分被去除了），是可以用这四种传统处理法来区分的。
| 处理法名称 | 处理过程 | 口感 |
| :--- | :--- | :--- |
| 日晒 | 日晒就是在浮选后，直接进行晾晒，期间需要进行翻动。日晒后的咖啡果实保留有外果皮、果肉、内果皮。 | 风味上有发酵感、甜感好、酸度低 、重量感高  |
| 蜜处理 | 使用去皮机去除外果皮和部分果肉，让咖啡豆带着果胶进行干燥。 | 十分接近日晒、发酵感弱于日晒，甜感突出、重量感弱于日晒 |
| 水洗 | 使用去皮机去除外果皮和部分果肉，让咖啡豆带着果胶进行发酵池，发酵过程会让咖啡果实褪去果胶，只保留内果皮。打捞上来，冲洗干净，进行干燥。 | 发酵感不明显、植物、新鲜植物花果的香气、口感轻薄、酸质明亮 |
| 湿刨法 | 湿刨法与水洗类似，不同点在于会在含水率降低到40%左右去除内果皮，然后进行干燥。 | 有典型的草本、香料的香气、甜感不错、酸度偏低、苦味偏重、醇厚度重 |

<br>

## 烘培工艺

处理法结束后得到的是咖啡生豆，此时的咖啡豆本身还具有活性，无法直接使用。需要经过烘培中的一系列化学反应（焦糖化反应&梅拉德反应）

养豆期：烘焙是原先致密的结构转变成蓬松的蜂窝状结构，内部附着二氧化碳气体，需要一段让咖啡豆在阴冷干燥的地方静置，排除内部二氧化碳气体，让烟熏感褪去，通常时间为3-10天

### 烘培阶段

在讲解烘培度，也就是你在包装上面看到的”中度烘培“，”深度烘培“，往往和烘培阶段有关系，咖啡的烘培阶段分为如下五个：

- 第一阶段：脱水。咖啡生豆吸收热量，水分受热蒸发
- 第二阶段：转黄。热量吸收到一定程度，咖啡颜色逐渐转黄
- 第三阶段：一爆。持续加热会让咖啡豆中的水蒸气和二氧化碳不断增加，这些气体使咖啡内部压力增强，导致咖啡豆内部结构发生改变，咖啡豆膨胀开来发出噼里啪啦的爆裂声。
- 第四阶段：发展。咖啡豆风味得到发展，并发生一部分的类别上的转变，通常精品咖啡在该阶段就结束了。
- 第五阶段：二爆。咖啡持续吸收热量，体积不断膨胀，直到细胞被撕裂，发出相比一爆而言较为沉闷的噗噗的爆裂声

### 烘培度与特点

| 烘培度 | 结束阶段 | 口感 |
| :-- | :-- | :-- |
| 轻度烘焙 | 一 爆开始至一爆中 | 青草、花香、蔗糖 |
| 肉桂烘焙 | 一爆中段 | 果酸、花香 |
| 中度烘焙 | 一爆末至一爆结束 | 吐司、牛奶、果酸、黄糖 |
| 高度烘焙 | 一爆结束至二爆 | 坚果、焦糖 |
| 城市烘焙 | 二爆起零星 | 焦糖、巧克力 |
| 深城市烘培 | 二爆中之前 | 胡椒、辛辣、黑巧克力 |
| 法式烘焙 | 二爆中段 | 烟灰、丁香、皮革 |
| 意式烘焙 | 油脂稍微渗出之前 | 橡胶、医药品 |

<br>

而以上的8种烘培度又可以从浅到深，两两粗略划分为浅度烘培、中度烘培、中深度烘培、深度烘培。
