## 意图识别的 prompt 模板

一种可行的模板如下

```yaml
Label a users message from a conversation with an intent. Reply ONLY with the name of the intent.

The intent should be one of the following:
- 询问
- bug
- 指令
- 无关

Message: 请问 property.json 如何配置？
Intent: 询问
Message: 我的自动补全无法使用，是不是有bug？
Intent: bug
Message: 帮我上传一下这份数据
Intent: 指令
Message: 为数不多我觉得很好的动漫了
Intent: 无关
Message: M1系列可以跑iPhone和iPad游戏
Intent:
```

这样，LLM 会给出如下的回答：

```
Intent: 无关
```

这样就得到了关于 “M1系列可以跑iPhone和iPad游戏” 这个对话的语义识别。其实也就是一种 few shot 的执行策略。

为了压缩数据量，并且获得更加结构化的返回数据，我们可以把指令编码成数字ID，并在每次回答使用 json 进行标注，这在示例文本特别多的时候非常好用：

```yml
Label a users message from a conversation with an intent. Reply ONLY with the name of the intent.

The intent should be one of the following:
- 0
- 1
- 2
- 3

Message: 请问 property.json 如何配置？
Intent: { id: 0 }
Message: 我的自动补全无法使用，是不是有bug？
Intent: { id: 1 }
Message: 帮我上传一下这份数据
Intent: { id: 2 }
Message: 为数不多我觉得很好的动漫了
Intent: { id: 3 }
Message: M1系列可以跑iPhone和iPad游戏
Intent: { id: <answer here> }
```

可能的返回：

```
Intent: { id: 2 }
```

这样，就算LLM返回多余的文本，我们只需要通过正则表达式匹配第一个 `{}` 就好了，里面的信息就是我们想要的。如果大模型返回的消息中没有我们事先规定好的结构，则重新询问。

## 长上下文的询问

如果预设的数据非常多的情况下，比如上面的 pair 有 1000 条的情况下，把这 1000 条组装成 prompt 扔进大模型里面有点低效。我们可以事先用这些 prompt 创建一个上下文，然后利用一些大模型 API 提供的多轮对话模式进行对话。

这样可以直接规约大模型的输出范式，此处以文心一言的 API 为例，我们可以把上面的对话拆分成 user 和 assistant 这两个 role：

```python
payload = json.dumps({
    "messages": [
        {
            "role": "user",
            "content": "Message: 大佬们，为啥我的digital ide启动之后所有功能都没启动捏？我配置了property文件，然后插件的vivado路经和modelsim路经都加上了\nIntent: "
        },
        {
            "role": "assistant",
            "content": "{ id: 0 }"
        },
        {
            "role": "user",
            "content": "话说digital-ide打开大的verilog卡死了\nIntent: "
        },
        {
            "role": "assistant",
            "content": "{ id: 1 }"
        },
        {
            "role": "user",
            "content": "请问一下，第一次点击对文件仿真可以出波形文件，再次点击的时候就会提示unknown module type了。是哪个配置没配置好？\nIntent: "
        },
    ]
})
```

这样，返回的结果就非常准确了，我测试下来，100%只返回一个 json：

```
{ id: 0 }
```
