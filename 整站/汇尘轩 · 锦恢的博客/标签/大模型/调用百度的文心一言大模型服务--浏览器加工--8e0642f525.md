### 获取令牌 access_token

基本的代码很简单，要先获取 access_token，然后再进行调用：

```python
import requests as r
import json

api_key = 'xxx'
secret_key = 'xxx'

def get_access_token():
    headers = {
        'Content-Type': 'application/json',
        'Accept': 'application/json'
    }

    url = f'https://aip.baidubce.com/oauth/2.0/token?grant_type=client_credentials&client_id={api_key}&client_secret={secret_key}'
    payload = json.dumps("")

    res = r.post(
        url=url,
        data=payload,
        headers=headers
    )

    resJson = res.json()
    access_token = resJson.get('access_token')
    assert isinstance(access_token, str), 'access_token 获取失败，详细信息' + str(resJson)
    return access_token

access_token = get_access_token()
```

这个步骤可以放在程序的初始化阶段，然后每隔一天更换一次即可。



### 单轮对话

目前 `ernie-lite-8k` 和 `ernie_speed` 这两个 id 的模型暂时免费。下面的例子使用 `ernie-lite-8k`，如果需要 `ernie_speed`，自行在 url 中替换即可。

基本调用方式和 openai 的 API 差不多，message 字段一共三个角色：‘user’, ‘assistant’, ‘system’：

 ```python
payload = json.dumps({
    "messages": [
        {
            "role": "user",
            "content": "介绍一下初音未来"
        }
    ]
})

headers = {
    'Content-Type': 'application/json'
}

url = 'https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop/chat/ernie-lite-8k' + access_token
res = r.post(url, headers=headers, data=payload)
resJson = res.json()
print(resJson.get('result'))
 ```

### 多轮对话

多轮对话和早期 openai 的 API 方式一样，需要用户自己保存过去的对话记录，然后送入模型，这个需要你自己维护一个消息队列，这里假设已经搞完了：

```python
payload = json.dumps({
    "messages": [
        {
            "role": "user",
            "content": "介绍一下初音未来"
        },
        {
            "role": "assistant",
            "content": "初音未来（初音ミク/Hatsune Miku）是日本的一个虚拟女性歌手 ..."
        },
        {
            "role": "user",
            "content": "我上一个提的问题是什么"
        }
    ]
})

headers = {
    'Content-Type': 'application/json'
}

url = 'https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop/chat/ernie-lite-8k' + access_token
res = r.post(url, headers=headers, data=payload)

print(res.json()['result'])
```

输出：

```
您上一个提的问题是“介绍一下初音未来”。
```





### 流式对话

所谓流式对话，也就是我们平时使用的 LLM 那样子的对话模式。只需要加一个 stream=True 参数即可。

```python
payload = json.dumps({
    "messages": [
        {
            "role": "user",
            "content": "介绍一下初音未来"
        }
    ],
    "stream": True
})

headers = {
    'Content-Type': 'application/json'
}

url = 'https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop/chat/ernie-lite-8k' + access_token
res = r.post(url, headers=headers, data=payload, stream=True)

for line in res.iter_lines():
    line_text: str = line.decode('UTF-8')
    if line_text.startswith('data:'):
        iter_json = json.loads(line_text.lstrip('data: '))
        print(iter_json['result'].strip())
```

当然，为了应对这种句子断掉的问题，可以自己做一些简单的优化，比如取消分行。一个简单的优化如下：

```python
cache = []

for line in res.iter_lines():
    line_text: str = line.decode('UTF-8')
    if line_text.startswith('data:'):
        iter_json = json.loads(line_text.lstrip('data: '))
        result: str = iter_json['result']
        cache.append(result)
        if result.endswith('。') or result.endswith('.'):
            sentence = ''.join(cache).strip()
            print(sentence)
            cache.clear()

if len(cache) > 0:
    print(''.join(cache).strip())
```
