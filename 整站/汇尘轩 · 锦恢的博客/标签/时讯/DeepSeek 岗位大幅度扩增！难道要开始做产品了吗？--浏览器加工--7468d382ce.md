## 定位的转变：从研究机构到产品公司

在过去，DeepSeek 对自己的定位就是一家量化公司附属的大模型研究机构，专门做各种各样的理论研究和对应的模型验证。而大家能用到的 DeepSeek 模型服务，更多只是这家公司工程师强大工程能力的一种外溢。

但是大家会发现，真正能够影响和改变大家日常生活的，往往不是那些被供奉神坛的科学理论，而是一件又一件实实在在的应用产品。像大家在大模型和智能体领域比较热火的 skill、MCP、[agents.md](http://agents.md) 协议，ptc 等等，越来越多的足以影响生态发展的东西，都已经不再只是论文了，而是一件又一件诸如 claude code，codex 产品它所培养出的市场情绪和用户习惯。

所以 DeepSeek 现在的做法很明显，他们已经开始将自己的定位从一家研究机构转为一家产品公司了。得去做产品，才能让越来越多的普通人用上这些产品，感受到 AI 的力量，从而传递更加广泛的价值观和影响力。甚至从产品的角度去研究改变下一个时代的应用范式，这些相比于做理论研究或许能产生更加广泛的影响，而这也或许是 DeepSeek 更想看到的一个结果。

## 职位构成：deepseek 眼中的 AI 市场

当然，我想另一个被更多人关注的，是这次 DeepSeek 招聘公告上所罗列的职位构成，因为这可不单纯只是一个又一个科技公司的职位。从这些职位的名称与结构设置，你能看出来 DeepSeek 对于目前 AI 和智能体商业和技术认知是什么。首先你能看到，虽然大家都在鼓吹说 AI 能把程序员取代了，但是 DeepSeek 罗列的岗位里面，还是安安稳稳地将正常的前后端与测试岗位列了出来，而不是单纯找一个所谓的 AI 全栈工程师来全权负责这一块的构建，这意味着 DeepSeek 内部的高层是非常清醒的，他们知道现在的 AI Coding 在商业产品的开发这个层级上，能做到什么样一个程度。这一块仍然是需要有专业工程师，才能安稳落地一个商业级产品的。

我想，这份招聘广告本身就是对某些鼓吹程序员无用论的无良营销号自媒体的一记响亮的耳光。

其次，这次最亮眼的莫过于第一个大类里面的两个 Agent 相关的岗位：一个是 Agent harness，另一个是 Agent Infra，很多人对这两个岗位相关的负责内容可能没有一个很清楚的认识，其实这也是这几个月才刚刚提出来并开始被各个厂商践行的。

首先，Agent harness 解决的是 autonomous agent 在结构设计、工具排布等一系列系统性问题上的设计和各类工程问题的解决。这些知识的系统化教程感兴趣的朋友可以关注我的系列博客：[锦恢的 AI Agent 小白教程（一）Agent 的基本概念与分类](https://zhuanlan.zhihu.com/p/1962274523752691074)

> 合集在这里：[汇尘轩 - 锦恢的博客](https://link.zhihu.com/?target=https%3A//kirigaya.cn/blog/collection%3Fname%3D%25E9%2594%25A6%25E6%2581%25A2%25E7%259A%2584%2BAI%2BAgent%2B%25E5%25B0%258F%25E7%2599%25BD%25E6%2595%2599%25E7%25A8%258B)

简单来说，如果 DeepSeek 能将他们自己的 agent harness 做完，那么 DeepSeek 就能立刻产出一个和 Claude Code、Codex 同层级的 coding agent 产品。所以大家可以拭目以待，估计不出半年就能出现。

毕竟如果经常使用deepseek的朋友都知道deepseek官方网站上的这个接入Agent的工具跳转到的是Claude Code 安装。而Claude Code的最新版本已经把deepseek给屏蔽掉了。所以从产品体验的角度来说，这一页文档所代表的内容其实是比较糟糕的。但是deepseek本身在之前对自己的定位并不是一家做产品的公司，所以他们并不需要为此做出任何的交付承诺。

agent infra 这个概念还比较新，这个概念最早听到是字节跳动的小龙虾直播邀请，当时邀请了我，雪碧，硅基流动的杨老师还有另外几位朋友。我们直播完了之后，字节飞书的PM就请我们在杭州夜市吃了顿烧烤。当时杨老师又非常高瞻远瞩的预测的未来agent的几个主要的基建方向。他认为其实主要分两类，一类是做Agent Infra，另一类是做Agent CLI，agent infra 的话其实主要就是agent framework，sandbox这些基础设施，它更加适合作为一家产品或者是科技公司的中台，而不太适合作为一个国内的创业项目，因为投资比较难拉，而且目前因他的价值还没有被业内广泛的认可。Agent CLI 机会可能会更大一点。当然这个就属于题外话了，我们以后再说。

我看到最后还有一栏AI跨界研究人才，这让我不禁想到了硅谷那边不少初创设置的一类新的岗位叫做AI builder，其实这一类人他比较符合很多自媒体和营销号吹的那种未来程序员，也就是一个人负责一个人和AI组合，完成需求分析和MVP的整体构建上线。从而充分发掘AI潜在的落地场景，并且快速的验证小规模的可行性。为大部队的规模产品化指导方向，你可以认为他们是产品航线上的领航员。

怎么说呢？还是非常不错的机会，只可惜我去年就签三方了，我原本还跟朋友打赌说，如果deepseek的打折能够永久，那我立刻去deepseek。看来那次算诳语，我得毁约了 hhh。

当然，如果你对 deepseek 的岗位感兴趣的话，当然是非常欢迎报名的。只是这边锦恢可能需要为你泼盆冷水。毕竟作为全国，哦不，全球顶级的量化机构下辖的公司，他们这次就算把岗位数量翻倍，HC顶多也只有200人不到。这是什么概念呢？你要知道阿里巴巴，腾讯，字节跳动这三家无数毕业生梦寐以求的互联网大厂，其中任何一家每年校招都会至少招成千上万人。而这次 deepseek 给出的HC上限也只是200人不到，而且原文中给的是“尽可能”，那么为了不被成堆的简历淹没，我想deepseek肯定会对这次招聘的学历有着极高的要求，甚至有可能直接卡在C9。要不然就是要求有一定的工作经验。
