## 基本原理

重写 navigator.geolocation.getCurrentPosition 这个函数即可，该函数用于异步获取当前电脑的地理信息，包括经纬度，移动速度等等。我们只需要将第一个回调函数的输入变量自己定义即可。


## 实现代码

我把代码写成了油猴脚本，直接使用即可，[油猴脚本教程](https://kirigaya.cn/blog/article?seq=165)。

```js
// ==UserScript==
// @name         腾讯文档(打卡)响应拦截器
// @namespace    https://kirigaya.cn/home
// @homepage     https://kirigaya.cn/home
// @homepageURL  https://kirigaya.cn/home
// @version      0.0.1
// @description  腾讯文档(打卡)响应拦截器
// @author       锦恢
// @match        https://docs.qq.com/form/page/clock/*
// @icon         https://pic1.zhimg.com/v2-b4251de7d2499e942c7ebf447a90d2eb_xll.jpg?source=32738
// @grant        none
// ==/UserScript==


function recoverConsole() {
    const iframe = document.createElement('iframe');
    iframe.style.display = 'none';
    document.body.appendChild(iframe);
    window.console = iframe.contentWindow.console;
}

(function() {
    'use strict';

    // 恢复标准输入
    recoverConsole();

    navigator.geolocation.getCurrentPosition = (success, error, options) => {
        const latLonString = window.prompt('输入经纬度，用逗号分隔', '22.3193039,114.1693611');
        let [lat, lon] = latLonString.split(',');
        lat = parseFloat(lat);
        lon = parseFloat(lon);
        const pos = {
            timestamp: Date.now(),
            coords: {
                accuracy: 2019,
                altitude: null,
                altitudeAccuracy: null,
                heading: null,
                latitude: lat,
                longitude: lon,
                speed: null
            }
        }
        success(pos);
    }
})();
```

## 使用方法

进入浏览器插件商店，输入 “篡改猴” 并下载，点击新建脚本，然后将其中内容替换为上面的代码，然后 ctrl + S 后退出。

进入腾讯文档，点击定位，会出现一个对话框，输入对应的经纬度即可。
