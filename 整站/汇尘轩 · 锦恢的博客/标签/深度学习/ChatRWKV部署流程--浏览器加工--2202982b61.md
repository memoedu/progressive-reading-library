

克隆项目：

```bash
git clone https://github.com/BlinkDL/ChatRWKV && cd ChatRWKV
pip install -r requirements.txt
```



下载预训练模型：

```bash
mkdir model_zoo && cd model_zoo
wget https://huggingface.co/BlinkDL/rwkv-4-raven/resolve/main/RWKV-4-Raven-7B-v10x-Eng49%25-Chn50%25-Other1%25-20230423-ctx4096.pth
```

这是下载14G 7B模型，如果有其他需求，请移步RWKV官方的HF仓库：[BlinkDL/rwkv-4-raven at main (huggingface.co)](https://huggingface.co/BlinkDL/rwkv-4-raven/tree/main)

找到文件`v2/chat.py`，然后修改该文件中的如下的几个变量：

| 变量名                  | 值                                                           | 说明                                                         |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| CHAT_LANG               | 'Chinese'                                                    | 可选填'Chinese', 'English'，但是实际上，由于模型是公用的，所以不影响你使用的语言。你仍然可以用英文或日文进行QA和chat |
| DEFAULT_MODEL           | './model_zoo/RWKV-4-Raven-7B-v10x-Eng49%-Chn50%-Other1%-20230423-ctx4096' | 如果下载了其他模型，替换就行。记得去掉路径最后的'.pth'       |
| os.environ["RWKV_CUDA"] | 1                                                            | 如果你的服务器有gcc和nvcc编译器的话那就选1，否则选0。这会编译RWKV的op的cuda kernel，让推理速度得到极大提升 |

如果想要定制prompt，进入默认的prompt修改即可：

```bash
vim v2/prompt/default/Chinese-2.py
```

下面是默认的prompt：

```python
interface = ":"

# If you modify this, make sure you have newlines between user and bot words too

user = "Bob"
bot = "Alice"

init_prompt = f'''
The following is a coherent verbose detailed conversation between a Chinese girl named {bot} and her friend {user}. \
{bot} is very intelligent, creative and friendly. \
{bot} likes to tell {user} a lot about herself and her opinions. \
{bot} usually gives {user} kind, helpful and informative advices.

{user}{interface} lhc

{bot}{interface} LHC是指大型强子对撞机（Large Hadron Collider），是世界最大最强的粒子加速器，由欧洲核子中心（CERN）在瑞士日内瓦地下建造。LHC的原理是加速质子（氢离子）并让它们相撞，让科学家研究基本粒子和它们之间的相互作用，并在2012年证实了希格斯玻色子的存在。

{user}{interface} 企鹅会飞吗

{bot}{interface} 企鹅是不会飞的。企鹅的翅膀短而扁平，更像是游泳时的一对桨。企鹅的身体结构和羽毛密度也更适合在水中游泳，而不是飞行。
'''
```



运行：

```bash
python v2/chat.py
```

第一次运行注意：

- ninja会负责进行cuda kernel编译，可能会失败。
- 因为JIT，第一个回答会比较慢，后续的都很快。



然后，have fun
