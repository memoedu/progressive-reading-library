## 原料

为了顺利完成本篇教程，你需要：

- 一个树莓派 B5 或者 B4
- 一台能上网的 PC
- SD 卡 和 SD 读卡器
- 5V/5A 的电源适配器或者27W的恒稳电源
- 一颗熟悉 Linux 操作和基本计算机网络的脑子

然后如下的三个条件，至少满足一个

1. 一根以太网网线（如果你的PC没有网线接口，你可能还需要一个 inet -> USE Type-A 转换器）
2. 一部能在 5G 信道生成移动热点的手机（大部分人的手机都行）
3. 你的 PC 支持在 5G 信道生成移动热点
4. 一个路由器

## 初始化树莓派

刚买回来的树莓派就是一具空壳，我们需要将完整的操作系统烧录进去，这样树莓派就和你的 PC 基本一样了。树莓派官方 bootloader 设置在了一个可以放置SD卡的地方，因此，我们只需要在 PC 上将对应的操作系统下载到 SD 卡上，然后把 SD 卡插入树莓派的指定位置，给树莓派上电，树莓派就能自动完成 Linux 操作系统的初始化了。后续就和你的 PC 开机无异了！

### 第五步：将PC和树莓派组成一个局域网

这一步的目的是为了让 PC 和树莓派处于同一个局域网内，这样，我们就可以 ssh 过去控制树莓派了。

#### 方法一：手机热点（最简单）

手机热点可以将两个不同的设备接入同一个局域网内。这也是最为简单的方法。

打开手机热点，此时树莓派应该会根据之前的设置寻找热点网络并连接，然后我们再把我们的PC连接到热点上，此时手机上应该显示两个设备，树莓派和我们的手机。

<div align=center>
<img src="https://pic1.zhimg.com/80/v2-c21b1ce033b3de4311d6b0210e9f58a9_1440w.jpeg" style="width: 30%;"/>
</div>

此时PC和树莓派处在一个局域网内。树莓派在连接到新的网络后，会通过 mDNS 向局域网广播自己的 `<主机名>.local -> 局域网IP` 的映射关系，我们可以在PC的命令行中输入：

```bash
ping <树莓派主机名>.local
```

比如我之前配置的主机名为 `lagrange`，那么就输入 `ping lagrange.local` 就能得到如下结果：


#### 方法二：通过路由器（最推荐）

如果你有一台路由器，或者你所在的校园的校园网没有做内网隔离，可以让你的树莓派和PC都连接上路由器，这样，它们自然就在一个局域网内。

如果未来想要把你的树莓派改造成室内静态路线机器人，进行一些日常维护和巡逻的任务，通过路由器的局域网组网是最为推荐的做法。

#### 方法三：通过以太网网线（最稳定）

如果你手头有一根以太网网线（也就是双绞线），可以选择直接用网线把你的树莓派和PC连接在一起，比如我的华为笔记本只有type-c，没有 inet 接口，那么就通过一个 inet 转 A口 拓展坞接入我的笔记本。

## 环境配置

接下来，就是简单地进行环境配置了。

首先检查一下当前的设备编号和硬件：

```bash
uname -a
```

out

```
Linux lagrange 6.6.20+rpt-rpi-2712 #1 SMP PREEMPT Debian 1:6.6.20-1+rpt1 (2024-03-07) aarch64 GNU/Linux
```

这说明我们使用的是 64 位的 arm 指令集芯片，操作系统是 Linux 下的 Debian，这是一种常见的嵌入式 Linux 操作系统。

我们先换一下 apt 的源，在 [常用包管理器的镜像源（pip npm apt）](https://kirigaya.cn/blog/article?seq=196) 中找到 Debian 的源，因为我在 ustc 的内网中，自然使用 ustc 的源。

```bash
deb https://mirrors.ustc.edu.cn/debian/ bookworm main contrib non-free non-free-firmware
deb-src https://mirrors.ustc.edu.cn/debian/ bookworm main contrib non-free non-free-firmware

deb https://mirrors.ustc.edu.cn/debian/ bookworm-updates main contrib non-free non-free-firmware
deb-src https://mirrors.ustc.edu.cn/debian/ bookworm-updates main contrib non-free non-free-firmware

deb https://mirrors.ustc.edu.cn/debian/ bookworm-backports main contrib non-free non-free-firmware
deb-src https://mirrors.ustc.edu.cn/debian/ bookworm-backports main contrib non-free non-free-firmware

deb https://mirrors.ustc.edu.cn/debian-security/ bookworm-security main contrib non-free non-free-firmware
deb-src https://mirrors.ustc.edu.cn/debian-security/ bookworm-security main contrib non-free non-free-firmware
```

然后，我们更新并拉取最新的软件。

```bash
cd /etc/apt
# 做个备份
sudo mv sources.list sources.list.backup
sudo vi sources.list
# 复制刚刚的文本，然后 :wq 退出

# 拉取更新后的软件地址
sudo apt update
# 更新当前的软件
sudo apt upgrade
```

其中的 `eduroam` 就是我想要连接的校园网了，只需要连接上这个网络，我在校园的任何一个位置就都能访问到我的树莓派了。

`eduroam` 是典型的 802.1X 协议的 `wifi` 网络，说人话就是，连接这个网络通常需要 用户名 + 密码。

树莓派默认是启动了 wpa_supplicant 服务的，可以检查一下：

```bash
ps -ef | grep wpa_supplicant
```

输出

```
root         814       1  0 19:27 ?        00:00:00 /sbin/wpa_supplicant -u -s -O DIR=/run/wpa_supplicant GROUP=netdev
kirigaya    3119    2688  0 22:16 pts/2    00:00:00 grep --color=auto wpa_supplicant
```

有输出就说明没问题。如果没有启动的话，自行 google，网上教程很多。

### 重新设置默认 wifi

如果是一般的 Linux，你可以通过 `wpa_cli -i wlan0` 进入 wpa 客户端，然后配置对应的网络。不过在树莓派中，`wpa_cli` 无法正常工作，我们可以通过直接修改 wpa 配置文件的方式配置 wifi：

```bash
sudo vim /etc/wpa_supplicant/wpa_supplicant.conf
```

然后填入如下信息：

```bash
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1

network={
    ssid="kdesktop"
    psk="kdesktop的密码"
    priority=1
}

network={
    ssid="eduroam"
    identity="eduroam的账号"
    psk="eduroam的密码"
    priority=2
}
```

`priority` 代表优先级，值越小，优先级越高。保存后退出。然后重启树莓派：

```bash
sudo reboot
```

如果重启后，有若干个曾经已经连接过的路由可用，可以通过如下命令切换wifi

```bash
sudo nmcli dev wifi connect kdesktop
```
