# 教学的连贯与干扰问题

> [原文链接](https://zhuanlan.zhihu.com/p/359061669)

在学习过程中，神经网络连接呈现出[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]和[连贯](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coherence)[2]这两个对立的特征。这两种相互竞争的机制对有效的教育策略产生了深远影响。

[连贯性](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coherence)[2]体现了神经网络中有意义的连接。它的积极作用在于能够构建有意义的、结构完整的、高度[抽象](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Abstract_knowledge)[3]且[稳定](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Stability)[4]的记忆。

[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]则是不同记忆相互竞争以求保留的过程。[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]的积极作用在于促进[泛化](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Generalization)[5]，通过[泛化](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Generalization)[5]，学习[模型](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Model)会[遗忘](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Forgetting)[6]与新输入信息[不一致](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Consistency)[2]的次要成分，从而不断完善自身。

[连贯性](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coherence)[2]使记忆通过增强神经连接而变得更加牢固。而在[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]过程中，旧有记忆可能被新记忆取代或随机遗忘。

**[大规模教育](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Prussian_model_of_education)**[7]**的内在缺陷在于，同一条知识可能对一个孩子有益，却对另一个孩子造成负面影响。**

在[自由学习](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Free_learning)[8]中，[学习内驱力](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Learn_drive)[9]奖励机制引导学习者做出能最大化知识[连贯性](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coherence)[2]的选择。[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]过程在这里被用于知识[泛化](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Generalization)[5]和提高[一致性](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Consistency)[2]。在[自由学习](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Free_learning)[8]中，[连贯性](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coherence)[2]得到最大化，而[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]则成为一种积极的力量。

相比之下，在[强制教学](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coercive_teaching)[10]中，外部力量主导了知识的输入。这放大了[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]的影响。结果导致稳定知识的吸收微乎其微，干扰变得具有破坏性，而知识的连贯性也被削弱。

从神经突触的层面来看，在[自由学习](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Free_learning)[8]中，连贯性促进了有益神经连接的形成，而干扰则消除了不必要的连接。但在[强制学习](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coercive_learning)[10]中，干扰成为主导力量。它可能破坏有益的连接，甚至取代原本应属于有用记忆的连接。

这里用[拼图游戏比喻](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Jigsaw_puzzle_metaphor)[11]来说明连贯性与干扰的相互作用：

在[自由学习](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Free_learning)[8]中，学习者寻找最匹配的拼图块，并因成功构建连贯的拼图而获得奖励。
在[强制教学](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coercive_teaching)[10]中，学习者被迫接受不匹配的拼图块，这些块破坏性地干扰了拼图的整体布局，不仅[挫伤了学习者的积极性](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Why_kids_hate_school)[12]，还使学生无法构建大型且连贯的知识结构。

[自我导向学习](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Self-directed_learning)[13]相较于传统学校教育最显著的优势在于，它能够优化连贯知识的构建。

> 图示说明：记忆连接可以在特定情境下被强化或抑制。根据概念被激活的具体情况，我们可能会产生不同的联想。这是模式识别的一个重要方面，而情境本身就是模式的组成部分。举例来说，在使用英语时，我们希望「狗」这个概念能够激活英文单词 &#34;dog&#34;；而在使用俄语时，则希望激活俄文单词 &#34;собака&#34;。
> 图中展示了概念 A 如何根据情境 1 或情境 2 分别激活概念 B 或 C。概念 B 和 C 应该相互抑制它们因概念 A 引发的自身激活（图中用深蓝色连接表示）。在[强制学习](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Coercive_learning)[10]的环境中，不恰当的情境 C 的激活会持续抑制概念 A 和概念 B 之间联系的形成。
> 例如，如果我们错误地学习到麦哲伦是从葡萄牙而非西班牙开始他的环球航行，那么在相同的情境下（如在课堂上）提到麦哲伦时，这种错误的联系就会被不断强化，即使老师立即给予纠正。解决这个问题的方法是创造新的学习情境，这为建立不受[干扰](https://link.zhihu.com/?target=https%3A//supermemo.guru/wiki/Interference)[1]的新记忆路径提供了机会。
