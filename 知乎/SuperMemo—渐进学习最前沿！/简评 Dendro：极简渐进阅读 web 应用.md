# 简评 Dendro：极简渐进阅读 web 应用

> [原文链接](https://zhuanlan.zhihu.com/p/373005210)

> 本文使用 [Zhihu On VSCode](https://zhuanlan.zhihu.com/p/106057556) 创作并发布
## 前言

好久不见，朋友们！最近忙于把自己的学习环境迁移到 Mac 上，花了不少时间，没有怎么更新。

在倒腾过程中，我也发现，SuperMemo 不能跨平台的缺点无疑会劝退不少同学。而且由于 SuperMemo 的渐进阅读工具集已经发展了 20 多年，功能太多了，对于新手入门非常不友好。

于是乎，我调研了一下有没有简单易上手的渐进阅读软件，还顺便翻译了一下博士所写的[渐进阅读最小定义](https://zhuanlan.zhihu.com/p/372072085)。

在体验了几款自称实现渐进阅读功能的软件后，我找到它——**Dendro**，包含**导入**、**阅读排期**、**摘抄挖空**、**间隔重复**、**知识树**和**优先级**的**跨平台**渐进阅读应用！

接下来我们来预览一下这些功能的界面吧！

## 待办队列

点击主屏幕的 Engage，就能开始学习今天要阅读的摘抄卡片和需要回忆的问答卡片了。

### 摘抄卡片

可用来阅读的卡片，Add Note 就是摘抄，可以生成更小片段的摘抄卡片，Add Task 就是挖空，可以生成问答卡片，书签则是用来标记上一次阅读到文章的位置。

Remove from feed 就是暂停卡片，不再复习，next 就是下一张卡片：

![](https://picx.zhimg.com/v2-3f1ceb75f5909e8348dbe83e42823def_1440w.png)
Image

这个就是挖空的界面：

![](https://pic1.zhimg.com/v2-d74b2ec5dd33c83566e3e3cede9febe6_1440w.png)
Image

### 问答卡片

点击 show answer 显示背面，然后有 bad、ok、good 三个选项可以选择

![](https://pic1.zhimg.com/v2-d6ef875b2ebccf1ca971732ecc37eabc_1440w.png)
Image

点击选项后，会显示间隔天数

![](https://pic2.zhimg.com/v2-ae73610bc336882131022aa23a2e3b21_1440w.png)

另外这些正面和背面都是点击即可修改。

## 知识树

点击右上角三个原点的按钮，就能看的 view tree 的选项，美中不足之处在于只能看每篇文章的知识树，并且不能自己修改。

## 结语

Dendro 实现了渐进阅读的核心功能，并且做了不少简化，非常适合想要体验渐进阅读全流程的朋友。

不过，可能有人会问我，既然如此，为什么还要用 SuperMemo？用 Dendro 不就好了？

嘛。。。你看看 Dendro 的收费吧：

![](https://pica.zhimg.com/v2-c3e2995dc201c1f16c65cb6721f4644a_1440w.png)
Image

SuperMemo18 买断只需要 66 美元，Dendro 一年收费 99 美元。。。

另外，SuperMemo 所有数据都存储在本地，而 Dendro 全部在云上，可以说是两个极端了，不过我认为放本地更安心一些。

最后，SuperMemo 虽然功能庞杂，不少功能使用频率很低，但是这些功能对我这种重度用户来说，不能没有啊 233
