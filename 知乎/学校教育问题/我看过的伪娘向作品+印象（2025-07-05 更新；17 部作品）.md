# 我看过的伪娘向作品+印象（2025-07-05 更新；17 部作品）

> [原文链接](https://zhuanlan.zhihu.com/p/1910648684556826579)

自上次[分享我看过的百合向作品](https://zhuanlan.zhihu.com/p/1088994950)得到热烈反响已经过去了大半年，一些同好似乎对我的口味产生了错误的印象（都怪我天天发百合图，bushi），这次也来分享一批伪娘向的作品。不过这类作品实在过于稀少，所以我就找了点图来填充一下（不要怪我水啊）

前排提醒：

本清单不包含 TS 向作品（比如不当哥、乱马）

本清单不包含 homo 作品（比如女装山脉系列。所以放心，下面都是正常的 BG 向作品，不会把你掰弯的！被男主掰弯的自己面壁思过（雾））

我认为这类作品的主要看点：女装的羞耻感，以及看着男主在暴露身份的边缘游走的刺激感（但没有这种描写也可以，还有其他看点）

另外，由于很多作品是我初高中时期看的，已经快是十年前的事情了，所以印象不会很具体，随便看看就行了。

作品的顺序大概和我看的顺序一致，不用太在意，况且有些我也记不清什么时候看的了。

## 女装皇家教师（小说）

意外地发现是一个轻松的恋爱喜剧作品。我经常要在看小说的时候憋笑，不然家里人会觉得我在看什么怪东西（确实是怪东西）。

我的 GitHub 头像至今为止都没有换过，一直是男主夏洛克。

![](https://pica.zhimg.com/v2-1051061b69120131c5a00f41b6bb366e_1440w.jpg)
懂不懂初恋（划掉）的含金量啊？作者是写出《文学少女》的那位野村大妈（合家欢狂魔）。

比较可惜的是男主的姐姐古琳达的故事没有展开。另外野村大妈真的很喜欢在最后一卷把所有人都配对，很无语。
